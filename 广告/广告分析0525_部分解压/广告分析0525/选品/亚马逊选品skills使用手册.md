## 三、方法①：竞品分析与消费者VOC

### 核心流程

```
竞品评论（差评/中评/问答）
        ↓
提取消费者之声 (VOC)
        ↓
┌──────────┬──────────┬──────────┐
│  痛点     │ 未满足需求 │ 惊喜点    │
└──────┬───┴────┬─────┴────┬─────┘
       ↓         ↓          ↓
  解决痛点    填补空白    放大优势
       ↓         ↓          ↓
      重新定义产品 → 创新
```

**实操要点：**
- 重点看**差评和3星评论**——痛点最集中
- 看**QA区**——消费者主动提出的需求
- 对比多个竞品的共同痛点 → 行业级机会

## 四、方法②⑪：市场容量与利润可行性评估

### 必须量化的核心指标

| 指标类别 | 具体指标 | 判断标准 |
|---------|---------|---------|
| **需求验证** | Google Trends趋势         | 上升/稳定 ✅ 下降 ❌ |
| **市场规模** | 类目月搜索量、Top100月销量 | 长尾链接仍有量 ✅ |
| **竞争难度** | 关键词竞争度、SPR指数      | 适中 ✅ 过高 ❌ |
| **广告成本** | CPC竞价、CPA              | CPA < 售价×15% ✅ |
| **广告占比** | 头部ASIN广告流量占比       | 仍需广告维持 = 有空间 ✅ |
| **利润率** | 毛利率 / 净利率             | 毛利 > 30%，净利 > 15% ✅ |
| **退款率** | 类目平均退款率              | < 5% 优 / 8-12% 需警惕 |
 自然流量+自然订单 利润与CPA

## 六、方法④⑥：新类目节点 + 冷门蓝海

### 新细分类目策略

| 机会类型 | 说明 | 行动 |
|---------|------|------|
| 亚马逊新开小类目 | 大类目中独立出的新节点 | 持续监控类目树变化，第一时间进入 |
| 新兴品类 | 全新产品形态或概念 | 快速验证需求，抢占先发优势 |

### 高门槛蓝海策略

| 壁垒类型 | 示例 | 竞争优势 |
|---------|------|---------|
| **认证壁垒** | FDA、510K、医疗器械认证 | 绝大多数卖家无法进入 |
| **技术壁垒** | 科学/工业/精密仪器类 | 需要专业知识和供应链 |
| **资质壁垒** | 特定行业许可证 | 合规成本高，竞争者少 |

> 🔑 **核心逻辑**：用门槛换护城河，壁垒越高，利润越稳。

## 八、方法⑫：「元素迁移」创新选品法（重点）

### 核心公式

```
  爆款 = [热门赛道] + [高热度情感内核] + [高价值功能]
```


### 三步走战略

#### 第一步：全维解构 (Deconstruction)

将竞品拆解为标准化的标签颗粒：

```
┌─────────────────────────────────────────────────┐
│  基础身份层                                      │
│  ├─ 品类 (Category)                             │
│  ├─ 主题/IP (Theme)                             │
│  └─ 目标用户 (Target User)                      │
├─────────────────────────────────────────────────┤
│  视觉感官层                                      │
│  ├─ 风格 (Style)     ├─ 材质 (Material)         │
│  ├─ 色系 (Color)     └─ 形状 (Shape)            │
├─────────────────────────────────────────────────┤
│  功能价值层                                      │
│  ├─ 硬功能：功率/噪音/触控/LED/发声/动态/定制化    │
│  ├─ 软价值(装饰)：氛围/焦点/主题基石              │
│  └─ 软价值(礼品)：情感表达/纪念时刻/派对交换       │
└─────────────────────────────────────────────────┘
```

#### 第二步：数据验证 (Validation)

用BSR/月销量验证每个标签的市场热度：

| 销量 \ 出现频率 | 高频 | 低频 |
|:---:|:---:|:---:|
| **高销量** | 🟢 **核心积木**（必须有） | 🔵 **蓝海差异点**（机会！） |
| **低销量** | 🟡 过度同质化（避开） | ⚫ 无效元素（忽略） |

#### 第三步：重组创新 (Reconstruction)

```
锁定热门赛道
    ↓
植入高热度情感内核（场景/人群/情绪价值）
    ↓
叠加高价值功能（解决痛点/升级体验）
    ↓
= 高成功率新品
```




---

### 元素迁移实操分析模板

以德国站厨房清洗机 (Waschsauger ) 为例：

```
Step 1: 数据收集
  └─ 核心关键词前台搜索 → 卖家精灵下载竞品数据
     （ASIN/标题/五点/品牌/价格/评分/评论数/BSR/功能/材质/设计）

Step 2: 市场概览
  ├─ 价格分布直方图
  ├─ 评分×评论数柱状图
  ├─ 品牌市场份额饼图
  └─ 高销量产品特征识别

Step 3: 元素深度洞察
  ├─ 设计与美学：标题词云 → 流行元素/颜色/材质/工艺
  ├─ 功能参数：功率/噪音/配件/供电方式等分布统计
  └─ 客户反馈：情感分析 → 痛点提取 → 共词矩阵

Step 4: 元素迁移策略
  ├─ 成功元素提炼（高评分×高评论产品的USP）
  ├─ 创新组合（痛点×缺失功能×跨品类元素融合）
  └─ 趋势预测（明年设计/材质/功能新方向）

Step 5: 产品定义输出
  ├─ 使用场景定义
  ├─ 用户画像构建
  ├─ 关键参数确定
  └─ 差异化卖点锁定
```

## 九、基于流量结构的逆推选品（运营视角补充）

### 三维流量结构分析

| 维度 | 工具 | 核心判断 |
|------|------|---------|
| **关键词流量结构** | SIF + 卖家精灵 + 西柚 | 流量层级梯度、是否存在断层式垄断 |
| **商品销量结构** | 卖家精灵市场分析 | 头/腰/尾销量分布、进入空间 |
| **竞品流量结构** | 卖家精灵 + 西柚反查 | 出单词构成、推广资源需求 |

### 流量垄断快速判断

| 指标 | ✅ 可进入 | ❌ 慎入 |
|------|:---:|:---:|
| TOP1流量占比 | < 5% | 远超5% |
| TOP10流量占比 | < 20% | 远超20% |
| TOP20流量占比 | < 40% | 远超40% |
| 流量递减 | 平缓 | 断崖式 |
| TOP ASIN是否依赖广告 | 是（有空间）| 否（固化）|

```

分析类目关键词 + 目标竞品流量结构
       ↓
判断两个核心问题：
  ① 该类目是否存在结构性的细分切入机会？
  ② 该机会所需的推广资源是否匹配自身能力？
       ↓
结论：做 or 不做
```

> **核心价值**：通过前置的流量结构分析，规避注定推广失败的选品，提高选品成功率和推款成功率。

### 什么是"流量结构"？

**本质 = 搜索需求及出单分布的结构透视**

| 维度 | 内容 | 分析目标 |
|------|------|---------|
| **类目关键词流量结构** | 关键词库的ABA排名/搜索需求分布 | 判断流量层级梯度、是否存在断层 |
| **类目商品销量结构** | 头部/腰部/尾部商品的销量分布 | 判断市场集中度与进入空间 |
| **目标竞品流量结构** | 竞品的搜索+关联、自然+付费流量分布 | 反推推广策略与资源需求 |

## 三、四大分析维度详解

### 📊 维度一：类目关键词流量结构分析

#### 1. 搭建细分品类关键词库

**操作步骤：**

1. **Step 1**：通过BSR榜单，利用SIF插件对目标竞品"加入拓词收集箱"→一键拓词（近30天）→导出数据
2. **Step 2**：复制ASIN进入卖家精灵"拓展流量词"→全部变体拓词（近30天）→导出数据
3. **Step 3**：合并两份数据，用Vlookup将SIF的相关性判定结果匹配到卖家精灵数据中

**关键词库包含的核心指标：**
- 相关性判断
- ABA排名、搜索量（流量层级）
- PPC竞价
- TOP3点击转化份额
- SPR竞争指数
- 词频分析（快速了解属性分类）

**关键词分类标准：**

| 分类 | ABA排名 |
|------|---------|
| 头部词 | TOP 1万以内 |
| 腰部词 | 1万 - 10万 |
| 长尾词 | 10万以上 |

**分析要点：**
- 是否存在断层式流量分级词
- 头部流量词是否被垄断
- 不同属性词的流量与竞争对比（如颜色词brown belt vs black belt，brown有更多细分，可能是切入口）

#### 2. 类目核心关键词深度分析

**以类目代表词为分析对象（如mens belt），重点看：**

**① 流量垄断判断标准：**

| 指标 | 健康（未垄断） | 危险（垄断） |
|------|--------------|-------------|
| TOP1流量占比 | < 5% | 远超5% |
| TOP10流量占比 | < 20% | 远超20% |
| TOP20流量占比 | < 40% | 远超40% |
| 流量递减方式 | 平缓递减 | 断崖式下降 |

**② 流量类型分析：**
- TOP ASIN是否仍需较高**广告流量占比**维持排名 → 说明广告仍有效，还有推广空间
- 反之，若纯自然排名固化 → 广告效果有限，不适合进入

**③ 评论基数门槛：**
- TOP10是否90%过万评论 → 判断进入壁垒
- 是否存在三位数评论的ASIN在头部 → 说明新品有突破可能

**④ 款式+价格带分布分析：**

> 对TOP30/50/100的ASIN做**产品标签分类**（款式、材质、价格段等），制作透视表：

- 统计不同款式的流量分布与数量分布
- 寻找**空白价格段**（如编织带有4.99/8.99/11.99，19.99是否空白？）
- 识别**增长趋势款式**（评论基数不高但排名靠前 = 增长可观）

> ⚠️ **注意**：空白高价段需验证市场接受度，不能盲目认为高价=机会。需综合考虑产品成本、买家实际需求、痛点解决能力。

---

### 📊 维度二：类目商品销量结构分析

**利用卖家精灵"市场分析-销量分布图"**

**两个关键判断：**

| 判断点 | 积极信号 | 消极信号 |
|--------|---------|---------|
| 长尾链接（排名90-100）销量 | 仍有可观销量 → 市场容量大 | 几乎无量 → 市场太小或垄断严重 |
| 排名梯度分布 | 无明显断层，平缓递减 → 后来者易上位 | 断崖式分布 → 头部固化严重 |

**进阶分析（导出Excel）：**
- 统计TOP20商品/品牌/销量分布
- 看头部品牌竞争格局及上新频率
- 看尾部新品的款式分布、上新情况、销售占比
- 可将目标款式建成卖家精灵"产品库"，做细分市场分析

---

### 📊 维度三：目标竞品流量结构分析

**选取3-5个直接竞品，分两类分析：**

| 竞品类型 | 分析重点 |
|---------|---------|
| **头部竞品** | 覆盖多少/哪些流量词、付费流量占比、搜索vs关联占比、重点出单词、**未覆盖的遗漏词** |
| **长尾新品** | 有效主推词（自然排名靠前+有广告排名的词）→ 直接模仿复制 |

**操作步骤：**

1. **Step 1**：卖家精灵关键词反查 → 确定搜索vs关联、自然vs付费的流量分布占比
2. **Step 2**：卖家精灵+西柚双工具反查 → 导出数据综合分析词频、CPC、点击集中度、ABA排名、自然/广告排名
3. **Step 3**：西柚"流量洞察" → 确认头部/腰部/长尾词的数量与流量占比

**横向对比3-5个竞品：**
- 流量词分布差异
- 排名数据表现差异
- 推广难度评估
- 确认被验证有效的流量配比（是否必须拿下头部词？还是腰部词即可？）

## 六、核心总结

> **选品的本质不是找产品，而是找"结构性机会"。**

1. **关键词库** → 了解流量分布特性，判断出单结构（单一头部词 vs 多属性多词根）
2. **核心词分析** → 确定细分款式需求分布、竞争情况、价格带空白，判断是否有推广空间
3. **销量结构** → 快速判断市场容量与进入难度，量化所需推广资源
4. **竞品流量** → 验证推广可行性，获取有效流量词，发现竞品未覆盖的机会词

**一句话总结：先看能不能做（流量结构判断），再看怎么做（竞品推广策略复制），最后看值不值得做（资源匹配度评估）。**

## 五、核心方法论②："元素迁移"创新选品法

### 核心逻辑

> 将市场验证过的成功产品视为"热门积木"的组合。通过**拆解旧爆款，提取高权重元素标签，再像搭乐高一样重新组合**，打造高成功率的新品。

### 三步走战略

#### 第一步：全维解构 (Deconstruction)

建立标准化标签体系，将竞品打散为数据颗粒：

| 层级 | 标签维度 | 示例 |
|------|---------|------|
| **基础身份层** | 品类、主题/IP、目标用户 | 家居装饰 / 圣诞主题 / 年轻女性 |
| **视觉感官层** | 风格、材质、色系、形状 | 极简风 / 金属 / 莫兰迪色 / 圆形 |
| **硬功能层** | 实用功能 | 功率、噪音、触控、LED发光、定制化 |
| **软价值层-装饰** | 装饰场景价值 | 夜间氛围、主题基石、焦点展示 |
| **软价值层-礼品** | 情感社交价值 | 情感表达、纪念时刻、派对交换 |

#### 第二步：数据验证 (Validation)

通过BSR/月销量验证每个标签的市场热度：

| 组合 | 含义 | 策略 |
|------|------|------|

| **低销量 + 低频元素** | 无效元素   | ❌ 不用（无市场验证）  |

**爆款公式：**

```

## 一、产品分析

> **模块目标**：全面评估目标产品（或对标ASIN）的Listing质量、历史表现、运营健康度，判断该产品是否值得参考或对标。

---

### 1.1 Listing概览

**分析内容：**

| 分析项 | 具体内容 | 分析目的 |
|--------|---------|---------|
| **标题** | 标题结构、关键词密度、品牌词位置、核心卖点表达 | 判断文案SEO水平 |
| **五点描述** | 卖点提炼、痛点覆盖、功能/参数/场景描述 | 评估转化说服力 |
| **A+页面** | 是否有A+、图文质量、品牌故事、对比图表 | 判断品牌化程度 |
| **主图/副图** | 主图白底合规性、副图场景/功能/尺寸展示 | 评估视觉转化力 |
| **价格** | 当前售价、是否有Coupon/Deal、历史价格波动 | 定价策略判断 |
| **变体** | 变体数量、类型（颜色/尺寸/套装）、主力变体 | 产品线布局参考 |
| **类目节点** | 大类/小类节点、是否精准归类 | 流量入口分析 |
| **配送方式** | FBA / FBM / SFP | 运营模式判断 |

**实操要点：**
- 快速扫描Listing完整度：标题字符数是否用满、五点是否充分、图片数量是否≥7张
- 是否有视频（Video）—— 视频已成转化率重要影响因子
- 是否有品牌旗舰店（Brand Store）—— 判断品牌化投入

---

### 1.2 产品成绩

**核心数据：**

| 数据项 | 说明 | 判断逻辑 |
|--------|------|---------|
| **当前BSR排名** | 大类排名 + 小类排名 | 当前市场位置定位 |
| **当前月销量(sd)** | 估算月销量 | 量化出单规模 |
| **最佳排名日期** | 历史最高排名及对应销量 | 峰值天花板参考 |
| **BSR排名趋势** | 近7天/1个月/3个月/6个月/1年/全部 | 判断上升or下降趋势 |

**实战案例（如截图所示）：**

```
当前状态：
├─ 大类 Beauty & Personal Care BSR: 91914
├─ 小类 Rotary Shavers BSR: 143
└─ 当日月销量: 125

最佳成绩：
├─ 日期: 2024年8月26日
├─ 大类BSR: 1366 / 小类BSR: 5
└─ 月销量: 4000
```

> **判断**：从BSR 1366跌至91914，峰值月销4000降至125，需警惕该产品可能已进入衰退期或遭遇运营事故。

---

### 1.3 产品关键节点

**分析框架**：追踪产品BSR排名的关键变动节点，还原其运营轨迹。

| 时间节点 | 排名变化 | 可能原因分析 |
|---------|---------|------------|
| **排名大幅上升** | BSR从4648→2963 | 返校季预热 + Prime会员日余波 + 广告加大 |
| **持续上升期** | BSR从2586→1944，小类升至第4 | 加大广告/站内促销，转化强劲(sd=3000) |
| **季节性上升** | BSR从3157→2535 | 万圣节/圣诞购物季来临，礼品属性受益 |
| **大促爆发** | BSR从2073→1529 | 黑五网一促销 + Coupon/价格调整(sd 7000→8000) |
| **断崖式下跌** | BSR从6818→39159，小类从9→65 | ⚠️ 断货/差评爆发/竞对打压(sd 50→1000) |

**关键节点分析的价值：**
- 还原竞品的**运营节奏**（何时加广告、何时做促销）
- 识别**季节性波动**规律
- 发现**运营风险信号**（断崖下跌 = 断货/差评/侵权）
- 为自己的新品规划**上架时间窗口**

---

### 1.4 评论真实性

**分析维度：**

| 检测项 | 方法 | 风险信号 |
|--------|------|---------|
| **评论增长速度** | 对比月销量与月评论增速比 | 评论增速远超正常留评率(1-3%) |
| **评论时间分布** | 是否集中在某几天大量出现 | 短期内集中爆发 = 刷评嫌疑 |
| **评分分布** | 5星/4星/3星/2星/1星占比 | 5星占比>85%且无中差评 = 异常 |
| **VP标记** | Verified Purchase占比 | VP占比过低 = 刷评风险 |
| **评论内容质量** | 是否雷同、是否有真实使用细节 | 模板化评论 = 虚假 |
| **评论者画像** | 是否为高频评论账号 | 同一账号短期内大量评论 = 刷手 |

**判断价值：**
- 评论水分大 → 竞品实际竞争力可能被高估
- 评论真实 → 该竞品的评分和反馈更值得参考

---

### 1.5 库存管理能力

**分析维度：**

| 检测项 | 方法 | 判断 |
|--------|------|------|
| **断货历史** | BSR排名是否有突然消失/暴跌的时段 | 断货 = 供应链弱 |
| **库存深度** | 加购测试法/工具检测当前库存量 | 库存充足 = 运营稳定 |
| **补货频率** | 库存波动周期 | 周期稳定 = 供应链成熟 |
| **断货后恢复速度** | 断货到排名恢复用了多久 | 恢复快 = 有经验 / 慢 = 运营弱 |

**选品意义：**
- 竞品频繁断货 → 我们的**进入窗口**
- 竞品供应链稳定 → 需要更强的差异化

---

### 1.6 产品分析模块总结

```
产品分析 = Listing质量评估 + 销售成绩追踪 + 运营节奏还原 
          + 评论可信度 + 供应链稳定性

核心产出：
├─ 该产品是否值得对标？
├─ 其运营水平如何？（Listing/广告/促销/库存）
├─ 有哪些运营漏洞可以被我们利用？
└─ 其销售成绩的可复制性如何？
```

---

### 2.1 价格销量图

**分析内容：**

| 分析维度 | 具体操作 | 判断 |
|---------|---------|------|
| **价格分布** | 统计类目TOP100产品的价格段分布 | 识别主流价格带和空白价格段 |

```
价格段分布示例：
$5-$10   ████████████ 35%  ← 低价走量区

$20-$30  ████ 12%  ← 品质溢价区
$30+     ██ 8%  ← 高端/空白机会？
```

### 2.2 利润试算

**标准利润计算模型：**

| 项目 | 说明 | 示例 |
|------|------|------|
| **售价** | 目标定价 | $24.99 |
| **-** 采购成本 | 含包装、配件 | -$4.00 |
| **-** 头程运费 | 海运/空运到FBA仓 | -$1.50 |
| **-** FBA费用 | 配送费+仓储费 | -$5.50 |
| **-** 平台佣金 | 通常15% | -$3.75 |
| **-** 广告费用 | 按ACOS 25-35%估算 | -$3.00 |
| **-** 退货成本 | 按类目退货率估算 | -$0.75 |
| **-** 其他费用 | 标签/质检/保险等 | -$0.50 |
| **=** **净利润** | | **$5.99** |
| **=** **净利润率** | | **24.0%** |

**关键利润指标：**

| 指标 | 建议标准 |
|------|---------|
| 毛利率 | > 30% |
| 净利率（含广告） | > 15% |
| 单件净利润 | > $9-15（视品类） |

### 2.3 盈亏平衡

**盈亏平衡分析：**

```
盈亏平衡点 = 固定投入成本 ÷ 单件净利润

固定投入成本包括：
├─ 首批采购成本（MOQ × 单价）
├─ 首批头程运费
├─ 产品摄影/视频制作
├─ 前期广告预算（推新期）
├─ 样品/打样费用
├─ 商标注册/品牌备案
└─ 其他前期投入

示例：
  固定投入 = $5,000
  单件净利 = $5.99
  盈亏平衡 = 835件
  按月销200件计算 → 约4.2个月回本
```

**判断标准：**

| 回本周期 | 评价 |
|---------|------|
| < 3个月 | ✅ 优秀，风险低 |
| 3-6个月 | 🟡 正常，可接受 |
| 6-12个月 | 🟠 较长，需谨慎 |
| > 12个月 | ❌ 风险高，建议重新评估 |

- Google Trends上升 + 亚马逊销量上升 → ✅ 强信号
- Google Trends下降 + 亚马逊销量上升 → 🟡 平台内迁移，需深入分析
- Google Trends下降 + 亚马逊销量下降 → ❌ 市场萎缩

---

### 3.6 关键词搜索趋势

**数据来源：ABA品牌搜索词 / 卖家精灵 / 西柚**

| 分析项 | 说明 |
|--------|------|
| 核心词月搜索量趋势 | 需求是在增长还是萎缩 |
| ABA排名变化 | 搜索需求在整个亚马逊中的排位 |
| 季节性关键词出现时间 | 何时开始布局季节性产品 |
| 长尾词增长情况 | 是否有新的细分需求在涌现 |

### 3.7 关键词竞争

|---------|------|------|
| **SPR（8天推首页预估单量）** | 数值高低 | 推广难度量化 |
| **PPC建议竞价** | CPC金额 | 广告成本预估 |

| **TOP3转化集中度** | 前3名ASIN的转化份额 | 出单是否集中 |

```

### 3.8 垄断分析

**垄断程度判断矩阵：**

| 指标 | ✅ 分散（可进入） | ❌ 垄断（谨慎） |
|------|:---:|:---:|
| TOP1市场份额 | < 10% | > 25% |
| TOP3市场份额 | < 25% | > 50% |
| TOP10市场份额 | < 50% | > 75% |
| 品牌集中度 | 多品牌分散 | 1-2个品牌主导 |
| TOP1流量占比 | < 5% | > 10% |
| 亚马逊自营占比 | 无或很少 | 多个自营链接 |

**垄断类型识别：**

```
品牌垄断 → 1-2个品牌占据绝大部分份额（如Anker在充电宝）
├─ 策略：差异化场景/人群切入，避免正面竞争

ASIN垄断 → 单个链接占据超高份额
├─ 策略：寻找该ASIN的弱点（差评痛点）进行定向改进

价格垄断 → 某个价格段被完全占据
├─ 策略：寻找空白价格带切入

流量垄断 → 核心关键词被头部锁死
├─ 策略：通过长尾词/关联流量迂回进入
```

| **新品平均到达排名** | 新品能到什么位置 | 天花板预估 |
| **新品达到盈亏平衡的时间** | 回本周期 | 资金压力评估 |

**判断标准：**

| 新品成功率 | 评估 |
|-----------|------|
| > 40% | ✅ 市场友好，新品有明确机会 |
| 15-40% | 🟡 需要差异化+运营能力 |
| < 15% | 🟠 竞争激烈，新品存活难 |
| < 5% | ❌ 极度内卷，不建议进入 |

- 利润测算表
- 风险评估报告

---

### 选品方法论（详细）

#### 选品核心原则

```
1. 市场规模
   - 月销量 > 3000单
   - 有持续需求（非季节性过强）
   - 增长趋势向上

2. 竞争程度
   - 头部垄断度 < 50%
   - 新品有上架机会
   - Review数量分布合理

3. 利润空间
   - 售价 - 成本 > 30%
   - FBA费用占比 < 40%
   - 有定价空间

4. 运营难度
   - 无特殊认证要求
   - 包装/运输无特殊限制
   - 侵权风险低
```

#### 选品分析维度

| 维度 | 检查项 | 标准 |
|------|--------|------|
| 销量 | 月均销量、趋势 | 稳定或增长 |
| 价格 | 平均售价、波动 | 稳定在合理区间 |
| Review | 平均数量、星级 | 4.3+为佳 |
| 新品 | 上架数量、表现 | 有新品存活空间 |
| 广告 | CPC、ACOS | 可控范围 |
| 变体 | 变体数量、销量分布 | 不过度集中 |

#### 利润测算公式

```
单品利润 = 售价 - (采购成本 + 头程运费 + FBA费用 + 平台佣金)

毛利率 = (售价 - 成本) / 售价 × 100%

目标：毛利率 ≥ 30%
```
