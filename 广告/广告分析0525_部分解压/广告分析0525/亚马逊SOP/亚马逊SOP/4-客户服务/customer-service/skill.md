# Customer Service Skill

## 用途

客服全流程管理，从问题识别到解决闭环。

## 问题分类

| 类型 | 占比 | 紧急程度 | 处理时效 |
|------|------|---------|---------|
| 订单问题 | 30% | 中 | 24小时 |
| 物流问题 | 25% | 高 | 12小时 |
| 产品问题 | 20% | 中 | 24小时 |
| 退换货 | 15% | 中 | 48小时 |
| 投诉 | 10% | 高 | 4小时 |

## 退款策略

### 退款决策树
```
问题类型 → 严重程度 → 解决方案
     │
     ├─ 轻微问题（包装磨损）→ 部分退款（20-30%）
     │
     ├─ 中等问题（功能正常但不满意）→ 部分退款（30-50%）或退货
     │
     ├─ 严重问题（产品损坏/缺失）→ 全额退款+补发
     │
     └─ 欺诈行为（明显恶意）→ 拒绝退款+证据保留
```

### 部分退款话术
```
We understand your concern and would like to offer a partial refund
of $X (XX% of your purchase price) as a resolution.

This will be processed immediately upon your approval.

Would this be acceptable to you?
```

## A-Z Claim处理

### A-Z Claim类型
| 类型 | 原因 | 胜诉率 |
|------|------|-------|
| 未收到货 | 物流问题 | 高 |
| 描述不符 | 产品问题 | 中 |
| 欺诈 | 恶意订单 | 低 |

### 应对策略
```
1. 及时响应（72小时内）
2. 提供完整证据：
   - 发货记录
   - 物流跟踪
   - 签收证明
   - 产品照片
3. 主动联系客户解决
4. 必要时提交申诉
```

## 差评应对

### 差评分类
| 类型 | 处理方式 |
|------|---------|
| 产品质量差 | 道歉+补发/退款+改进 |
| 物流慢 | 道歉+补偿+跟进物流 |
| 描述不符 | 道歉+退货+改进Listing |
| 服务态度差 | 道歉+升级处理 |
| 恶意差评 | 申诉删除 |

### 差评申诉（Request Removal）
```
可申诉的差评类型：
1. 评价包含淫秽或暴力内容
2. 评价包含卖家个人身份信息
3. 明显是竞争对手的恶意评价
4. 评价与产品无关

申诉路径：
Seller Central > Orders > Manage Orders > Feedback
```

## 使用示例

### 示例1：处理客户投诉
```
用户：客户抱怨产品坏了，要求退款
助手：
1. 确认订单和产品信息
2. 分析问题：
   - 客户反馈：收到时已破损
   - 可能原因：运输损坏/产品质量

3. 解决方案：
   - 先表达歉意
   - 提供补发新品
   - 或全额退款（客户选择）
   - 客户选择全额退款

4. 执行：
   - 同意全额退款$29.99
   - 标记订单为已解决
   - 记录问题用于改进
```

### 示例2：处理差评
```
用户：收到1星差评，说功能不工作
助手：
1. 查看差评内容
2. 判断类型：产品质量问题
3. 站内消息联系客户：
   - 表达歉意
   - 询问具体情况
   - 提供解决方案（换货/退款）
4. 尝试解决后邀请修改评价
5. 如果问题合理，可申请移除
```

## 最佳实践

1. **快速响应** - 4小时内首次回复
2. **态度友好** - 专业且有同理心
3. **解决问题** - 首次解决率>90%
4. **主动沟通** - 问题闭环前多次跟进
5. **记录完整** - 所有沟通留档
6. **数据分析** - 每周问题分析
7. **改进闭环** - 问题反馈产品/采购改进
