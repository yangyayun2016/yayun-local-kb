# Review Generator Skill

## 用途

评价获取和管理，提升产品评分和评价数。

## 评价类型

| 类型 | 来源 | 可靠性 | 获取难度 |
|------|------|-------|---------|
| 自然评价 | 真实购买 | 高 | 难 |
| Vine评价 | 亚马逊Vine | 高 | 中 |
| 投诉求评价 | 卖家请求 | 中 | 中 |
| 站外评价 | 独立站等 | 中 | 难 |

## 评价获取方法

### 1. Request a Review
```
功能位置：卖家后台 > 订单 > 请求评论

发送时间：收到货后4-30天

效果：提升评价率30-50%
```

### 2. 产品插页
```
设计要点：
1. 简洁美观
2. 真诚请求
3. 提供帮助渠道
4. 避免强制要求

话术示例：
"如果您有任何问题，请随时联系我们，
我们将在24小时内回复。如满意，欢迎在
亚马逊留下您的评价，帮助更多买家。"
```

### 3. 邮件跟进
```
发送时间线：
Day 1：发货通知
Day 5：到货提醒
Day 10：请求评价
Day 15：感谢/二次请求（如需要）

注意：频率不要过高
```

### 4. Vine计划
```
适用条件：
- 完成品牌备案
- 新品（90天内上架）
- FBA库存充足

费用：$200-$750（根据索评数量）

流程：
1. 注册Vine计划
2. 发送产品给Vine评论员
3. 等待评论（通常14-30天）
4. 评论显示

优缺点：
✓ 评论可信度高
✓ 初期快速积累评价
✗ 费用高
✗ 可能收到差评
```

## 合规要求

### 禁止行为
```
绝对禁止：
1. 刷单（Fake orders）
2. 购买评价（Paid reviews）
3. 交换评价
4. 要求只给好评
5. 差评返现
6. 使用第三方刷评服务
```

### 合规引导
```
✓ 请求诚实评价（好坏都要）
✓ 引导客户联系客服解决问题
✓ 提供优质产品和服务
✓ 优化Listing减少误解
✓ 使用亚马逊官方Request a Review
```

### 违规处罚
| 违规类型 | 处罚 |
|---------|------|
| 轻微违规 | 警告 |
| 一般违规 | 删除评价、账号降权 |
| 严重违规 | 封号 |

## 差评管理

### 差评监控
```
监控频率：每日
监控渠道：
- 卖家后台订单
- 邮件通知
- 第三方工具预警

发现后立即处理（24小时内）
```

### 差评回复模板
```
主题：Regarding your recent purchase

Dear [Customer],

Thank you for taking the time to share your feedback.
We sincerely apologize that your experience did not meet expectations.

[针对具体问题具体分析]

We would like to make this right:
[具体解决方案]

Please contact us directly at [邮箱] so we can assist you.

Best regards,
[品牌名] Customer Service
```

### 差评申诉（申请移除）
```
可申诉的差评类型：
1. 评论包含卖家个人身份信息
2. 评论包含淫秽或暴力内容
3. 评论与产品无关
4. 明显是竞争对手的恶意评价

申诉路径：
Seller Central > Orders > Feedback > Request Removal
```

### 评价修改引导
```
话术示例：
"We understand your concern and have taken action to
address this issue. If the product still doesn't meet
your expectations, we would be happy to offer a
replacement or full refund.

If you're satisfied now, would you consider updating
your review to reflect your current experience?"
```

## 评价分析

### 分析维度
| 分析项 | 关注点 |
|-------|-------|
| 评分分布 | 1-5星各占比例 |
| 好评关键词 | 客户认可的卖点 |
| 差评关键词 | 需要改进的点 |
| 时间趋势 | 评分是否在改善 |

### 评价情感分析
```
好评通常提到：
- 质量好
- 性价比高
- 物流快
- 包装好

差评通常提到：
- 描述不符
- 质量问题
- 尺寸问题
- 功能缺失

→ 这些信息用于产品改进
```

### 问题统计
| 问题类型 | 出现次数 | 占比 | 改进方向 |
|---------|---------|------|---------|
| 尺寸不符 | 25 | 35% | 更新Listing尺寸描述 |
| 功能异常 | 15 | 21% | 改进产品质量 |
| 物流损坏 | 10 | 14% | 改进包装 |
| 包装简陋 | 8 | 11% | 升级包装 |
| 其他 | 13 | 19% | - |

## 使用示例

### 示例1：新品Vine计划
```
用户：新品刚上架，想用Vine计划
助手：
1. 确认条件：
   - 已品牌备案 ✓
   - FBA库存充足 ✓
   - 90天内上架 ✓

2. 分析风险：
   - Vine评论员评价较严格
   - 可能收到2-3星评价
   - 费用不可退

3. 建议方案：
   - 先做20个Vine产品（如$200）
   - 观察评论情况
   - 再决定是否追加

4. 执行：
   - 注册Vine计划
   - 发送产品给评论员
   - 监控评论并及时回复
```

### 示例2：差评分析和改进
```
用户：这周有3个差评，都说尺寸不符
助手：
1. 分析差评内容：
   - 客户期望：10英寸
   - 产品标注：10英寸
   - 实际测量：9.5英寸（含误差）

2. 确认问题：
   - 产品确实偏小
   - 或客户理解有误

3. 改进措施：
   - 更新Listing尺寸描述（更精确）
   - 在五点中增加尺寸说明
   - 考虑改进产品（如果可能）

4. 客户沟通：
   - 回复现有差评
   - 告知实际尺寸
   - 提供退换货选项
```

## 最佳实践

1. **合规第一** - 严禁任何刷评行为
2. **及时回复** - 差评24小时内回复
3. **产品为本** - 产品质量是评价基础
4. **主动请求** - 用Request a Review
5. **数据分析** - 定期分析评价趋势
6. **改进闭环** - 评价反馈产品改进
7. **竞品监控** - 对比竞品评价
