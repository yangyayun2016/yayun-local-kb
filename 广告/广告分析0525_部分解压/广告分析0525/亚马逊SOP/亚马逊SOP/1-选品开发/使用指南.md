## product-selector (选品分析)

### 使用场景
- 新品类市场分析
- 竞品销量估算
- 利润空间计算
- 风险评估

### 使用示例
```
用户：帮我分析"bike fender"这个品类在美国站的市场

助手会：
1. 查询市场规模和趋势
2. 分析TOP10竞品销量和价格
3. 计算平均利润空间
4. 评估侵权风险
5. 提供选品建议
```

### 输出
- 市场容量分析
- 竞争度评估
- 利润测算表
- 风险评估报告

---

### 选品方法论（详细）

#### 选品核心原则

```
1. 市场规模
   - 月销量 > 3000单
   - 有持续需求（非季节性过强）
   - 增长趋势向上

2. 竞争程度
   - 头部垄断度 < 50%
   - 新品有上架机会
   - Review数量分布合理

3. 利润空间
   - 售价 - 成本 > 30%
   - FBA费用占比 < 40%
   - 有定价空间

4. 运营难度
   - 无特殊认证要求
   - 包装/运输无特殊限制
   - 侵权风险低
```

#### 选品分析维度

| 维度 | 检查项 | 标准 |
|------|--------|------|
| 销量 | 月均销量、趋势 | 稳定或增长 |
| 价格 | 平均售价、波动 | 稳定在合理区间 |
| Review | 平均数量、星级 | 4.3+为佳 |
| 新品 | 上架数量、表现 | 有新品存活空间 |
| 广告 | CPC、ACOS | 可控范围 |
| 变体 | 变体数量、销量分布 | 不过度集中 |

#### 利润测算公式

```
单品利润 = 售价 - (采购成本 + 头程运费 + FBA费用 + 平台佣金)

毛利率 = (售价 - 成本) / 售价 × 100%

目标：毛利率 ≥ 30%
```

## supplier-manager (供应商管理)

### 使用场景
- 找新供应商
- 多家比价
- 供应商绩效考核
- 订单跟踪

### 使用示例
```
用户：帮我找3家以上做自行车配件的工厂

助手会：
1. 在1688/Alibaba搜索
2. 筛选符合条件的供应商
3. 获取报价和交期
4. 生成比价分析表
5. 推荐最优供应商
```

### 使用示例2
```
用户：帮我跟踪订单PO-20240115-001的进度

助手会：
1. 查询供应商订单状态
2. 确认生产进度
3. 跟踪物流状态
4. 预警潜在延误
```

### 供应商筛选要点

**资质要求：**
- 工厂 > 贸易公司（优先）
- 有出口经验
- 能提供样品
- 配合度高

**比价维度：**
| 项目 | 重要性 | 说明 |
|------|--------|------|
| 单价 | 高 | 直接影响利润 |
| MOQ | 中 | 资金周转 |
| 交期 | 高 | 运营节奏 |
| 质量 | 高 | 退货率/差评率 |
| 配合度 | 中 | 响应速度 |

**供应商评估表：**
```
评估维度：
1. 产品质量 (1-10分)
2. 价格竞争力 (1-10分)
3. 交期稳定性 (1-10分)
4. 沟通响应 (1-10分)
5. 问题处理 (1-10分)

综合得分 = 平均分
推荐阈值：≥7.5分
```

## 常见问题

Q: 选品分析需要提供什么信息？
A: 提供品类关键词、目标市场、预算范围即可。

Q: 供应商比价需要多长时间？
A: 一般24小时内可获取3-5家供应商报价。

Q: 如何判断产品是否有侵权风险？
A: 检查：1)  商标词 2)  专利外观 3)  品牌设计

Q: 选品需要看哪些核心数据？
A: 销量、价格、Review、广告数据、竞争度。
