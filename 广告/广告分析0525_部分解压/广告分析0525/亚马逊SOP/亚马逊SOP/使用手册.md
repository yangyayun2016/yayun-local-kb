## Xflow OS 核心理念

### 我们的使命
> **让卓越可复制** — 通过标准化的SOP与实战智慧，帮助每一个品牌拿到结果。

### 核心差异化
| 传统培训 | Xflow OS SOP |
|---------|-------------|
| 卖"藏宝图"（理论） | 卖"全地形越野车"（工具+SOP）+ "专业向导"（专家） |
| 泛泛而谈 | 精确到天、责任到人 |
| 信息差 | 透明化、可执行 |

### 四阶段执行体系
```
T-1 准备期（发货前）    →  市场调研、盈利模型分析、利润测算
   ↓
T-2 预热期（发货后-上架前）→ 视觉开发、文案埋词、关键词库建立
   ↓
T-0 激活期（上架后）    →  划线价设置、属性自检、QA与初级评论布局
   ↓
T+1 爆发期（推广中）    →  站外辅助、关键词上首页、广告透明计划
```

### Solution Kit 输出结构
每个skill输出包含以下三要素：
- **X Flow（流程）**: 交互式Checklist、时间轴控制、责任到人
- **Y Method（方法论）**: 每个环节背后的逻辑与思考
- **Z Resource（资源/工具）**: 直接可用的模板、工具、专家链接

#### 适用场景

- 竞品销量估算
- 利润空间计算
- 风险评估
- 供应商筛选

#### 使用方法
```
1. 提供品类关键词
2. 获取市场规模数据
3. 分析TOP10竞品
4. 计算利润空间
5. 评估风险等级
```

#### 输出示例
- 选品可行性报告
- 竞品分析表
- 利润测算表
- 风险评估表

供应商开发、比价议价、绩效考核、订单跟踪、质量管控。

### 7.2 task-scheduler (任务调度)

#### 用途
定时执行自动化任务，支持Cron表达式、周期任务、任务队列管理。

#### 适用场景
- 每天早上9点下载广告报告
- 每周一生成销售周报
- 每小时检查库存预警
- 每天定时上传新产品

#### Cron表达式示例
```
# 每分钟执行
* * * * *

# 每天上午9点执行
0 9 * * *

# 每周一上午9点执行
0 9 * * 1

# 每月1号上午9点执行
0 9 1 * *

# 工作日每小时执行
0 * * * 1-5
```

### 7.4 listing-generator (Listing生成)

#### 用途
自动生成亚马逊产品标题、五点描述、A+内容、搜索关键词。

#### 适用场景
- 新品上架
- Listing优化
- 多语言版本生成
- 竞品对标分析

#### 标题撰写公式
```
品牌名 + 核心品类词 + 核心卖点 + 材质/颜色 + 尺寸 + 数量
```

#### 标题黄金法则
- 前80字符：核心关键词（移动端可见）
- 80-120字符：次要关键词
- 120-200字符：补充信息

#### 五点描述策略
```
1. 开篇吸引 + 核心卖点
2. 材质/工艺优势
3. 使用场景/便利性
4. 解决的问题
5. 品牌/售后承诺
```

### 7.5 inventory-monitor (库存监控)

#### 用途
实时监控库存状态、预警补货、分析库存周转、减少滞销风险。

#### 核心功能
- 实时库存查询
- 售罄日期预测
- 补货建议计算
- 库存预警通知
- 滞销品识别

#### 预警级别
| 级别 | 售罄天数 | 颜色 | 行动 |
|------|---------|------|------|
| 紧急 | <3天 | 🔴 | 立即补货 |
| 警告 | 3-7天 | 🟡 | 加快补货 |
| 正常 | 7-14天 | 🟢 | 按计划补货 |
| 充足 | >14天 | ⚪ | 暂无需补货 |

### 7.7 advertising-optimizer (广告优化)

#### 用途
优化亚马逊广告策略、调整竞价、分析ACOS、提升ROAS。

#### 广告类型
| 类型 | 展示位置 | 适用场景 |
|------|---------|---------|
| SP（商品广告） | 搜索结果/商品页 | 核心推广 |
| SB（品牌广告） | 搜索结果顶部 | 品牌曝光 |
| SD（展示广告） | 站内/站外展示 | 再营销 |

#### 核心指标
| 指标 | 公式 | 健康标准(成熟期) |
|------|------|----------------|
| ACOS | 广告花费/广告销售额 | <30% |
| ROAS | 广告销售额/广告花费 | >3.3 |
| CTR | 点击次数/展示次数 | >0.6% |
| CVR | 订单数/点击次数 | >10% |

## 八、账号合规模块

### 8.1 account-health-monitor (账号健康)

#### 用途
绩效监控、违规预警、合规检查、申诉处理、账号安全。

#### 绩效指标目标
| 指标 | 目标 | 超标后果 |
|------|------|---------|
| ODR | <1% | 账号冻结 |
| 取消率 | <2.5% | 警告 |
| 迟发率 | <4% | 警告 |
| 有效追踪率 | >95% | 影响流量 |

#### 违规类型
| 违规类型 | 严重程度 | 后果 |
|---------|---------|------|
| 操纵评论 | 严重 | 永久封号 |
| 销售假货 | 严重 | 永久封号 |
| 商标侵权 | 中 | Listing下架 |
| 操纵排名 | 中 | 降权/封号 |
