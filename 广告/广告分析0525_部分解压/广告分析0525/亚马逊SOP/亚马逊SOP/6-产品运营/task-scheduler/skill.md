# Task Scheduler Skill

## 用途

定时执行自动化任务，支持多种调度模式和任务管理。

## 调度类型

### 1. Cron表达式调度
```
# 每分钟执行
* * * * *

# 每天上午9点执行
0 9 * * *

# 每周一上午9点执行
0 9 * * 1

# 每月1号上午9点执行
0 9 1 * *

# 工作日每小时执行
0 * * * 1-5
```

### 2. 间隔调度
```
# 每30分钟执行
*/30 * * * *

# 每2小时执行
0 */2 * * *

# 每15秒执行（测试用）
*/15 * * * * *
```

### 3. 一次性调度
```python
# 指定时间执行
执行时间 = "2024-01-15 09:00:00"
```

### 4. 任务队列
```python
# 顺序执行
任务队列 = [
  "下载广告报告",
  "分析数据",
  "生成报表",
  "发送邮件"
]
```

## 亚马逊运营定时任务示例

### 示例1：每日广告数据监控
```
任务：每天上午10点下载广告报告
Cron: 0 10 * * *
操作：
  1. 登录卖家后台
  2. 进入广告页面
  3. 选择昨天日期范围
  4. 下载报告
  5. 分析ACOS数据
  6. 发送通知
```

### 示例2：库存预警检查
```
任务：每小时检查库存
Cron: 0 * * * *
操作：
  1. 获取当前库存
  2. 计算预计可售天数
  3. 如果<7天，发送预警
  4. 如果<3天，发送紧急预警
```

### 示例3：每周销售报告
```
任务：每周一生成上周销售报告
Cron: 0 9 * * 1
操作：
  1. 下载7天销售数据
  2. 计算各项指标
  3. 生成图表
  4. 生成Word报告
  5. 发送到邮箱
```

## 使用方式

### 方式1：直接调用
```bash
# 创建定时任务
claude-code task-scheduler create --name "daily-report" --cron "0 9 * * *" --command "python generate_report.py"
```

### 方式2：通过Claude Code
```
用户：帮我设置每天早上9点下载广告报告
助手：使用task-scheduler技能创建定时任务：
1. 任务名称：daily-ad-report
2. 执行时间：每天9:00 (Cron: 0 9 * * *)
3. 执行操作：调用browser-automation下载广告报告
4. 完成通知：发送Slack消息
5. 失败重试：3次，间隔5分钟
```

## 任务状态监控

| 状态 | 说明 |
|------|------|
| pending | 等待执行 |
| running | 正在执行 |
| completed | 已完成 |
| failed | 失败 |
| paused | 暂停 |

## 日志查看
```bash
# 查看今天任务日志
task-scheduler logs --today

# 查看任务执行历史
task-scheduler history --task daily-report --days 7

# 实时查看任务执行
task-scheduler logs --follow --task daily-report
```

## 最佳实践

1. **任务解耦** - 每个任务只做一件事
2. **幂等性** - 任务可重复执行，结果一致
3. **设置超时** - 防止任务卡住
4. **日志保留** - 保留至少7天日志
5. **告警机制** - 失败及时通知
6. **资源控制** - 避免同时运行过多任务
