# SOP Generator Skill（Xflow OS核心）

## 用途

根据用户输入的产品信息，生成**完整的亚马逊新品上架Solution Kit**。

这不是"生成Listing文案"，而是生成：
1. **可交互的在线SOP工作台**（带时间倒推、责任人、进度追踪）
2. **每个环节的方法论文档**（为什么、怎么做）
3. **可直接使用的模板和工具**（Excel、Checklist、工具链接）

> **一句话总结**: 不卖"如何做亚马逊"的课程，卖"一套能自动运转、并在关键节点有专家指引的亚马逊赚钱系统"

---

## Solution Kit 结构

### X Flow（流程图）

```
新品上架全流程 - 按T-1/T-2/T-0/T+1组织
│
├── T-1 准备期（发货前）
│   ├── 选品分析 → 盈利模型 → 供应商 → 采购 → 质检 → 发货
│   └── [输出: VC选品利润测算表]
│
├── T-2 预热期（发货后-上架前）
│   ├── 关键词库 → 文案埋词 → 图片/视频 → 品牌故事
│   └── [输出: 关键词库Excel + 图片需求表 + 视频需求表]
│
├── T-0 激活期（上架后）
│   ├── 收录检查 → 划线价 → QA布局 → 评论监控
│   └── [输出: 激活期Checklist]
│
└── T+1 爆发期（推广中）
    ├── Vine计划 → 广告投放 → 透明计划 → 站外辅助
    └── [输出: 推广里程碑表]
```

### Y Method（方法论）

每个环节输出包含：
```
1. 为什么要在这个时间点做？
2. 这个环节的标准是什么？
3. 常见的坑是什么？
4. 如何验收这个环节？
```

### Z Resource（资源/工具）

- Excel模板（关键词库、利润测算表、跟踪表）
- Checklist（产品图片需求、视频需求、激活期自查）
- 工具链接（关键词工具、收录检查工具）
- 专家联系方式（卡点时找谁咨询）

环节2.1: 关键词库搭建
────────────────────
Q: 为什么要这个时间点做？
A: 发货后有10-15天缓冲期，必须在FBA到货前完成所有文案准备

Q: 标准是什么？
A: 至少200个关键词，分为：
   - 核心词（10个）：measuring cups, stainless steel measuring cups
   - 长尾词（50个）：best measuring cups for baking
   - 属性词（140个）：with lid, dishwasher safe

Q: 常见坑是什么？
A: 1. 关键词不够精准  2. 没有分级  3. 忽视小语种

Q: 如何验收？
A: 关键词库包含200+词，每词标注搜索量、竞争度、优先级

环节4.3: 透明计划
────────────────────
Q: 为什么要做透明计划？
A: 防止跟卖 + 获得专属页面 + 提高转化率

Q: 什么时候启动？
A: T-7到T-1之间最佳，利用预售期

Q: 预算怎么分配？
A: 首周预算 = 预期日销 × $0.5，后续根据转化调整

## 使用方法

### 基本使用
```
用户：帮我生成一个新品的完整SOP

助手：请提供以下信息：
1. 产品名称和类目
2. 目标售价和成本
3. 目标市场（站点）
4. 预计发货日期
5. 供应商和品牌
```

### 高级使用
```
用户：用我现有的关键词库Excel生成SOP

助手：好的，我会：
1. 解析你的Excel格式
2. 嵌入到SOP里程碑中
3. 生成配套的图片/视频需求表
4. 生成激活期Checklist
```

## 最佳实践

1. **按时序执行** - 按里程碑时间轴推进，不要跳过任何环节
2. **责任到人** - 每个环节指定负责人，明确截止时间
3. **节点review** - 关键节点（如T+3、T+7、T+14）进行复盘
4. **及时纠偏** - 发现偏差立即调整，不要等到最后
5. **配合工具** - 使用配套的Excel模板和检查工具
