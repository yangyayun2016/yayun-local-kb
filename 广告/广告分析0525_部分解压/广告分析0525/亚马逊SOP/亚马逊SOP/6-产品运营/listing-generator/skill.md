# Listing Generator Skill（Xflow OS SOP版）

## 用途

生成亚马逊Listing的**完整Solution Kit**，包含可交互的流程图、方法论指导、直接可用的资源工具。

> **Xflow OS 理念**: 不卖"怎么写"，而是卖"一套能自动运转的Listing工作台"

## Solution Kit 输出结构

### X Flow（流程）— 交互式SOP工作台

```
阶段T-2: 预热期（发货后-上架前）
├── 环节2.1: 关键词库搭建     [负责人: 运营]  [预计耗时: 3天]
├── 环节2.2: 文案埋词布局     [负责人: 文案]  [预计耗时: 2天]
├── 环节2.3: 产品图片需求表   [负责人: 运营→设计] [预计耗时: 5天]
├── 环节2.4: 产品视频需求表   [负责人: 运营→推广] [预计耗时: 7天]
├── 环节2.5: 关联视频需求     [负责人: 推广]  [预计耗时: 10天]
└── 环节2.6: 品牌故事&旗舰店  [负责人: 品牌]  [预计耗时: 3天]
```

### Y Method（方法论）— 每个环节背后的逻辑

**关键词库搭建方法论**：
```
1. 为什么要这个时间点做？
   → 发货后-上架前有10-15天缓冲期，必须在FBA到货前完成所有文案准备

2. 关键词库标准
   → 种子词库（核心大词）× 高转化词库 × 长尾词库

3. 验收标准
   → 至少200个关键词，分级为A/B/C级
```

### Z Resource（资源/工具）— 直接可用的模板

- 模板1: 关键词库Excel模板（可直接下载）
- 模板2: 产品图片需求表Checklist
- 模板3: 产品视频需求表Checklist
- 工具: 竞品关键词抓取工具
- 工具: 搜索量趋势分析工具

## 标题撰写规范

### 黄金法则
```
品牌名 + 核心关键词 + 核心卖点 + 材质/颜色 + 尺寸 + 数量
```

### 字符分配建议
- 前80字符：核心关键词（移动端可见）
- 80-120字符：次要关键词
- 120-200字符：补充信息

### 正确示例
```
JOYOSO Stainless Steel mixing bowls Set of 3 - Non-slip Bottom,
Dishwasher Safe, Measurement Lines, Shatter Resistant for Kitchen
```

### 错误示例
```
Best Amazing Awesome Fantastic 5-Piece Kitchen Bowls Set - Beautiful
Colors and Great Quality You Will Love!!! (Click to Buy Now!)
```

## 五点描述策略

### 痛点→解决方案结构
```
1. 开篇吸引 + 核心卖点
2. 材质/工艺优势
3. 使用场景/便利性
4. 解决的问题
5. 品牌/售后承诺
```

### 关键词布局
- 每点1-2个核心关键词
- 自然融入，非堆砌
- 大小写正确

## A+内容模块

### 推荐模块组合
1. 品牌故事模块
2. 对比图模块
3. 功能特性模块
4. 产品细节模块
5. 使用场景模块

## 关键词研究

### 来源
- 竞品标题
- 亚马逊搜索下拉框
- 广告报告
- 第三方工具（Helium10、Jungle Scout）
- 客户评论

### 筛选标准
- 相关性（与产品相关）
- 搜索量（有足够搜索）
- 竞争度（适中竞争）
- 转化率（有购买意图）

## 违禁词清单

### 严禁使用的词
- 最（Best、#1、Number 1）
- 便宜（Cheap）
- 保证（Guarantee、Promise）
- 绝对（Absolutely）
- 免费（Free）
- 最好（Better than）

### 特殊符号
- ! ? $ % * 不建议使用
- 全部使用大写字母开头

## 最佳实践

1. **移动端优先** - 优化前80字符
2. **关键词自然** - 避免生硬堆砌
3. **突出差异化** - 与竞品形成对比
4. **持续优化** - 根据广告数据调整
5. **合规第一** - 严格遵守亚马逊规则
6. **多版本测试** - A/B测试不同文案
