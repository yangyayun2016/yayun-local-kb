Here’s the full English translation of your detailed plan for creating a website and software development platform (codename: **wish.new taste.ai**):

---

### **Detailed Plan: Creating a Website and Software Development Platform (Codename: wish.new taste.ai)**

#### 1. **Project Overview**
   - **Platform Name**: wish.new taste.ai (codename)  
   - **Positioning**: A framework for developers and consumers to build projects, helping to break down requirements, generate executable subtasks, and evaluate project resources (time/budget/technical difficulty).  
   - **Core Value**:  
     - Solves the "idea to execution" gap by providing structured thinking.  
     - Uses AI to generate professional documents (e.g., PRD) and task breakdowns.  
     - Offers industry case templates and resource evaluation tools.  

---

#### 2. **Target Audience**  
   - **Primary Users**:  
     1. **Independent Developers/Small Teams**: Lack product managers and need to quickly clarify requirements.  
     2. **Entrepreneurs/Non-Technical Users**: Have ideas but don’t know how to translate them into technology.  
     3. **Product Managers**: Want to standardize PRD and task management processes.  
   - **User Pain Points**:  
     - Vague requirements that are hard to break into actionable tasks.  
     - Lack of expertise in writing professional PRDs.  
     - No clear understanding of project budgets or tech stack choices.  

---

#### 3. **Core Features (Key Features)**  
   - **Feature Module 1: Structured Requirement Input**  
     - Form/chat-based input: Guides users to fill in project goals, audience, scenarios, etc.  
     - Supports uploading vague requirements (text/voice), with AI extracting key details.  
   - **Feature Module 2: AI-Generated PRD**  
     - Generates industry-standard **Product Requirement Documents** (including goals, user personas, feature lists, tech stack recommendations).  
     - Customizable PRD templates (e.g., SaaS/e-commerce/ERP categories).  
   - **Feature Module 3: Task Breakdown (TaskMaster)**  
     - Automatically decomposes PRDs into subtasks (e.g., UI design, API development, testing).  
     - Tasks support priority tagging, dependencies, and time/cost estimates.  
   - **Feature Module 4: Resource Estimation**  
     - Estimates development costs (labor/cloud expenses) based on tech stack and task volume.  
     - Provides technical difficulty ratings (Low/Medium/High) and learning resources.  
   - **Feature Module 5: Case Library & Templates**  
     - Categorized industry examples (e.g., SaaS/CRM/Amazon category templates).  
     - Users can reference PRDs and task lists from similar projects.  

---

#### 4. **Tech Stack**  
   - **Frontend**: React/Vue + TypeScript (responsive design, supports Web/App).  
   - **Backend**: Node.js/Django (handles AI requests and task management logic).  
   - **AI Tools**:  
     - ChatGPT API: For PRD generation and requirement analysis.  
     - Potential fine-tuned models: Optimized for tech stack recommendations and task breakdowns.  
   - **Database**: PostgreSQL/MongoDB (stores user projects and templates).  
   - **Deployment**: AWS/Azure (SaaS support).  

---

#### 5. **PRD Generation Prompt (ChatGPT Expert Mode)**  
   ```markdown
   Role: You are a senior product manager skilled in transforming vague requirements into structured PRDs.  
   Task: Generate a professional **Product Requirement Document** based on user input, including:  
   1. **Project Goal**: 1-2 sentences clearly stating core value.  
   2. **User Personas**: Key user groups and pain points.  
   3. **Feature List**: Modular descriptions with priorities (P0/P1/P2).  
   4. **Tech Stack Suggestions**: Recommendations for frontend/backend/database based on project scale.  
   5. **Non-Functional Requirements**: Security, performance, etc.  
   Requirements: Output in Markdown, use professional terminology, and maintain logical rigor.  
   ```

---

#### 6. **Subtask Breakdown (TaskMaster Example)**  
   - **Example Requirement**: User wants to develop a cross-border e-commerce SaaS tool.  
   - **Breakdown Logic**:  
     1. **Market Research**: Analyze competitors (e.g., Shopify), target country compliance.  
     2. **Core Features**:  
        - Multi-currency payment integration (subtask: Stripe/PayPal API integration).  
        - Product category management (subtask: Design category tree database structure).  
     3. **Tech Selection**: Compare React (frontend) vs. Ruby on Rails (backend).  
     4. **Risk Assessment**: E.g., currency conversion latency issues.  

---

#### 7. **Project Category Reference**  
   - **Supported Categories**:  
     | Category   | Example Template         | Tech Stack Reference      |  
     |------------|--------------------------|---------------------------|  
     | SaaS       | Notion-like tools        | MERN (MongoDB + React)    |  
     | E-commerce | Amazon category management | Java/Spring Boot         |  
     | ERP/CRM    | Odoo/Salesforce          | Python/Django            |  

---

#### 8. **Development Roadmap (MVP First)**  
   - **Phase 1**: Basic requirement input + AI-assisted PRD generation.  
   - **Phase 2**: Task breakdown system + simple resource calculator.  
   - **Phase 3**: Case library integration + team collaboration features.  

---

#### 9. **Risks & Mitigation**  
   - **Risk 1**: AI-generated PRDs lack precision.  
     - **Solution**: Add manual review steps with editable templates.  
   - **Risk 2**: Outdated tech stack recommendations.  
     - **Solution**: Regular database updates + user-customizable tech weights.  

---

### **Next Steps**:  
1. Draft a detailed PRD using the above framework (use ChatGPT for initial draft).  
2. Design an MVP prototype (Figma/Wireframe).  
3. Develop the core requirement input and AI interaction module.
