## 一、核心策略思路

### 🎯 分时精细化运营
| 维度 | 操作要点 |
|------|----------|
| **分时竞价调整** | 根据出单高峰/低峰，动态调整竞价 |
| **分时预算调整** | 出单高峰时段全覆盖，无出单时段不曝光或少曝光 |
| **出单高峰统计** | 分析最近30天每小时出单数据，找出高峰时间点 |

### 🚫 否词策略
| 否词触发条件 | 说明 |
|-------------|------|
| 高点击不出单 | 设置点击次数阈值，超过不出单即否 |
| ACOS超高 | 高点击但ACOS过高 |
| 转化率过低 | 低于设定转化率阈值 |
| CPA过高 | 超过毛利承受范围 |

### 📊 阈值设定体系
| 指标 | 作用 |
|------|------|
| **转化率** | 低于X%关闭 |
| **点击次数** | 大于X次不出单关闭 |
| **CPA** | 大于X元关闭 |
| **毛利率** | 低于X%关闭 |
| **广告 vs 自然订单占比** | 合理安排预算依据 |

## 四、坑位快照分析要点

| 分析维度 | 具体内容 |
|---------|---------|
| **竞品位置** | 每小时竞品在关键词下的自然位、广告位 |
| **断层机会** | 是否有位置空缺可以抢占 |
| **流量大小** | 关键词的流量规模 |
| **曝光位置** | 首页首位为最佳 |
| **曝光时长** | 时长越久越好，波动性越低越好 |
| **ASIN滚动率** | 自然位/广告位的稳定性 |
| **获得率** | 广告位获得曝光的比例 |
| **竞争难度** | 该词的竞争激烈程度 |
| **自然流量份额** | 在该词下的自然流量占比 |

## 五、广告策略核心逻辑

### 🏆 竞争卡位原则（6个"比他强"）
```
1️⃣ 人家在的位置 ──► 我也在
2️⃣ 我要超过他 ──► 排在他前面
3️⃣ 人家没在的时间 ──► 我在
4️⃣ 人家没在的广告位 ──► 我在
5️⃣ 人家没在的自然位 ──► 我在且靠前
6️⃣ 曝光时长 ──► 比他更长
```

### 📈 市场分析维度
```
├── 类目平均转化率
├── 核心关键词广告点击转化率
├── 竞品ASIN转化率
├── 平均CPC
├── 竞争对手排名（广告位+自然位）
└── 综合市场类目情况
```

## 八、预算计算公式模型

```
设定：每天广告预算 → 平均CPC → 可获得点击数
         ↓
点击数 × 转化率 = 广告订单数
         ↓
广告订单 + 自然订单 = 总订单
         ↓
分析广告/自然订单占比 → 反向优化预算分配
```
