# Listing问题处理技能使用指南

## 触发场景

当用户描述以下问题时自动触发：
- "Listing流量突然下降了"
- "产品排名一直掉"
- "Listing被下架了"
- "Buy Box不见了"
- "Listing被篡改了"

## 使用方法

直接描述问题，技能会自动：
1. 识别问题类型
2. 提供诊断分析
3. 给出解决方案
4. 输出执行步骤

## 示例对话

```
用户：我的ASIN B0XXX 最近流量掉了50%，排名从第3页掉到第10页了

助手（使用本技能）：
【Listing问题诊断报告】

问题类型：流量下降
ASIN：B0XXX
问题描述：流量下降50%，排名大幅下滑

诊断分析：
1. 检查广告数据：确认是自然流量还是广告流量下降
2. 检查排名变化：分析关键词排名和类目排名
3. 检查Reviews：近期是否有差评导致转化下降
4. 检查竞品：是否有竞品降价或上新

解决方案：
步骤1：检查广告报表
- 路径：卖家后台 → 广告 → 搜索词报告
- 关注：展示量、点击率、转化率

步骤2：检查自然排名
- 工具：Keepa/Jungle Scout
- 对比：历史排名趋势

步骤3：检查差评情况
- 路径：卖家后台 → 评价
- 关注：近期新增差评

步骤4：优化动作
- 优化广告：增加Bid或新增关键词
- 提升转化：分析差评原因并改进
- 增加流量：参加促销活动

推荐工具：
- Keepa - 追踪排名趋势
- Helium 10 - 关键词分析
- 卖家精灵 - 竞品监控

预防措施：
1. 每日监控排名数据
2. 及时处理差评
3. 保持价格竞争力
4. 定期优化Listing
```

## 问题类型速查

| 问题类型 | 关键词 | 优先处理 |
|---------|--------|---------|
| 流量下降 | 流量、曝光、排名 | 立即处理 |
| 降权 | Buy Box丢失、限制 | 紧急处理 |
| 被篡改 | 被改、图片不见 | 立即处理 |
| 违规下架 | 被下架、违规 | 立即申诉 |
| 变体错误 | 变体问题、合并拆分 | 检查修复 |
