# Product Selector Skill

## 用途

智能选品决策支持，从市场调研到利润测算全流程分析。

## 选品流程

```
市场调研 → 竞品分析 → 利润测算 → 风险评估 → 供应商筛选 → 选品决策
```

## 市场分析

### 市场规模判断
| 指标 | 分析方法 |
|------|---------|
| BSR分布 | 分析BSR 1-100的商品数量和销量 |
| 关键词搜索量 | 使用Jungle Scout/Helium10估算 |
| 新品表现 | 观察新品BSR爬升速度 |

### 市场趋势分析
```
上升期：销量持续增长，适合进入
平稳期：稳定市场，适合差异化
下降期：谨慎进入或清仓
季节性：抓住旺季，避开淡季
```

### 竞争度评估
| 指标 | 低竞争 | 中竞争 | 高竞争 |
|------|-------|-------|-------|
| 头部占比（BSR 1-10） | <30% | 30-50% | >50% |
| 新品数量（月均） | <10 | 10-30 | >30 |
| 平均评分 | <4.3 | 4.3-4.6 | >4.6 |

## 竞品分析

### 头部竞品调研表
| ASIN | 价格 | BSR | 评分 | 评论数 | 月销量估算 | 差异化点 |
|------|------|-----|------|--------|----------|---------|
| B001 | $29.99 | 15 | 4.5 | 2000 | 1500 | 无品牌 |
| B002 | $34.99 | 8 | 4.7 | 5000 | 3000 | A+页面 |

### 差评分析（痛点挖掘）
```
常见差评类型：
1. 质量问题（30%）
2. 尺寸不符（25%）
3. 功能不足（20%）
4. 包装破损（15%）
5. 描述不符（10%）

→ 这些就是我们的改进机会！
```

## 利润测算

### 成本结构表
```
成本项                 金额      占比
─────────────────────────────────────
产品成本              $5.00     16%
头程运费（均摊）       $2.00      6%
FBA费用               $4.50     14%
平台佣金（15%）        $4.50     14%
推广费用（20%）        $6.00     19%
其他费用（仓储等）     $1.50      5%
─────────────────────────────────────
总成本                $23.50     74%
利润                  $8.50      26%
```

### 定价策略
```
毛利率 ≥ 30% 为健康水平
定价 = 成本 / (1 - 目标毛利率 - 平台费率 - 推广费率)

示例：
成本 = $20
目标毛利率 = 35%
平台佣金 = 15%
推广预留 = 15%
────────────
定价 = $20 / (1 - 0.35 - 0.15 - 0.15)
     = $20 / 0.35
     = $57.14
```

## 风险评估

### 侵权风险检查
- 商标查询（USPTO）
- 专利查询（Google Patents）
- 外观专利排查
- 图片版权排查

### 认证要求
| 产品类型 | 可能需要的认证 |
|---------|--------------|
| 电子产品 | FCC、UL |
| 儿童产品 | CPC、CPSIA |
| 食品/化妆品 | FDA |
| 户外用品 | REACH |

### 风险等级
| 风险类型 | 高 | 中 | 低 |
|---------|---|---|---|
| 侵权风险 | 放弃 | 规避 | 接受 |
| 同质化 | 放弃 | 差异化 | 接受 |
| 季节性 | 放弃 | 季节运营 | 接受 |

## 选品决策标准

### 合格选品条件
```
✓ 月搜索量 > 10,000
✓ 头部垄断度 < 50%
✓ 平均评分 < 4.5（有机会）
✓ 毛利率 > 30%
✓ 无明显侵权风险
✓ 有差异化空间
```

### 打分模型
| 维度 | 权重 | 评分标准 |
|------|------|---------|
| 市场规模 | 20% | 大>8, 中5-8, 小<5 |
| 竞争程度 | 20% | 低>8, 中5-8, 高<5 |
| 利润空间 | 25% | >30%>8, 20-30%5-8, <20%<5 |
| 增长趋势 | 15% | 上升>8, 平稳5-8, 下降<5 |
| 差异化空间 | 20% | 容易>8, 中等5-8, 难<5 |

总分 > 60分为可选品

## 使用示例

### 示例1：新品类市场调研
```
用户：帮我分析厨房用品市场的机会
助手：
1. 搜索 "kitchen tool set" 相关品类
2. 找到BSR 1-100的商品
3. 分析：
   - 月市场规模：$500K+
   - 头部垄断度：35%
   - 平均评分：4.4
   - 新品存活率：中等

4. 头部竞品：
   - 产品A：$29.99，BSR#5，4.5星
   - 产品B：$24.99，BSR#12，4.3星（差评多）

5. 差异化机会：
   - 材质升级（从塑料到金属）
   - 包装改进
   - 配件增加

6. 结论：可行，需进一步利润测算
```

### 示例2：利润测算
```
用户：这款产品定价$35，能有多少利润
助手：
1. 成本拆解：
   - 产品成本：$8
   - 头程：$2
   - FBA：$5
   - 佣金（15%）：$5.25
   - 推广预留（20%）：$7
   - 其他：$1.5

2. 总成本：$28.75
3. 利润：$6.25（17.9%）

4. 建议：
   - 当前定价利润偏低
   - 建议提价至$39.99
   - 或寻找供应商降低成本
```
