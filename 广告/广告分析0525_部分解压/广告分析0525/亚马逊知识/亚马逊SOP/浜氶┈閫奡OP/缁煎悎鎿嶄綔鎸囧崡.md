## 一、开店注册

### 1.1 账号类型对比

| 类型 | 个人卖家 | 专业卖家 |
|------|---------|---------|
| 月租费 | 无 | $39.99/月 |
| 可创建Listing | 有限制 | 无限制 |
| 特色权限 | 无 | 有 |
| 适合 | 偶尔销售 | 长期经营 |

### 1.2 开店所需资料

#### 美国站
- **公司资料**
  - 营业执照（扫描件）
  - 法人身份证

- **收款账户**
  - 第三方收款账号（万里汇、派安盈、PingPong等）
  - 或美国银行账户

- **信用卡**
  - 可接收美元的国际信用卡
  - Visa/MasterCard

- **电话**
  - 可接收验证码的手机号

#### 欧洲站（额外要求）
- **VAT税号**
  - 英国、德国、法国、意大利、西班牙等
- **KYC审核资料**
  - 公司章程
  - 银行对账单
  - 法人地址证明

### 1.3 注册流程步骤

```
步骤1：创建卖家账户
    ↓
步骤2：填写公司信息
    ↓
步骤3：填写收款信息
    ↓
步骤4：填写信用卡信息
    ↓
步骤5：填写店铺信息
    ↓
步骤6：进行视频验证（部分情况）
    ↓
步骤7：等待审核通过
```

### 1.4 欧洲站KYC审核要点

**KYC审核所需材料：**

| 材料类型 | 要求 |
|---------|------|
| 营业执照 | 有效期内，加盖公章 |
| 法人身份证 | 正反面，有效期内 |
| 银行对账单 | 3个月内，有银行盖章 |
| 公司章程 | 最新版本，有股东签字 |
| 授权书 | 如非法人操作 |

**审核触发原因：**
- 注册时信息不完整
- 收款账户变更
- 信用卡变更
- 累计销售额达到一定阈值

## 二、账号安全

### 2.1 防关联核心原则

**硬件层面：**
- 独立电脑
- 独立网线/IP
- 独立路由器

**软件层面：**
- 独立浏览器环境
- 独立指纹（UA、Canvas、WebGL等）
- 独立Cookie/LocalStorage

**账号资料：**
- 独立收款账户
- 独立信用卡
- 独立电话号码
- 独立产品图片和文案

### 2.2 关联因素及后果

| 关联要素 | 风险等级 | 后果 |
|---------|---------|------|
| 相同IP | 高 | 强制下线/封号 |
| 相同设备 | 高 | 强制下线/封号 |
| 相同信用卡 | 中 | 审核/警告 |
| 相同收款 | 高 | 封号 |
| 相同产品图片 | 中 | Listing合并/降权 |
| 相同文案 | 低 | 降权 |

### 2.3 账号冻结常见原因

1. **绩效不达标**
   - ODR（订单缺陷率）>1%
   - 迟发率>4%
   - 取消率>2.5%

2. **违规操作**
   - 操纵评论
   - 假货/仿品
   - 侵权（商标/专利）

3. **账号关联**
   - 多账号被检测到关联

### 2.4 申诉流程

**申诉信模板：**

## 三、Listing优化

### 3.1 Listing七要素

```
┌─────────────────────────────────────────────────┐
│              产品标题 (Title)                    │
├─────────────────────────────────────────────────┤
│  主图 (Main Image)                              │
├───────────────┬─────────────────────────────────┤
│  五点描述     │         产品描述 (Description)  │
│  (Bullet      │                                 │
│   Points)     │                                 │
├───────────────┴─────────────────────────────────┤
│  A+页面 (A+ Content)                            │
├─────────────────────────────────────────────────┤
│  价格 (Price) / 变体 (Variations)               │
├─────────────────────────────────────────────────┤
│  评价 (Reviews) / 问答 (QA)                     │
└─────────────────────────────────────────────────┘
```

### 3.2 标题撰写公式

**公式：**
```
品牌名 + 核心品类词 + 核心卖点 + 材质/颜色 + 尺寸 + 数量/单位
```

**示例：**
```
ANJAYLIE Waterproof Phone Pouch for Beach, Swimming -
Transparent Touch Screen Friendly IPX8 Water Resistant Dry Bag
with Adjustable Neck Strap (2 Pack, Blue)
```

**标题优化要点：**
- 前80字符包含核心关键词（移动端可见）
- 避免使用特殊字符（!、*、$等）
- 不使用他人商标词
- 长度控制在150-200字符

### 3.3 图片要求

**主图标准：**
| 要求 | 规格 |
|------|------|
| 背景 | 纯白(RGB 255,255,255) |
| 尺寸 | 至少1000x1000像素 |
| 格式 | JPEG、PNG、GIF |
| 内容 | 产品占画面85%以上 |
| 禁止 | 水印、logo、文字、配件 |

**副图建议：**
1. 产品正面图
2. 使用场景图
3. 尺寸对比图
4. 细节特写图
5. 包装/内容物图
6. 说明书/配件图

### 3.4 五点描述撰写

**结构模板：**

```
1. 核心卖点 + 解决痛点
   [产品名称] helps you [核心功能] without [痛点]

2. 材质/工艺优势
   Made of [材质], featuring [工艺特点]

3. 使用场景
   Perfect for [场景1], [场景2], and [场景3]

4. 功能特性
   Includes [功能1], [功能2], and [功能3]

5. 品牌/售后承诺
   We offer [售后服务] for your peace of mind
```

**五点优化策略：**
- 每条不超过500字符
- 每条2-3个核心卖点
- 包含1-2个相关关键词
- 使用简洁有力的句子
- 避免冗长描述

### 3.5 变体设置

**变体类型：**
| 类型 | 示例 |
|------|------|
| 颜色变体 | Red, Blue, Black |
| 尺寸变体 | S, M, L, XL |
| 数量变体 | 1 pack, 2 pack, 4 pack |
| 材质变体 | Plastic, Metal, Wood |

**变体创建注意事项：**
- 父子变体关系清晰
- 变体主题选择准确
- 各子ASIN信息完整
- 库存数量设置正确

### 3.6 A+页面设计模块

**推荐模块组合：**

| 模块 | 用途 | 位置 |
|------|------|------|
| 品牌故事 | 建立品牌认知 | 模块1-2 |
|  banner图 | 品牌/产品展示 | 间隔使用 |
| 标准对比表 | 突出优势 | 核心位置 |
| 生活方式图 | 场景代入 | 穿插使用 |
| 细节特写 | 品质展示 | 配合文案 |
| 功能特点 | 信息传递 | 重点内容 |

## 四、FBA物流发货

### 4.1 FBA vs FBM对比

| 项目 | FBA | FBM |
|------|-----|-----|
| 物流时效 | 快（Prime） | 较慢 |
| 获得Buy Box | 更容易 | 较难 |
| 成本 | 仓储费+配送费 | 仅物流费 |
| 库存管理 | 亚马逊负责 | 自己负责 |
| 客户服务 | 亚马逊处理 | 自己处理 |
| 适合 | 中大卖家、成熟产品 | 新品、小卖家 |

### 4.2 FBA费用构成

**美国站费用：**

| 费用类型 | 计算方式 |
|---------|---------|
| 配送费 | 按尺寸/重量分段计算 |
| 仓储费 | 每月按立方英尺计算 |
| 长期仓储费 | 超过365天额外收取 |
| 移除费 | 按件计算 |
| 退货处理费 | 按件计算 |

**费用计算示例（小号标准尺寸）：**

```
配送费：$2.5-4/件
月度仓储费：$0.75-2.5/立方英尺/月
```

### 4.3 FBA发货操作流程

**步骤1：创建货件**
```
卖家后台 → 库存 → 管理FBA库存 → 创建货件
```

**步骤2：选择商品**
```
勾选需要发货的SKU → 设置发货数量
```

**步骤3：设置包装**
```
选择包装类型：
- 单件商品
- 原厂包装
- 混合包装
```

**步骤4：填写发货地址**
```
填写实际发货仓库地址
（可使用货代仓库地址）
```

**步骤5：选择目的仓库**
```
亚马逊分配或手动选择
考虑：距离、费用、入库速度
```

**步骤6：打印标签**
```
下载FBA标签（贴在每件商品）
下载外箱标签（贴在外箱）
```

**步骤7：发货至亚马逊**
```
联系货代安排运输
提供物流单号
```

### 4.4 箱规要求

| 项目 | 要求 | 备注 |
|------|------|------|
| 纸箱尺寸 | 单边≤63.5cm | 超过需特殊处理 |
| 单箱重量 | ≤22.5kg（美国） | 超过需贴黄色标签 |
| 承重能力 | 需承受堆叠 | 建议用加厚纸箱 |
| 包装材料 | 填充完整 | 防止运输损坏 |

### 4.5 FBA分仓与合仓

**分仓：**
- 亚马逊自动将货件分配到多个仓库
- 可能增加头程成本

**合仓：**
- 申请将货件合并到同一仓库
- 收取合仓费用

**分仓策略：**
- 销量大的SKU → 分仓测试
- 新品/小批量 → 使用合仓

### 4.6 FBA库存管理

**IPI（库存绩效指标）目标：**
- 维持在400分以上
- 避免仓储限制

**滞销库存处理方式：**
1. 降价促销
2. 站内秒杀
3. 移除库存（创建移除订单）
4. 清理库存（LC）
5. 捐赠

## 五、站内广告

### 5.1 广告类型对比

| 类型 | 全称 | 展示位置 | 适用场景 |
|------|------|---------|---------|
| SP | Sponsored Products | 搜索结果/商品页 | 核心推广 |
| SB | Sponsored Brands | 搜索结果顶部 | 品牌曝光 |
| SD | Sponsored Display | 站内/站外展示 | 再营销 |
| SPV | Sponsored Videos | 搜索结果/商品页 | 视频推广 |

### 5.2 自动广告策略

**投放方式：**
- 自动投放（系统匹配关键词）
- 紧密匹配
- 宽泛匹配
- 同类商品
- 关联商品

**自动广告目的：**
1. 收集搜索词数据
2. 发现高绩效关键词
3. 测试Listing相关性

**优化周期：**
- 每7-14天分析一次
- 添加否定关键词
- 将高绩效词转为手动

### 5.3 手动广告策略

**关键词投放：**
| 匹配方式 | 作用 | 竞价策略 |
|---------|------|---------|
| 精准匹配 | 高相关性 | 较高竞价 |
| 词组匹配 | 中等相关 | 中等竞价 |
| 宽泛匹配 | 低相关性 | 低竞价/关闭 |

**商品投放：**
- 定位ASIN（竞品）
- 定位类目（同行）

### 5.4 广告报表分析

**核心指标：**

| 指标 | 公式 | 健康标准(成熟期) |
|------|------|----------------|
| ACOS | 广告花费÷广告销售额 | <30% |
| ROAS | 广告销售额÷广告花费 | >3.3 |
| CTR | 点击次数÷展示次数 | >0.6% |
| CVR | 订单数÷点击次数 | >10% |
| TACoS | 广告花费÷总销售额 | <15% |

**优化动作：**

| 情况 | 分析 | 动作 |
|------|------|------|
| 高展示、低点击 | 主图/价格/排名问题 | 优化主图/检查价格 |
| 高点击、低转化 | Listing质量问题 | 优化五点/价格 |
| 高ACOS | 竞价过高/关键词不准 | 降低竞价/否定低效词 |
| 低ROAS | 投入产出比低 | 重构广告结构 |

### 5.5 广告否定策略

**需要否定的类型：**
1. 不相关搜索词
2. 低转化高点击词
3. 亏损严重词
4. 品牌词（除非投放品牌广告）

**否定方式：**
- 否定关键词（精确/短语）
- 否定商品（ASIN）

### 6.2 差评处理流程

**Step 1：分析差评类型**
- 产品问题（质量/功能/描述不符）
- 物流问题（延误/损坏/丢失）
- 服务问题（沟通/响应）
- 恶意评价

**Step 2：针对性处理**

| 差评类型 | 处理方式 |
|---------|---------|
| 产品问题 | 退款/补发/改进产品 |
| 物流问题 | 联系物流/补发/补偿 |
| 服务问题 | 道歉/改进服务流程 |
| 恶意评价 | 收集证据/申诉删除 |

**Step 3：联系客户**
- 站内信/邮件联系
- 解决问题
- 引导修改评价

**Step 4：申诉删除（如符合条件）**
- 评价含侮辱性语言
- 评价与产品无关
- 确认是刷单账号

### 6.3 Request a Review功能

**使用方式：**
```
卖家后台 → 订单 → 请求买家评论
```

**最佳使用时间：**
- 签收后4-30天
- 避免周末发送

**限制：**
- 每订单仅可发送一次
- 需在签收后90天内

## 七、跟卖处理

### 7.1 跟卖是什么

**跟卖定义：**
其他卖家在同一个Listing下销售与你相同的产品。

**跟卖影响：**
- 抢走购物车（Buy Box）
- 拉低价格
- 稀释Reviews
- 抢占流量

### 7.2 防跟卖策略

**主动防护：**
1. **品牌备案**
   - 注册商标
   - 完成亚马逊品牌备案
   - 使用Brand Registry功能

2. **透明计划（Transparency）**
   - 每件产品贴透明计划码
   - 可防止假冒产品

3. **独家计划（Exclusives）**
   - 只在亚马逊销售
   - 获得专属标识

4. **产品差异化**
   - 独特包装
   - 定制配件
   - 组合销售

### 7.3 赶跟卖方法

**方法1：品牌投诉**
```
路径：亚马逊品牌注册 → 违规举报
类型：商标侵权
提供：品牌授权书、ASIN截图
```

**方法2：测试购买**
```
1. 用小号购买跟卖产品
2. 收到货后检查
3. 如果是假货/描述不符
4. 投诉假冒商品
```

**方法3：发送警告信**
```
Subject: Cease and Desist - [Brand] Trademark Infringement

Dear [Seller],

We are the authorized brand owner of [Brand Name].

Your listing for ASIN [ASIN] is using our trademark without authorization.
This constitutes trademark infringement.

Please remove your listing within 24 hours.
Otherwise, we will take further legal action.

Best regards,
[Brand Owner]
```

**方法4：联系亚马逊**
```
通过Seller Performance Team
或
通过Report a Violation页面
```

### 7.4 被跟卖应对流程

```
发现被跟卖
    ↓
确认对方是否跟卖（同产品）
    ↓
检查自己是否完成品牌备案
    ↓
有品牌 → 品牌投诉/警告信
    ↓
无品牌 → 测试购买/假冒投诉
    ↓
持续跟卖 → 加入透明计划/独家计划
```

| Deal网站 | 促销 | 中 | 低 |

### 8.2 Deal网站推广

**主流Deal网站：**
| 站点 | 地区 | 特点 |
|------|------|------|
| Slickdeals | 美国 | 人气最高、审核严 |
| Dealnews | 美国 | 门槛低 |
| HotUKDeals | 英国 | 英国最大 |

**发帖要求：**
- 折扣力度大（20%+ off）
- 评分高（4星以上）

### 8.4 站外引流效果评估

**核心指标：**

| 指标 | 含义 | 计算方式 |
|------|------|---------|
| 转化率 | 购买占比 | 订单数÷点击数×100% |
| ROAS | 广告回报率 | 销售额÷广告花费 |
| 跳出率 | 跳出比例 | 跳出数÷总访问数 |
| 订单周期 | 转化时间 | 下单时间-引流时间 |

**评估方法：**
1. 使用带参链接（UTM参数）
2. 跟踪流量来源
3. 对比站内数据
4. 计算真实ROI

## 附录B：常见问题FAQ

### Q1：新品上架多久可以打广告？
A：建议上架完成、Listing优化好后立即开启广告。

### Q2：广告预算多少合适？
A：新品建议日预算$20-50，根据ACOS和转化情况调整。

### Q3：新品没有评论怎么办？
A：使用Vine计划，或通过Request a Review功能索评。

### Q4：ACOS太高怎么处理？
A：降低竞价、优化关键词、优化Listing、排查无效流量。

### Q5：如何提高关键词排名？
A：提高销量、优化Listing质量、增加Reviews、使用广告推广。

### Q6：库存IPI分数低怎么办？
A：清理滞销库存、提高售出率、避免积压。

### Q7：收到小红旗怎么办？
A：分析原因、解决问题、及时申诉、预防再次发生。
