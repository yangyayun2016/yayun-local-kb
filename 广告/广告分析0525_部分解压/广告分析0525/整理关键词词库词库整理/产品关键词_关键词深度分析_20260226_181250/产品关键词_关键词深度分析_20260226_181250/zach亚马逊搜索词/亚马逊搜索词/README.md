# 亚马逊搜索词报告分析器 · Skill 分享包

本文件夹为 **亚马逊搜索词报告分析器** 的脱敏分享版，可用于在 **Coze**（扣子）等平台创建团队使用的分析机器人。

---

## 文件说明

| 文件 | 用途 |
|------|------|
| **亚马逊搜索词报告分析器_Coze提示词.md** | 主提示词：复制到 Coze 机器人的「人设/系统指令」或「开场白」中，作为分析逻辑与输出规范 |
| **关键词分类逻辑说明.md** | 8 种关键词分类的判定标准与决策树，可供 AI 或人工参考 |
| **01_字段说明文档.md** | Brand Analytics 报告字段说明，便于理解数据含义 |
| **Coze配置说明.md** | 在 Coze 中创建该技能机器人的简要步骤 |

---

## 在 Coze 中使用

1. 新建一个 **知识库** 或 **对话型机器人**。
2. 将 **亚马逊搜索词报告分析器_Coze提示词.md** 的全文放入机器人的 **系统提示词 / 人设**。
3. （可选）将 **关键词分类逻辑说明.md**、**01_字段说明文档.md** 上传为知识库文档，并让机器人在回答时引用。
4. 用户使用方式：上传 Brand Analytics 搜索词报告 CSV，或粘贴报告内容/关键表格，让机器人按 7 维度分析并输出建议。

---

## 数据与隐私

- 本包已脱敏：无内部项目路径、无具体品牌/账号信息、无 Cursor/Claude 专用指令。
- 分析逻辑与输出格式与原 Skill 一致，可直接用于团队协作。

---

## 依赖说明

- **数据来源**：亚马逊 Seller Central → Brand Analytics → Search Query Performance（搜索查询表现）报告，需品牌备案。
- **报告格式**：CSV，UTF-8 编码，需包含搜索频率排名、搜索词、点击量最高的品牌/类别/商品 #1–#3、报告日期等字段（详见 01_字段说明文档.md）。
