# 📘 Skill 2：广告位和自然位的稳定性分析

## 2.1 稳定性为什么重要

```
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  📊 稳定性 = 曝光时长 = SIF的核心因子                           │
│                                                              │
│  ┌──────────────────────────────────────────────────┐        │
│  │                                                  │        │
│  │  排名稳定 → 曝光时长长 → SIF高 → 自然流量多        │        │
│  │  排名波动 → 曝光时长短 → SIF低 → 自然流量少        │        │
│  │                                                  │        │
│  │  ════════════════════════════════════              │        │
│  │                                                  │        │
│  │  📐 从ECPM方差角度理解：                           │        │
│  │                                                  │        │
│  │  排名稳定 = CTR/CVR方差小                         │        │
│  │  → max = 期望 - r×方差(小)                        │        │
│  │  → 综合评分高 → 系统给你持续的好排名                │        │
│  │                                                  │        │
│  │  排名波动 = CTR/CVR方差大                         │        │
│  │  → max = 期望 - r×方差(大)                        │        │
│  │  → 综合评分低 → 系统不信任你，排名忽上忽下          │        │
│  │                                                  │        │
│  └──────────────────────────────────────────────────┘        │
│                                                              │
└──────────────────────────────────────────────────────────────┘

│  │  → 自然单占比在上升 = 良性                        │        │
│  │  → 自然单占比停滞或下降 = 需要排查                 │        │

>
> 广告与自然的平衡是亚马逊运营**最难但最有价值**的技能：
>

> 2. **重视稳定性** — 稳定的排名 >> 偶尔冲高的排名（因为曝光时长）
> 3. **定性+定量分析CVR** — 对比类目/竞品/自身历史，三层穿透
> 4. **杠杆策略匹配阶段** — 冲刺期用提高降低，稳定期用仅降低/固定
> 5. **都在前5的决策** — 看价格、销量敏感度、类目、CVR、战略目标五维判断
> 6. **动态平衡方法** — "试探10%-观察3天-数据验证-决策调整"循环
> 7. **每天都在变** — 平衡点不是一成不变的，需要持续校准
>
> **掌握这项平衡术 = 掌握亚马逊运营的"核心艺术"** 🎨

> **💡 终极总结**：
>
> SB/SBV广告最容易被误解和误用：
>
> 1. **不要指望SB/SBV拉关键词排名** — 这是SP的任务
> 2. **不要指望SB/SBV做新品收录** — 这靠Listing埋词和SP自动广告
> 3. **SB/SBV的真正价值** — 品牌曝光、品牌收录、整体链接权重和转化率提升
> 4. **评估方式完全不同** — 不看关键词ACoS，看品牌搜索量和整体数据
> 5. **使用时机有讲究** — 前期以SP为主导，中后期逐步加入SB/SBV
> 6. **三者协同才是最优** — SP攻城拔寨 + SB制空权 + SBV特种打击
>

# 📘 Skill 1：ASIN自然位滚动率 — 理解关键词的竞争动态

## 1.1 什么是自然位滚动率

```
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  📐 ASIN自然位滚动率 的定义                                    │
│                                                              │
│  ┌──────────────────────────────────────────────────┐        │
│  │                                                  │        │
│  │  定义：                                          │        │
│  │  根据某关键词下的自然位数量和自然位ASIN数量         │        │
│  │  等数据综合计算得出的指标                          │        │
│  │                                                  │        │
│  │  本质含义：                                       │        │
│  │  该关键词下，自然排名位置中ASIN的"更替速度"         │        │
│  │  = 首页的ASIN是否经常在变？还是长期稳定不变？       │        │
│  │                                                  │        │
│  │  ════════════════════════════════════              │        │
│  │                                                  │        │
│  │  📐 计算要素：                                     │        │
│  │                                                  │        │
│  │  ① 自然位数量                                     │        │
│  │  └→ 该关键词搜索结果中有多少个自然排名位置           │        │
│  │  └→ 去掉广告位后，剩下的纯自然位有多少个            │        │
│  │                                                  │        │
│  │  ② 自然位ASIN数量                                 │        │
│  │  └→ 在一定时间周期内                               │        │
│  │     出现在这些自然位上的不同ASIN有多少个             │        │
│  │                                                  │        │
│  │  ③ 滚动率 = ASIN变化频率                           │        │
│  │  └→ 如果自然位有20个，但不同ASIN有80个出现过        │        │
│  │     → 滚动率高 = 位置在频繁更替                    │        │
│  │  └→ 如果自然位有20个，不同ASIN只有22个              │        │
│  │     → 滚动率低 = 位置非常稳固                      │        │
│  │                                                  │        │
│  └──────────────────────────────────────────────────┘        │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 2.2 SIF加权因子详解

```
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  📐 SIF的三大加权因子                                          │
│                                                              │
│  SIF = 自然关键词流量 × a + 曝光时长 × b + 位置前后 × c        │
│                                                              │
│  ┌──────────────────────────────────────────────────┐        │
│  │                                                  │        │
│  │  加权因子①：自然关键词流量 × 常量a                  │        │
│  │  ┌──────────────────────────────────────┐        │        │
│  │  │ 含义：该关键词的搜索量大小               │        │        │
│  │  │ 权重逻辑：                              │        │        │
│  │  │ • 搜索量越大 → 流量池越大                │        │        │
│  │  │ • 即使你位置一般，大词的绝对流量也可观     │        │        │
│  │  │ • 常量a决定了搜索量在SIF中的权重          │        │        │
│  │  │                                      │        │        │
│  │  │ 💡 你不能改变搜索量                     │        │        │
│  │  │ 但你可以选择搜索量大的词来投放            │        │        │
│  │  └──────────────────────────────────────┘        │        │
│  │                                                  │        │
│  │  加权因子②：曝光时长 × 常量b                       │        │
│  │  ┌──────────────────────────────────────┐        │        │
│  │  │ 含义：你在某个位置上待了多长时间           │        │        │
│  │  │ 权重逻辑：                              │        │        │
│  │  │ • 24小时中在首位待了22小时 vs 6小时       │        │        │
│  │  │ • 同样位置，时长差异导致流量差异巨大       │        │        │
│  │  │ • 常量b决定了时长在SIF中的权重            │        │        │
│  │  │                                      │        │        │
│  │  │ 💡 曝光时长是你最能影响的因子              │        │        │
│  │  │ 通过稳定出单+合理广告预算来延长           │        │        │
│  │  └──────────────────────────────────────┘        │        │
│  │                                                  │        │
│  │  加权因子③：位置前后 × 常量c                       │        │
│  │  ┌──────────────────────────────────────┐        │        │
│  │  │ 含义：你在搜索结果中的排名位置            │        │        │
│  │  │ 权重逻辑：                              │        │        │
│  │  │ • #1位的CTR >> #10位 >> #20位          │        │        │
│  │  │ • 位置越靠前 → 点击概率越高              │        │        │
│  │  │ • 位置的权重非线性递减                   │        │        │
│  │  │ • 常量c决定了位置在SIF中的权重            │        │        │
│  │  │                                      │        │        │
│  │  │ 💡 位置通过提升ECPM来改善                │        │        │
│  │  │ 提升CTR/CVR → ECPM↑ → 更好的位置      │        │        │
│  │  └──────────────────────────────────────┘        │        │
│  │                                                  │        │
│  └──────────────────────────────────────────────────┘        │
│                                                              │
│  📊 SIF vs 自然流量份额占比 vs 自然位赢得率                     │
│                                                              │
│  ┌──────────┬─────────────────────────────────────┐          │
│  │ SIF       │ 综合流量获取效率（三因子加权）         │          │
│  │ (综合)    │ = 量+位置+时长的综合评分              │          │
│  ├──────────┼─────────────────────────────────────┤          │
│  │ 自然流量   │ 你通过自然排名获得的流量               │          │
│  │ 份额占比   │ 占该关键词总流量的比例                 │          │
│  │ (占比)    │ = 你的自然点击 ÷ 该词总搜索量         │          │
│  ├──────────┼─────────────────────────────────────┤          │
│  │ 自然位    │ 你的ASIN在该词的自然位上               │          │
│  │ 赢得率    │ 出现的频率/占比                       │          │
│  │ (频率)    │ = 你出现在自然位的次数 ÷ 总监测次数    │          │
│  └──────────┴─────────────────────────────────────┘          │
│                                                              │
│  ⭐ 三者关系：                                                │
│  SIF是最综合的指标（考虑了量+位+时长）                           │
│  自然流量份额 = SIF的"结果表现"                                │
│  自然位赢得率 = SIF的"过程表现"                                │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

# 📘 Skill 4：算法打分体系 — 5大评分维度

```
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  📐 关键词算法打分 — 五维评分模型                               │
│                                                              │
│  ┌──────────────────────────────────────────────────┐        │
│  │                                                  │        │
│  │  综合得分 = f(商业价值, 广告选词, 点击转化率,       │        │
│  │              流量得分, 机会指数)                    │        │
│  │                                                  │        │
│  │  满分：100分                                      │        │
│  │                                                  │        │
│  └──────────────────────────────────────────────────┘        │
│                                                              │
│  ┌──────────────────────────────────────────────────┐        │
│  │                                                  │        │
│  │  维度①：商业价值得分 ⭐⭐⭐⭐⭐ (权重最高)           │        │
│  │  ┌──────────────────────────────────────┐        │        │
│  │  │                                      │        │        │
│  │  │  衡量：该关键词能带来多少商业回报         │        │        │
│  │  │                                      │        │        │
│  │  │  评分要素：                             │        │        │
│  │  │  • 搜索量（月均搜索量）                  │        │        │
│  │  │    → 搜索量越大 → 商业价值越高            │        │        │
│  │  │  • 客单价（该词下产品的平均售价）          │        │        │
│  │  │    → 客单价越高 → 单次转化利润越大        │        │        │
│  │  │  • 购买意图强度                          │        │        │
│  │  │    → "buy wireless earbuds" > "earbuds"│        │        │
│  │  │  • 竞争度（广告竞价水平）                │        │        │
│  │  │    → 竞争度适中 → 投入产出比最优          │        │        │
│  │  │                                      │        │        │
│  │  │  📊 评分范围：0~100分                    │        │        │
│  │  └──────────────────────────────────────┘        │        │
│  │                                                  │        │
