# ASIN 广告健康诊断标准 SOP v2.0（八层诊断法）

> 适用范围：任意亚马逊 ASIN 的广告健康度周期性诊断（周检/月检/事故复盘）
> 上游依赖：amazon-ppc-economics（定线）｜下游对接：amazon-ppc-profit-diagnosis（定档定动作）
> 数据源：天机OS（领星同步）+ 卖家精灵/SIF/Sorftime MCP + Amazon BA 搜索词绩效
> 本 SOP 由 B0XX-01 案例（2026-05 事故）验证后固化。所有非官方阈值标注 `engineering_assumption (ea)`。

---

## 0. 设计原则（TRACE）

- **T**rigger：ACOS 跳档、BSR 异动、预算打满告警、周期性巡检，四类事件任一触发。
- **R**equired data：L0 八项数据缺一先补，绝不编造 CVR / 毛利率。
- **A**ssumption：临界点击数、AHS 权重、五档系数均为 `ea`，随类目校准。
- **C**alculate：经济参数一律由 economics 脚本产出（唯一权威线），诊断端只消费不重算。
- **E**xplain：每层输出一句经营结论；最终动作必须带"预期锚线 + 复检日期"。

---

## L0 · 数据准备（八项清单，缺一先补）

| # | 数据 | 来源 | 用途 |
|---|------|------|------|
| 1 | 搜索词报告（30-90天） | 领星下载中心 / 广告后台 | 实际 CPC、点击、广告订单、广告 CVR |
| 2 | 订单数据（拆广告单/自然单） | lx_profit_asin_daily / 业务报告 | 自然单占比 s、整体 CVR |
| 3 | 类目平均 CVR | 卖家精灵 / SIF / 品牌分析 | CVR 基准锚点 |
| 4 | 广告出单临界值 | 默认 15 击/单（隐含 CVR≈6.67%）`ea`，优先用 1/实际广告CVR 校准 | 词级生死判定 |
| 5 | 自己目标 CVR | 运营目标 | 目标态 CPC 上限 |
| 6 | 竞品 CVR | 卖家精灵反查 | 判断目标是否现实 |
| 7 | 实际广告 CVR | 搜索词报告：广告订单÷广告点击 | 现实态可承受 CPC |
| 8 | 广告前毛利率 | (gross_profit + 广告费) ÷ 总销售额 | 平本 ACOS |

**铁律：目标 / 类目 / 竞品 / 实际，四个 CVR 必须同时摆上桌。**

补充数据（结构层与外部层需要）：Campaign 操作日志、预算打满记录、广告位报告、BA 点击/购买占比、SIF 关键词需求时机、竞品 BSR 同期序列。

## L1 · 经济基线（唯一权威线）

```
中心方程   ACOS = CPC ÷ (CVR × 客单价)
CPC上限    = 目标ACOS × 客单价 × 广告CVR          ← 出价只能用广告CVR
平本ACOS   = 广告前毛利率                          ← 最重要的一条共识
平本CPC    = 平本ACOS × 客单价 × 广告CVR
CPA        = CPC ÷ CVR；CPA上限 = 目标ACOS × 客单价
日预算     = 预计日单量 × CPA
TACOS      = ACOS × (1 − 自然单占比s)
等效CPC上限 = 基础上限 ÷ (1 − s)                   ← 飞轮判断用整体口径
```

输出物：`ppc_config.json`（economics export，每周或参数变动时刷新）。
校验规则：目标 ACOS 必须 < 平本 ACOS，差值即净利空间；广告 CVR 漂移超 ±15% → 触发重锚。

**双口径判断（本SOP新增，B0XX-01 案例教训）：**
- 广告口径：实际 CPC vs 平本 CPC → 判断单笔广告盈亏。
- TACOS 口径：实际 CPC vs 等效平本 CPC → 判断飞轮层面是否值得硬扛。
- **两口径结论冲突时（广告口径亏、TACOS 口径可承受），优先保飞轮**：给高效 Campaign 加预算，同时用词级止损（L5）控制出血，严禁一刀切断投。

## L2 · ACOS 五档分区（锚线自动推导，禁止拍固定阈值）

| 档位 | 上界 | 含义 | 默认动作 |
|------|------|------|---------|
| 🟢 优质 | ≤ 目标 × 0.7 | 净利充沛 | 加预算放量 |
| 🔵 健康 | ≤ 目标 | 达成目标 | 维持并寻找扩量词 |
| 🟡 预警 | ≤ 目标 + (平本 − 目标)/2 | 侵蚀净利 | 收词/分时段/降广泛，观察2周 |
| 🟠 承压 | ≤ 平本 | 逼近盈亏线 | 词级止损 + 结构下钻 |
| 🔴 亏损 | > 平本 | 广告后毛利为负 | 立即进入 L4-L7 全链路诊断 |

毛利率或目标 ACOS 变动 → 五档整体自动平移。新品期可声明牺牲比例（如 ×1.3）放宽止损线，但 (平本, 等效目标] 区间必须标记"有意亏损带"——意愿可以放宽止损线，不能改写数学盈亏线。

---

## L3 · 月度趋势（区分趋势恶化 vs 单月事故）

必看序列（≥12个月）：销量 / 销售额 / 广告费 / ACOS / TACOS / 毛利润 / 广告后毛利率 / CPC。

判定规则：
- 连续 2 个月降档 → 趋势性问题，进入 L5 词效与 L6 外部对标。
- 单月跳档（跳 ≥2 档）→ 事故性问题，先查操作日志与日级花费（直接跳 L7）。
- CPC 环比 +30% 以上 → 市场竞争加剧信号，立即核对预算打满记录（L4）。
- 涨价后销量不降反升 → 定价健康且有提价空间，记入基本面加分。

---

## L4 · 投放结构诊断（Campaign × 广告位 × 预算）

### 4.1 结构完整性
- 广告类型：仅 SP = 单点故障结构（红）；SP+SB 或 SP+SD（黄）；SP+SB+SD/SBV（绿）。
- 匹配层次：是否有 精准主推 / 词组收割 / 广泛+自动探索 三层结构。

### 4.2 广告位下钻铁律
**禁止看汇总广告位 ACOS，必须下钻到 Campaign × 广告位。** 同一位置在不同 Campaign 结论可以完全相反（案例：搜索首位在「海王」25.3% 健康，在「顶首页」65.9% 亏损）。
- 某位置亏损、其余位置健康 → 只调该位置倍增系数（降至0%），不停活动。
- 三个位置全面超平本 → 整活动暂停重建。

### 4.3 预算打满监控（先行预警指标，早于 ACOS）
| 打满频次 | 判定 | 动作 |
|---------|------|------|
| >3 次/周 `ea` | 🟡 告警 | Feishu 推送，核对是否高效活动被掐 |
| >20 次/月 `ea` | 🔴 红色 | 高效流量被人为断供，立即重配预算 |

高效活动（优质/健康档）打满 = 加预算；亏损活动打满 = 先做 L5 词级清洗再谈预算。

---

## L5 · 词级三维验证（广告ACOS × BA购买占比 × SIF需求时机）

单一维度不判生死，三维交叉后才下结论：

| 广告ACOS | BA购买占比 | SIF时机 | 结论 |
|----------|-----------|---------|------|
| 超平本 | 0% | 淡季/不匹配 | 🔴 立即停投（双重死刑） |
| 超平本 | 0% | 旺季 | 🔴 停投（市场旺但产品不匹配，不是竞价问题） |
| 优质(≤目标×0.7) | 高 | 旺季 | 🟢 最优先加投提价 |
| 优质/健康 | — | — | 🟢 加投 |
| 0 单 | 有自然购买份额 | 旺季峰值未到 | 🔵 大词养自然排名，布局窗口期，不判死刑 |

词级生死规则：
- 点击 > 临界值（1/广告CVR，默认≈20 击 `ea`，×1.0~1.5 安全系数）仍 0 单 → 否词或降至 $0.15。
- 点击 < 临界值 → 数据不足，不判死刑（尤其月搜 >10万 的大词）。
- **错位量化指标**：`亏损词花费占比 = Σ(超平本+BA为0 词花费) ÷ 总花费`，>30% `ea` 即词效红色。
- 挖掘动作：BA 购买占比极高的长尾词 + 已有自然排名（P1/P2）无广告的词 → 待投放清单。
- 词根聚合（单词根/双词根词频×ACOS）用于发现属性级流量倾斜，指导独立活动拆分。

---

## L6 · 外部对标归因（先问：是市场跌还是我跌？）

归因三分法（对比 ≥2 个竞品同期 BSR）：

| 现象 | 归因 | 动作 |
|------|------|------|
| 竞品同步下滑，幅度相当 | 市场 β | 按兵不动，保预算过冬 |
| 只有我们下滑 | 内部 α | 全力自查（库存/Listing/广告/差评） |
| 我们跌幅显著更大（如 4x vs 1.5x） | 混合 | 剥离市场 β，聚焦内部 α（进入 L7） |

---

## L7 · 根因链还原（闭合到日级）

要求：因果链必须还原到 **具体日期 + 具体 Campaign + 具体动作**，结论可被时间线证伪。

标准模板：
```
外部诱因（旺季/竞争加剧）→ CPC 上涨 x% → 日预算打满时点前移 →
某 Campaign 断投（日期）→ 广告日花费 $A → $B → 广告流量断崖 →
销量不足 → 自然排名（L3权重）失血 → BSR 恶化 N 倍 → 飞轮反转
```

飞轮成本核算：断投省下的广告费 vs 自然位权重回吐的重建成本（通常为 4~6 周超额投放 `ea`）。自然单占比越高（s>50%），断投的真实代价越大——这类链接的广告费本质是权重资产的维护费。

---

## L8 · 行动分级与闭环

### 输出格式（三级）
- **P1 今日止损**：停亏损词/亏损活动、恢复预算供给（总盘 = 目标日单量 × CPA）。
- **P2 本周修复**：位置级修正（只关位置不关活动）、高效词提价、新词上线、打满告警配置。
- **P3 中期布局**：大词自然排名窗口、广告类型补短板（SB/SD）、评论加速、闭环校准。

### 每条动作必须包含
① 具体参数（预算 $X→$Y、出价 $Z）② 预期锚线（回落到哪一档）③ 复检日期（默认 T+14）。

### 标准闭环四步
```
① economics export → ppc_config.json（每周/参数变动时）
② diagnosis 消费 config + 搜索词报告 → 五档分区/止损/待投放（每日）
③ 聚合导出 actuals.json + 操作日志回写（重要调整必须记录"日期-动作-反馈"）
④ calibrate → 漂移报告；广告CVR漂移超 ±15% → 回 ① 重锚
```

## 附A · 广告健康分 AHS（0-100，`ea` 权重）

| 维度 | 权重 | 评分要点 |
|------|------|---------|
| 经济面 | 30% | 当前档位（亏损35/承压50/预警65/健康80/优质95）± 双口径冲突修正 |
| 结构面 | 20% | 广告类型完整性、预算打满频次、位置级健康度 |
| 词效面 | 25% | 亏损词花费占比、高效词预算覆盖率、待投放清单积压 |
| 传导面 | 15% | 自然单占比 s、s 的趋势（长期停在 0~20% = AOT 传导失效） |
| 基本面 | 10% | LQS、评分、评论数/月增、定价健康度、库存 |

分级：≥80 健康 ｜ 60~79 亚健康 ｜ 40~59 承压 ｜ <40 危重。

## 附B · 指标异常速查（来自广告知识库诊断树）

| 症状 | 广告层原因 | Listing层原因 |
|------|-----------|--------------|
| 无/低曝光 | 词少、词不准、预算少、bid低 | SEO埋词少、链接权重低、无购物车 |
| 点击少/CTR低 | 同上 | 点击页面差（主图/标题/价格/Review/促销） |
| CVR低 | 词不精准、位置差 | 详情页差（图组/A+/视频/五行/促销/竞品） |
| ACOS高 | bid高 或 CVR低 或 价格低 | 按 ACOS = CPC÷(CVR×Price) 三因子逐一排除 |
| TACOS高 | 上述 + 广告单占比高 | 自然收录少、自然位差 → 查 AOT 传导 |

## 附C · 结构性 vs 战术性问题判别（红黄绿）

- 🔴 实际 CPC > CPC上限 × 1.3 且 CVR 低于类目均值 → **结构性**：先修 Listing/价格，调竞价无效。
- 🟡 CPC上限 × 1.0~1.3 → **战术性**：收词、分时段、降广泛，观察 2 周。
- 🟢 实际 CPC ≤ 上限 且 词级点击/出单 ≤ 临界值 → 可加预算放量。
- 特例（本SOP新增）：CPC 超广告口径平本线但低于 TACOS 等效线、且 s>50% → **供给性**：加预算保飞轮，词级控出血。
