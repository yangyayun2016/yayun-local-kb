# ColdNet 冷启动推荐算法 —— 亚马逊新品推荐系统应用详解

> 依据：Sanskar Tewatia / Mahmudur Rahman / Dhruv Garg，《ColdNet: Treatment Effect Estimation with
> Cold-Start, Imbalance, and Zero-Inflated Outcomes》，Amazon Applied Science，13th Amazon Consumer
> Science Conference (CSS 2026)。已在生产环境部署，每周处理40亿+预测，美国+3个欧盟市场。

## 〇、诚实声明：这套系统在做什么，不在做什么

ColdNet原文是一个**需要训练的神经因果网络**（DragonNet架构 + 按结果分层集成 + K-Means/FAISS索引），训练需要2.29亿条带处理标签的历史样本和SageMaker级别的算力。**你现在没有这个训练数据和基础设施，所以本系统不是在复现那个神经网络本身**，而是复刻论文中已经被验证、且不依赖梯度训练就能直接使用的**推断时规则**：

- 析取准则（Disjunctive Criterion）判定冷启动 —— 规则，可直接用
- 冷启动样本用"相似样本群的分位数聚合"而非"自身历史"来估计 —— 这是K-Means+FAISS的简化版，用余弦相似度+近邻分位数聚合替代
- w=0.1（个体）/ 0.9（群体）混合公式 —— 论文18组超参数扫描验证过的最优值，直接复用
- 暖启动样本直接用个体信号，不做群体混合 —— 论文原文的严格改善保证（strict improvement guarantee）

**不在做的**：真正训练一个DragonNet预测GMV/转化率的神经网络。`individual_signal`（个体早期信号）在本系统里是用SPR等第三方工具能拿到的早期指标（如8天关键词首页订单数）做的代理，不是论文里 μ̂(X) 那个训练出来的潜在结果头。这点必须清楚，否则容易高估这套规则系统的精确度。

## 一、论文核心机制 → 新品推荐系统映射表

| 论文概念 | 论文原文机制 | 本系统对应实现 | 来源 |
|---------|--------------|----------------|------|
| Cold-Start判定 | 析取准则：6个历史活动特征（offer级×4 + ASIN级×2，90/365天窗口）任一为零 → 冷启动，覆盖97.9%原始样本 | 改造为：**90天新品期内** 且 offer级或ASIN级历史（销售额/发货量）任一为零 | 论文2.5节 + Appendix H.2，原文 |
| 冷启动样本处理 | 不用自身NCM预测，检索k个相似训练样本，用分位数聚合（q=0.45）估计结果 | 用余弦相似度在"同样处于新品期"的竞品池中找最相似的k个，取其早期表现的分位数 | 论文2.5节 + Algorithm 1 |
| 为什么用分位数不用均值 | 冷启动结果零膨胀，均值聚合会被少数高值异常点带偏，超参数分析证实均值聚合使MAE恶化+1.3% | 直接复用q=0.45分位数聚合，明确禁止均值聚合 | 论文Appendix F，表8 |
| 混合公式 | ~μt* = w·μ̂t* + (1-w)·ŷcluster，最终 w=0.1（即冷启动预测90%来自相似群体，仅10%来自个体自身信号） | 直接复用：冷启动ASIN的推荐分数 = 0.1×个体信号 + 0.9×相似群体分位数 | 论文2.5节 + Algorithm 1第30-31行 |
| 暖启动处理 | 暖启动样本直接返回NCM输出，不做任何聚类混合（严格改善保证：K-Means只对冷启动生效，暖启动预测完全不变） | 一旦脱离新品期判定（非冷启动），直接用个体信号，w=1.0 | 论文2.5节 + 表3（Warm cohort的∆2=0.0%） |
| 局部性很重要 | k从100降到10，冷启动MAE改善从-17.4%提升到-19.1%，单调改善 | k_neighbors默认设为10，与论文最终配置一致 | 论文Appendix F |
| 聚类数不敏感 | K∈{10,20,50,100}表现几乎相同（-18.2%~-18.3%），说明K-Means只是加速近邻搜索的工具，真正起作用的是FAISS近邻检索本身 | 本系统跳过真正的K-Means分区（样本量不够大，没必要），直接对全部候选竞品池做余弦相似度检索，效果等价 | 论文Appendix F |
| 冷启动核心假设 | "非历史特征相似的冷启动样本倾向于表现出相似结果"（Key Insight，2.5节原文） | **这正是你提出的"竞品相似度"概念**：不是与爆款比相似度，而是与"同样在新品期内、表现好"的竞品比相似度——论文用的正是这个逻辑 | 论文2.5节原文 |

## 二、你的几个实战洞察，和论文的对应关系

### 1. "竞品相似度不是爆款竞品，而是同样新品期内销量好的竞品"

这个判断和论文的Key Insight完全一致，甚至可以说你独立推导出了论文的核心假设。原文原话："非历史特征相似的冷启动样本倾向于表现出相似结果"——重点是**"冷启动样本"之间比较**，而不是拿一个已经度过冷启动期、数据充分的爆款来做参照系。用爆款做参照系，本质上是论文里"基于均值的兜底策略会忽略冷启动主体之间的结构相似性"这个反面案例——爆款的成功路径（可能是长期积累的评论、广告投入、供应链优势）和一个新品能否被推荐，是两套不同的因果结构。

### 2. 父体合并导致ASIN失去新品推荐资格

论文的析取准则区分了两个粒度（Appendix H.2）：
- **Offer级**（4个特征）：追踪"这个具体的卖家-商品组合"本身的表现
- **ASIN级**（2个特征）：追踪"这个产品跨所有卖家"的整体表现

⚙️ **这是你的业务外推，论文本身没有直接讨论新品徽章/父体合并**，但可以用论文的特征定义解释你观察到的现象：如果一个新变体被合并进已有父体，ASIN级聚合数据会因为兄弟变体的历史销售而**不再是零**，即便这个具体子体（offer级）本身仍是全新的、零历史。如果亚马逊下游的"新品资格"判断逻辑是看ASIN/父体层级而非offer层级，这个新变体就会被系统误判为"非新品"，从而失去新品推荐资格——这与论文强调的"析取准则必须覆盖两个粒度，缺一个都会漏判"是同一个逻辑陷阱的两种体现。本系统会显式检测并预警这种情况。

### 3. SPR 8天关键词首页订单数 + 周二/周三更新节奏

⚙️ 这部分完全是你的实战经验，论文未涉及具体的第三方工具更新周期。但可以用论文的"生产部署"章节佐证一个更底层的事实：**ColdNet本身也是按周更新的**（原文："当前生产系统由AWS Lambda触发，进行每周推断和季度模型重训练"）。这说明亚马逊自己的因果推荐系统也是周更节奏，你观察到的SPR周二更新、发货数据周三更新，很可能就是在追踪同一套底层周更新机制的不同侧面。

据此我实现了一个"冷启动观察窗口计算器"：给定ASIN开始被收录/产生数据的星期几，和系统更新的星期几，计算从上架到系统完成N次判断更新，实际经过了多少天。你给的例子——周五开始收录、数据周三更新——代入计算得到12天，与你的手算完全吻合。

## 三、系统设计：新品推荐强度评分（NPRS, New Product Recommendation Score）

### 计算流程

1. **判定冷启动状态**：90天新品期内 + 析取准则（offer级或ASIN级历史任一为零）
2. **检测父体合并风险**：若已合并且offer级仍为零但ASIN级因兄弟变体不再为零 → 预警"可能被误判为非新品"
3. **计算冷启动观察窗口**：基于收录起始星期 + 系统更新星期，算出实际经过的天数
4. **个体早期信号**：基于SPR类工具的早期指标（如8天关键词首页订单数），归一化到0-1
5. **相似群体估计**：在"同样处于新品期内"的竞品池中，用余弦相似度（基于品类/价格/属性等非历史特征）找最相似的k=10个，取其早期表现的45分位数
6. **混合**：
   - 若冷启动：`分数 = w×个体信号 + (1-w)×群体估计`，w基础值0.1（论文原值）
   - ⚙️工程扩展：论文的w是固定超参数，不随时间变化；本系统按"已经历几次系统更新周期"做小幅爬升（每经历一次更新周期，w+0.15，上限0.6，仍在冷启动定义内不会到1.0），这是为了反映"冷启动早期几乎全靠群体判断，但随着自身数据积累，个体信号权重应该逐步提高"的直觉，**非论文原文内容**
   - 若已脱离冷启动（暖启动）：直接用个体信号，w=1.0，不做任何群体混合（论文的严格改善保证）
7. **老店铺加权**：⚙️纯业务假设，论文把卖家经营年限列为协变量（seller characteristics: tenure），但没有公开具体加权公式。本系统按年限分档给最终分数加成（≥5年+15%，≥2年+8%，≥1年+3%），你需要结合自己账号的实际数据验证这个加成幅度是否合理。

## 四、局限性（继承自论文 + 本系统自身）

- 论文原文明确写了适用范围局限："冷启动定义（6个特征的析取准则）以及超参数（K,k,q,w）是针对特定数据集调优的，实践者应在自己的数据上验证这些选择"——本系统直接沿用了论文的k=10、q=0.45、w=0.1，你的实际类目/店铺情况可能需要重新校准，用之前做的`calibrate_weights.py`思路同样适用于这里的w值
- `individual_signal`是SPR类工具的代理指标，不是论文里真正训练出来的因果预测头，二者的可信度不是一个量级的东西
- 相似群体的"竞品池"需要你自己去SIF/Sorftime/卖家精灵这类数据源拉取同类目新品的早期表现，本系统只提供计算逻辑，不提供数据源
- 父体合并的风险预警是基于论文特征定义做的合理外推，不是论文验证过的结论，建议先在小范围验证这个假设是否成立
