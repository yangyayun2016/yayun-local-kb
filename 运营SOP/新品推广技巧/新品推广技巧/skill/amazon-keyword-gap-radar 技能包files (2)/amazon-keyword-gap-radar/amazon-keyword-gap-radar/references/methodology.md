# 方法论参考（references/methodology.md）

## 1. 为什么用「份额矩阵」找短板

同一个词，四个ASIN的自然流量份额横向可比——竞品自然份额高，
证明该词**能养出自然位**（需求真实、类目相关性通过A9验证）；
我方份额≈0，说明差距不在市场而在自己。这比拍脑袋选词可靠得多：
**每个GAP词都是竞品替你验证过的需求。**

## 2. 六类标签的设计逻辑

判定顺序 LEAK → DEFEND → OPP → GAP → BLUE → TAIL，互斥：

- **LEAK 优先判**：钱正在漏是最紧急的信号。它是 AOT L3（权重不沉淀）
  在词粒度上的显影——广告份额有、自然份额无 = 该词成交未转化为权重。
  成因两种：词CVR低于市场均值（A9不给权重）→ 降位/否词；
  或投放时间不足 → 续投观察。用「关键词点击转化率」列对照判断。
- **DEFEND 其次**：自然≥2%的词是现金流来源，识别出来是为了
  防止盲目"优化"动了根基（改标题误删防守词是常见事故）。
- **OPP 在 GAP 之前**：0.5~2% 说明已收录、已有初始权重，
  边际成本最低。打词永远先打临门一脚，再补短板。
- **GAP 的门槛设在竞品自然≥2%**：低于此的词竞品自己也没吃透，
  不构成"被验证的需求"。
- **BLUE 是战略级观察**：全员<1%的大词要么相关性弱要么格局未定，
  低价卡位可以，重仓不行。

## 3. 优先分公式

```
进攻类(OPP/GAP):  score = log10(SV+1) × 份额 ÷ (1 + Top3点击集中度/100)
防守/漏损类:      score = log10(SV+1) × 我方对应份额
```

- log10 压缩搜索量量纲：35万的词不应比3500的词重要100倍，
  权重差距应该是2个数量级压成2倍
- Top3点击集中度惩罚：集中度80%意味着前三个ASIN吃掉八成点击，
  新进入者实际可得流量大打折扣，难度系数×1.8
- OPP 系数×2：临门一脚的边际ROI最高，排序上应压过同分GAP

## 4. 与 AOT / SPR 的闭环

```
流量词雷达(词级静态) ──打词清单──▶ SPR/8 定日单量与预算
        ▲                              │
        │                              ▼
   4周后重跑对比                 SP集中投放执行
        ▲                              │
        └──── AOT引擎(时序动态) ◀──────┘
              验证 TE转正 / FHI爬升 / 排名破线
```

雷达回答「打哪些词」，SPR/8 回答「打多重」，AOT 回答「打没打动」。
三件套构成 天机OS 的关键词作战循环。

## 5. 卖家精灵导出格式约定

- 第1行为「数据导出日期」说明行，表头在含「关键词」的行
- ASIN列命名模式：`B0XXXXXXXX\n总流量份额 / 自然流量份额 / 广告流量份额`
- 份额为百分比字符串（"9.7157%"），0 可能是字符串"0"
- 「流量竞争力」列为JSON样式描述文本，当前版本不参与计算
- 建议竞价三列（最低/推荐/最高），脚本取「推荐」
