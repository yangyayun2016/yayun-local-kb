# Amazon 流量词短板与机会雷达

把 2000+ 行的多产品词表压缩成一张作战地图：哪些词在漏钱（烧而不沉）、
哪些词竞品验证过而我方缺席（短板）、哪些词临门一脚就能打透（机会）、
哪些词是护城河（防守）。每个词给优先分和动作建议。

## 何时用

- 拿到卖家精灵「多产品对比流量词」导出后的第一步分析
- 制定关键词布局 / 打词清单 / 广告预算再分配前
- AOT 飞轮巡检判定 L3/L4 断链后，下钻到词级找修复入口

## 工作流

### 第1步：确认我方ASIN

导出文件包含多个ASIN，**必须先确认哪个是我方**（脚本参数 `--self`）。
用户未说明时主动询问，不要猜。文件中的ASIN列表脚本会自动识别并在
传错时打印候选。

### 第2步：跑雷达

```bash
python scripts/gap_radar.py --input <卖家精灵导出.xlsx> --self B0XXXXXXXX \
  [--out-dir 输出目录] [--top 30]
```

自动完成：定位表头行（跳过"数据导出日期"行）→ 正则识别
`ASIN+总/自然/广告流量份额` 列 → 六类打标 → 输出三件套：

1. `流量词雷达_<ASIN>.xlsx` — 汇总sheet（COUNTIF/SUMIF公式聚合）+
   明细sheet（按标签优先级排序、色块标记、冻结首行、自动筛选）
2. `流量词雷达_<ASIN>.json` — 每类Top N 机器可读清单（喂给后续投放脚本）
3. 终端简报 — 可直接贴飞书/微信群

### 第3步：解读六类标签（判定互斥，按此优先级）

| 标签 | 判定（份额%） | 含义与动作 |
|------|------|------|
| 🔴 LEAK 烧而不沉 | 我方广告≥1 且 自然<0.5 | **AOT L3的词级定位**。查该词CVR：达标→续投等沉淀；不达标→降位/换匹配/否词 |
| 🟡 GAP 短板词 | 竞品自然max≥2 且 我方总<0.5 | 竞品验证过的需求我方缺席。先补收录（标题/ST埋词），再SP低位测试 |
| 🟢 OPP 临门一脚 | 我方自然0.5~2 且 SV≥1000 | **最优先进攻**：已收录未打透，SP集中加码，按SPR/8定日单量冲前3页 |
| 🔵 DEFEND 防守词 | 我方自然≥2 | 护城河：保排名、广告降配、盯竞品侵蚀 |
| ⚪ BLUE 蓝海词 | SV≥5000 且 全员总<1 | 无人吃透的大词，验证相关性后低价卡位 |
| ⬜ TAIL 长尾观察 | 其余 | 不投入，季度复查 |

优先分 = log10(SV+1) × 相关份额 ÷ (1+Top3点击集中度/100)。
Top3集中度作难度惩罚：前排越垄断的词，打进成本越高，排序自动后移。
全部阈值在 `assets/weights.json`（工程假设，可按类目调）。

### 第4步：与AOT飞轮巡检联动

- LEAK 词数量多 + AOT 判 L3 断链 → 互相印证，修复动作直接落到这批词
- OPP + GAP 的 Top 清单 = AOT L4「集中打透1-2个词」的弹药库，
  按优先分从上往下打，预算 = SPR/8 ÷ 广告CVR × CPC（建议竞价列可参考）
- 打词 4 周后重跑 AOT 引擎验证 TE 是否转正、FHI 是否爬升

### 第5步：进阶数据（可选）

已连接 MCP 时可补充验证：卖家精灵 `keyword_miner`/`keyword_research`
查词的竞争与进入价值，`traffic_keyword` 反查我方实际曝光词与雷达结果
交叉核对；SIF `market_get_keyword_competition` 看词的前20 ASIN格局。

## 边界与注意

- 流量份额是该词流量的分配占比，不是绝对流量；同表内可比
- 竞品品牌词（如对比ASIN的品牌名）会进GAP，投放需评估品牌词投流合规与转化风险，默认建议排除
- SV=0 的词是ABA未收录长尾，LEAK里出现时优先否词
- 导出文件必须含「关键词/周搜索量/各ASIN三类份额」列，缺列时脚本按0处理并提示
- read_only 模式读不了卖家精灵导出（维度元数据不标准），脚本已内置普通模式
