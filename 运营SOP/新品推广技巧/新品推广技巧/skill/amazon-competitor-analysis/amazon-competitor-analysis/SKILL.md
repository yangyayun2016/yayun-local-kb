# 亚马逊竞品ASIN推广节奏分析

## 概述

本技能用于对亚马逊竞品ASIN进行系统化的推广节奏分析，输出一份结构化的HTML报告。报告涵盖从上架到成熟期的完整运营轨迹，帮助卖家还原竞品的定价、评论、流量、广告策略。

## 触发条件

- 用户提供一个或多个ASIN，要求分析竞品
- 用户要求分析某个竞品的推广节奏/运营策略
- 用户想了解竞品的定价、评论、流量、排名变化规律
- 用户说"帮我拆解这个竞品"、"看看这个ASIN怎么做起来的"等

## 数据获取

### 第一步：使用MCP工具获取原始数据

依次调用以下工具获取竞品完整数据（根据用户连接的MCP工具选择）：

**卖家精灵MCP工具（优先）：**
1. `asin_detail` — 获取ASIN基础信息（标题、品牌、类目、卖家、上架时间等）
2. `keepa_info` — 获取历史趋势数据（价格、排名、评论、卖家数变化等）
3. `asin_prediction` — 获取销量与销售额数据（日/月维度）
4. `traffic_keyword` — 获取流量关键词表现
5. `traffic_keyword_stat` — 获取流量关键词结构概览
6. `traffic_listing_stat` — 获取流量来源结构（自然/广告占比）
7. `review` — 获取评论列表

**SIF MCP工具（补充）：**
1. `ops_get_asin_sales_trend` — 销量趋势
2. `ops_get_asin_traffic_trend` — 流量趋势
3. `ops_get_listing_traffic_overview` — 流量结构总览
4. `ops_get_listing_traffic_structure` — 变体流量结构

### 第二步：数据整理

将原始数据整理为以下结构化格式：

```
基础信息：ASIN, 标题, 品牌, 类目路径, 卖家名, 上架日期, 当前价格, 当前评分, 当前评论数
时间序列（日维度）：日期, 大类排名, 小类排名, 日销量, 成交价, LD价, Coupon价, 全部流量, 自然流量, 广告流量, 自然%, 广告%, SP常规%, SP推荐%, SB%, SBV%
关键事件：首次上架, 首次出单, 首条评论, 首次改价, 首次DEAL, 首次COUPON, 首次PRIME, 首次卖家增加, 首次修改标题, 首次修改主图
```

## 报告生成

### HTML报告结构

生成一个**单文件HTML报告**，使用内联CSS和Chart.js（CDN引入）。报告包含以下模块，按顺序排列：

---

### 模块1：报告头部

```
标题：[ASIN] 竞品前4个月推广节奏分析报告
分析周期：YYYY-MM-DD ~ YYYY-MM-DD
核心指标卡片（横排4个）：
  - 前4月总销量 XXX
  - 前4月销售额 XXX（带货币符号）
  - 累计评论增长 XXX
  - 大类最佳排名 XXX（BSR）
```

### 模块2：关键时间节点

用时间线（timeline）样式展示：

| 节点 | 说明 |
|------|------|
| 首次上架 | YYYY-MM-DD |
| 最早出单 | YYYY-MM-DD |
| 首条评论 | YYYY-MM-DD |
| 首次改价 | YYYY-MM-DD |
| 首次DEAL | YYYY-MM-DD，价格XXX |
| 首次COUPON | YYYY-MM-DD |
| 首次PRIME | YYYY-MM-DD |
| 首次出单BuyBox价 | XXX |
| 首次卖家增加 | YYYY-MM-DD |
| 首次修改标题 | YYYY-MM-DD |
| 首次修改主图 | YYYY-MM-DD |

### 模块3：核心趋势图表

使用Chart.js绘制以下图表：

**图表A - 排名/成交价/评论数综合趋势（组合图）**
- X轴：日期
- Y轴左：大类排名BSR（折线，反转轴，数值越低排名越好）
- Y轴左：小类排名（折线）
- Y轴右：成交价（折线）
- Y轴右2：评论数（面积图）
- 注意：排名轴需要反转（值越小越靠上）

**图表B - 月度销量结构对比（堆叠柱状图）**
- X轴：月份
- 三组柱：全部流量对应销量、自然流量对应销量、广告流量对应销量

**图表C - 月度新增评论数（柱状图）**
- X轴：月份
- Y轴：新增评论数

### 模块4：前4个月汇总表

表格形式，每行一个月：

| 月份 | 策略标签 | 销量 | 成交价 | 大类BSR最佳 | 小类最佳 | 评论数 | 留评率 | 广告费占比 | 新增广告 |
|------|---------|------|--------|------------|---------|--------|--------|-----------|---------|

策略标签自动判断逻辑：
- 第1个月：若成交价低于后续月份均值 → "低价切入+评论拉升"
- 第2-3个月：若排名波动<20% → "排名维持期"；否则 → "排名回落观察"
- 第4个月：若广告占比上升 → "广告调整+排名冲刺"

### 模块5：月度推广节奏拆解（核心模块）

每个月一个展开/收起的卡片，包含以下子模块：

```
MONTH N — 第N个月（起止日期）策略标签

■ 销量与排名
  销量XXX，成交额XXX，大类排名最佳XXX，小类排名最佳XXX

■ Listing策略
  标题修改N次，主图修改N次，点击率优化动作描述

■ 价格策略
  月初成交价XX → 月末成交价XX，月均成交价XX
  BuyBox区间：XX ~ XX
  关键改价点：日期=价格（列举所有改价事件）
  LD活动N次

■ 评论策略
  评论从X增至Y，月新增Z，留评率X%
  评分X.X，评论质量判断（强/中/弱）

■ 流量策略
  全部流量XXX
  自然/广告占比：XX%/XX%
  新增广告N次
  SP常规/推荐占比：XX%/XX%

■ 风险判断（用颜色标记）
  🟢 正常 / 🟡 需关注 / 🔴 高风险
  判断规则：
  - 留评率 > 3% → 🔴 需警惕刷单风险
  - 留评率 1~3% → 🟡 略高，需观察
  - 广告占比 < 5% 但排名快速上升 → 🟡 排名来源不明
  - 评论增速异常（月增>100且留评率>5%）→ 🔴 高度疑似刷单
```

### 模块6：效果总结

```
大类排名变化：从XXXXX → XXXX（最佳XXX，最差XXX）
小类排名变化：最佳XX
累计销量：XXXX
累计成交额：XXXX
```

### 模块7：明细数据表（可折叠）

提供以下维度的数据表，每个表格都支持折叠展开：

1. **全量明细**：日维度完整数据
2. **前4月明细**：上架后前4个月日维度数据
3. **前8周明细**：上架后前8周日维度数据
4. **近N月聚合**：按最近N个月聚合
5. **前N月聚合**：按上架后前N个月聚合
6. **第N月聚合**：指定月份聚合
7. **第N周聚合**：指定周聚合

每个表格的列：
日期, 大类排名MIN, 小类排名MIN, 卖家数, 销量, 成交额, 成交价, 定价MAX, 定价MIN, LD数, 评论数, 评分, 新增评论, 留评率, 新增广告, 修改标题, 修改主图, 全部流量, 自然流量, 广告流量, 自然%, 广告%, SP常规%, SP推荐%, SB%, SBV%

## HTML输出规范

### 样式要求
- 使用深色专业主题（深蓝/深灰背景 + 亮色文字）
- 指标卡片使用渐变色背景
- 风险等级用颜色编码（绿/黄/红）
- 图表使用Chart.js，通过CDN引入：`https://cdnjs.cloudflare.com/ajax/libs/Chart.js/4.4.1/chart.umd.min.js`
- 表格支持横向滚动（数据列较多时）
- 月度拆解卡片默认展开第1个月，其余收起
- 所有数据表默认收起，点击展开

### 响应式
- 在PC端宽度1200px下完整展示
- 卡片布局使用CSS Grid，小屏自动换行

### 文件输出
- 输出为单个HTML文件
- 文件名格式：`{ASIN}_竞品分析报告_{日期}.html`
- 保存到 `/mnt/user-data/outputs/`

## 数据不足时的处理

如果MCP工具未返回某些数据字段：
- 该字段显示 "—" 或 "数据缺失"
- 不要编造数据
- 在报告末尾注明哪些数据未获取到
- 建议用户通过其他渠道补充

## 示例调用流程

```
用户: 帮我分析一下 B0DFY7C9BK 这个竞品的推广节奏

Claude:
1. 调用 asin_detail 获取基础信息
2. 调用 keepa_info 获取历史趋势
3. 调用 asin_prediction 获取销量数据
4. 调用 traffic_keyword_stat 获取流量结构
5. 调用 traffic_listing_stat 获取流量来源
6. 整理数据，生成HTML报告
7. 保存到 /mnt/user-data/outputs/ 并 present_files
```
