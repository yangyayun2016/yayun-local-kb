# 每日广告诊断规则 v1.0

诊断层是「宏观」层：看账户/Campaign 每日 KPI 相对近期均值的变化趋势，
用于快速回答"今天广告是不是出问题了"，而不是逐词判断止损/待投放（那是中观/微观层，见另外两份文档）。

---

## 一、数据要求

需要一份**按天（Date 维度）汇总的广告数据**，覆盖至少最近 30 天，字段建议：

```
Date
Campaign Name（可选，不提供则按账户整体汇总）
Impressions
Clicks
Spend
Sales
Orders
```

如果同时能提供**总销售额（含自然流量）**，可以额外计算 TACOS；没有则只输出 ACOS/ROI，
并在报告中注明"TACOS 缺少自然销量数据，暂不可算"。

---

## 二、对比窗口定义

```
昨日（D-1）      = 数据中最新的一个完整自然日
近 7 日均值       = D-7 至 D-1 共 7 天的日均值（不含昨日单独展示，是"最近一周"的基线）
近 30 日均值      = D-30 至 D-1 共 30 天的日均值
```

> 如果数据不足 30 天，用实际可用天数计算均值，并在报告中标注"数据不足30天，均值为 N 天均值"。

---

## 三、诊断指标清单

每个指标都要输出：**昨日值 / 7日均值 / 30日均值 / 相对7日均值涨跌幅 / 相对30日均值涨跌幅 / 趋势符号**

| 指标 | 计算方式 |
|------|---------|
| 广告花费 Spend | 原始值求和 |
| 广告销售额 Sales | 原始值求和 |
| ACOS | Spend / Sales |
| TACOS | Spend / 总销售额（需自然销量数据） |
| ROI | (Sales × 广告前毛利率 − Spend) / Spend |
| 广告订单数 Orders | 原始值求和 |
| CVR | Orders / Clicks |
| CPC | Spend / Clicks |
| 预算打满率 | 实际花费 / 当日预算（Campaign 层，如有预算数据） |

**趋势符号规则：**
```
涨跌幅 = (昨日值 − 对比均值) / 对比均值

|涨跌幅| < 10%   → "→" 持平
涨跌幅 ≥ 10%     → "▲" 上升（对花费/ACOS/CPC 是坏信号，对 Sales/Orders/ROI 是好信号）
涨跌幅 ≤ -10%    → "▼" 下降（对花费/ACOS/CPC 是好信号，对 Sales/Orders/ROI 是坏信号）
```
注意"好坏"是反的：ACOS 的"▲"要标红提示，Orders 的"▲"要标绿提示。
输出报告时务必按指标类型标注好坏方向，不要让用户自己去猜箭头是好是坏。

---

## 四、诊断结论生成逻辑

按以下优先级给出**一句话结论**（放在诊断单最上方）：

```
1. IF 昨日 Spend 相对 7日均值 ▲ ≥ 30% AND 昨日 Orders 相对 7日均值 未同步上升
   → "花费异常放大但订单未跟上，疑似误触发竞价或新词抢量，需要立即核查"

2. IF 昨日 ACOS 相对 7日均值 ▲ ≥ 20% AND ACOS 已超过 breakeven（盈亏平衡ACOS）
   → "昨日广告已进入亏损区，建议立即执行止损模块"

3. IF 昨日 Orders 相对 7日均值 ▼ ≥ 30% AND Spend 未同步下降
   → "花费不变但转化骤降，优先检查 Listing / 库存 / 差评 / 竞对动作，而非直接砍广告"

4. IF 预算打满率 = 100% AND ACOS ≤ target_acos（健康区或优质区）
   → "预算是当前的增长瓶颈，建议提高日预算或转入待投放模块评估提价"

5. IF 近 7 日 ACOS 稳定在 floor~target 区间（健康区）AND 30日趋势平稳
   → "广告运行健康，无需干预"

6. 其他情况 → 输出各项指标涨跌，不强行给结论，交给用户结合词根/关键词层判断
```

---

## 五、异常问题模块（Anomaly Detection）

除了每日趋势诊断，还要单独扫描以下"结构性异常"，这些异常往往不是单纯 ACOS 能反映的：

| 异常类型 | 判定条件 | 建议动作 |
|---------|---------|---------|
| 花费骤增无转化 | Spend 昨日 ▲≥30%（vs 7日均值）且 Orders = 0 | 立即核查是否误触发广泛匹配/自动词抢量 |
| 展示量骤降但出价未变 | Impressions 昨日 ▼≥40%（vs 7日均值），Bid 未调整 | 检查 Listing 是否被抑制（差评/库存/合规） |
| CPC 骤增 | CPC 昨日 ▲≥25%（vs 7日均值） | 检查竞对是否加大出价，或类目竞争加剧 |
| 转化率骤降 | CVR 昨日 ▼≥40%（vs 7日均值），Clicks 样本 ≥20 | 优先查 Listing/价格/库存问题，而非否词 |
| 预算连续打满 | 连续 3 天预算打满率 = 100% 且 ACOS 健康 | 待投放模块：建议提预算 |
| 库存断货期异常 | 若提供库存数据，缺货期间的数据不纳入止损/待投放判断 | 标记为"数据不可用（缺货期）"，跳过该期间判断 |

**安全机制（与止损/待投放规则共用）：**
异常检测只负责"标红提示"，不直接触发自动执行动作——所有异常都归入"人工复核"清单，
因为异常往往是外部因素（竞对、Listing、库存）导致，不能靠广告规则单方面解决。
