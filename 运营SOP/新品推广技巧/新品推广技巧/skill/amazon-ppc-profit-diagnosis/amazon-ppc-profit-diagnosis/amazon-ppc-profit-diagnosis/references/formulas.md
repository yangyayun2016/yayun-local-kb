# 核心公式手册 v1.0

本文档是「广告利润诊断」Skill 的计算基础。所有脚本计算、诊断报告、止损/待投放建议，
最终都要能追溯到这里的某条公式。

---

## 一、术语约定（先统一口径，避免 gross_profit 歧义）

| 术语 | 英文字段 | 含义 |
|------|---------|------|
| 客单价 | selling_price | 单件售价（AOV，如果一单多件需换算成单均） |
| 单位毛利（广告前） | unit_profit_pre_ad | 售价 - COGS - FBA费 - 佣金 - 其他费用（**不扣广告费**） |
| 广告前毛利率 | pre_ad_margin | unit_profit_pre_ad / selling_price，等价于「盈亏平衡 ACOS」 |
| 广告后毛利 | net_profit | unit_profit_pre_ad × 销量 - 广告花费（**扣完广告费的最终毛利**） |
| 广告后毛利率 | post_ad_margin | net_profit / 总销售额 = 广告前毛利率 - ACOS |
| 目标 ACOS | target_acos | 卖家主动设定的广告花费占比目标 |
| 上调阈值 | acos_ceiling | 目标 ACOS 允许上浮的上限，超过则进入预警/止损区 |
| 下调阈值 | acos_floor | 目标 ACOS 允许下浮的下限，低于则视为"效率过高"，触发待投放评估 |

> ⚠️ 常见误区：很多人把"毛利率"默认理解成"广告前毛利率"，导致目标 ACOS 设置过于激进。
> 本 Skill 强制区分"广告前"与"广告后"，所有阈值判断都基于**广告前毛利率**（即盈亏平衡 ACOS）。

---

## 二、盈亏分析架构（核心公式）

```
广告前毛利率（盈亏平衡 ACOS） = (广告后毛利 + 广告花费) / 总销售额
                              = 广告前毛利 / 总销售额

广告后毛利率 = 广告前毛利率 - ACOS
```

**判断逻辑：**

```
ACOS < 广告前毛利率  →  广告盈利（每单广告后仍有净利）
ACOS = 广告前毛利率  →  广告盈亏平衡（广告后净利 = 0）
ACOS > 广告前毛利率  →  广告亏损（广告费吃掉了全部毛利，甚至倒贴）
```

**示例（历史基准值，可在规则配置中按产品覆盖）：**

```
该产品广告前毛利率历史范围：约 19%–29%，月均约 24%
→ Break-even ACOS ≈ 24%（默认值，用户可修改）
```

## 三、eCPM/CTR/CVR → 亚马逊广告核心公式映射

来自互联网广告的漏斗逻辑（曝光 → 点击 → 转化 → 收入）可以直接映射到亚马逊广告：

```
广告销售额 = 点击量 × CVR × 客单价
广告花费   = 点击量 × CPC
ACOS       = 广告花费 / 广告销售额
           = (点击量 × CPC) / (点击量 × CVR × 客单价)
           = CPC / (CVR × 客单价)
```

**由此反推 CPC 上限（按销售额/ACOS控制）：**

```
CPC 上限 = 目标 ACOS × CVR × 客单价
```

**示例：**
```
客单价 = $30，CVR = 10%，目标 ACOS = 30%
CPC 上限 = 30 × 10% × 30% = $0.90
```
→ 如果类目平均 CPC 已经高于 $0.90，说明这个类目长期很难做到 30% ACOS，
目标 ACOS 需要上调，或者转化率/客单价需要提升，否则该系列词根建议直接归入观察/止损候选。

## 四、按利润控制（而非只按销售额控制）

用销售额控制 ACOS 有个问题：不同产品毛利差异巨大，同样 30% ACOS，
毛利 50% 的产品很健康，毛利 20% 的产品可能已经在亏钱。所以要换算成"可承受广告成本"。

```
单笔订单可承受广告成本 (Max CPA) = 单位毛利（广告前）× 毛利牺牲比例

可承受 CPC = CVR × Max CPA
           = CVR × 单位毛利（广告前）× 毛利牺牲比例
```

**毛利牺牲比例（sacrifice_ratio）是本 Skill 的核心可调参数：**

| 牺牲比例 | 含义 | 适用阶段 |
|---------|------|---------|
| < 100% | 广告后仍保留部分毛利 | 成熟期产品，追求广告净利 |
| = 100% | 广告花光全部毛利，广告后净利=0 | 盈亏平衡投放（等价于 Break-even ACOS） |
| > 100% | 主动亏损做广告，用毛利以外的钱换排名/份额 | 新品冲排名、大促前蓄流量、清库存 |

**示例（用户提供的原始案例）：**
```
产品单位毛利 = $6
CVR = 8%（不考虑自然订单）
出单临界点击数 = 1 / CVR = 12.5 次点击出 1 单
毛利牺牲比例 = 100%（盈亏平衡）

可承受 CPC = 6 × 8% × 100% = $0.48
```
→ 只要类目平均 CPC 长期高于 $0.48，这个产品在 8% CVR 下，
长期很难在保本的情况下把 ACOS 做到理想水平——除非提升 CVR、涨价或提高牺牲比例（愿意亏本推广）。

## 五、广告出单临界值与预算测算

```
出单临界点击数 = 1 / CVR

广告预算（单均，即 CPA） = 出单临界点击数 × CPC
                        = CPC / CVR

目标 CPA = 目标 ACOS × 客单价
```

用途：判断某个 Search Term / Target 至少要跑够多少点击、花多少钱，
才有统计意义去判断"这个词到底出不出单"——这也是止损规则里
"最少观察点击数"（默认 20，来自 Amazon 官方建议）和"止损点击阈值"（默认 35）的计算依据。

## 六、目标 ACOS 的五档健康分区（上调阈值 / 下调阈值）

这是本 Skill 相比单纯"健康/不健康"二分法的核心增强：
**目标 ACOS 不是一条线，而是一个区间，区间外还要再分层。**

```
设：
  floor  = 下调阈值（Target ACOS × (1 − 下浮系数)）
  target = 目标 ACOS
  ceiling = 上调阈值（Target ACOS × (1 + 上浮系数)）
  breakeven = 广告前毛利率（盈亏平衡 ACOS）

五档分区（按 ACOS 从低到高）：

┌─────────────────────────────────────────────────────────────┐
│ ① 优质区    ACOS ≤ floor                    → 待投放候选（增量）│
│ ② 健康区    floor < ACOS ≤ target            → 维持现状        │
│ ③ 预警区    target < ACOS ≤ ceiling          → 观察，小幅降价   │
│ ④ 承压区    ceiling < ACOS ≤ breakeven       → 降价/降预算      │
│ ⑤ 亏损区    ACOS > breakeven                 → 止损（否词/关停）│
└─────────────────────────────────────────────────────────────┘
```

**默认阈值系数（可在规则配置中覆盖）：**
```
下浮系数 = 20%   →  floor   = target_acos × 0.8
上浮系数 = 20%   →  ceiling = target_acos × 1.2
```

**示例：**
```
目标 ACOS = 25%，下浮系数 20%，上浮系数 20%，Break-even ACOS = 36%

floor    = 25% × 0.8 = 20%
ceiling  = 25% × 1.2 = 30%
breakeven = 36%

分区：
  ACOS ≤ 20%        → ① 优质区，待投放
  20% < ACOS ≤ 25%  → ② 健康区，维持
  25% < ACOS ≤ 30%  → ③ 预警区，观察/小幅降价
  30% < ACOS ≤ 36%  → ④ 承压区，降价/降预算
  ACOS > 36%         → ⑤ 亏损区，止损
```

> 注意：分区只是"方向判断"，是否真的执行止损/待投放，还要结合订单量、点击量样本是否充足
> （见 `references/diagnosis-rules.md` 与 `references/scale-up-and-root-clustering.md`）。
> 有订单的对象即使落在④/⑤区，也优先降 bid 而不是直接否词——这条安全机制在所有子规则中保持一致。

## 七、TACOS / ROI 补充公式

```
TACOS = 总广告花费 / 总销售额（含自然+广告，需要 Business Report 或订单汇总数据）
ROAS  = 广告销售额 / 广告花费 = 1 / ACOS
ROI   = (广告销售额 × 广告前毛利率 − 广告花费) / 广告花费
      = 真实的广告投入产出比（比 ROAS 更准确，因为扣掉了成本）
```

TACOS 反映广告在整体生意中的依赖程度：TACOS 持续走高但销售额不涨，
说明自然流量在萎缩、广告在"续命"而非"增量"，需要在诊断报告中重点标记。
