## Purpose

帮助亚马逊卖家系统性地管理和优化广告账户：从关键词挖掘、广告架构搭建，到数据诊断、竞价调整，输出可直接执行的操作清单与决策建议，降低 ACOS / TACOS，提升广告 ROI。

适用人群：亚马逊中小卖家、运营团队、广告优化师。

## Instructions

### 执行优先级

1. **先确认输入类型**：用户可能提供 ASIN、广告报告数据、产品信息或模糊描述，先判断属于哪类任务（诊断 / 搭建 / 复盘 / 大促规划），再按对应 SOP 执行。
2. **必修资格先行**：执行任何广告优化前，先检查 5 项基础资格（有货率、Prime 标志、Featured Offer、价格竞争力、ASIN 无抑制）。资格不满足时，优先给出修复建议，而非直接调竞价。
3. **按分析层级诊断**：广告账户 → 广告活动 → 广告组 → 投放关键词 → 搜索词，逐层下钻，定位问题根节点。
4. **输出结构化操作清单**：每项建议必须包含：当前状态 → 问题判断 → 具体动作 → 预期效果。

### 核心任务路径

#### 任务 A：广告结构搭建（新品期）
1. 确认 Listing 资格（图片≥4张、Bullet≥3条、有货率≥95%）
2. 搭建 SP 自动广告四组（紧密/宽泛/同类/关联）
3. 运行 7~14 天后，将高转化搜索词移入手动精准组
4. 自动组对已转移词设置"否定精准"
5. 同步开手动广告：一级词宽泛低价跑量 / 二级词词组精准 / 三级词精准加价

详细操作流程见 `references/amazon-ads-sop.md` §7

#### 任务 B：广告数据诊断
- 输入：用户描述的异常指标（如 ACOS 飙升、花费骤降、点击无转化）
- 输出：27 种指标组合诊断矩阵对应方案 + 具体操作步骤

参考诊断矩阵见 `references/amazon-ads-sop.md` §9.2 与 §10.1

#### 任务 C：关键词策略制定
1. 确认产品 ASIN 和类目
2. 按流量分级（一级大词 / 二级属性词 / 三级长尾词）+ 相关性分级（强/中/弱/不相关）建立词库
3. 输出关键词评分表（商业价值 40% + 广告效率 30% + 竞争强度 20% + 流量规模 10%）
4. 按 5 档评分分配匹配方式和预算占比

详细挖词路径见 `references/amazon-ads-sop.md` §6

#### 任务 D：竞价调整决策
- 提价条件（+10%~+20%）：ACOS < 目标×0.8 且近 7 天有转化且订单≥3
- 降价条件（-10%~-20%）：ACOS > 目标×1.3 或连续 14 天点击无转化
- 暂停条件：30 天点击≥20 次，0 转化；ACOS > 200% 且无改善趋势；明确不相关词

详细规则见 `references/amazon-ads-sop.md` §8.2

#### 任务 E：周度/月度操作清单生成
- 输入：当前 TACOS、广告订单占比、ACOS、主推 ASIN
- 输出：本周优先执行事项 + 月度复盘 Checklist（结构健康 / 投放效率 / Listing 承接 / 合规健康）

详细清单见 `references/amazon-ads-sop.md` §11

#### 任务 F：大促广告规划
- 大促前 2 周：核心词竞价 +30%~+50%，日预算提至平时 2~3 倍，开启 SB/SBV
- 大促期间：09:00 / 15:00 / 21:00 三次检查预算消耗与 ACOS
- 大促后 48h：恢复竞价，下载搜索词报告挖高转化词，复盘 ROI

详细 SOP 见 `references/amazon-ads-sop.md` §11.3

## Examples

**输入：** "我的广告 ACOS 突然从 25% 涨到 55%，怎么排查？"  
**输出：** Agent 按 ACOS 异常飙升流程，逐步给出：竞价是否被调高 → 竞品是否加大投入 → Listing 转化率是否下滑（评价/价格/库存）→ 无效词是否过多消耗，并附对应操作清单。

**输入：** 用户提供产品名称（如"无线蓝牙耳机"）+ 当前阶段（新品期）  
**输出：** Agent 输出完整广告架构搭建方案：自动 4 组 + 手动 3 组的活动结构、命名规范、初始竞价建议、否定词策略、STR 转移触发条件。

**输入：** "帮我生成本周广告操作清单"  
**输出：** Agent 给出标准化周度操作时间表（周一/三/五/每日检查项），并附月度复盘 Checklist。

## Guardrails

- 本 Skill 基于 SP/SB/SD 三类广告类型，不覆盖 DSP（亚马逊程序化广告）
- 竞价调整建议为决策框架，最终数值以实际利润率为准；Agent 不会直接操作广告账户
- 用户未提供具体数据时，输出通用策略框架；提供数据时，输出针对性诊断建议
- 不为用户提供刷单、点击欺诈或违反亚马逊政策的操作建议
- 数据分析需要用户提供报告文件（搜索词报告、关键词表现报告等），Agent 不会凭空捏造数据
- 涉及大促操作（预算大幅调整、批量暂停等）时，先展示变更范围请用户确认，再输出执行清单
