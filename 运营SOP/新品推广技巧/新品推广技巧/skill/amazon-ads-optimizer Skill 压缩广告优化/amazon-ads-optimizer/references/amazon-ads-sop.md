## 一、广告基础认知

### 1.1 核心理念

> 广告的本质不是"花钱买流量"，而是**把有购买意图的用户从正确曝光一路护送到下单**。

亚马逊转化率不是单一页面元素的结果，而是：

**流量匹配度 × 详情页信息质量 × 价格与配送吸引力 × 信任信号 × 可购买性资格** 共同作用的产物。

### 1.2 广告与自然流量的关系

```
广告投放 → 点击量↑ → 关键词排名↑ → 自然曝光↑ → 自然出单↑ → ACOS↓
```

广告的长期价值不只是直接出单，更是**通过广告积累关键词排名，降低对广告的依赖度（TACOS）**。

### 1.3 广告投放的四个核心变量

| 变量 | 公式 | 说明 |
|------|------|------|
| 曝光量（E） | — | 流量入口，受竞价、关键词、Listing质量影响 |
| 点击率（CTR） | 点击量 / 曝光量 | 反映广告吸引力 |
| 转化率（CVR） | 广告订单 / 点击量 | 反映 Listing承接能力 |
| ACOS | 广告花费 / 广告销售额 | 核心盈亏指标 |

**ROI公式：**  
`ROI = (广告订单量 × 单价 × 利润率) / (点击量 × CPC)`

**ROAS公式：**  
`ROAS = 广告销售额 / 广告花费 = ACOS的倒数`

## 二、三大广告类型

### 2.1 商品推广（Sponsored Products，SP）

| 项目 | 说明 |
|------|------|
| 适用场景 | 任何阶段，核心广告类型 |
| 广告位置 | 搜索结果顶部 / 其他位置 / 商品详情页 |
| 素材类型 | 不可自定义（系统自动抓取主图+标题） |
| 投放方式 | 自动投放 + 手动投放（关键词匹配 & 商品匹配） |
| 落地页 | 商品详情页 |
| 竞价增幅上限 | 搜索结果首页顶部 ≤100% / 其他位置 ≤50% |
| 优先级 | ★★★★★ |

**SP自动投放四种匹配类型：**

| 匹配类型 | 说明 | 适用场景 |
|----------|------|----------|
| 紧密匹配（Close Match） | 与商品紧密相关的搜索词 | 精准曝光，优先开启 |
| 宽泛匹配（Loose Match） | 与商品不紧密相关的词 | 探索长尾词 |
| 同类商品（Substitutes） | 类似商品详情页展示 | 竞品拦截 |
| 关联商品（Complements） | 互补商品详情页展示 | 互补场景曝光 |

> 搜索结果页表现好 → 加重**紧密+宽泛**匹配  
> 商品详情页表现好 → 加重**同类+关联**商品投放

---

### 2.2 品牌推广（Sponsored Brands，SB）

| 项目 | 说明 |
|------|------|
| 适用场景 | 品牌旗舰店上线后，扩大品牌知名度 |
| 广告位置 | 搜索结果顶部 & 底部 |
| 素材类型 | 可自定义（品牌Logo + 标语 + 商品组合） |
| 投放方式 | 手动投放（关键词匹配 & 商品匹配） |
| 落地页 | 品牌旗舰店 / 商品集合页 / 视频页面 |
| 竞价增幅 | 无额外增幅限制 |
| 优先级 | ★★★★☆ |

**SBV（品牌推广视频）** 适用于有高质量产品视频的卖家，点击率通常高于普通SP广告。

---

### 2.3 展示型推广（Sponsored Display，SD）

| 项目 | 说明 |
|------|------|
| 适用场景 | 再营销 / 竞品ASIN拦截 / 品类覆盖 |
| 广告位置 | 登录页 / 搜索结果左侧&顶部 / 商品详情页 / 下单页面 |
| 素材类型 | 可自定义 |
| 投放方式 | 手动投放（商品匹配 & 再营销浏览定向） |
| 落地页 | 商品详情页 |
| 竞价增幅上限 | 最高可提高 ≤300% |
| 优先级 | ★★★☆☆ |

---

### 2.4 广告类型预算分配建议

| 广告类型 | 新品期 | 成长期 | 成熟期 |
|----------|--------|--------|--------|
| SP | 100% | 70% | 60% |
| SB | 0% | 20% | 25% |
| SD | 0% | 10% | 15% |

## 三、核心指标体系

### 3.1 广告核心指标定义

| 指标 | 定义 | 公式 | 健康范围 | 警戒线 |
|------|------|------|----------|--------|
| **ACOS** | 广告花费占广告销售额比例 | 广告花费 / 广告销售额 | 15%—35% | >50% |
| **TACOS** | 广告花费占总销售额比例 | 广告花费 / SKU总销售额 | 8%—15% | >20% |
| **CTR** | 广告点击率 | 点击量 / 曝光量 | 0.3%—0.5% | <0.1% |
| **CVR** | 广告转化率 | 广告订单 / 点击量 | 10%—25% | <5% |
| **CPC** | 每次点击费用 | 广告花费 / 点击量 | 视类目 | >利润40% |
| **CPA** | 每个广告订单成本 | 广告花费 / 广告订单量 | — | >毛利润 |
| **ROAS** | 广告花费回报率 | 广告销售额 / 广告花费 | >3 | <2 |
| **广告订单占比** | 广告依赖度 | 广告订单 / 总订单 | 30%—50% | >70% |

### 3.2 CPC扣费原理

```
你的CPC = (下一位的Bid × 下一位的质量得分) / 你的质量得分 + $0.01
```

> 质量得分高 → 相同ACOS下可以用更低竞价占据更好位置

### 3.3 三大广告位特性对比

| 广告位 | 曝光量 | 点击率 | 转化率 | 竞价增幅上限 |
|--------|--------|--------|--------|-------------|
| 搜索结果首页顶部 | 低 | 高 | 高 | ≤100% |
| 商品详情页面 | 高 | 低 | 低 | ≤50% |
| 搜索结果其他位置 | 中 | 中 | 中 | ≤50% |

**策略建议：** 主推词优先攻打**首页顶部**，竞品拦截用**商品页**，预算不足时降低**其他位置**溢价。

## 四、影响点击率的因素

### 4.1 产品因素（Listing层面）

**高优先级因素（直接影响CTR）：**

| 因素 | 优化方向 |
|------|----------|
| **主图质量** | 高对比度、单主体、少干扰；长边≥1000px支持缩放；场景图/尺寸对比图提升吸引力 |
| **标题** | 简洁明了，核心词前置；结构：品牌+品类+核心属性+规格；避免堆词 |
| **价格竞争力** | 参考竞品中位价格；保持到手价在竞争区间内 |
| **评分与评价数** | 目标：≥4.0星，≥15条评价；首页无差评优先处理 |
| **促销标签** | Coupon/折扣/30天最低价/划线价 → 直接提升搜索页吸引力 |
| **亚马逊标签** | Best Seller / Amazon Choice / Hot New Release → 社会认同信号 |
| **秒杀活动** | LD / BD / DOTD → 紧迫感驱动点击 |
| **Prime标志** | 有Prime标志的ASIN CTR和CVR均更高 |
| **多变体展示** | 广告中展示多颜色/尺码属性（需设置折扣触发显示） |

### 4.2 广告因素

| 因素 | 说明 | 操作建议 |
|------|------|----------|
| **关键词精准性** | 投放词与搜索意图匹配度 | 大词用宽泛低价跑，长尾词精准匹配 |
| **竞价高低** | 直接决定广告位置 | 竞价低 → 广告位靠后 → CTR差 |
| **广告预算** | 预算不足 → 广告提前停投 → 全天覆盖率低 | 保证全天预算不断 |
| **否词设置** | 否词过多屏蔽大词 → 曝光量骤降 | 精准否定，避免过度否定 |
| **广告时段** | 投放时间段影响流量质量 | 分析订单时间分布，按需设置时段 |
| **库存状态** | 低库存/断货 → 广告被限/失效 | 广告期间保证≥15天库存 |
| **购物车赢得率** | 没有Featured Offer → 广告无效 | 先获得购物车资格再投广告 |
| **账号绩效** | 账号健康问题影响广告展示 | 保持ODR<1%，账号健康绿色 |

## 五、影响转化率的因素

> 来源：亚马逊CVR 100因素研究报告（按优先级分组）

### 5.1 必须先修复的资格类因素

**这些因素不修复，广告流量再大也无效：**

| 因素 | 操作 |
|------|------|
| 有货率（In-stock Rate） | 保持≥95%，断货立即停广告 |
| Prime资格 | FBA或SFP获取Prime标志 |
| Featured Offer（购物车） | 稳定赢得首选购买按钮≥90% |
| 价格竞争力 | 到手价相对竞品保持合理区间 |
| 免费配送 | 尽量提供免费/Prime配送方案 |
| 页面无抑制状态 | 定期检查ASIN是否被suppressed |

### 5.2 页面内容优化（影响CTR和CVR）

| 因素 | KPI | 操作建议 |
|------|-----|----------|
| 标题可读性 | CTR、CVR | 1秒内读懂品类+核心属性；结构：品牌+品类+属性+规格 |
| 类目归属准确 | 搜索曝光率、CVR | 修正误分类，确保与搜索意图一致 |
| 关键属性完整率 | 筛选曝光率 | 填满尺寸/材质/兼容/年龄段等关键属性 |
| Bullet数量与覆盖率 | CVR、退货率 | ≥5条；覆盖用途/尺寸/限制/产地等 |
| Bullet利益点优先 | 停留时长、CVR | 每条Bullet用"场景收益+证据"写法 |
| 规格参数完整性 | 退货率、Q&A | 明确尺寸/容量/兼容型号/适用边界 |
| 变体关系正确性 | 变体跳失率 | 整理父子体逻辑，避免错误合并 |

### 5.3 视觉内容优化

| 因素 | 预期影响 | 操作建议 |
|------|----------|----------|
| 主图辨识度 | CTR +5%~+20% | 高对比、单主体、少干扰的主图 |
| 图片数量 | CVR +2%~+10% | 目标6~8张；至少4张 |
| 多角度展示 | 退货率↓ | 正/侧/接口/底部/附件全覆盖 |
| 尺寸/比例信息图 | 退货率↓、CVR↑ | 用实物/真人/场景给尺寸参照 |
| 使用场景图 | CVR +1%~+8% | 增加真实使用场景，减少抽象展示 |
| 视频覆盖率 | CVR +2%~+10% | 做15~45秒功能/开箱/安装视频 |
| 细节特写 | 退货率↓ | 对易被质疑的工艺/材质/结构给局部特写 |

### 5.4 A+内容与品牌旗舰店

| 因素 | 预期影响 | 操作建议 |
|------|----------|----------|
| Basic A+ | CVR +3%~+10% | 品牌备案后优先给主推ASIN上A+ |
| Premium A+ | CVR +4%~+15% | 高客单/强讲解型品类优先上Premium |
| A+风险消除内容 | 退货率↓、CVR↑ | 在A+里显式讲兼容/尺寸/材质/限制 |
| 品牌比较表 | AOV↑ | 用比较表减少"选错型号"风险 |
| 品牌旗舰店 | 新客CVR↑ | 建Store作为品牌流量和广告落地页 |
| Store移动端优化 | 移动CVR↑ | 用移动预览反复检查首屏与下拉导航 |

### 5.5 价格与促销

| 因素 | 预期影响 | 操作建议 |
|------|----------|----------|
| 相对价格指数 | CTR/CVR +5%~+25% | 建立竞品价格监控，核心词下保持合理区间 |
| 免费配送可得性 | CVR +2%~+15% | 尽量提供免费配送或Prime方案 |
| 优惠券使用率 | CVR +2%~+10% | 对主推ASIN做"小额高感知"Coupon测试 |
| 首选买方价格竞争力 | Featured Offer% +3%~+20% | 监控被抢购物车的价格阈值 |
| 促销与广告联动 | 促销ROAS↑ | 促销前3~7天预热，期间保障预算全覆盖 |

### 5.6 用户评价与信任

| 因素 | 预期影响 | 操作建议 |
|------|----------|----------|
| 星级均值 | CVR +5%~+25% | 先解决低星根因，再扩量 |
| 评价数量 | CVR +3%~+20% | 冷启动期优先积累前10/30/50条 |
| 近期评价增速 | CVR↑ | 持续积累真实评价，不只看总量 |
| 低星评价集中问题率 | CVR +2%~+15% | 用主题聚类修复头部痛点 |
| Q&A覆盖率 | CVR +1%~+8% | 对高频疑虑建立FAQ与图文解答 |
| Vine冷启动 | 首批评价时间↓ | 新品/新变体谨慎使用Vine |
| 退货率 | CVR质量指标 | 把退货率当"转化质量KPI"而非售后KPI |

## 六、关键词策略 SOP

### 6.1 关键词分层体系

**流量分级（3级）：**

| 等级 | 定义 | 周搜索量参考 | 广告策略 |
|------|------|-------------|----------|
| 一级词（大词） | 品类核心词，流量最大 | >10,000 | 宽泛匹配低价跑，搜漏流量 |
| 二级词（中词） | 属性词/场景词，中等流量 | 1,000~10,000 | 词组/精准匹配，重点投放 |
| 三级词（长尾词） | 高意图长尾词 | <1,000 | 精准匹配，高转化加价 |

**关键词相关性分级（4级）：**

| 等级 | 说明 | 广告处理 |
|------|------|----------|
| 强相关 | 核心品类词，意图完全贴合 | 精准匹配，核心投放 |
| 中相关 | 属性相关，部分意图匹配 | 词组匹配，测试投放 |
| 弱相关 | 边缘关联，意图不确定 | 宽泛匹配低价探索 |
| 不相关 | 品类不符，意图背离 | 设为否定词 |

### 6.2 关键词挖掘路径

**Step 1：竞品反查（核心步骤）**
```
① 找10个最相近竞品ASIN
② 在SIF多产品对比 → 下载流量数据
③ 用AI（Claude/Gemini）分析：流量分级 + 相关性分级 + 周搜索量 + 流量垄断度
```

**Step 2：卖家精灵拓词**
```
① 选取20个竞品ASIN
② 关键词优化 → 拓展流量词
③ 下载数据 → 关键词词库追踪
④ AI打标分类
```

**Step 3：品类拓词**
```
① SIF选细分品类 → 下载品类拓词数据
② 人工相关性筛查
③ 补充长尾词库
```

**Step 4：商机探测器验证**
```
① 后台商机探测器 → 份额占比分析
② 确认大词搜索量真实性
③ 识别细分需求词
```

**Step 5：词频统计**
```
分析1词根 / 2词根 / 3词根的搜索量加权词频
→ 找出高频修饰词（型号/属性/场景/竞品品牌）
```

### 6.3 关键词评分算法（选词逻辑）

**综合评分 = 商业价值（40%）+ 广告效率（30%）+ 竞争强度（20%）+ 流量规模（10%）**

**广告投放分类（按评分5档）：**

| 档位 | 分数区间 | 日预算占比 | 匹配方式 |
|------|----------|-----------|----------|
| 最高优先级（核心投放） | ≥80 | 25%~35% | 精准匹配 |
| 高优先级（重点投放） | 65~79 | 15%~25% | 精准+词组 |
| 正常投放 | 50~64 | 10%~15% | 词组匹配 |
| 值得测试 | 35~49 | 5%~10% | 宽泛匹配 |
| 小额测试 | 20~34 | <5% | 宽泛低价 |
| 暂不投放 | <20 | 0% | 加否定词 |

## 七、广告结构搭建 SOP

### 7.1 推荐广告架构

```
广告账户
  ├── [新品探索层] SP自动广告
  │     ├── 紧密匹配组（Close Match）
  │     ├── 宽泛匹配组（Loose Match）
  │     ├── 同类商品组（Substitutes）
  │     └── 关联商品组（Complements）
  │
  ├── [核心流量层] SP手动精准广告
  │     ├── 一级核心词组（精准匹配，高竞价）
  │     ├── 二级属性词组（精准+词组，中竞价）
  │     └── 三级长尾词组（精准匹配，低竞价）
  │
  ├── [品牌防守层] SP手动精准 - 品牌词
  │     └── 自身品牌词（防止竞品截流）
  │
  ├── [竞品拦截层] SP商品定向
  │     └── 竞品ASIN定向（高评分竞品详情页）
  │
  └── [品牌扩张层] SB / SBV / SD
        ├── SB品牌词广告（品牌认知）
        ├── SBV视频广告（高转化场景）
        └── SD再营销（浏览过未购买人群）
```

### 7.2 广告分组原则

1. **不同变体分组投放**（颜色/尺码不同的SKU分开组）
2. **同一投放词不同匹配方式分组**（精准/词组/宽泛分开）
3. **不同词根的投放词分组投放**
4. **大类目核心关键词 1v1 投放**（一个广告活动对应一个广告组一个关键词）

### 7.3 STR搜索词转移流程（核心优化动作）

```
自动广告发现高转化词
        ↓
移入手动精准广告组（精准匹配，提高竞价）
        ↓
在自动广告组中将该词设为「否定精准」
        ↓
手动精准组持续优化竞价 → 成为核心出单词
```

### 7.4 广告活动命名规范

**建议格式：** `[品类]_[广告类型]_[匹配类型]_[日期]`

例：
- `耳机_SP_Auto_20260101`
- `耳机_SP_Exact_核心词_20260101`
- `耳机_SB_品牌词_20260101`

## 八、竞价策略 SOP

### 8.1 三种竞价策略选择

| 策略 | 说明 | 适用场景 |
|------|------|----------|
| **固定竞价** | 不随转化率调整，保证曝光量 | 新品期/数据收集期；查看竞价直接效果 |
| **动态竞价-提高或降低** | 高转化机会提价≤100%（首页）/ ≤50%（其他）；低转化降价 | 成长期/成熟期主流策略，提升转化效率 |
| **动态竞价-仅降低** | 只降不升，控制广告费 | 滞销品清库存；不主推商品 |

**新品期推荐：** 固定竞价（收集数据）→ 转为动态提高降低（优化效率）

### 8.2 竞价调整规则

**提高竞价（+10%~+20%）条件：**
- ACOS < 目标ACOS × 0.8
- 点击量高但展示量不足（排名不够）
- 近7天该词有转化，订单≥3

**降低竞价（-10%~-20%）条件：**
- ACOS > 目标ACOS × 1.3
- 连续14天点击无转化
- 单次点击成本 > 产品利润 × 30%

**暂停关键词条件：**
- 30天点击≥20次，0转化
- ACOS > 200% 且无改善趋势
- 明确不相关词（已人工确认）

### 8.3 否定词操作规则

| 否定类型 | 适用场景 |
|----------|----------|
| 否定精准 | 已在手动精准组投放的词（防内耗） |
| 否定词组 | 明显不相关词/竞品品牌词 |
| 广告组级否定 | 针对特定广告组过滤 |
| 广告活动级否定 | 全局过滤，**谨慎使用** |

## 九、广告数据分析 SOP

### 9.1 分析层级框架

**五个分析维度，从上到下逐层诊断：**

```
① 广告活动层  → 关注：超预算时间、总点击量、广告位分布
② 广告组层    → 关注：转化率、CPC、ACOS对比
③ 投放关键词层 → 关注：点击率、转化率、ACOS/ROI
④ 搜索词层    → 关注：点击量、转化率（判断否定/拓词）
⑤ 推广商品层  → 关注：点击量、转化率（判断暂停/重点推广）
```

### 9.2 广告指标27种组合诊断矩阵

**曝光量（低/中/高）× 点击率（低/中/高）× 转化率（低/中/高）+ 0转化3种 = 30种情况**

**高频核心场景诊断：**

| 组合 | 问题诊断 | 优化方向 |
|------|----------|----------|
| 高曝光_低CTR_低CVR | 关键词相关性差或主图吸引力弱 | 优化主图/标题，或否定该词 |
| 高曝光_高CTR_低CVR | Listing承接能力差（详情页问题） | 优化价格/图片/评价/A+ |
| 中曝光_高CTR_高CVR | **最理想状态** | 提高竞价扩大曝光 |
| 低曝光_高CTR_高CVR | 竞价不足 | 提高竞价争取更多曝光 |
| 高曝光_低CTR_高CVR | 主图/标题需优化但产品质量好 | 优化搜索页展示元素 |
| 任意曝光_高点击_0转化 | Listing严重问题（价格/评价/缺货） | 立即检查Listing所有要素 |
| 低曝光_低CTR_低CVR | 竞价过低+关键词不精准 | 提价或换词 |

### 9.3 搜索词报告分析四步法

**Step 1：** 下载过去7天搜索词报告

**Step 2：** 筛选点击量≥5的词

**Step 3：** 分类处理：

```
有转化 + ACOS达标      → 加入手动精准，提高竞价
有转化 + ACOS超标      → 降低竞价或否定
无转化 + 点击≥15次    → 否定该词
无转化 + 点击<5次     → 继续观察
不相关词（任何点击量）→ 否定词组或否定精准
```

**Step 4：** 每周将高转化搜索词更新到关键词词库

### 9.4 必备报告类型

| 报告名称 | 下载频率 | 核心用途 |
|----------|----------|----------|
| 搜索词报告 | 每周 | 发现新词 / 否定无效词 |
| 关键词表现报告 | 每周 | 竞价调整依据 |
| ASIN表现报告 | 每月 | 评估广告素材效果 |
| 广告活动报告 | 每月 | 整体结构复盘 |
| Rufus提示词报告 | 每月 | 优化AI搜索覆盖 |

## 十、广告优化决策矩阵

### 10.1 ACOS异常处理流程

**ACOS突然飙升：**
```
1. 检查竞价是否被调高
2. 检查竞品是否加大投入（抬高CPC）
3. 检查Listing转化率是否下降（评价/价格/库存）
4. 降低无效词竞价，暂停高点击0转化词
```

**ACOS异常低（可能流量不足）：**
```
1. 检查广告预算是否提前耗尽
2. 检查关键词竞价是否过低
3. 检查展示量是否正常
4. 适度提高竞价扩大曝光
```

**CTR突然下降：**
```
1. 检查主图是否被修改或被竞品超越
2. 检查价格竞争力（是否被竞品低价打压）
3. 检查Review数量变化（负评影响）
4. 检查是否丢失促销标签/BS标签
```

**转化率下降：**
```
1. 检查Listing内容是否被篡改
2. 检查近期差评根因
3. 检查库存/发货时效
4. 检查价格是否失去竞争力
```

**广告花费骤降：**
```
1. 检查预算是否提前耗尽（调高日预算）
2. 检查关键词竞价是否过低
3. 检查广告活动/广告组状态
4. 检查ASIN是否被抑制
```

### 10.2 广告优化四层路径

```
Layer 1：先修资格（1~2周）
  → 保价格、补库存、抢Prime、修Featured Offer、清抑制、补≥4张图和3条Bullet
  → 先止损，恢复CTR/CVR基线

Layer 2：修详情页核心疑虑（2~6周）
  → 重拍主图/尺寸图/场景图；修标题；补兼容与规格；建FAQ；上Basic A+
  → 提升ATC与CVR，降低退货

Layer 3：修搜索与广告错配（4~8周）
  → 用SQP找高点击低转化查询；做否定词；建自动+手动双层；保证全天预算覆盖
  → 提升高意图流量占比与ROAS

Layer 4：品牌与复购系统（1~2个季度）
  → 建/改Brand Store；Store移动端优化；配合SB/Display/站外流量；季度更新
  → 提升品牌新客、AOV与跨品复购
```

## 附录：常见问题 FAQ

| 问题 | 解答 |
|------|------|
| 新品应该先开自动还是手动？ | 先开自动广告7~14天积累数据，再同步开手动精准 |
| 广告预算如何分配？ | SP 70% / SB 20% / SD 10%；新品期100%投SP |
| 什么时候暂停广告？ | 库存不足15天时暂停，防止断货损伤排名 |
| 自动和手动竞价哪个更高？ | 通常手动精准竞价更高；自动广告中等竞价作为探词工具 |
| ACOS高就要降预算吗？ | 不一定。先排查关键词质量还是Listing转化问题，针对性处理 |
| 广告没有曝光怎么办？ | 检查：竞价是否过低→预算是否不足→关键词是否有搜索量→Listing是否被抑制 |
| 点击多但不出单怎么办？ | 检查：价格竞争力→评价状态→主图/标题→库存/配送时效→是否低意图流量 |
| TACOS高说明什么？ | 广告依赖度高，自然流量占比低；需要通过广告积累关键词排名提升自然出单 |
