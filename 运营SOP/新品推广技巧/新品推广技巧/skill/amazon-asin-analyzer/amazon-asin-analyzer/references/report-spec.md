# 竞品分析报告结构规范

## HTML 输出规范

- 单文件 HTML，内联 CSS + Chart.js（CDN: https://cdnjs.cloudflare.com/ajax/libs/Chart.js/4.4.1/chart.umd.min.js）
- 深色专业主题（深蓝/深灰背景 + 亮色文字）
- 指标卡片使用渐变色背景
- PC 端宽度 1200px 完整展示，CSS Grid 卡片布局小屏自动换行
- 表格支持横向滚动
- 月度拆解卡片默认展开第 1 个月，其余收起；所有数据表默认收起

---

## 报告模块顺序

### 模块 1：报告头部

- 标题：`[ASIN] 竞品前4个月推广节奏分析报告`
- 分析周期：YYYY-MM-DD ~ YYYY-MM-DD
- 核心指标卡片（横排 4 个）：前4月总销量 / 前4月销售额 / 累计评论增长 / 大类最佳排名(BSR)

---

### 模块 2：关键时间节点（Timeline 样式）

| 节点 | 说明 |
|------|------|
| 首次上架 | YYYY-MM-DD |
| 最早出单 | YYYY-MM-DD |
| 首条评论 | YYYY-MM-DD |
| 首次改价 | YYYY-MM-DD |
| 首次 DEAL | YYYY-MM-DD，价格 XXX |
| 首次 COUPON | YYYY-MM-DD |
| 首次 PRIME | YYYY-MM-DD |

---

### 模块 3：核心趋势图表（Chart.js）

**图表 A — 排名/成交价/评论数综合趋势（组合图）**
- X轴：日期
- Y轴左：大类排名 BSR（折线，反转轴）+ 小类排名（折线）
- Y轴右：成交价（折线）+ 评论数（面积图）

**图表 B — 月度销量结构对比（堆叠柱状图）**
- X轴：月份
- 三组柱：全部流量销量 / 自然流量销量 / 广告流量销量

**图表 C — 月度新增评论数（柱状图）**
- X轴：月份 / Y轴：新增评论数

---

### 模块 4：前4个月汇总表

每行一个月，列：月份 / 策略标签 / 销量 / 成交价 / 大类BSR最佳 / 小类最佳 / 评论数 / 留评率 / 广告费占比 / 新增广告

**策略标签自动判断逻辑：**
- 第1个月：成交价低于后续月均值 → `低价切入+评论拉升`
- 第2-3个月：排名波动 < 20% → `排名维持期`；否则 → `排名回落观察`
- 第4个月：广告占比上升 → `广告调整+排名冲刺`

---

### 模块 5：月度推广节奏拆解（核心模块，可折叠卡片）

每月卡片包含：

**■ 销量与排名**
销量、成交额、大类排名最佳、小类排名最佳

**■ Listing 策略**
标题修改N次，主图修改N次，点击率优化动作

**■ 价格策略**
月初→月末成交价，月均价，BuyBox区间，关键改价点，LD活动次数

**■ 评论策略**
评论从X增至Y，月新增Z，留评率X%，评分，评论质量（强/中/弱）

**■ 流量策略**
全部流量，自然/广告占比，新增广告次数，SP常规/推荐占比

**■ 风险判断（颜色标记）**

| 条件 | 风险等级 |
|------|---------|
| 留评率 > 3% | 🔴 需警惕刷单风险 |
| 留评率 1~3% | 🟡 略高，需观察 |
| 广告占比 < 5% 但排名快速上升 | 🟡 排名来源不明 |
| 月增评论 > 100 且留评率 > 5% | 🔴 高度疑似刷单 |
| 其他 | 🟢 正常 |

---

### 模块 6：效果总结

- 大类排名变化：从 XXXXX → XXXX（最佳 / 最差）
- 小类排名最佳
- 累计销量 / 累计成交额

### 模块 7：明细数据表（可折叠，默认收起）

提供以下维度表格，每个支持折叠展开：

1. 全量明细
2. 前4月明细
3. 前8周明细
4. 近N月聚合
5. 前N月聚合
6. 第N月聚合
7. 第N周聚合

**每表列字段：**
日期 / 大类排名MIN / 小类排名MIN / 卖家数 / 销量 / 成交额 / 成交价 / 定价MAX / 定价MIN / LD数 / 评论数 / 评分 / 新增评论 / 留评率 / 新增广告 / 修改标题 / 修改主图 / 全部流量 / 自然流量 / 广告流量 / 自然% / 广告% / SP常规% / SP推荐% / SB% / SBV%
