## Purpose

为亚马逊卖家和选品团队提供从**数据层 → 算法层 → 交付层**的全链路市场调研洞察，覆盖：

- **市场洞察报告（MarketingInsight）**：基于亚马逊底层数据（销量、BSR、关键词、评分、品牌集中度），识别款式心智/趋势矩阵、市场进入难易程度、机会款式、竞争格局
- **消费者洞察报告（ConsumerInsight）**：基于 VOC（用户评论）+ 社媒讨论，输出三圈层信息生态模型、关键人群画像、JTBD 映射、KANO 需求矩阵
- **产品成功方案（ProductSolution）**：结合上述两层洞察，给出差异化产品定义、定价策略、GTM 路径、商业可行性预测，命名规范遵循 **LUXEPET PRO** 品牌标准

## Instructions

### 第一步：理解输入

用户输入可以是：
- 类目名称（如 "towel warmer bucket"、"electric golf caddy"）
- 关键词或 ASIN
- 已有市场数据（CSV/文本粘贴）
- 明确指定输出哪份报告（市场洞察 / 消费者洞察 / 产品方案，或三份全出）

若用户只提供类目名称，使用卖家精灵 MCP 工具自动查询数据（`sellersprite_product_node`、`sellersprite_market_research_statistics`、`sellersprite_market_product_concentration`、`sellersprite_market_brand_concentration`、`sellersprite_market_price_distribution`、`sellersprite_market_seller_type_concentration`、`sellersprite_market_rating_distribution`、`sellersprite_market_ratings_count_distribution`）

### 第二步：数据建模（底层数据层 → 算法层）

#### 2.1 款式识别与打标
- 从搜索量、销量数据中识别 2-5 个核心"心智款式"（Style Labels）
- 对每款计算：趋势动能（Momentum）= 综合近期搜索增长率 × 销量规模
- 对每款计算：市场份额（Market Share）= 该款 SKU 销量 / 全品类总销量

#### 2.2 波士顿战略矩阵定位
- 高动能 + 高份额 → **核心主流（Core Mainstream）**：乱世争霸赛
- 高动能 + 低份额 → **新星爆发（Emerging Stars）**：黄金选品机会
- 低动能 + 高份额 → **成熟存量（Legacy/Cash Cow）**：防守优化
- 低动能 + 低份额 → **利基衰退（Niche/Decline）**：回避

#### 2.3 卖点 SI 指数计算
- SI（特异性指数）= 某卖点在特定款式中的渗透率 / 该卖点在全市场的渗透率
- SI > 1.2：核心成交卖点
- SI 1.0-1.2：溢价支撑
- SI 0.8-1.0：基础准入
- SI < 0.8：无差别/反向，不建议投入

#### 2.4 市场集中度算法（市场集中度分析模块）
计算以下指标：
- **HHI**（赫芬达尔-赫希曼指数）= Σ(各品牌市场份额²)
  - < 1,000：高度竞争
  - 1,000-1,800：适度集中
  - 1,800-2,500：寡头主导
  - > 2,500：极度集中/垄断
- **CR1 / CR3**：Top1 / Top3 品牌销售额占比
- **NPRS**（新品存活率）= 有效新品数 / 样本新品总数
- **NETI**（新进入者威胁指数）= 近期新品销量增量 / 市场总销量增量
- **Bd**（行为偏离度）= 价格波动系数 × 促销频率系数
- **CI**（综合竞争强度）= f(St, Bd, Dm)，输出 0-100 评分，分高/中/低三级

#### 2.5 机会款式判断规则
| 趋势动能 | 市场份额 | 竞争强度 | 判定 |
|---------|---------|---------|------|
| 高 | 高 | 高 | ✅ 机会款式（乱世争霸赛，差异化策略） |
| 高 | 低 | 低 | ✅ 机会款式（新星爆发，蓝海切入） |
| 低 | 高 | 任意 | ❌ 成熟存量，防守优化 |
| 低 | 低 | 任意 | ❌ 非机会款式，回避 |

#### 2.6 消费者信息生态三圈层建模
- **核心圈（Core Layer）**：来自电商评论 VOC，分析正面/负面体感、使用场景矩阵、功能优先级
- **中间圈（Middle Layer）**：来自社媒/论坛讨论，分析口碑传播结构（YouTube/TikTok/Reddit/Instagram）、信号强度
- **外围圈（Outer Layer）**：文化叙事层，挖掘消费者深层动机和生活方式认同

#### 2.7 关键人群 Persona 建模
每个 Persona 包含：
- 命名格式：角色 + 场景 + 核心约束
- 人群规模占比估算
- 人群边界（使用场景、信息偏好、价格敏感度）
- 决策驱动（主驱动 + 次驱动）
- 核心 JTBD（主任务 + 辅助任务）
- 关键反对点 & 成交条件
- 洞察-需求-功能映射表（含 KANO 分类：基础需求/期望需求/魅力需求）
- 证据偏好（Proof Kit）

### 第三步：输出交付层（HTML 报告生成）

生成符合参考设计规范的 HTML 报告，包含三套独立文件：

#### 📊 Report 1: MarketingInsight.html（市场洞察）
结构顺序：
1. **报告头部**：品类名称 + 市场 + 日期 + 战略定性标签
2. **款式诊断卡**（每个机会款式一张）：款式定性 / 卖点 SI / 价格带 / 头号竞对 / 缝隙识别 / 落地策略
3. **波士顿战略矩阵图**（文字矩阵版，4象限说明）
4. **款式心智/趋势矩阵 TABLE A**：各款式趋势动能基准
5. **卖点战略角色矩阵**：全量卖点 × 各款式 SI 值 × 角色分类 × 商业洞察
6. **竞争格局发现**：
   - 市场地图（价格带 × 款式 ASIN 数量 / 销售额 / 销售量）
   - 市场集中度分析（HHI / CR3 / NPRS / NETI / Bd / CI + 格局叙述）
   - 分款式竞争强度全览
   - 机会款式判断（表格 + 分析结论）

#### 👥 Report 2: ConsumerInsight.html（消费者洞察）
结构顺序：
1. **数据口径说明**（品类/时间/地域/语言/样本构成）
2. **三圈层信息生态模型**（Core/Middle/Outer Layer 卡片 + 跨圈层启示）
3. **核心圈分析**：体验数据画像 / 使用场景矩阵 / 功能优先级矩阵 / VOC 样本展示 / 核心洞察
4. **中间圈分析**：内容类型分布 / 社媒信号强度样本 / 信号结论 / 话题传播矩阵 / KOL 画像 / 季节性趋势
5. **外围圈分析**：文化叙事三大主线 / 跨圈层一致性验证 / 数据总览
6. **关键人群发现**（每个 Persona 一个完整章节）
7. **关键洞察 Key Findings**（4-6 条结构化发现）

#### 🚀 Report 3: ProductSolution.html（产品成功方案）
结构顺序（以 LUXEPET PRO 品牌规范命名方案）：
1. **封面**：品牌名称 + 市场 + 5大模块概览（Framework/Persona/JTBD/KANO/Solid Arguments）
2. **方案A - Essential "实用革新者"**（或按类目命名）：
   - 产品定义 & 核心价值主张
   - 创新定位（WHY战略机会 / WHAT创新杠杆）
   - 目标人群精准画像（规模 + 人口统计 + 核心痛点 + 购买触发）
   - 市场真实数据（搜索量/竞品价格/退货率/甜蜜价格带）
   - JTBD 任务矩阵（功能诉求/情感诉求/KANO/关键时刻）
   - 用户旅程六阶段（动机激发→信息搜索→评估对比→购买决策→满意体验→分享传导）
   - 成功论证（3-5个数据论据）
3. **市场进入策略**：定价策略 / 竞品对比 / 渠道价格矩阵
4. **产品实现方案**：设计语言 / 技术规格 / 核心供应商 / BOM成本 / 质量认证路径
5. **商业可行性分析**：市场份额预测(季度) / 销量收入预测 / 单位经济模型(CAC/LTV) / ROI / 风险矩阵
6. **GTM推广营销策略**：Product Message House / 精准渠道 / 故事仓 / Campaign / Service Design / 发布节奏 / 成功指标
7. **方案B / 方案C**（可选，针对不同价格带/人群的差异化方案）

### 第四步：HTML 设计规范

参考 `references/report-design-system.md` 中的设计语言标准：
- **配色方案**：深色专业风格（#0a0e1a 背景）+ 金色强调（#f0c040）+ 品牌色渐变
- **卡片组件**：圆角卡片（border-radius: 12px）+ 微妙阴影（box-shadow: 0 4px 20px rgba(0,0,0,0.3)）
- **数据表格**：striped rows + 响应式 / 支持 horizontal scroll on mobile
- **指标展示**：大数字 + 标签 + 趋势箭头 / emoji 辅助语义
- **战略矩阵**：2×2 象限用 grid 布局，4 象限不同背景色区分
- **报告导航**：固定顶部导航栏 + 锚点跳转

### 第五步：LUXEPET PRO 品牌规范说明

当输出产品方案报告时，方案命名格式遵循：
- **方案A（Essential）**："实用革新者" — 中端价位，极致功能效率，性价比突破
- **方案B（Pro）**："智能守护者" — 高端技术，AI/数据服务，认证壁垒
- **方案C（Designer）**："美学典藏" — 奢华定位，设计溢价，社交符号

每个方案均需输出：产品概念一页纸（One-Pager） + 人群洞察卡片 + JTBD价值地图

## Examples

**输入：** 用户说 "帮我分析 towel warmer bucket 市场，输出三份报告"
**输出：** 
1. 调用卖家精灵 MCP 获取类目数据
2. 运行款式建模 → 竞争强度算法 → 机会判断
3. 生成 MarketingInsight.html（含款式矩阵/市场地图/集中度分析）
4. 生成 ConsumerInsight.html（含三圈层/Persona/JTBD）
5. 生成 ProductSolution.html（含 LUXEPET PRO 三方案/GTM/商业可行性）

**输入：** 用户提供 ASIN B08ZMXQRPZ 要求竞品拆解和市场进入判断
**输出：** 拉取竞品详情 → 定位款式归属 → 输出竞争缝隙分析 + 机会款式报告

## Guardrails

- **数据来源透明**：报告必须注明数据口径（时间范围/地域/样本量），不伪造数据
- **算法指标解释**：HHI/SI/CI/NPRS/NETI 等指标必须附判定标准说明，不裸露数字
- **输出格式**：优先生成完整 HTML 文件并上传 Library；若用户只需摘要，提供结构化文字摘要
- **卖家精灵 MCP 调用限制**：若当前 session 无卖家精灵授权，提示用户先完成 SellerSprite 平台授权
- **产品方案免责声明**：ProductSolution 中的成本/销量/ROI 预测为模型估算，需结合实际供应链数据校正
- **LUXEPET PRO 品牌名仅为方案示例**：用户可替换为自有品牌名，报告框架不变
- **不做的事**：不提供具体工厂联系方式；不保证财务预测准确性；不执行实际采购或上架操作
