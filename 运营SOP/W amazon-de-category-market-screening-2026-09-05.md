# Amazon德国站类目市场分层筛选方案

更新日期：2026-09-05  
状态：主管确认前的建议版，不得直接视为已批准筛选规则。

## 一、目标与市场定义

目标是从 Amazon 德国站发现适合进一步调研的潜在市场，同时控制接口调用量和人工复核成本。

最终市场单位为：

> Amazon.de 站点 + 唯一叶子类目 Node ID（节点编号）

大类目和二级类目仅用于控制抓取范围，不作为最终市场单位。关键词用于分析搜索需求，不能替代类目节点定义市场。

## 二、推荐执行顺序

1. 整理 Amazon.de 大类目表，由主管确认需要研究的大类范围。
2. 只整理已纳入大类下的二级类目，根据轻量条件筛选二级类目。
3. 仅抓取通过筛选的二级类目下的叶子节点。
4. 对叶子类目执行轻量市场筛选，形成约 300～500 个候选市场。
5. 验证候选市场的 Best Sellers（畅销榜）链接和榜单容量。
6. 根据项目规模选择：
   - 标准方案：留约 150 个有效市场，执行完整市场审计并最终排序 100 个；
   - 小批量方案：先挑选 30～50 个市场执行完整审计，再排序选出十几个重点市场。

未经主管确认大类和二级类目范围，不得再次直接全站抓取全部叶子市场。

## 三、筛选步骤一：二级类目筛选

### 3.1 目的

判断哪些产品方向符合团队能力，值得继续抓取其叶子类目。该步骤以人工可判断的信息为主，不需要先购买大量市场数据。

### 3.2 硬性排除条件

满足任意一项即排除：

- 非实物商品，如应用、数字音乐、电子书、Prime Video、礼品卡等；
- 药品、食品、补充剂；
- 强监管医疗产品；
- 高风险化学品、易燃易爆品；
- 武器及明显高安全风险产品；
- 明显依赖品牌或 IP（知识产权）授权的市场；
- 强认证且团队当前没有进入能力的产品；
- 超大、超重或安装施工复杂，不适合当前物流能力的产品；
- 类目名称和范围无法确认时标记“待确认”，不得静默纳入。

### 3.3 四维固定评估

每个维度只能选择高、中、低，并换算为固定分数：

| 维度 | 高 | 中 | 低 |
|---|---:|---:|---:|
| 中国供应链匹配度 | 2 | 1 | 0 |
| 产品改款与差异化空间 | 2 | 1 | 0 |
| 物流履约友好度 | 2 | 1 | 0 |
| 合规可控程度 | 2 | 1 | 0 |

结果规则：

- 6～8 分：纳入叶子类目抓取范围；
- 4～5 分：交主管复核；
- 0～3 分：暂不抓取；
- 触发硬性排除：无论得分多少均排除；
- 主管可以例外保留，但必须填写原因。

### 3.4 二级类目筛选表字段

建议字段：

> 一级大类｜二级类目｜Node ID｜是否实物｜监管风险｜供应链匹配度｜差异化空间｜物流友好度｜合规可控度｜总分｜硬性排除原因｜主管决定｜备注

## 四、筛选步骤二：叶子类目市场筛选

### 4.1 基础有效性门槛

必须同时满足：

- 有明确叶子类目名称及唯一 Node ID；
- Best Sellers 链接有效；
- 不是父级、集合页或关键词搜索页；
- 销量、销售额等核心字段不为空；
- 同一 Node ID 只保留一条；
- 同名但 Node ID 不同的市场分别保留。

### 4.2 建议轻量数据门槛

| 指标 | 建议条件 |
|---|---:|
| TOP100 月销量 | ≥10,000 件 |
| TOP100 月销售额 | ≥€200,000 |
| 平均价格 | €8～60 |
| 平均评论数 | ≤5,000 |
| TOP3 商品销量占比 | ≤45% |
| TOP3 品牌销量占比 | ≤70% |
| TOP3 卖家销量占比 | ≤80% |
| Amazon 自营销量占比 | ≤30% |
| 近 3 个月新品销量占比 | ≥3% |

上述条件建议采用“全部同时满足”的规则，形成统一、可复核的候选池。

使用 2026-09-04 德国站 15,661 条去重叶子类目数据模拟，在尚未排除非实物、高风险和主管不做大类的情况下，共约 553 个市场满足上述数值条件。完成范围和风险排除后，预计形成约 300～500 个候选市场。

该数量只是当前数据快照的模拟结果，不是最终项目结论。

### 4.3 暂不设为硬门槛的指标

- 中国卖家占比：过低可能代表进入障碍，过高也可能代表同质化，只用于辅助判断；
- 平均评分：不能直接证明市场机会或进入难度；
- 旺季：季节性市场不应直接排除；
- 毛利率：当前全量类目底表没有统一可靠口径，留到正式深度审计；
- 单一综合分：不能覆盖明显的合规、品牌或 Amazon 自营风险。

### 4.4 候选数量偏离时的固定调整顺序

如果候选不足 300 个，依次放宽：

1. TOP100 月销量降至 ≥8,000 件；
2. TOP100 月销售额降至 ≥€150,000；
3. 近 3 个月新品销量占比降至 ≥2%；
4. Amazon 自营销量占比放宽至 ≤35%。

如果候选超过 500 个，依次收紧：

1. 平均评论数降至 ≤3,000；
2. Amazon 自营销量占比降至 ≤20%；
3. TOP3 商品销量占比降至 ≤40%；
4. 平均价格收窄至 €10～50。

不得为达到目标数量临时随机修改条件。每次调整必须记录调整前后条件、候选数量和原因。

### 4.5 叶子类目筛选表字段

建议字段：

> 一级大类｜二级类目｜叶子类目｜Node ID｜Best Sellers 链接｜九项筛选指标｜各条件通过状态｜自动筛选结果｜风险排除原因｜主管例外保留｜最终候选状态

## 五、全量叶子类目抓取的历史执行记录

2026-09-04 曾直接调用 Sorftime 德国站类目市场分页接口：

- 每页返回 20 个类目及数据源已有市场字段；
- 连续读取 785 页，得到 15,694 条原始记录；
- 按 Node ID 去重后得到 15,661 个市场；
- 根据 Node ID 批量生成 Amazon Best Sellers 链接；
- 分层打开 6 个 Amazon 页面抽验，6/6 对应正确；
- 数据已保存为 CSV（逗号分隔值文件）和 Excel（电子表格）底表。

接口返回的销量、销售额、价格、评论数、集中度、新品、中国卖家和 Amazon 自营占比均为第三方爬虫数据库已有字段，不是本次逐页打开 Amazon 后重新计算的结果。

该全量抓取产生了约 785 次分页请求。以后不得默认复用此做法；必须优先执行大类和二级类目范围筛选。

## 六、额度与执行门槛

所有大批量接口任务在执行前必须先报告：

- 预计页数；
- 预计接口调用次数；
- 已知计费方式或额度风险；
- 小样本验证范围；
- 自动停止门槛；
- 是否已有本地缓存可以复用。

标准执行方式：

1. 先抓取 1～5 页验证字段和数据质量；
2. 汇报预计成本和完整执行量；
3. 获得用户确认后才继续；
4. 每批落盘并支持断点续跑；
5. 已有原始数据不得重复调用获取。
