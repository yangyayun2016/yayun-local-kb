# 亚马逊广告 SOP（标准操作流程）

---

## 一、广告策略总览

### 1.1 广告目标层级

| 阶段 | 目标 | 核心指标 |
|------|------|----------|
| 新品期（0–30天） | 曝光 & 积累数据 | 展示量、点击量、CTR |
| 成长期（31–90天） | 提升排名 & 控制ACOS | ACOS、转化率、BSR |
| 成熟期（90天+） | 盈利 & 规模扩张 | TACOS、ROAS、广告利润 |
| 促销期 | 冲量 & 清库存 | 订单量、广告花费ROI |

### 1.2 广告类型选择矩阵

| 广告类型 | 适用场景 | 优先级 |
|----------|----------|--------|
| SP（Sponsored Products）| 任何阶段，核心广告 | ★★★★★ |
| SB（Sponsored Brands）| 品牌旗舰店上线后 | ★★★★☆ |
| SD（Sponsored Display）| 再营销 / 类目拦截 | ★★★☆☆ |
| SBV（Sponsored Brands Video）| 有高质量视频素材 | ★★★★☆ |

## 二、新品期广告搭建 SOP

### 2.1 搭建前置条件

- [ ] Listing 已完整优化（标题 / 五点 / 描述 / A+ / 图片7张+）
- [ ] Review ≥ 0（新品允许0评，但15条以上效果更佳）
- [ ] 库存充足（预备至少60天销售量）
- [ ] 价格竞争力确认（参考竞品 & Buy Box）

### 2.2 广告组结构（推荐架构）

```
Campaign（广告活动）
  ├── Ad Group 1：自动投放（Auto）
  │     ├── 紧密匹配（Close Match）
  │     ├── 宽泛匹配（Loose Match）
  │     ├── 同类商品（Substitutes）
  │     └── 互补商品（Complements）
  └── Ad Group 2：手动精准（Exact）
        └── 核心关键词 × 精准匹配
```

### 2.3 新品期预算 & 竞价设置

| 参数 | 推荐值 | 备注 |
|------|--------|------|
| 日预算 | $20–$50 | 视类目竞争程度调整 |
| 自动广告竞价 | $0.50–$1.20 | 高于建议竞价10–20% |
| 手动精准竞价 | 建议竞价 × 1.2 | 新品需激进竞价 |
| 竞价策略 | 动态竞价-提高和降低 | 新品期抢曝光 |

### 2.4 关键词来源

1. **自动广告跑7天** → 下载搜索词报告 → 提取高点击词
2. **竞品ASIN反查** → Helium10 / Jungle Scout / Brand Analytics
3. **脑暴核心词** → 品类词 + 属性词 + 使用场景词
4. **长尾词补充** → 用途词 + 人群词 + 节日词

## 三、广告优化 SOP（周度执行）

### 3.1 每周操作时间表

| 操作日 | 任务 |
|--------|------|
| 每周一 | 下载搜索词报告，添加否定关键词 |
| 每周三 | 检查竞价表现，调整出价 ±10–20% |
| 每周五 | 将高转化搜索词升级为手动精准词 |
| 每月1日 | 月度复盘，预算 & 结构调整 |

### 3.2 关键词竞价调整规则

**提高竞价（+10–20%）条件：**
- ACOS < 目标 ACOS × 0.8
- 点击量高但展示量不足（排名不够）
- 关键词有转化，近7天订单 ≥ 3

**降低竞价（-10–20%）条件：**
- ACOS > 目标 ACOS × 1.3
- 连续14天点击无转化
- 单次点击成本 > 产品利润 × 30%

**暂停关键词条件：**
- 30天点击 ≥ 20次，0转化
- ACOS > 200% 且无改善趋势

### 3.3 搜索词否定操作规则

| 否定类型 | 适用场景 |
|----------|----------|
| 否定精准 | 该词已在手动精准组投放（避免内耗） |
| 否定词组 | 明显不相关词（如竞品品牌词、品类不符词） |
| 广告组级否定 | 仅针对特定广告组过滤 |
| 广告活动级否定 | 全局过滤，慎用 |

## 四、广告结构进阶 SOP（成长期）

### 4.1 STR（搜索词转移）操作流程

```
自动广告 → 发现高转化词
     ↓
添加至手动广告（精准匹配）
     ↓
在自动广告组中将该词设为【否定精准】
     ↓
手动精准组持续优化竞价
```

### 4.2 广告结构分层建议

```
Layer 1：捕获层（自动广告）
  - 目的：发现新词 / 低成本流量
  - 竞价：中等偏低

Layer 2：核心层（手动精准 - 核心词）
  - 目的：主要出单来源
  - 竞价：激进，保护排名

Layer 3：防御层（手动精准 - 品牌词）
  - 目的：防止竞品截流
  - 竞价：低，按需开启

Layer 4：扩展层（手动词组/宽泛）
  - 目的：长尾流量 / 新词发现
  - 竞价：中等
```

### 4.3 ASIN 定向广告（SD/SP）

**进攻策略：**
- 定向竞品 ASIN → 在竞品详情页展示广告
- 优先选价格更高、Review更少的竞品

**防守策略：**
- 定向自身 ASIN → 防止流量被竞品截走
- 适用于高销量核心 SKU

## 五、广告指标监控 SOP

### 5.1 核心指标参考基准

| 指标 | 健康范围 | 警戒线 |
|------|----------|--------|
| ACOS | 15–35%（视利润率） | > 50% |
| TACOS | 8–15% | > 20% |
| CTR | 0.3–0.5% | < 0.1% |
| 转化率 CVR | 10–25% | < 5% |
| CPC | 视类目，$0.3–$1.5 | > 利润的40% |
| 广告订单占比 | 30–50% | > 70%（依赖广告） |

### 5.2 异常情况处理流程

**CTR 突然下降：**
→ 检查主图是否被修改 → 检查价格竞争力 → 检查 Review 数量变化

**转化率下降：**
→ 检查 Listing 是否被篡改 → 检查 Review 负评 → 检查库存/发货时效

**ACOS 突然飙升：**
→ 检查竞价是否被调高 → 检查竞品是否加大投入 → 降低无效词竞价

**广告花费骤减：**
→ 检查预算是否耗尽 → 检查关键词竞价是否过低 → 检查广告状态

## 六、促销期广告 SOP（Prime Day / 黑五 / 节日大促）

### 6.1 大促前2周操作

- [ ] 将核心关键词竞价提升 30–50%
- [ ] 日预算提升至平时 2–3倍
- [ ] 开启 SB / SBV 广告，提升品牌曝光
- [ ] 检查 Lightning Deal / Coupon 是否设置完成

### 6.2 大促期间监控（每日）

- 上午9点：检查预算消耗进度
- 下午3点：检查 ACOS，决定是否加价
- 晚上9点：检查日预算是否即将耗尽，及时补充

### 6.3 大促后操作

- 大促结束后48小时内将竞价恢复正常水平
- 下载大促期间搜索词报告，挖掘新的高转化词
- 评估大促 ROI，复盘预算分配是否合理

## 七、广告报告使用 SOP

### 7.1 必备报告类型

| 报告名称 | 下载频率 | 核心用途 |
|----------|----------|----------|
| 搜索词报告 | 每周 | 发现新词 / 否定无效词 |
| 关键词表现报告 | 每周 | 竞价调整依据 |
| ASIN 表现报告 | 每月 | 评估广告素材效果 |
| 广告活动报告 | 每月 | 整体结构复盘 |
| 购买行为报告 | 每月 | 了解消费者行为路径 |

### 7.2 搜索词报告分析步骤

1. 下载过去7天搜索词报告
2. 筛选：点击量 ≥ 5 的词
3. 分类处理：
   - 有转化 + ACOS 达标 → 加入手动精准
   - 有转化 + ACOS 超标 → 降低竞价或否定
   - 无转化 + 点击 ≥ 15 → 否定
   - 无转化 + 点击 < 5 → 继续观察

## 八、广告账户健康检查清单（月度）

### 账户结构健康

- [ ] 广告活动命名规则统一（建议：品类_类型_日期）
- [ ] 每个广告活动关键词数量 ≤ 200
- [ ] 无重复关键词在多个手动精准组同时投放
- [ ] 自动广告组已设置必要否定词

### 投放效率健康

- [ ] TACOS 维持在目标范围内
- [ ] 广告订单占总订单比例 ≤ 50%
- [ ] 无长期亏损（ACOS > 100%）且点击 > 50次的关键词
- [ ] 预算利用率 > 80%（预算未被充分消耗需排查）

### 数据合规健康

- [ ] 广告花费与销售额数据核对无误
- [ ] 排除品牌词干扰后的 TACOS 指标正常
- [ ] 所有广告素材符合亚马逊政策（图片/视频规范）

## 九、常见问题 FAQ

**Q: 新品应该先开自动还是手动？**
A: 先开自动广告7–14天，积累数据后再同步开手动精准广告。

**Q: 广告预算应该怎么分配？**
A: SP 占 70%，SB 占 20%，SD 占 10%。新品期可100%投SP。

**Q: 什么时候该暂停广告？**
A: 库存不足15天时暂停广告，防止断货损伤排名与广告数据。

**Q: 自动广告和手动广告竞价哪个更高？**
A: 通常手动精准词竞价更高，自动广告作为辅助/探词工具维持中等竞价。

**Q: ACOS 高就要降预算吗？**
A: 不一定。先排查是关键词质量问题还是Listing转化问题，针对性处理比直接降预算更有效。
