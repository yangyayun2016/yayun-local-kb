# 输出格式规范

## HTML 报告结构

### 1. 生命周期概览
- 当前阶段（萌芽期/增长期/成熟期/衰退期/季节波动）
- 阶段置信度
- 综合判断

### 2. Amazon 趋势证据
- 搜索量趋势图
- 购买量趋势
- 同比/环比增长率

### 3. Google 外部趋势
- Google Trends 趋势图
- 与 Amazon 同步性

### 4. 头部 ASIN 趋势
- 销量趋势
- BSR 变化
- 价格变化

### 5. 新品进入分析
- 新品数量
- 新品销量占比
- 新品存活率

### 6. 机会判断
- 是否还能进入
- 适合策略（快进快出/长期运营/差异化）

### 7. 风险提示
- 主要风险点
- 需要警惕的信号
