# 输出格式规范

## HTML 报告结构

### 1. 风险概览
- 风险总评分（低/中/高）
- 适合进入程度
- 核心结论

### 2. 壁垒分析（6项）
每项包含：
- 壁垒类型
- 严重程度（无/低/中/高）
- 关键数据
- 风险说明

### 3. 关键证据
- 头部品牌占比
- 卖家国家分布
- 评论数门槛
- 价格区间分布
- 新品进入可能性

### 4. 差评风险
- 高频差评类型
- 合规/安全风险
- 售后问题

### 5. 最终结论
- 适合进入：风险低，壁垒可控
- 仅适合差异化：有壁垒但可通过差异化绕过
- 不适合新手：壁垒高，需要资源
- 不建议进入：壁垒极高，新品无机会
