# 竞争壁垒与风险评估

识别市场是否存在强品牌、强评论、强价格、强供应链或强合规壁垒，避免选到"看起来有需求但很难打"的产品。

## 输入参数
| 参数 | 说明 | 示例 |
|------|------|------|
| 站点 | Amazon 站点 | US |
| 关键词 | 核心产品词 | pet grooming brush |
| 类目节点 | 可选 | nodeIdPath |
| 目标月份 | 可选 | yyyyMM |
| 头部样本 | Top 10 / Top 20 | |
| 新品定义 | 上架 N 个月内 | 3个月 |
| 分析维度 | 品牌/卖家/评论/价格/变体/差评 | |

## 执行步骤
1. **类目识别** - product_node 根据关键词查找类目
2. **卖家分布** - market_seller_country_distribution 分析卖家国家/地区分布
3. **竞品查找** - competitor_lookup 获取品牌/卖家/评论/评分/销量/价格/上架时间
4. **ASIN 详情** - asin_detail 查看头部商品变体/配送/Listing/卖家信息
5. **差评分析** - review 分析合规/安全/质量/售后高风险问题

## 输出格式
HTML 报告，包含：
- 风险总评分（低/中/高）
- 壁垒类型（品牌/评论/价格/变体/供应链/合规售后）
- 关键证据（品牌占比/卖家国家/评论门槛/新品可能性/价格趋势/差评风险）
- 结论（适合进入/仅差异化/不适合新手/不建议进入）

## 异常处理
- 缺少关键词：追问用户
- 无类目数据：扩大搜索范围
- 头部样本不足：减少样本数重试
- MCP 调用失败：提示重试
