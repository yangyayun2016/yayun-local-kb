# 新品切入角度分析

从竞品弱点、用户差评、关键词缺口中找到新品差异化切入方案。

## 输入参数
| 参数 | 说明 | 示例 |
|------|------|------|
| 站点 | Amazon 站点 | US |
| 目标关键词 | 核心产品词 | desk organizer |
| 竞品 ASIN | 可选，建议3-10个 | B09XXXXXX |
| 目标月份 | 可选 | yyyyMM |
| 评论星级 | 默认 1-3 星 | 1-3 |
| 关注方向 | 功能/材质/尺寸/套装/颜色/场景/礼品/便携/安装 | |
| 目标价格带 | 可选 | |

## 执行步骤
1. **竞品查找** - competitor_lookup 找到关键词下主要竞品
2. **竞品详情** - asin_detail 获取竞品详情（卖点/规格/变体/价格/评分）
3. **差评分析** - review 分析低星评论，识别高频不满和未满足需求
4. **流量词分析** - traffic_keyword 获取竞品流量词，判断用户需求词
5. **需求词拓展** - traffic_extend 识别场景词和痛点词

## 输出格式
HTML 报告，包含 3-5 个切入方向，每个方向包含：
- 目标用户
- 使用场景
- 要解决的痛点
- 建议功能/规格
- 建议价格带
- 可使用关键词
- 对应竞品弱点
- 差异化强度：高/中/低
- 落地难度：高/中/低
- 推荐优先级

## 异常处理
- 缺少目标关键词：追问用户
- 竞品 ASIN 无效：跳过该 ASIN，继续分析其他
- 无低星评论：扩大评论范围（1-4星）
- MCP 调用失败：提示重试
