# 亚马逊 CDQ（Composite Data Quality）评分算法详解

> 依据：Amazon ASCS（精选与目录系统团队）CDQ v3，2025年3月发布，用于检测listing目录数据的完整性、准确性、一致性。

---

## 一、总体结构

CDQ 由 **7 个维度**加权构成，总分区间 **100–120**（100为基础满分，Product Type Classification 是 0–20% 的额外加分维度）。

| # | 评估组 | 维度 (Component) | 权重 | 满分要求 |
|---|--------|------------------|------|----------|
| 1 | Detail Page | 结构化属性质量 Structured Attributes Quality | **30%** | 详情页"产品概述"+"深度信息"组件中所有适用属性完整且正确 |
| 2 | Detail Page | 标题质量 Title Quality | **25%** | 完整、正确、长度/大小写规范、关键词覆盖好、无堆砌/违规 |
| 3 | Detail Page | 描述摘要质量 Bullet Points | **5%** | ≥3条要点，无违禁/敏感词 |
| 4 | Detail Page | 图片质量 Image Quality | **15%**（孤儿ASIN为18.75%）| ≥4张图，无图片缺陷，支持缩放 |
| 5 | Detail Page | A+页面质量 A+ Content | **5%** | 存在A+内容（二元判分） |
| 6 | Detail Page | 变体质量 Variation Quality | **20%**（孤儿ASIN N/A，权重重新分配） | 变体家族主题及属性全部正确、一致 |
| 7 | Discoverability | 产品类型分类 Product Type Classification | **0–20%**（加分项） | 有准确、相关的细分类目叶节点 |

**孤儿ASIN（Orphan ASIN，非变体家族）权重重分配逻辑：**
变体质量20%不适用时，剩余80%权重按原比例等比放大到100%，即：
`新权重 = 原权重 / 80 × 100`
例：图片质量 15/80×100 = **18.75%**；结构化属性 30/80×100 = 37.5%；标题 25/80×100=31.25%；五点 5/80×100=6.25%；A+ 5/80×100=6.25%。

## 二、各维度详细算法

### 1. 结构化属性质量（30%）—— 正确性优先于完整性

- 评估对象：产品概述中的 **Top 6 RAI属性**（由NLP模型Relevance Attribute Index识别的最重要6项属性）+ 深度信息组件中的 **Band A/B属性**（合称"Depth Widget"）
- **Band A**：描述产品本质特征、区分同类产品的核心属性（如笔记本电脑的处理器、内存、系统、屏幕尺寸）
- **Band B**：区分同一产品不同变体/版本的属性，帮助客户选型（如颜色、接口类型）
- RAI排序依据：客户评论、Q&A、搜索词、标题描述、竞品官网数据综合分析，**因品类而异，非固定列表**
- **评分公式**：`评分 = Σ(完整且正确属性的权重)`，即完整性(Completeness)与准确性(Accuracy)两个子维度加权
- **严重缺陷判定**：多数产品类型下前6项属性出错，或前10项相关属性完整性 <50%（部分Softline品类排序逻辑不同）→ 触发严重缺陷，直接拖累等级至D

### 2. 标题质量（25%）—— TQS（Title Quality Score）逻辑

标题按 **A / B / C 三级** 评分：

**A级（CDQ标题质量=100%）**，需同时满足：
- 标题完整性评分 ≥ 0.6（标注品牌名+主关键词+≥3个核心属性+适用人群/场景/意图+无语法错误，5项各占0.2权重）
- 标题冗余度评分 = 1（无关键词堆砌，同词重复不超2次）
- 标题长度 ≤ 200字符（含空格；标题75字符+HIGHLIGHT 125字符，建议75–200字符区间）
- 管道符评分 > 0（含至少1个 `|` 或分隔符区分信息段）
- 特殊字符评分 = 1（无 `! $ ? _ { } ^ ¬ ¦` 等不可读字符）
- 限制性短语评分 = 1（无受限短语，如"符合FSA/HSA要求"等）

**B级**（CDQ标题质量≥50%）：未违反政策，但上述任一维度未达标

**C级 / 违规标题**（CDQ标题质量=0%，等级直接为U，CDQv3评分为N/A）：
- 完整性评分 < 0.4（标注属性<2个），或
- 冗余度评分 ≤ 0.6（同语境重复词/短语>2次），或
- 标题长度 > 200字符，或
- 存在受限短语（受限短语阈值<1）

**亚马逊标题合规硬性规则**：
- 字符数≤200，禁用特殊字符 `! $ ? _ { } ^ ¬ ¦`
- 禁止全大写；每词首字母大写（介词/连词/冠词除外）
- 数字用阿拉伯数字，不用英文单词
- 同词重复禁止（品牌名不可出现两次）
- 禁止主观评价用语（"Hot Item"/"Best Seller"等）
- 禁止促销/营销词（Free Shipping、100% Guaranteed、Gift、Warranty等）
- 禁止健康/医疗/杀虫类敏感声明词：antimicrobial、antibacterial、antifungal、sanitize、disinfect、sterilize、pesticide、insecticide、anti-mites、detoxify、UV sterilize、marijuana、heroin、drugs 等
- 结构建议：品牌 + 核心产品名 + 关键属性（颜色/规格/材质）；移动端可读性（建议75–200字符区间兼顾展示与GEO）

### 3. 描述摘要质量 / 五点描述（5%）

- ≥3条 bullet → **100%**
- ≥1条 bullet → **50%**
- 无 bullet → **0%**
- 附加规则：五点中不得含违禁/敏感关键词（触发关键词检查即扣分/清零）
- 建议遵循 **0/1/3原则**：0项功能遗漏、1个最核心卖点、≥3个魅力卖点，不喧宾夺主

### 4. 图片质量（15%，孤儿ASIN为18.75%）

| 图片数量 | 是否有缺陷 | 得分 |
|---------|-----------|------|
| ≥4张 | 无缺陷 | **1.0（100%）** |
| ≥4张 | 有缺陷 | **0.4（40%）** |
| <4张 | 无缺陷 | **0.6（60%）** |
| <4张 | 有缺陷 | **0.0（0%）** |

- 主图需支持缩放（建议1000+像素）
- 补充判定：**IAI（Imaging Attribute Index，图像属性指数）** ≥0.4 为达标线，评估图片集相对同品类竞品的完整度
- 有效像素占比建议 ≥85%（S3图库系统标准），关键判定顺序：产品在图片中的占比 → 图片打标签（利于关键词收录匹配）

### 5. A+页面质量（5%）—— 二元判分

- 存在A+内容 → **1.0（100%）**
- 不存在 → **0.0（0%）**
- 无部分分：目前CDQ只判"有无"，不判内容质量（**内容质量评估计划2026年上线**）

### 6. 变体质量（20%，孤儿ASIN N/A）

- 核心要求：整个变体家族的**变体主题（Variation Theme）**及其属性必须全部正确、一致、不重复
- **🔴 严重缺陷**（立即处理）：错误属性值、单位制混用、变体信息冗余、本地化错误、子项重复
- **🟡 非严重缺陷**（逐步改善）：值未标准化、格式不匹配、变异主题选择错误
- 变体数量建议 ≥2个，属性丰富且跨SKU一致

### 7. 产品类型分类 / 可搜索性（Discoverability，0–20%加分）

- 满分要求：拥有**准确、相关的细分类目叶节点（Node ID）**
- 关联能力建设：
  - **NPL新品发现流程**：发布前6–12个月提交NPL详情与上市策略；Priority 1/2需参加SAS Discoverability Office Hours；发布前4–6周提交A+内容并加入Vine；上市当天需核查搜索/展示广告是否正常投放
  - **全链路指标追踪**：Traffic（每10万顾客的Glance Views）→ Consideration（加购率 = Add to Cart/Glance Views）→ Conversion（转化率 = Units/Glance Views）
  - **DART工具**（Discoverability Analytics & Research Tool）：从搜索视角洞察客户需求，定位需要补充的属性

## 三、缺陷分级体系（决定是否触发强制降级）

| 缺陷等级 | 判定标准 | 对总分/等级的影响 |
|---------|---------|------------------|
| **策略违规 Policy Violation** | 索引/网站抑制、标题政策违规（不完整/冗余/受限词/长度或大小写错误）、关键词堆砌、含违禁敏感词 | **强制等级 = U**，CDQ评分记为 N/A |
| **严重缺陷 Egregious Defect** | 多数品类下前6项相关属性出错，或前10项相关属性完整性<50%；变体严重缺陷（错误值/单位混用/信息冗余/本地化错误/子项重复） | **强制等级 = D（评分0）**，严重损害得分及客户体验 |
| **非严重缺陷** | 值未标准化、格式不匹配、变体主题选择错误等 | 按对应维度权重扣分，可随时间修复改善 |

## 四、综合评分与等级映射

总分区间 **0–120**（100基础 + 0–20 Discoverability加分）：

| 等级 | 分数区间 | 含义 |
|------|---------|------|
| **A++** | >100（100–120） | 极高（加分档） |
| **A+** | 85–100 | 高质量 |
| **A** | >85 | 尚可 |
| **B** | 70–85 | 低质量-无缺陷 |
| **C** | 0–69.99 | 低质量-非严重缺陷 |
| **D** | 0 | 低质量-严重缺陷（触发严重缺陷即强制） |
| **U** | N/A | 低质量-政策违规（触发策略违规即强制） |

> **原文标注说明**：原文中 A+（85–100）与 A（>85）区间存在重叠表述，属于官方原文的边界模糊。在下方Python实现中，我按"分数越高等级越优"的原则将其拆分为**不重叠**的区间（A+: 95–100，A: 85–95），并在代码注释中标明这是工程化假设，实际以亚马逊后台Brand/Vendor Central显示等级为准。

## 五、优先修复顺序建议（基于权重与缺陷杠杆）

1. **先查策略违规/严重缺陷**（U/D是硬性天花板，不修复则无论其他维度多好都无法提分）
2. **标题（25%）**：低成本高杠杆，重点修正长度、堆砌词、违禁词、品牌名前置
3. **结构化属性（30%）**：权重最高，优先补全Top 6 RAI属性 + Top 10相关属性，正确性优先于完整性
4. **图片（15%/18.75%）**：先补到≥4张，再消灭图片缺陷（0.4→1.0是最大单项跳变）
5. **变体（20%，非孤儿ASIN）**：统一主题属性，消除重复/单位混用
6. **五点描述（5%）&A+（5%）**：权重小但改造成本低，顺手拿满
7. **可搜索性（0–20%加分）**：完善类目叶节点，追求A++
