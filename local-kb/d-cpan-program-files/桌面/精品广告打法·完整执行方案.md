## 一、广告目标层级与阶段规划

### 1.1 四阶段目标矩阵

| 阶段 | 时间 | 核心目标 | 主打广告类型 | 核心指标 | ACOS目标 |
|------|------|----------|-------------|----------|----------|
| **新品期** | D1~D30 | 曝光 + 积累数据 + 关键词收录 | 自动广告为主 + 手动广泛辅助 | 展示量、点击量、CTR | 不设上限，数据优先 |
| **成长期** | D31~D90 | 排名提升 + 控制ACOS | 手动精细化（词组为主）+ ASIN定投 | ACOS、CVR、BSR排名 | 目标ACOS ≤ (1-毛利率)×100% |
| **成熟期** | D90+ | 盈利 + 规模扩张 | 全层级协同（精准词+视频+品牌） | TACOS、ROAS、广告利润 | TACOS ≤ 12% |
| **促销期** | 大促节点 | 冲量 + 排名跃升 | 全火力开启 + 站外联动 | 订单量、广告ROI | 允许阶段性亏损 |

### 1.2 阶段切换触发条件

```
新品期 → 成长期 触发条件（满足以下任意2条）：
  □ 自动广告已积累 ≥ 200次点击
  □ 已找到 ≥ 3个有转化的核心搜索词
  □ 评价数 ≥ 10条，评分 ≥ 4.0
  □ 核心词自然排名出现在前100位

成长期 → 成熟期 触发条件（满足以下任意2条）：
  □ ACOS 连续2周达标
  □ 核心词自然排名稳定前20
  □ 广告订单占总订单比例 ≤ 55%
  □ TACOS < 15% 且持续下降趋势
```

## 二、上线前：核心关键词选定 SOP

> 上线前做好这一步，是整个精品广告打法的地基。核心词选错，后续所有投入都打折。

### 2.1 数据来源双引擎

| 数据来源 | 获取方式 | 核心价值 |
|----------|----------|----------|
| **亚马逊后台商机探测器** | Seller Central → Growth → Product Opportunity Explorer | 直接看细分类目的搜索词流量占比，官方数据最权威 |
| **ABA（Brand Analytics）搜索词报告** | Brand Analytics → Search Query Performance / Search Catalog Performance | 可用竞品ASIN反查该ASIN依赖哪些词出单，获取真实购买转化词 |

### 2.2 商机探测器操作步骤

```
Step 1：进入商机探测器
路径：Seller Central → Growth → Product Opportunity Explorer
选择目标站点（如美国站）

Step 2：输入核心竞品ASIN
  方法A：在搜索框输入竞品ASIN，查看该ASIN所在的细分Niche
  方法B：直接搜索核心品类词，浏览系统推荐的细分Niche列表

Step 3：进入细分Niche，查看搜索词数据
  重点关注字段：
  ┌─────────────────────────────────────────────────────┐
  │ 搜索词          │ 搜索量   │ 搜索增长率 │ 单击率   │
  │ 转化率          │ 前3 ASIN │ 点击份额  │ 购买份额 │
  └─────────────────────────────────────────────────────┘

Step 4：筛选高价值词
  筛选条件（同时满足）：
  ✅ 搜索量 排名靠前（该Niche中Top 20%）
  ✅ 相关性强（与产品功能/用途高度匹配）
  ✅ 点击份额前3 ASIN 合计 < 85%（仍有进入空间）
  ✅ 搜索增长率 ≥ 0%（非衰退词）
```

### 2.3 ABA搜索词报告操作步骤

```
Step 1：打开搜索词报告
路径：Brand Analytics → Search Catalog Performance（推荐）
      或 Search Query Performance（按品牌维度）

Step 2：用竞品ASIN反查（核心操作）
  在 Search Catalog Performance 中：
  → 筛选器选择"ASIN"
  → 输入核心竞品ASIN（选3~5个头部竞品）
  → 下载各ASIN的流量词数据

  关键字段解读：
  ┌──────────────────────────────────────────────────────────────┐
  │ Search Query    │ 该词带来的Impressions │ Clicks │ Cart Adds │
  │ Purchases       │ Click Share（点击份额）│ Purchase Share     │
  └──────────────────────────────────────────────────────────────┘

Step 3：找到"高流量 + 有购买"的词
  筛选标准：
  ✅ 该词的 Purchase Share（购买份额）> 0（有真实成交）
  ✅ 该词的 Click Share（点击份额）在竞品中靠前
  ✅ 该词是竞品多个ASIN共同依赖的词（多个竞品都出现 = 品类核心词）
```

### 2.4 6~10个核心关键词最终确认标准

```
候选词池（通常从商机探测器+ABA可以找到30~100个词）
         ↓
按以下四个维度打分，取综合分最高的6~10个：

┌──────────┬──────────────────────────────────┬──────┐
│ 评估维度 │ 判断标准                           │ 权重 │
├──────────┼──────────────────────────────────┼──────┤
│ 流量规模 │ 该词搜索量占Niche总流量的占比       │ 35% │
│ 相关性   │ 词义与产品的匹配程度（1~5分人工评） │ 35% │
│ 竞争可及 │ 前3 ASIN购买份额合计 < 80%         │ 20% │
│ 转化信号 │ 竞品在该词下有明确购买数据          │ 10% │
└──────────┴──────────────────────────────────┴──────┘

目标：6~10个核心词合计流量占比 ≥ 60%~70%
（即：守住这几个词，就守住了大半流量入口）
```

### 2.5 词根整理（核心词的延伸基础）

```
找出6~10个核心词后，对每个词做词根拆解：

示例（以"wireless earbuds"为例）：
  核心词：wireless earbuds
  词根1：wireless（修饰词）
  词根2：earbuds（品类词）
  延伸组合：
    → wireless earbuds for running
    → wireless earbuds noise cancelling
    → best wireless earbuds
    → wireless earbuds waterproof

作用：词根是广泛匹配投放的基础，宽泛匹配会覆盖所有包含词根的搜索词
广泛匹配会把 wireless earbuds 的所有变体词、同义词都覆盖到
→ 目的是通过广泛匹配发现这些延伸词中哪些有转化，再升级为词组/精准
```

## 四、第一层：自动广告（探词基础层）

### 4.1 创建规范

| 参数 | 设置 |
|------|------|
| **广告活动名称** | `[品类]_SP_Auto_[上线日期]`（如：Earbuds_SP_Auto_20260522） |
| **广告活动类型** | Sponsored Products |
| **投放类型** | 自动投放（全部4种类型开启） |
| **竞价策略** | **动态竞价 - 提高和降低** |
| **默认竞价** | **建议竞价的 85%**（Ads Console 会显示建议竞价，取该数值 × 0.85） |
| **日预算** | 新品期建议 $30~$50（确保全天不断投） |
| **广告位溢价** | 搜索结果首页顶部：**20%~30%**（新品期不宜过高，先探数据） |

### 4.2 四种自动匹配类型的分工

| 类型 | 作用 | 新品期是否开启 | 竞价调整建议 |
|------|------|--------------|-------------|
| **紧密匹配（Close Match）** | 覆盖与产品高度相关的搜索词 | ✅ 全力开启 | 维持85%基础竞价 |
| **宽泛匹配（Loose Match）** | 覆盖相关性稍低的搜索词 | ✅ 开启探索 | 可设为基础竞价的70% |
| **同类商品（Substitutes）** | 在竞品详情页展示 | ✅ 开启进攻 | 维持85%基础竞价 |
| **关联商品（Complements）** | 在互补品详情页展示 | ✅ 开启探索 | 可设为基础竞价的70% |

### 4.3 自动广告的核心任务

```
自动广告的3个核心任务：

任务1：发现出单搜索词
  → 每7天下载搜索词报告
  → 筛选：有转化 + 相关性强的词 → 转移到手动精准层（见第十章）
  → 筛选：有点击无转化 + 不相关词 → 添加否定词

任务2：持续运行积累数据
  → 自动广告不要频繁开关，保持持续运行
  → 系统需要积累足够数据才能优化匹配

任务3：为eCPM积累基础数据
  → 自动广告期间的CVR数据是eCPM拟合的基础
  → CTR表现反映主图和价格的市场接受度
```

### 4.4 自动广告的否词管理

```
每7天执行一次否词清理：

【需要否定的词类型】
  类型A：高点击无转化词（点击≥10次，0转化）→ 否定精准
  类型B：明显不相关词（词义与产品无关）→ 否定词组
  类型C：已转移到手动精准层的词 → 否定精准（防止内耗）
  类型D：竞品品牌词（非主动进攻期）→ 否定词组

【否词操作位置】
  广告活动层级否词：适用于全局过滤，慎用
  广告组层级否词：针对该组投放过滤，常用
```

## 五、第二层：手动广告核心词投放（1v1精准层）

### 5.1 核心架构原则：1 × 1 × 1 × 1

```
1个广告活动
  └── 1个广告组
        └── 1个推广SKU（单个ASIN）
              └── 1个关键词

原因：
  ① 1v1结构让每个词的数据独立，便于精确判断该词的表现
  ② 可以针对每个词单独设置竞价，不受其他词影响
  ③ 可以针对每个词单独控制预算
  ④ 坑位监控时，能精确知道是哪个词的哪个广告位在出单
```

### 5.2 手动广告活动命名规范

```
命名格式：[品类]_SP_Manual_[匹配类型]_[关键词简称]_[日期]

示例：
  Earbuds_SP_Manual_Broad_WirelessEarbuds_20260522
  Earbuds_SP_Manual_Phrase_WirelessEarbuds_20260601
  Earbuds_SP_Manual_Exact_WirelessEarbuds_20260701

  规则说明：
  - Broad = 广泛匹配阶段
  - Phrase = 词组匹配阶段（升级后新建，原广泛活动保留观察期）
  - Exact = 精准匹配阶段（进一步升级后新建）
```

### 5.3 初始竞价设置逻辑

```
手动广告初始竞价设置分3档：

档位一：核心词（流量Top 1~2个词）
  初始竞价 = 建议竞价 × 1.2~1.3
  首页顶部溢价 = 50%~80%
  策略：激进占位，必须抢首页首位

档位二：重要词（流量Top 3~5个词）
  初始竞价 = 建议竞价 × 1.0~1.1
  首页顶部溢价 = 30%~50%
  策略：稳定首页，不一定每次首位

档位三：补充词（流量Top 6~10个词）
  初始竞价 = 建议竞价 × 0.85~1.0
  首页顶部溢价 = 20%~30%
  策略：保持首页曝光，控制成本

广泛匹配阶段竞价 × 0.8（低于词组和精准，因为流量更宽泛，转化率相对低）
词组匹配阶段竞价 × 1.0（基准）
精准匹配阶段竞价 × 1.2（最精准，值得提竞价争首位）
```

### 5.4 竞价策略选择

| 阶段 | 竞价策略 | 原因 |
|------|----------|------|
| **新品期（广泛匹配阶段）** | 动态竞价 - 提高和降低 | 让系统自动在高转化机会提价，获取更多出单数据 |
| **成长期（词组匹配阶段）** | 动态竞价 - 提高和降低 | 继续优化，向高转化词倾斜 |
| **成熟期（精准匹配阶段）** | 固定竞价 或 动态提高和降低 | 精准词已知转化率，固定竞价可精确控ACOS |

### 5.5 手动广告日预算分配

```
总日预算分配参考（以总预算$100/天为例）：

第一层（自动广告）：$20（20%）
  → 持续探词，低预算维持即可

第二层（手动核心词）：$60（60%）
  → 按词的流量权重分配
  → 流量Top1~2词：各$15~$20
  → 流量Top3~6词：各$5~$8

第三层（ASIN定投+类目）：$15（15%）

第四层（视频/品牌旗舰店）：$5（5%）
  → 成熟期逐步增加至15%~20%
```

## 六、第三层：ASIN定投 + 类目广告（流量扩张层）

### 6.1 ASIN定投：从出单ASIN中找目标

**触发条件：** 自动广告或手动广告运行4~6周后，有足够的ASIN出单数据。

**操作步骤：**

```
Step 1：从广告报告中找出已出单的商品ASIN
  下载路径：Ads Console → 报告 → 商品报告（Products Report）
  筛选：有转化（Purchases > 0）的目标ASIN列表
  
Step 2：分析这些出单ASIN的特征
  ┌────────────────────────────────────────────────────────┐
  │ 分类                 │ 出单ASIN特征      │ 投放策略    │
  ├────────────────────────────────────────────────────────┤
  │ 进攻型定投           │ 竞品ASIN（已出单）│ SP商品定向  │
  │ 互补型定投           │ 互补品ASIN（已出单）│ SP商品定向│
  │ 防守型定投           │ 自身ASIN          │ SD商品定向  │
  └────────────────────────────────────────────────────────┘

Step 3：建立ASIN定投广告活动
  命名：Earbuds_SP_ASIN_进攻_20260601
  结构：1个活动 → 1个广告组 → 投放多个同类竞品ASIN
  竞价：建议竞价的85%~100%
  竞价策略：动态竞价 - 提高和降低
```

**ASIN定投目标选择策略：**

```
进攻目标优先选：
  ✅ 价格高于我方10%~30%的竞品
  ✅ 评分低于我方（最好 < 4.2星）
  ✅ 评论数少于我方
  ✅ 近期有差评爆发的竞品

避免定投：
  ❌ 评分≥4.8且评论>5000条的强势竞品（截流成功率极低）
  ❌ 正在做DOTD/大型BD的竞品（该时段其CVR极高，我方截流成本太高）
```

### 6.2 类目广告：品类整体覆盖

**触发条件：** 成长期（D31开始），与ASIN定投同步开启。

**操作步骤：**

```
Step 1：建立类目投放广告活动
  命名：Earbuds_SP_Category_20260601
  投放类型：手动投放 → 商品投放 → 类目投放

Step 2：选择目标类目
  方法：在商品投放中选择与产品最相关的1~3个子类目
  细分筛选器设置：
  ┌────────────────────────────────────────────────────────────┐
  │ 筛选维度   │ 设置建议                                       │
  ├────────────────────────────────────────────────────────────┤
  │ 价格范围   │ 高于我方$5以上的区间（定向对我有价格优势的场景）│
  │ 品牌筛选   │ 排除强势头部品牌，保留中小品牌类目              │
  │ 评分筛选   │ ≤ 4.1星（定向质量较弱的类目段）                 │
  └────────────────────────────────────────────────────────────┘

Step 3：竞价设置
  初始竞价：建议竞价的75%~85%
  策略：动态竞价 - 仅降低（类目广告转化率通常低于关键词，严控成本）
  
Step 4：监控重点
  类目广告的ACOS通常高于关键词广告，属正常现象
  关注：是否带来了新词的曝光和出单（看搜索词报告）
  ACOS目标：允许比总目标高20%~30%
```

## 七、第四层：视频广告 + 品牌旗舰店子页面广告（品牌放大层）

### 7.1 开启前提条件

```
视频广告（SBV）开启前提：
  ✅ 品牌已完成注册（Brand Registry）
  ✅ 有高质量产品视频（15~45秒，横版16:9）

  ✅ 品牌旗舰店已建立且内容完整
```

## 八、SIF坑位监控实操

### 8.1 SIF监控的配置步骤

```
Step 1：在SIF中输入要监控的关键词
  进入 SIF → 关键词排名追踪功能
  输入6~10个核心词
  选择站点（如amazon.com）
  设置追踪频率（推荐：每小时自动抓取）

Step 2：关联我方ASIN
  在追踪设置中绑定我方产品ASIN
  系统会自动标记我方ASIN在各坑位的排名

Step 3：配置竞品ASIN
  同时添加3~5个核心竞品ASIN进行对比追踪
  系统会同时显示竞品在各坑位的排名变化

Step 4：设置监控维度
  需要同时追踪的4个坑位：
  ① 自然位（Organic Position）
  ② SP广告推荐位（Sponsored Top Position）
  ③ SP广告常规位（Sponsored Other Position）
  ④ SB/SBV广告位（Brand/Video Position）
```

### 8.2 每小时坑位快照读取方法

**SIF数据读取标准流程（5分钟/次）：**

```
打开SIF追踪面板，对每个核心词读取以下数据：

【我方排名读取】
  自然位：第___位（目标：逐周上升）
  SP推荐位：第___位（目标：稳定第1~2位）
  SP常规位：第___位（辅助参考）
  SB位：是否出现（是/否）

【竞品排名对比】
  竞品A在SP推荐位：第___位 vs 我方第___位
  竞品B在SP推荐位：第___位 vs 我方第___位
  → 谁在我前面？他们是否刚刚加价？

【排名变化趋势】
  我方自然位本小时 vs 上小时：上升/下降/持平
  连续3小时下滑 → 触发竞价调整预警
```

### 8.3 坑位数据→竞价决策映射

```
场景一：SP推荐位我方第1位，自然位稳定上升
  → 理想状态，维持竞价不变
  → 如果ACOS低于目标15%以上，可小幅降竞价5%节省成本

场景二：SP推荐位我方第2~3位
  → 当前竞价不足以稳定占首位
  → 对该词竞价 +10%，观察1~2小时是否恢复首位

场景三：SP推荐位未出现（掉出首页）
  → 竞价明显不足 或 广告预算耗尽
  → 立即检查：①今日预算剩余 ②竞价是否偏低
  → 竞价 +20%，或提高日预算

场景四：竞品突然出现在我前面（新进首位）
  → 进入SIF查看该竞品当前状态（是否有促销/降价）
  → 若竞品做LTD：等4~6小时LTD结束后再追
  → 若竞品持续占位：竞价 +15% 强夺首位

场景五：自然位连续3天无变化（停留在第25~50位）
  → 说明广告流量未有效转化为排名信号
  → 检查：CVR是否正常？是否需要促销配合拉转化？
  → 考虑上线Coupon（5%~10%）提升转化率
```

### 8.4 SIF快速监控时间安排

```
每日监控时间节点（结合目标市场时区）：

以美国站为例（北京时间）：
  06:00（美东前日17:00）→ 下午购物高峰开始
  09:00（美东前日20:00）→ ⭐晚间黄金时段高峰（最重要）
  11:00（美东前日22:00）→ ⭐晚间高峰延续
  13:00（美东00:00）    → 夜间低谷检查
  21:00（美东08:00）    → 早间上班前购物
  23:00（美东10:00）    → ⭐午前购物高峰

黄金时段（北京09:00~12:00）必须每小时监控一次
其他时段每2~3小时监控一次
```

## 九、匹配方式升级路径（广泛→词组→精准）

### 9.1 三种匹配方式特性对比

| 匹配方式 | 流量覆盖范围 | 精准度 | 转化率 | CPC水平 | 适用阶段 |
|----------|-------------|--------|--------|---------|----------|
| **广泛匹配** | 最广（包含词根的所有变体） | 低 | 中低 | 低 | 新品探索期 |
| **词组匹配** | 中等（包含关键词短语的查询） | 中 | 中 | 中 | 成长期主力 |
| **精准匹配** | 最窄（仅完全匹配词） | 高 | 高 | 高 | 成熟期核心 |

### 9.2 广泛匹配适用条件与触发时机

```
开始用广泛匹配的条件：
  ✅ 对该词尚无足够的搜索词数据（通常是新词上线）
  ✅ 希望通过广泛匹配发现词的延伸变体
  ✅ 新品期/探索期

广泛匹配使用规范：
  竞价设置 = 建议竞价 × 0.8（低于词组/精准，控制成本）
  否词配合：每7天添加一批不相关词的否词
  核心动作：持续挖掘高转化搜索词，准备升级

升级到词组匹配的触发条件（满足任意2条）：
  □ 该词在广泛匹配下积累了 ≥ 30次点击
  □ 已有 ≥ 3次转化
  □ ACOS已在目标范围内
  □ 已确认该词的搜索变体中，词组匹配能覆盖主要变体
```

### 9.3 词组匹配：中部词和小词的直接入口

```
以下情况可以直接用词组匹配，跳过广泛匹配阶段：

条件：相关性比较高的中部词和小词
  → "中部词"：搜索量中等（月搜索量1,000~10,000）
  → "小词"：搜索量小（月搜索量 < 1,000）但高度精准

原因：
  ① 中小词词根明确，词组匹配已能覆盖主要变体
  ② 相关性高的词广泛匹配带来的额外流量价值有限
  ③ 直接词组匹配可以更快进入精细化控制阶段

词组匹配竞价 = 建议竞价 × 1.0（基准）
首页顶部溢价：30%~50%
```

### 9.4 从词组匹配升级到精准匹配

```
升级触发条件（同时满足）：
  ✅ 词组匹配下该词已稳定出单（≥ 2周持续有转化）
  ✅ ACOS在目标范围内
  ✅ 该词的主要变体已通过否词清理干净
  ✅ 每周出单量 ≥ 5单（规模足以支撑精准层）

升级操作：
  方式A（推荐）：
    → 新建一个广告活动，使用精准匹配，同一关键词
    → 原词组匹配活动保留（降低竞价观察，不要立刻关闭）
    → 在词组匹配活动中对该词添加"否定精准"（防内耗）
    → 观察2周，确认精准层表现 ≥ 词组层，再关闭词组层

  方式B（简化）：
    → 直接在原广告活动中修改匹配方式为精准
    → 风险：数据会有断层，需要重新积累学习期

精准匹配竞价 = 词组匹配竞价 × 1.2
首页顶部溢价：50%~100%（精准词值得争首位）
```

### 9.5 三层匹配同时运行的内耗防控

```
当同一关键词同时存在广泛/词组/精准三种匹配时，
三个广告活动会在同一竞价中互相竞争，推高CPC。

解决方案：层级否定

精准匹配活动 → 不设否词（最精准，优先级最高）
词组匹配活动 → 对精准词添加"否定精准"
广泛匹配活动 → 对精准词添加"否定精准"，对词组词添加"否定词组"

效果：
  搜索 "wireless earbuds"（精确匹配）→ 只走精准层
  搜索 "best wireless earbuds"（含词组）→ 走词组层（精准层不触发）
  搜索 "wireless earphones earbuds bluetooth"（宽泛）→ 走广泛层
```

## 十、搜索词筛选与1v1建组流程

### 10.1 搜索词报告下载与分析频率

```
新品期      每7天       找有转化的词，快速建手动组
```

### 10.2 搜索词四象限分类处理

```
下载搜索词报告后，按以下四象限处理：

              │ 高转化（CVR≥行业均值）
              │
  ┌───────────┼───────────┐
  │ 高点击    │ 高点击    │
  │ 高转化    │ 低转化    │
  │           │           │
  │ ★ 立即升级│ ⚠️ 找原因  │
  │ 到手动精准│ 改Listing │
  ├───────────┼───────────┤ ───── 低转化（CVR<行业均值）
  │ 低点击    │ 低点击    │
  │ 高转化    │ 低转化    │
  │           │           │
  │ 📈 提竞价  │ ❌ 否定    │
  │ 扩大曝光  │ 清理      │
  └───────────┴───────────┘
  低点击                   高点击
  （曝光不足）             （曝光充足）
```

### 10.3 高价值词1v1建组标准操作

```
触发条件：搜索词满足以下任意条件即可建组
  ○ 该词点击量 ≥ 5次 且 有转化
  ○ 该词是核心品类词（即使点击少，相关性强）
  ○ 该词与预设6~10个核心词高度相关

建组操作步骤（共8步）：

Step 1：确认词是否已有独立广告活动
  → 已有 → 检查表现，可能需调整竞价
  → 没有 → 新建（继续下一步）

Step 2：确认该词当前应使用哪种匹配方式
  → 大词/新词/无数据 → 广泛匹配
  → 中部词/有基础数据 → 词组匹配
  → 核心词/有充分数据 → 精准匹配

Step 3：新建广告活动
  命名：[品类]_SP_Manual_[匹配类型]_[词简称]_[日期]

Step 4：在广告活动中新建广告组
  命名与广告活动相同（1v1只有1个组）

Step 5：添加推广商品（仅添加该SKU的ASIN）
  注意：只添加1个ASIN（精品打法单SKU精准）

Step 6：添加关键词（仅1个词）
  匹配方式按Step2确认的类型选择
  初始竞价：参考建议竞价，按档位设置（见5.3）

Step 7：设置广告活动参数
  竞价策略：动态竞价 - 提高和降低
  首页顶部溢价：按词的重要性设置（核心词50%~80%，其余20%~50%）
  日预算：按词的重要性分配（见5.5）

Step 8：在原自动广告组中添加否定词
  将该词添加到自动广告的否定词组/否定精准
  → 防止自动广告和手动广告在同一词上互相竞争
```

### 10.4 建组后的跟踪管理

```
每个手动1v1广告活动建立后，建立跟踪记录：

追踪表字段：
  关键词 | 匹配方式 | 建组日期 | 初始竞价 | 当前竞价
  7天点击 | 7天转化 | 7天ACOS | 排名趋势 | 下步动作
  升级状态（广泛→词组→精准的进度）
```

## 十一、四阶段执行节奏与核心指标

### 11.1 新品期（D1~D30）：建基础、跑数据

```
【D1~D3：上线初始化】
  ✅ 自动广告上线（建议竞价85%，动态提高和降低）

核心指标目标（D30时）：
  曝光量：≥ 5,000次/天（视类目调整）
```

### 11.2 成长期（D31~D90）：攻排名、控成本

```
【D31~D45：手动层全力建设期】
  → 6~10个核心词全部建立独立手动广告活动（1v1结构）
  → 广泛匹配表现好的词开始向词组匹配升级
  → 中小词直接以词组匹配入场
  → ASIN定投广告开启（基于自动广告发现的出单ASIN）
  → 类目广告开启（辅助扩大覆盖面）

【D46~D60：精细化优化期】
  → 每7天按四象限分析调整竞价
  → 首位占据率目标：核心词Top2，SP推荐位稳定≥70%时长
  → SIF监控密度：黄金时段每小时一次

  → 关注ACOS从高位逐步降低

  → 视频广告素材准备完成后，开启SBV

核心指标目标（D90时）：
  ACOS：≤ (1-毛利率) × 100%（达到盈亏平衡）
  自然排名：≥ 2个核心词进入前20
  广告订单占比：≤ 60%（自然流量开始贡献）
  TACOS：< 18%
```

### 11.3 成熟期（D90+）：提利润、扩规模

```
【D90~D120：利润优化期】
  → 核心词全部升级精准匹配
  → 精准词竞价基于eCPM每2周微调一次（每次±5%~10%）
  → 开启品牌旗舰店子页面广告
  → TACOS目标设为12%，逐步向10%逼近

【D120+：规模扩张期】
  → 在天机打法核心词稳定后，向击穿关联流量方向扩展
  → 海量词收录打法辅助补充长尾词流量
  → 站外流量（TikTok/Deal站）配合大促节点投放

核心指标目标（D120时）：
  TACOS：≤ 12%
  ROAS：≥ 3
  自然排名：≥ 3个核心词进入前10
  广告利润：正向（广告带来的GMV利润 > 广告花费）
```

### 11.4 促销期：全火力冲量

```
大促前2周：
  ✅ 核心词竞价提升30%~50%
  ✅ 日预算提升至平时2~3倍
  ✅ 确认Coupon/Deals/Lightning Deal设置完成
  ✅ 库存确认充足（大促期间断货损伤极大）

大促期间（每日操作）：
  → 早高峰前：检查预算余额和广告状态
  → 高峰时段：每小时SIF坑位监控，确保首位占位
  → 发现竞品做DOTD：错峰或加竞价对抗（视竞品实力判断）

大促后48小时内：
  ✅ 竞价恢复正常水平
  ✅ 下载大促期间搜索词报告，挖掘新的高转化词
  ✅ 复盘各广告活动ROI，评估资金分配效率
```

## 十二、每日/每周操作清单

### 12.1 每日操作（20分钟）

```
【早上（开始工作前）】
□ 查看昨日广告花费是否在计划内（有无超预算或骤降）
□ 检查6~10个核心词在SIF中的当前自然排名
□ 检查Featured Offer状态（是否仍持有购物车）
□ 快速扫一眼昨日ACOS（有无异常波动）

【黄金时段（美东晚8~10点，北京时间约次日09:00~11:00）】
□ 打开SIF，逐词查看坑位快照（每个词2分钟，共约15分钟）
□ 记录各词的4个坑位排名到监控表
□ 判断是否需要调竞价（按场景映射表操作）
□ 记录最强竞品的促销状态（LTD/BD/DOTD）

【下午（结束工作前）】
□ 复盘今日有无执行竞价调整，效果如何
□ 检查自动广告今日花费（是否接近日预算上限）
□ 有无异常情况（广告活动被暂停/ASIN被抑制）
```

### 12.2 每周操作（60~90分钟）

```
【周一：搜索词报告处理】
□ 下载自动广告搜索词报告（最近7天）
□ 按四象限分类处理：高转化词升级/否定无效词
□ 新增手动广告1v1组（如有符合条件的搜索词）
□ 更新否词列表

【周三：竞价全面复盘】
□ 对所有手动广告活动，按四象限规则调整竞价（±10%~20%）
□ 检查各广告活动预算利用率（目标>80%）
□ 检查首页顶部溢价设置是否合理

【周五：数据汇总与决策】
□ 更新周度排名追踪表（自然位+广告位）
□ 计算本周各核心词的eCPM估算值
□ 评估匹配方式是否需要升级（广泛→词组→精准）
□ 更新竞品监控数据（竞品价格/评价/促销状态变化）

【每月第一天：月度复盘】
□ 检查广告目标层级是否达成（对照11.1~11.3目标）
□ 判断当前处于哪个阶段，下个月重点是什么
□ TACOS趋势分析（是否在下降通道）
□ 评估是否需要开启下一层广告（或升级匹配方式）
```

### 12.3 异常情况快速响应表

| 异常现象 | 第一反应（1分钟内） | 处理操作（5分钟内） |
|----------|-------------------|-------------------|
| 广告花费骤降（<昨日50%） | 检查广告活动是否被暂停 | 检查预算余额/ASIN状态/竞价是否被意外改低 |
| ACOS突然飙升（>目标2倍） | 检查当日有无异常大额点击 | 下载当日搜索词报告，找高消耗低转化词否定 |
| 核心词排名骤降 | 检查竞品是否有DOTD/LTD | 判断是否跟竞价；DOTD竞品错峰应对 |
| Featured Offer丢失 | 立即查价格是否被竞品打低 | 根据利润空间决定是否跟价 |
| 自动广告曝光骤降 | 检查是否否词过多屏蔽大词 | 审查最近一批否词操作，撤销过度否定 |
| 自然排名突然消失 | 检查ASIN是否被suppressed | 进入Manage Inventory修复合规问题 |
