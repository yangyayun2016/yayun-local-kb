SOLDY CROSS-BORDER ECOMMERCE PRODUCT STRATEGY

Soldy的跨境电商行业产品运营策略

从独立视频创作产品，升级为跨境电商工作流中的视频内容生产层：独立创作工作台、可嵌入的商品视频创作引擎与多平台连接器协同发展。

产品定位架构设计商家工作流生态接入商业化路径落地路线
核心结论路线比较产品架构商家界面接入工具使用流程商业化路径落地路线最终建议

核心结论

Soldy不应该试图成为新的跨境ERP，也不应只停留在一个需要商家单独登录的视频网站。最适合的产品形态是三部分协同：

独立创作工作台

Soldy Studio

承载品牌理解、复杂创作、Storyboard、Campaign与多版本管理。

可嵌入创作引擎

Soldy Connect

进入ERP、刊登工具、选品工具、广告工具和商品页面。

多平台连接能力

Creative API

以异步Job API和Webhook为底座，再向SaaS、自动化平台与AI Agent提供连接器、MCP和插件。

商家可以在原有ERP、刊登工具、选品工具或广告工具里直接调用Soldy；只有复杂创作，才进入Soldy完整工作台。

1

Soldy Studio：独立创作中枢

继续保留现有Soldy网站，负责Brand Kit和品牌资产管理、Agent深度创作、Story Video、Hooks Studio、Marketing Studio、项目历史与团队协作，以及复杂Campaign和多版本管理。

它是“创意总工作台”，但不要求商家每天都从这里开始。

2

Soldy Connect：进入商家现有工作流

这是最应该优先建设的产品。形态包括Chrome浏览器插件、SaaS内嵌侧边栏、商品列表中的“使用Soldy生成视频”按钮、带商品上下文的安全跳转链接，以及Shopify、TikTok Shop和Amazon应用。

商家不再重新找图、复制标题和填写参数。例如：

选择ASIN → 点击“生成商品视频” → 自动带入标题、图片、品牌、卖点 → 选择Amazon SB Video → 生成3个版本 → 返回素材库
3

Soldy Creative API：面向ERP、SaaS与AI工作流

把Soldy包装成标准化、可异步调用的视频创作能力。底层用Creative Job API创建任务，用Webhook返回方向、进度与成片；上层再封装平台连接器、Remote MCP和原生插件。

商品资料 + 品牌资料 + 平台 + 经营任务↓create_job → creative_ready → render_completed↓方向 + 脚本 + Hook + 视频 + 封面 + 字幕 + 发布规格

调用方只需要表达经营任务，不需要理解Soldy内部模型、Mode和渲染流程。

Creative API的任务类型

amazon_listing_videoamazon_sponsored_brands_videoamazon_sponsored_products_videoamazon_store_background_videotiktok_shoppable_videotiktok_hook_variationstiktok_ugc_adtiktok_live_teaseraffiliate_creator_reference
设计原则：API不应只有一个抽象的“生成视频”接口，而应直接表达商家的经营任务，让调用方自动获得正确的比例、时长、Hook、Mode和平台约束。

三、商家真正应该看到的操作界面

新用户不应该先看到UGC、TV Spot、Seedance和模型选择。第一步应该是选择自己要完成的经营任务。

Amazon任务

  • 为这个ASIN生成商品视频
  • 生成Sponsored Brands广告
  • 生成Sponsored Products无声卖点视频
  • 生成Brand Store背景视频
  • 生成站外引流视频
  • 为新品生成首发内容包

TikTok Shop任务

  • 为这个商品生成一周挂车内容
  • 生成5个不同首镜
  • 生成UGC种草视频
  • 生成开箱、测评或教程
  • 生成虚拟试穿视频
  • 生成直播预热视频
  • 生成达人创作参考
商家选择经营任务↓平台规格 → Hook → Mode → Avatar → 时长 → 比例 → Brand Kit

映射过程由Soldy在后台完成。这比要求商家先理解模型、提示词和创作工具容易得多。

四、优先进入哪些商家工具与自动化工作流

优先顺序不是简单按平台大小排列，而是看Soldy能否取得商品上下文、在关键节点被触发，并把方向、视频和任务状态送回原工作流。

1

工具合作：ERP、选品工具与浏览器插件

工具类型代表产品核心场景Soldy产品形态合作方案
ERP领星、店小秘、马帮Listing就绪、新品上架、广告建档或达人邀约时，批量选择SKU生成视频。商品行内按钮或侧边栏 + Creative Job API + Webhook；成片回写素材库或审核任务。先做单客户联合试点，再做账户互通；采用积分分成、API采购或ERP增值包。
选品工具卖家精灵、Helium 10、Jungle Scout把关键词、竞品、需求趋势与ASIN机会直接转成场景、Hook和视频Brief。“生成视频方向”按钮 + 带上下文安全跳转；先返回3个方向，确认后再渲染。共建类目模板和新品内容包；通过会员权益、联名活动和转化分成获客。
浏览器插件Amazon、TikTok Shop、Shopify商品页；合作方已有插件没有正式API合作时，读取当前商品页标题、图片、卖点和变体，一键唤起Soldy。Soldy Chrome插件或嵌入合作方插件的轻量面板；结果保存、下载或回到Soldy项目。作为最快的需求验证入口；验证高频页面后，再推动官方API或SaaS深度集成。

领星开放平台 · 卖家精灵开放平台

2

自动化与AI Agent：进入商家自己搭建的生产流

商家正在把“商品数据 → 内容生产 → 审核 → 分发”装进自动化平台和Agent。Soldy不需要替代这些编排工具，而要成为其中可被调用的视频生产节点。

工作流类型代表产品商家场景Soldy产品形态合作方案
可视化自动化n8n、Make、Zapier、Shopify Flow新品或Listing状态触发首发内容包；批量SKU定时生成；表现下降后补充Hook变体。原生节点/连接器 + Creative Job API + Result Webhook，输出job_id、方向、预览和成片URL。发布官方连接器与3—5个可复制模板；与平台服务商、自动化顾问共同交付商家方案。
Agent搭建平台Dify、扣子商家搭建“内容运营Agent”，在商品、品牌规则和平台目标之间自动选择视频任务。Dify Tool Plugin、扣子插件或Remote MCP；工具只暴露经营任务，不暴露模型参数。进入插件市场，提供Amazon新品、TikTok周内容等Starter Workflow，并联合招募标杆商家。
通用AI助手ChatGPT、Claude及其他MCP客户端在对话中完成“为这些SKU出方向、生成、查进度、取成片”；发布前保留人工确认。OAuth Remote MCP Server：create_video_job、get_video_job、list_creative_directions、cancel_video_job。先提供企业私有连接，再申请应用目录；以商家自有Soldy账户计费并保留调用日志。
产品顺序：先 API，后 MCP，再做平台适配。Creative Job API + Webhook是执行底座；MCP让不同Agent用同一组工具；原生节点和插件解决平台内分发。Skills 负责告诉 Agent 如何组合工具和遵守平台规则，但不能替代鉴权、执行、状态和计费。
触发器：新品创建 / Listing就绪 / 素材衰退↓工作流或Agent整理商品、品牌与平台目标↓Soldy create_video_job → Webhook返回方向与成片↓人工确认 → 回写素材库或进入发布队列

3

第三优先：TikTok Shop官方应用

TikTok Shop支持Public App和Custom App。Soldy可以先用Custom App服务小批量内测商家，再申请Public App进入应用市场。

产品形态：商品或达人任务旁的“生成挂车视频 / 达人样片”，自动同步商品资料，生成后进入审核与下载队列。
合作方案：与TikTok Shop服务商或MCN共建类目模板，先以商家自有Soldy账户试点，再申请公开应用和联合市场活动。

第一阶段只申请：店铺授权信息、Product Basic、商品图片与基础资料。不要一开始申请订单、履约、达人和财务等无关权限。

TikTok Shop应用开发 · API权限范围

4

第四优先：Amazon Selling Partner Appstore

Amazon SP-API可以获得ASIN属性、图片、尺寸、变体和Listing信息，适合自动生成视频Brief。公共应用需要OAuth授权并进入Selling Partner Appstore，安全与合规要求较高，因此建议在ERP和浏览器插件验证需求后再投入。

产品形态：以ASIN为入口生成Listing视频、Sponsored Brands或Sponsored Products视频，先返回方向与声明检查，再渲染并保存到Soldy项目。
合作方案：先和Amazon ERP或服务商共建任务模板与案例，验证付费后再投入Appstore审核；不申请订单、财务和履约等无关权限。

Amazon Catalog Items API · Amazon Appstore上架要求

5

第五优先：Shopify应用与Flow Action

Shopify应用可以嵌入后台读取商品标题、描述、图片、视频和变体，并把生成视频写回商品媒体库；Shopify Flow还允许Soldy成为商家自动化流程中的Action。

产品形态：后台商品页侧边栏 + “Create Soldy video job” Flow Action + “Video ready” Trigger。
合作方案：先用公开或定制应用验证授权、异步任务和回写，再发布Flow模板，与Shopify Agency共同销售新品首发与内容补量方案。

Shopify嵌入式应用 · Shopify Flow扩展 · Shopify商品API

五、建议的商家使用流程

整个常规流程应尽量控制在一个侧边栏或弹窗中；只有调整Brand Kit、Storyboard或复杂Campaign时才进入完整工作台。

1 选择商品ERP或Seller Center中的ASIN/SKU
2 点击Soldy商品旁的生成视频按钮
3 自动同步标题、图片、品牌、卖点、变体
4 选择任务选择经营任务而不是模型
5 推荐方向Soldy给出3个创意方向
6 确认Hook商家选择方向与首镜
7 批量生成生成3–6条视频
8 审核返回核对商品和声明，保存或下载
9 结果反馈根据表现生成下一批
核心体验指标：减少重复上传、减少工具切换、减少提示词学习，并让生成内容能够直接进入商家的素材和发布流程。

六、产品对应商业化路径（包含与生态伙伴合作方式）

三条产品路线采用不同收费方式：Studio直接服务商家，Connect通过生态伙伴获客和分销，Creative API与MCP按企业调用量收费。

Studio订阅与积分

向商家收取席位订阅、生成积分和高级Campaign费用；保留商家账户、品牌资产与升级关系。

Connect渠道分成

插件免费安装，商家使用自有Soldy账户；ERP、选品工具和服务商获得推荐佣金，深度伙伴可批量采购视频额度转售。

API与MCP用量计费

按任务量、时长、分辨率和并发收费，并设置企业最低月费；面向SaaS、Agent平台、代运营和大型品牌。

生态伙伴合作产品合作方式收益分配
ERP / SaaS内嵌Connect、Creative Job API联合试点、账户互通、结果回写；成熟后进入正式功能模块。推荐佣金、API批量采购或增值包分成。
选品工具 / 浏览器插件视频方向按钮、安全跳转、轻量面板共建类目模板、会员权益和联名获客活动。按激活、首购或持续消费分成。
自动化 / Agent平台原生节点、Tool Plugin、Remote MCP、Skills模板进入应用市场，发布可复制工作流；商家连接自己的Soldy账户。Soldy收取调用费，平台或实施伙伴获得渠道及交付收益。
平台服务商 / Agency / MCNTikTok、Amazon、Shopify任务模板联合交付新品首发、内容补量和达人样片方案。项目服务费 + 视频额度差价或联合套餐分成。
早期最容易推动：免费连接器 + 商家自有账户 + 体验积分 + 成交分成；验证用量后再转向额度采购和企业API合同。

合作原则：伙伴获得渠道与交付收益，Soldy保留创作引擎、账户体系和品牌关系；只在明确的大客户项目中提供有限白标。

七、落地顺序

0—2个月

验证入口

  • 上线Soldy Chrome插件
  • 支持Amazon、TikTok Shop、Shopify商品页一键带入
  • 建立Amazon/TTS经营任务模板
  • 生成后返回原页面或下载
  • 验证哪个入口使用率最高
2—5个月

建立可嵌入能力

  • 发布Creative Job API与Webhook
  • 提供SaaS组件、安全跳转和Remote MCP
  • 与一家Amazon工具和一家TikTok ERP试点
  • 用Shopify Flow验证触发、状态与回写
5—9个月

进入应用市场

  • TikTok Shop Public App
  • Amazon Selling Partner Appstore应用
  • 与领星、店小秘或马帮正式合作
  • 商品资料自动同步与成片回写
9个月以后

内容反馈闭环

  • 接入关键词和素材表现
  • 使用播放、点击与转化反馈
  • 建议下一批Hook和Mode
  • 创意疲劳提醒
  • 不进入预算、订单、库存与履约
长期边界：即使接入表现数据，Soldy仍聚焦“内容建议与再生产”，不要过早扩张为广告管理、订单、库存和履约系统。

最终建议

Soldy最合适的定位不是：

又一个商家需要每天登录的AI视频网站。

而是：

跨境电商SaaS里的视频内容生产层——商家在哪里管理商品、刊登、达人和广告，Soldy的“生成视频”按钮就出现在哪里。

独立Soldy负责品牌理解和复杂创作；Soldy Connect负责进入商家页面；Creative API负责异步任务与规模化分发。MCP、原生插件和Skills都是这三条路线的适配层，不应演变成彼此割裂的新产品。
