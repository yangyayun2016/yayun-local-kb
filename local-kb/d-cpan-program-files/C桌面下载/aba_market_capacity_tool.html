ABA 关键词市场容量估算工具｜最小公共样本量算法

用 ABA Top ASIN 点击占比 / 购买占比反推关键词点击量、订单量、CVR，并聚合成关键词市场容量。

1. 粘贴 ABA 数据

支持 CSV。必填字段：date, keyword, click_share1, order_share1, click_share2, order_share2, click_share3, order_share3。
可选字段：search_frequency, asin1, asin2, asin3, price, cogs, fba, referral_rate, keyword_group。占比可写 16.397% 或 0.16397。

说明：本工具是前端单文件版，不上传数据。大批量月度数据建议把最大 N 调高，但运行会变慢。

2. 程序原理

ABA 给出：p = Top ASIN 点击占比 / 购买占比。
真实关系：p ≈ x / N，其中 x 是该 ASIN 的整数点击/订单，N 是该关键词总点击/总订单。
反推目标：找到最小 N，使每个 p_i × N 都接近整数。
N_click = min N satisfying round(p_click_i × N) / N ≈ p_click_i
N_order = min N satisfying round(p_order_i × N) / N ≈ p_order_i

这不是数学课本里“几个整数求 LCM”的机械算法，而是“最小公倍数思想”：多个占比必须同时来自同一个总样本量，所以寻找那个最小公共分母 / 最小公共样本量。

3. 准确度评分

占比锚点数 小数精度 整数残差 订单≤点击 CVR 合理性

结果分为：高、中、低。低置信度通常来自占比缺失、ABA 百分比被截断、Top ASIN 变化、N 超过最大搜索范围，或关键词购买量太小。
