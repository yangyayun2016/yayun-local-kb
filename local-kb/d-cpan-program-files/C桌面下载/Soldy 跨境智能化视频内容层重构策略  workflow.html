1

Soldy Native Sandbox：无痛突破风控墙

基于 Chrome Extension V3 的真实环境。通过网页元素的智能化定位（AI Element Mapping），商家只需在自己日常使用的 ERP 或卖家中心页面顺手一划，插件即可利用大模型瞬间剥离出当前的标题、图册及核心卖点。杜绝云端 Headless 运行模式，用完全拟真的真人随机行为路径、点击延迟和鼠标移动轨迹，消灭验证码高发问题。

2

VLM Memory Engine：技术红利下的成本递减机制

引入类似 AllyHub 的 Compounds Down（复利进化）记忆算法。通过向量数据库储存特定品牌的视频生成记录，每一次调整和生成都会进化大模型的本地约束规则。当商家二次为同品牌或同品类生成视频时，系统不再重新消费全量 Context Token，直接调用沉淀下来的 Schema，让视频产出效率提升 300%，而大模型 Token 消耗成本下降 50% 以上。

新商品注入 → 匹配历史大卖类似风格模式 (LanceDB) → 检索高点击 Hook → 自动生成视频结构
3

Soldy Creative API / MCP：面向自动化时代

放弃重度复杂的前端交互，把视频能力原子化。深度拥抱 Model Context Protocol (MCP) 协议。提供开放式架构，允许高级卖家在自建的 Claude 或 Dify/n8n 自动化画布中，直接将其作为一个通用“Action Node”引入：
