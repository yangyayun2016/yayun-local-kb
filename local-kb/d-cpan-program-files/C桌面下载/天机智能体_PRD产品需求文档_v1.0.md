## 1. 产品概述

### 1.1 产品定位

**天机智能体**是一款专注于**跨境电商**场景的 AI Agent 平台。帮助跨境卖家、品牌运营者、选品团队通过自然语言指令完成选品、运营、营销、数据分析、内容生产等全链路工作，实现"一句话驱动多步骤自动化"。

> 核心口号：**一个智能工作台，驱动整个跨境电商业务**

### 1.2 与 StoreClaw 的对标与差异

| 维度 | StoreClaw | 天机智能体（新增/差异化） |
|---|---|---|
| 核心定位 | 跨境电商 AI 成长引擎 | 跨境电商 AI 智能体平台（更强 Agent 化） |
| Skills | 官方 Skills + 第三方安装 | 官方 + 社区共享市场 + **积分收益** |
| 模型 | 单一后台模型 | **多大模型可选**（GPT / Claude / Gemini / 国产大模型） |
| 数据 | 仅接平台 API | 平台 API + **自定义数据库直连** |
| 知识库 | 无 | **企业/个人知识库**（文档、FAQ、产品库） |
| 定时任务 | 支持 | 支持 + 模板库 + 可视化编排 |

## 4. 核心模块需求

### 4.1 智能对话 / 任务中心

**路由：** `/app/chat`

#### 4.1.1 功能概述
用户通过自然语言与智能体交互，可调用 Skills、连接器数据、知识库内容，完成单步或多步自动化任务。

#### 4.1.2 功能需求

| 编号 | 功能点 | 优先级 | 说明 |
|---|---|---|---|
| C-01 | 新建对话 | P0 | 点击"新建任务"创建独立对话上下文 |
| C-02 | 定制模型选择 | P0 | 对话前/中可切换底层大模型（GPT-4o / Claude / Gemini / 文心 / 通义等） |
| C-03 | 文件上传 | P0 | 支持 PDF、Word、Excel、图片、CSV，最大 50MB |
| C-04 | Skills 调用 | P0 | 对话中自动匹配或手动选择 Skill 执行 |
| C-05 | 项目关联 | P1 | 将对话归属到指定项目 |
| C-06 | 新用户引导卡片 | P1 | 首次使用展示推荐任务入口，避免空白页 |
| C-07 | 对话历史 | P1 | 支持历史记录搜索、置顶、删除 |
| C-08 | 多步骤工作流 | P1 | 单条指令可触发跨多个连接器的多步骤操作 |
| C-09 | 知识库调用 | P1 | 对话时可指定从知识库检索上下文 |
| C-10 | 交互式确认卡片 | P2 | 高风险操作（删除/发布）前展示确认卡片，防误操作 |

#### 4.1.3 页面布局
- 左侧：历史对话列表 + 项目树
- 中间：对话主区域
- 右侧（可折叠）：Skills 面板 / 资产库快捷入口 / 知识库引用显示

| 营销 & 推广 | 活动规划师、社媒内容专家、广告文案生成器、邮件营销 |

| 市场情报 | 市场情报官、竞争格局分析、品牌舆情监控 |
| 供应链 | 供应商查找器、成本计算器、定价优化器 |
| 文件处理 | PDF 处理、Excel 处理、Word 生成、PPT 生成 |
| 视觉创作 | 图片生成、产品图编辑、背景替换、视频生成 |

#### 4.3.3 功能需求

| 编号 | 功能点 | 优先级 | 说明 |

### 4.4 连接器（Connectors）

**路由：** `/app/connectors`

#### 4.4.1 功能概述
连接器是平台与外部平台/数据源的授权接入管理中心，支持 OAuth、API Key、MCP 协议以及自定义数据库连接。

#### 4.4.2 连接器分类

| 类别 | 平台 |
|---|---|
| 电商平台 | Shopify、Amazon、eBay、WooCommerce、Wix、Genstore、速卖通、Lazada、Shopee |
| 社媒平台 | TikTok、Instagram、Twitter/X、YouTube、Facebook、LinkedIn、Pinterest、小红书 |
| 营销工具 | Google Ads、Meta Ads、TikTok Ads、SellerSprite、Klaviyo |
| 数据分析 | Google Analytics 4、Google Search Console |
| 效率工具 | Gmail、Google Drive、Google Docs、Google Sheets、Notion |
| IM 通知 | Slack、Discord、飞书、企业微信 |
| 大模型 API | OpenAI、Anthropic、Google Gemini、文心一言、通义千问、DeepSeek、Mistral |
| 自定义 | MCP 协议接入、REST API 接入、自定义数据库（MySQL / PostgreSQL / MongoDB） |

#### 4.4.3 功能需求

| 编号 | 功能点 | 优先级 | 说明 |
|---|---|---|---|
| CN-01 | OAuth 授权连接 | P0 | 标准 OAuth 2.0 流程，支持一键授权 |
| CN-02 | API Key 配置 | P0 | 对不支持 OAuth 的平台支持 API Key 方式 |
| CN-03 | MCP 协议接入 | P1 | 兼容 MCP（Model Context Protocol）接入自定义工具 |
| CN-04 | 自定义数据库连接 | P1 | 支持填写 DB 连接串（MySQL/PG/Mongo），AI 可查询用户私有数据 |
| CN-05 | 连接状态检测 | P0 | 实时展示连接健康状态（正常/过期/异常） |
| CN-06 | 权限粒度控制 | P1 | 读/写权限分级，写权限需用户显式开启 |
| CN-07 | 多账号管理 | P1 | 同一平台支持绑定多个账号（如多个 Shopify 店铺） |
| CN-08 | 大模型 API 自配置 | P1 | 用户可填入自己的大模型 API Key，优先使用用户配置 |

### 4.7 知识库（Knowledge Base）

**路由：** `/app/knowledge`

> **这是天机相对 StoreClaw 的核心差异化模块之一。**

#### 4.7.1 功能概述
用户可将企业私有知识（亚马逊运营知识，经验，广告优化，选品，供应链知识，产品手册、运营 SOP、FAQ、竞品资料等）上传至知识库，AI 在对话和执行 Skills 时可从知识库中精准检索上下文，实现"知道你的业务"的个性化 AI 助手。

#### 4.7.2 功能需求

| 编号 | 功能点 | 优先级 | 说明 |
|---|---|---|---|
| KB-01 | 知识库创建与管理 | P0 | 创建多个知识库（如：产品库、运营 SOP 库、竞品库） |
| KB-02 | 文档上传与解析 | P0 | 支持 PDF、Word、TXT、网页 URL、Excel，自动切片入库 |
| KB-03 | 向量检索 | P0 | 基于 Embedding 的语义检索，对话时自动召回相关知识 |
| KB-04 | 知识库 × Skills 绑定 | P1 | 指定 Skill 优先从绑定的知识库检索上下文 |
| KB-05 | 知识库 × 对话绑定 | P1 | 新建对话时可选择关联的知识库 |

| KB-07 | 网页抓取入库 | P2 | 输入 URL，自动抓取正文内容并入知识库 |
| KB-08 | 知识库权限 | P2 | 团队版支持知识库的成员级共享 |
| KB-09 | 引用溯源 | P2 | AI 回答时显示引用来源（文件名 + 页码） |

#### 4.7.3 技术要点
- 文档解析：支持 OCR 识别扫描件
- Embedding 模型：OpenAI text-embedding-3 / 本地模型可选
- 向量数据库：Pinecone / Weaviate / pgvector（可配置）
- 检索策略：混合检索（向量 + 全文 BM25）

## 5. 新增差异化功能

### 5.1 技能共享市场 + 积分收益

#### 5.1.1 概述
建立面向开发者和服务商的 **技能共享生态**，用户发布 Skill 后，每当其他用户安装并调用该 Skill，原作者自动获得积分奖励。

#### 5.1.2 功能流程

```
创建 Skill → 提交审核 → 审核通过 → 上架社区市场
    ↓
他人安装 Skill → 他人调用 Skill 消耗积分 → 系统按比例分成给原作者
```

#### 5.1.3 功能需求

| 编号 | 功能点 | 优先级 | 说明 |
|---|---|---|---|
| SM-01 | 社区 Skills 市场 | P1 | 浏览所有社区共享 Skills，支持分类/评分/热度筛选 |
| SM-02 | Skill 发布流程 | P1 | 作者填写信息 → 提交 → 平台安全审核 → 上架 |
| SM-03 | 积分分成规则 | P1 | 他人每次调用 Skill 消耗积分的 20%~30% 归还作者（可配置） |
| SM-04 | 收益明细 | P1 | 作者可查看每个 Skill 的安装量、调用量、累计积分收益 |
| SM-05 | Skill 定价 | P2 | 支持免费 Skill / 付费 Skill（作者可设置积分单价） |
| SM-06 | 作者 Profile 页 | P2 | 作者主页展示已发布 Skills、简介、社区评价 |
| SM-07 | 举报 & 下架机制 | P1 | 用户可举报违规 Skill，平台审核后可下架 |

---

### 5.2 自定义数据库对接

#### 5.2.1 概述
允许企业用户将自有数据库（ERP、WMS、自建 CRM 等）直接接入天机，AI 可通过自然语言查询私有数据库，无需手动导出数据。

#### 5.2.2 功能需求

| 编号 | 功能点 | 优先级 | 说明 |
|---|---|---|---|
| DB-01 | 数据库连接配置 | P1 | 支持 MySQL、PostgreSQL、MongoDB，填写连接串并测试 |
| DB-02 | 数据表 Schema 导入 | P1 | 自动扫描并导入表结构，AI 理解数据含义 |

## 9. 技术架构要点

### 9.1 整体技术栈建议

| 层级 | 技术选型 |
|---|---|
| 前端 | Next.js 14 + TypeScript + TailwindCSS |
| 后端 | Node.js (Fastify) + Python（AI 任务服务） |
| AI 编排层 | LangChain / LlamaIndex + 自研 Skill 引擎 |
| 向量数据库 | pgvector（PostgreSQL）/ Pinecone（云端） |
| 关系型数据库 | PostgreSQL |
| 消息队列 | Redis + Bull / RabbitMQ（定时任务） |
| 文件存储 | AWS S3 / 阿里云 OSS |
| 认证 | NextAuth.js（OAuth 2.0）|
| 部署 | Vercel（前端） + AWS ECS / 阿里云 ACK（后端） |

### 9.2 Skill 引擎设计

```
Skill = {
  metadata: { name, description, trigger_keywords },
  system_prompt: "...",
  scripts: [ Python/Node.js 脚本 ],
  references: [ 参考文档 ],
  tools: [ 调用的连接器 API ]
}
```

- Skill 打包为 ZIP，上传后经沙箱安全检测
- 每个 Skill 运行在独立容器环境，防注入

### 9.3 数据安全

- 所有 API Key / DB 连接串使用 AES-256 加密存储
- 连接器 OAuth Token 加密落库，过期自动刷新
- 用户数据严格租户隔离
- 审计日志记录所有高权限操作
