# 店铺维度广告智能诊断

当用户要求店铺、账号、站点、全店、店铺维度处理清单时使用本参考。

## 目标

店铺维度诊断不是把所有 ASIN 平均看，而是找出：

- 哪些 ASIN/SKU 正在拉高店铺 ACOS。
- 哪些广告亏损被自然流量掩盖。
- 哪些高效 ASIN 因预算打满被限制。
- 哪些 Campaign 集群需要止损、修结构或放量。
- 需要补哪些数据才能下钻到可执行对象。

## 店铺维度流程

1. 确认店铺、站点、日期和诊断主题。
2. 汇总店铺近 7/14/30 天：广告花费、广告销售额、订单、ACOS、TACOS、CVR、CPC、毛利、盈亏平衡 ACOS。
3. 按 ASIN/SKU 分组，识别四类对象：
   - 红色止损：ACOS 超盈亏线、广告后毛利为负、CVR 下滑或亏损金额大。
   - 黄色复核：ACOS 高但自然流量强，可能掩盖广告亏损。
   - 绿色放量：ACOS 低于盈亏线且预算打满、排名或 ABA 仍有机会。
   - 灰色补数：缺广告活动、搜索词或利润数据，无法判断。
4. 按 Campaign 集群识别：
   - 高花费低转化活动。
   - 预算频繁打满但效率好活动。
   - 搜索首位烧钱活动。
   - Auto/Broad 探索层浪费。
   - Exact/Phrase 高效词承接不足。
5. 输出店铺层处理清单，再列出需要进入 ASIN/SKU 详细诊断的优先对象。

## 店铺处理清单格式

```text
处理清单：店铺-星辰大海 北美站US-2026-06-25诊断   ACOS提升（极高）

诊断摘要：
店铺广告 ACOS 上升，主要由若干 ASIN/SKU 的高 ACOS 与 CVR 下滑拉动；部分广告亏损可能被自然订单掩盖。

核心证据：
- 店铺 ACOS：X% -> Y%，变化 +Z%
- 当前7天 ACOS 均值：A%，高于盈亏平衡 ACOS B%
- CVR：C% -> D%，下降 E%
- 广告后毛利/广告亏损：...
- Top亏损 ASIN/SKU：...

建议动作：
1. 先对红色止损 ASIN/SKU 降低预算或暂停高 ACOS 活动，避免全店一刀切。
2. 补充近7天或30天广告活动和搜索词报告，定位高花费低转化对象。
3. 对绿色放量 ASIN 保留预算，避免误伤高效活动。
4. 本日复核搜索首位倍增、预算打满和 Auto/Broad 探索层。

需补充数据：
- Campaign 报告
- Search Term Report
- Placement 报告
- ASIN/SKU 利润和盈亏平衡 ACOS
```

## 店铺优先级

优先级 1：今日止损

- ACOS 极高且广告后毛利为负的 ASIN/SKU。
- 高花费、零订单或低 CVR 的 Campaign。
- 自然流量掩盖广告亏损的产品。

优先级 2：本周修结构

- Broad/Auto 流量浪费。
- Exact 承接不足。
- 搜索首位倍增只在部分 Campaign 上亏损。
- 高效 Campaign 预算长期打满。

优先级 3：中期增长

- ABA 购买份额高但广告覆盖低的词。
- SIF 显示旺季上行且本品适配的词。
- 有自然排名但广告没覆盖的长尾词。

## 店铺维度防线

- 不要因为店铺 ACOS 高就建议全店降预算；先拆 ASIN/SKU。
- 不要因为 TACOS 低就认为广告健康；必须看广告加权 ACOS 和盈亏线。
- 不要把市场整体回落和内部广告断投混为一谈；需要竞品同步对比。
- 缺 ASIN/SKU 明细时，只能输出店铺级止损和补数要求。
