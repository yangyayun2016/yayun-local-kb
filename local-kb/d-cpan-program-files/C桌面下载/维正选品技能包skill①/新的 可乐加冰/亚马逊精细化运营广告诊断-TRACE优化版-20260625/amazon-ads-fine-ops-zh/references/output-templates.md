## ASIN/SKU 维度处理清单

```text
处理清单：ASIN-星辰大海 北美站US-2026-06-25诊断   ACOS提升（极高）

诊断摘要：
ACOS X% -> Y%（up Z%），当前7天 ACOS 均值 A%，仍然偏高；近期 CVR 从 C% 跌至 D%（down E%），广告花费未同步收紧，导致 ACOS 远超盈亏平衡 ACOS B%。若广告后毛利率为负，广告正在加剧亏损。

核心证据：
1. 当前 ACOS 与7日均值：...
2. 盈亏平衡 ACOS / 目标毛利率：...
3. 广告后毛利率或广告亏损金额：...
4. CVR、CPC、点击和订单变化：...
5. 缺失数据：...

建议动作：
1. 建议人工复核：核对缺少的广告活动和搜索词报告数据，补充近7天或30天 Campaign 花费、订单、ACOS 以及搜索词点击转化率数据。
2. 复核前，先将该 ASIN 相关广告活动日预算总额降低约 50%，或暂停高 ACOS 活动，以控制烧钱速度。
3. 补齐报告后，定位高花费低转化投放，精准降出价或否定，减少浪费。
4. 对有订单且 ACOS 健康的词转 Exact 承接；对 ABA 购买份额高但广告覆盖少的词加精准。

历史参考：
如存在历史 recovered 或类似异常，写明历史 ACOS、CVR、毛利和动作，避免重复踩坑。

补充说明：
全部采纳 / 部分采纳 / 忽略时，记录原因。
```

## 自然流量掩盖广告亏损模板

```text
处理清单：ASIN-星辰大海 北美站US-2026-06-26诊断   广告亏损被自然流量掩盖（中）   ACOS提升（高）

诊断摘要：
该 ASIN 广告加权 ACOS 为 X%，远超盈亏平衡 ACOS Y%，造成广告亏损约 $Z。由于自然流量订单较多，整体 TACOS 可能较低，掩盖了广告亏损事实。

建议动作：
1. 补充近14天搜索词报告，包含花费、点击、订单、销售额、ACOS、CVR。
2. 补充广告活动层级 ACOS、出价和预算设置。
3. 通过人工分析精准降低亏损词出价或否定，目标是让加权 ACOS 回归盈亏平衡线附近。
```

```text
覆盖：月度销售广告数据、毛利、Campaign结构、关键词表现、广告位、预算打满、竞品对标、流量异常诊断
```

## 完整报告章节

1. 产品基础信息。
2. 第一层基础面：评分评论、价格竞争力、库存状态、Listing质量。
3. 月度销售、广告和毛利综合表现。
4. 盈亏分析框架。
5. 投放现状分析：Campaign、关键词、广告位、预算打满。
6. 竞品对标分析。
7. 排名/销量下滑根因诊断。
8. 可立即执行动作：今日、本周、中期，近1个月。
9. ABA 搜索词绩效报告分析。
10. 外部视角机会与下一步复盘。

## 文风要求

- 用“因为 A，导致 B，所以先做 C”写因果链。
- 不写空泛词，如“赋能增长、智能闭环、全面优化”。
- 每个动作要有对象和证据。
- 数据不足时直接写缺口，不假装能精确定位。
