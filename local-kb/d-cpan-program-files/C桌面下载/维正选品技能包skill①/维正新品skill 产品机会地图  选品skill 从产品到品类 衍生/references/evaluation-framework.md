# 亚马逊选品机会评估框架

在需要判断方向优先级、筛选候选产品或输出评分时，使用本框架。

## 1. 从单品到品类的变量

| 变量 | 拓展方式 | 常见信号 |
| --- | --- | --- |
| 人群 | 买家身份、年龄、角色、技能水平、使用对象 | for kids、for teachers、for renters |
| 场景 | 使用地点、事件、季节、礼品场景、工作流程 | office、wedding、graduation、rental apartment |
| 需求 | 用户要完成的任务、痛点、焦虑或情绪目标 | 展示、保护、收纳、安装、纪念、送礼 |
| 解决方案 | 产品形态、材质、结构、工艺、配件、组合方式 | acrylic、magnetic、foldable、no-drill、bundle |

## 2. 拓展关系分类

### 细分赛道

用于判断“把现有品类做深”的方向。

常见标签：

- 功能细分
- 场景细分
- 人群/适用对象细分
- 形态细分
- 材质/工艺细分
- 套装/组合/配件
- 保护/收纳

例子：`photo frame -> diploma frame`，展示对象从普通照片变成证书，使用场景和购买动机也随之变化。

### 互补赛道

用于判断“围绕完整使用流程做宽”的方向。

常见标签：

- 配件/耗材
- 适配/连接
- 安装/流程接续
- 替换/维护
- 场景共生

例子：`photo frame -> picture hanging strips`，它不是新的相框，而是解决相框安装流程里的配套需求。

### 组合/系统机会

用于判断多个产品是否可以组合成更完整的解决方案。

例子：`kids art frame + mounting strips + label cards`，不是只卖相框，而是卖“儿童作品展示与收纳系统”。

## 3. 市场验证指标

| 指标 | 回答的问题 | 判断提醒 |
| --- | --- | --- |
| 搜索量 | 有没有显性需求 | 高搜索量可能意味着高竞争 |
| 购买量 | 需求是否转化 | 要和搜索量一起看 |
| 购买率 | 购买意图是否强 | 中低搜索量但高购买率也可能有价值 |
| 趋势/季节性 | 需求是否稳定或增长 | 季节品要看库存节奏 |
| 商品数 | 供给是否拥挤 | 商品多不代表没有缝隙 |
| SPR/竞争代理指标 | 排名和竞争难度 | 只能做方向判断，不能单独定生死 |
| 平均价格 | 是否有利润空间 | 要叠加 FBA、退货、包装和推广成本 |
| Review 分布 | 新品是否有进入机会 | 关注低 Review 仍出单产品 |
| 评分和评论痛点 | 有无差异化机会 | 要转化成具体产品改进假设 |
| 价格带断层 | 是否存在定位空间 | 需要结合成本和用户价值判断 |
| 广告竞价 | 是否存在利润空间 | 需要结合成本和竞品判断 |
## 4. 候选机会评分

每项 1-5 分，可以使用 0.5 分。建议权重如下：

| 维度 | 权重 | 5 分标准 |
| --- | ---: | --- |
| 需求质量 | 20% | 需求真实、可转化、稳定或增长 |
| 竞争缝隙 | 20% | 存在低 Review 出单、弱 Listing、价格带断层或未满足场景 |
| 差异化路径 | 20% | 能清楚落到功能、材质、套装、图片、文案或场景表达 |
| 利润与履约 | 15% | 价格、尺寸、重量、FBA、退货风险支持目标毛利 |
| 供应链匹配 | 15% | 能复用供应商、材料、模具、工艺、包装或运营经验 |
| 风险可控 | 10% | 专利、合规、安全、类目限制和平台政策风险可控 |

决策区间：

- 4.2-5.0：优先深度验证。
- 3.5-4.1：进入候选池，先验证最弱假设。
- 2.8-3.4：观察或作为套装/配件角色。
- 2.8 以下：一般淘汰，除非有战略原因。

## 5. 硬性淘汰规则

出现以下情况时，暂停或淘汰：

- 专利、商标、合规、安全或平台限制风险不明且无法快速确认。
- 履约、推广和退货后无法达到目标利润。
- 只有需求，没有明确差异化路径。
- 供应链无法小批量测试或快速迭代。
- 只是浅层换色、换尺寸、换包装，没有新人群、新场景、新需求或新解决方案。

## 6. 最终判断原则

真正有价值的不是“AI 给了 50 个方向”，而是能用自己的品类理解，把 50 个方向筛成 5 个候选机会，再从 5 个候选机会里验证出 1 个真正值得测试的产品。
