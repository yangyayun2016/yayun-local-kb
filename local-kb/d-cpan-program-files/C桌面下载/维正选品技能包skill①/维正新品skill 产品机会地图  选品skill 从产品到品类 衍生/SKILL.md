# 亚马逊选品机会地图生成器

## Purpose
数据源：调用卖家精灵MCP，获取亚马逊站点的单品、关键词、ASIN、类目、卖家精灵导出结果或现有产品线的相关数据。

帮助用户把一个已验证的亚马逊单品、关键词或 ASIN，拆解为一张可执行的产品机会地图，并从大量拓展方向中筛选出少数值得继续验证或小批量测试的选品候选清单。

核心原则：AI 不完全100%替代选品判断，而是放大判断；不是直接给出100%爆品答案，而是提高发现机会、验证机会、沉淀品类认知的效率。

## 核心定义

单品/产品：针对特定人群 x 特定场景 x 特定需求，给出的一个特定解决方案。

品类：锁定上述公式中的 1-2 个变量作为锚点，围绕相邻人群、场景、需求或解决方案形成的一组相关解决方案集合。

从单品到品类：使用控制变量法，保留 1-2 个确定变量（核心变量），拓展其他变量，找到相邻机会。

## Instructions

1. 明确输入和约束。
   - 识别用户给的是单品、关键词、ASIN、类目、卖家精灵导出结果，还是已有产品线。（用卖家精灵MCP调取相关数据源-ASIN/品类详细数据）
   - 尽量确认站点、目标价格带、供应链能力、利润目标、合规限制、公司阶段、可复用资源。
   - 信息不足但仍可推进时，先基于显式输入分析，并把缺失信息标为“待验证”。

2. 拆解单品公式。
   - 拆出目标人群、使用场景、核心需求、当前解决方案、购买动机和完整使用流程。
   - 追问或推理：用户到底想完成什么？为什么要买？在哪里用？使用前后还需要什么？背后是功能需求还是情绪需求？

3. 生成产品机会地图。
   - 细分赛道：围绕现有品类做深，拓展展示对象、人群、场景、功能、形态、材质/工艺、套装/组合、保护/收纳等方向。
   - 互补赛道：围绕用户完整流程做宽，拓展配件/耗材、安装/连接、替换/维护、流程接续、场景共生等方向。
   - 组合机会：把单品、配件、耗材或使用指导组合成更完整的解决方案。

4. 标注拓展关系。
   - 对每个方向标注属于“细分赛道”“互补赛道”还是“组合/系统机会”。
   - 说明它是在扩人群、扩场景、扩需求、扩解决方案，还是只停留在颜色、尺寸、材质、包装数量等浅层变体。

5. 回到市场验证。
   - 使用用户提供的数据、卖家精灵、关键词工具、亚马逊搜索页、竞品列表、评论分析或其他可用证据。
   - 重点查看搜索量、购买量、购买率、趋势、季节性、商品数、SPR 或竞争代理指标、平均价格、供需比、Review 分布、评分缺口、低 Review 仍出单产品、价格带断层和头部垄断程度。
   - 不要只看搜索量。搜索量高不等于好做，搜索量低也不等于没机会。

6. 联动验证链路。
   - 用 AI-拓产品打开方向池。
   - 用关键词相关功能验证需求质量。
   - 用选产品/竞品分析验证竞争结构。
   - 用评论分析挖用户痛点和差异化切入点。
   - 回到供应链、利润、FBA 费用、专利、合规、MOQ、迭代速度和公司阶段做判断。

7. 筛选候选机会。
   - 先展开足够多方向，再筛成 5 个候选机会。
   - 对候选机会做透明评分，并说明保留或淘汰的原因。
   - 最后推荐 1-2 个优先验证或测试方向，以及下一步最低成本验证动作。

## Examples

输入：`以 photo frame 为起点，调用卖家精灵MCP，帮我做亚马逊选品机会地图。`

输出应包含：

- 单品拆解：photo frame 对应的人群、场景、展示需求、解决方案和购买动机。
- 细分赛道：shadow box frame、diploma frame、certificate frame、poster frame、puzzle frame、kids art frame 等。
- 互补赛道：picture hanging strips、wall anchors、photo corners、picture wire、glossy photo paper 等。
- 关系判断：说明哪些是在扩展示对象、哪些是在扩安装流程、哪些只是浅层变体。
- 数据验证：结合ABA排名，搜索量、购买量、购买率、SPR、商品数、价格、Review 和痛点判断机会质量。
- 候选筛选：把方向池收敛到 5 个候选，再推荐 1-2 个优先验证方向。
- 侵权风险：对候选机会做专利、商标、侵权和合规风险分析，并标注“低/中/高”风险等级。

## Guardrails

- 不把 AI 拓展结果当成最终选品答案。
- 不编造搜索量、销量、价格、Review、专利、合规或利润数据；没有数据时标为“未知/待验证”。
- 不用单一指标做结论，尤其不能只按搜索量判断能不能做。
- 不推荐明显侵权、仿牌、高合规风险、高安全风险或平台限制不明的产品。
- 不忽略供应链、利润、FBA、MOQ、迭代速度和公司阶段。
- 不把换颜色、换尺寸、换材质、换包装数量直接等同于品类机会，除非它对应明确的新人群、新场景、新需求或新解决方案。
