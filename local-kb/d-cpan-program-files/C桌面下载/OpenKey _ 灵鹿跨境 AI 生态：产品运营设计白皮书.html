核心结论

对标 Soldy 等海外浏览器 Agent 产品，我们拒绝做重度的全功能 ERP，也不局限于单一的视频渲染站。最契合中国跨境卖家的落地形态是“铁三角”协同：

独立创作工作台

OpenKey Studio

承载 Brand Kit（品牌资产）、深入的 RAG 知识库、Storyboard（分镜脚本）与复杂 Campaign 的宏观调配中枢。

本地扩展轻量面板

灵鹿 Connect

以 Chrome Extension 形式直接嵌入 ERP、刊登工具或商品页。利用本地真实浏览器沙盒，维持真实登录态与 IP，彻底解决反爬风控。

自动化连接能力

Creative Job API

以异步任务 API 和 Webhook 为底座，深度集成至 n8n、Dify、OpenClaw，向自动化生态提供标准 Remote MCP 节点。

“先做赚钱的 Agent，再做生态。” 卖家在现有 ERP 或 Listing 页面无感调用灵鹿；只有需要深度定制和管理大盘资产时，才登录 OpenKey 独立工作台。

1

OpenKey Studio：品牌资产与深度决策中枢

负责Brand Kit（品牌色、品牌调性、Logo印章风格）的长期沉淀。集成 Dify 矛盾分析工作流，对亚马逊 Review 差评及 TikTok 爆款趋势进行 RAG 深度检索，输出选品改良方案及高转化 Storyboard 脚本。

它是商家的“大脑”，建立品牌与底层技术模型的长期复利记忆（Memory）。

2

灵鹿 Connect：高频寄生型操作面板

以 Chrome 插件形式驻留。当卖家停留在亚马逊 ASIN 页面、卖家精灵趋势页或 ERP 刊登页时，无需切换工具，一键提取商品上下文。例如：

识别当前ASIN → 插件抓取标题/图片/卖点 → 调用 Dify 选品 Agent 识别竞品弱点 → 自动生成 3 组针对性买家秀脚本 → 唤起视频渲染引擎
3

Creative Job API & Webhook：自动化开发者的基石

暴露结构化的经营任务接口，彻底屏蔽底层复杂的模型参数（不让商家去猜模型或调提示词）。支持 n8n 原生节点与 ChatGPT/Claude 的 Remote MCP (模型上下文协议) 客户端。

四、优先切入的生态伙伴与自动化工作流

不盲目追求全大盘覆盖，依据“能否直接获取商品上下文”和“能否安全通过风控节点”进行梯队式生态合作。

1

第一优先：头部跨境 ERP、选品工具与自研插件（流量第一现场）

生态类型对标/代表产品高频应用场景产品融合形态合作与获客方案
跨境主流 ERP领星、店小秘、马帮新品上架、 Listing 就绪或大促广告建档时，一键批量勾选 SKU 触发内容流。ERP 商品列表行内集成“灵鹿生成”按钮/侧边栏；成片自动回写至 ERP 媒体素材库。联合大客户试点，接入领星开放平台，提供 ERP 增值订阅包或积分分成。
大盘选品工具卖家精灵、Helium 10在调研具有“爆款潜质”或“高差评率可改良”的类目时，直接进行元素迁移分析。提供“生成 AI 选品与视频 Brief 提案”按钮，支持一键安全带上下文跳转。共建“爆款元素迁移模版”，作为高级会员权益联名获客，按转化分成。
自研外挂插件Amazon/TikTok 官方后台商品页在官方没有开放 API 授权时，直接读取屏幕上的标题、图片和变体，完成冷启动。灵鹿 Chrome 原生扩展程序面板。作为最轻量、最快验证用户痛点与高频页面交互的 MVP 入口。
2

第二优先：自动化与 AI Agent 平台（打通高级商家的定制生产流）

新一代大卖家正在将内容与流量生产编排进自动化总线，灵鹿不去做编排软件，而是要做其中最可靠的“视频内容生产节点”。

平台类型代表产品商家应用场景灵鹿产品形态生态交付方案
可视化自动化平台n8n、Make、ZapierListing状态改变自动触发内容包；爆款视频播放衰退自动触发 Hook 变体补充。提供官方自研的 n8n Connector / 触发器节点；输出结构化的 job_id 及视频云端 URL。上架官方节点市场，随书附赠 3 套可直接复制的跨境自动化工作流模板。
AI 智能体编排Dify、扣子 (Coze)搭建“自动化内容运营 Agent”，根据品牌规则、产品说明书自发进行多轮次、长周期的内容迭代。封装标准 Dify Tool Plugin；工具层仅暴露明确经营语义，拒绝复杂模型参数。入驻插件生态，与行业知名 AI 实施顾问合作，面向中大型大卖家交付定制方案。
通用大模型客户端ChatGPT、Claude MCP在日常调教、对话中完成“帮我看看这几个 ASIN 的视频渲染进度，并把成片拉下来”。开发标准的 OAuth Remote MCP Server，暴露关键 Tool 指令。提供企业级私有 MCP 链接，使用商家 OpenKey 账户统一计费，保留安全调用审计日志。
技术演进策略：先 API 底座，后封装 MCP 规范，再适配各可视化平台。确保任何自动化 Agent 调用的都是同一套安全、稳定且具备防封指纹的执行核心。
3

第三优先：TikTok Shop 官方公共/定制应用

利用 TikTok Shop 开放平台能力。第一阶段优先申请 **Product Basic（商品基础资料）及商品图片权限**，严禁过早染指订单、财务、履约等高度敏感和高风控权限，保持应用轻量。先通过 Custom App 服务少数大卖家验证链路，再申请 Public App 上架服务商市场。

4

第四优先：Amazon Selling Partner Appstore (SP-API)

通过 Catalog Items API 调取 ASIN 的标准规格、类目节点、高频变体信息。因 Amazon 官方服务商生态审核极度冗长，建议先通过 ERP 合作和浏览器外挂插件跑通商业闭环，在录得稳定现金流后，再投入安全合规审计，进驻官方 Appstore。

五、全链路商家全自动化工作流程设计

以“消灭网页脏活累活”为核心，让卖家在最少的点击和无代码学习成本下完成全链路闭环。

1 自动选品Dify Agent 提取差评痛点进行元素迁移

5 红人自动化建联Brave Search 提纯邮箱，OpenClaw 批量发信寄样
6 素材多模态切片红人素材回流，VLM 自动识别结构化时间轴
7 AI 二创混剪自动生成 1 拆 10 爆款多语种字幕与配音短视频
8 矩阵式分发本地沙盒模拟人工点击，一键发布至站内外流量池
9 GEO 流量放大根据表现回流，指导下一批智能埋词与补量生产

六、多元化商业化路径与生态利益分配

不和生态伙伴抢生意。通过“伙伴获渠道与交付收益，OpenKey 留核心创意资产与用户关系”的原则设计共赢机制。

Studio 席位订阅 + 算力点数

面向终端大卖家收取固定月度/年度席位费，购买高级 Campaign 额度及长视频 VLM 渲染积分。牢牢锁定品牌资产（Brand Kit）所有权。

Connect 生态渠道让利分成

插件免费供卖家下载。对于 ERP、选品工具等流量入口伙伴，为其用户提供专属优惠券，并向伙伴提供高达 20%—30% 的持续流水佣金返点，或支持伙伴大批量低价采购积分转售。

API & MCP 企业用量合同

面向技术型大卖家、AI 独立实施顾问、大型 MCN 机构和代运营公司。采用按任务（Job）成功回调计费、按并发数和分辨率阶梯收费，阶梯设置企业最低月度承诺消（Commitment）。

  • 跑通 Amazon/TTS 页面数据一键提取。

  • 利用 OpenClaw 跑通飞书/邮件批量寄样流程，**完成第一个能独立赚钱、自带现金流的 Profitable Agent 验证。**
第 4 — 6 个月

第二阶段：内容与视觉深化

  • 发布标准的 Creative Job API 与 异步 Webhook。
  • 上线“红人原生素材 VLM 智能切片混剪”功能。
  • 集成 ElevenLabs 实现跨语种配音克隆与无损字幕对齐。
  • 打通“红人代发 -> 素材回流 -> AI 混剪 1 拆 10”的半自动化内容流水线。

  • 与至少一家主流跨境 ERP 厂商（如领星）达成深度内嵌联合试点。
第 10 — 12 个月

战略红线与边界：即使未来全面接入流量转化与表现数据，灵鹿仍旧死死聚焦于“内容建议与再生产层”，绝对不要过早扩张和染指广告预算管理、库存、订单及供应链履约等传统 ERP 的重度深水区。

最终战略建议

无论是 Soldy 还是灵鹿，最成功的产品定位永远不是：

又一个需要卖家记住网址、单独登录、去学习提示词的 AI 视频或独立选品网站。

它应该成为：

跨境电商整个大生态里无处不在的“内容+流量”基础设施生产层。

商家在哪里管理商品、在哪里浏览趋势、在哪里看广告自然位，灵鹿的“生成选品方向 / 智能一键做片 / 自动化找红人”按钮就寄生在哪里。 OpenKey 负责沉淀品牌复利记忆，灵鹿 Connect 负责本地沙盒第一现场破局，Creative API 负责自动化规模化爆发。用高鲁棒性的技术栈、最克制的切入路径，先做赚钱的 Agent，再稳步咬合出最坚固的跨境电商 AI 生态圈。
