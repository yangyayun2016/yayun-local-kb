# 亚马逊搜索词报告分析器

## 功能概述

这是一个专业的亚马逊搜索词报告分析工具，适用于**任何类目**的搜索词报告。通过8个维度的深度分析，帮助运营团队做出数据驱动的决策。

### 核心功能

1. **品牌竞争分析** - 识别市场主导品牌和竞争格局
2. **类别趋势分析** - 了解用户类别偏好和跨类别机会
3. **搜索词热度分析** - 追踪市场需求趋势和增长机会
4. **搜索词词频统计** ⭐ - 拆解搜索词，识别高频词汇（人群词/场景词/属性词/品牌词）
5. **商品竞争力分析** - 评估头部商品表现和市场覆盖度
6. **ASIN转化效率分析** - 四象限分类，识别明星商品和问题商品
7. **关键词转化效率分析** ⭐ - 评估关键词垄断度，识别黄金关键词和红海关键词
8. **时间序列分析** - 发现季节性规律和市场变化节点

### 适用场景

- 📊 **广告投放策略** - 选择高ROI关键词，优化出价策略
- ✍️ **Listing文案优化** - 标题、五点描述、A+内容的关键词布局
- 🎯 **选品决策** - 识别市场机会和竞争格局
- 🔍 **竞品监控** - 追踪竞争对手品牌和商品表现
- 📈 **市场趋势分析** - 发现新兴搜索词和季节性规律

## 分析流程

当你调用这个skill时，我会执行以下步骤：

### 第1步：识别和验证报告文件
- 自动查找当前目录或指定目录下的CSV文件
- 验证文件格式是否为亚马逊搜索词报告
- 支持单个文件或多个月份的报告文件

### 第2步：数据清洗和预处理
- 加载所有报告数据
- 清洗和标准化字段
- 处理缺失值和异常值
- 合并多月数据（如有）

### 第3步：执行8维度分析
我会依次执行以下分析：

#### 1. 品牌竞争分析
- 统计TOP品牌出现频率和排位分布
- 计算品牌市场集中度
- 识别新兴品牌和稳定品牌

#### 2. 类别趋势分析
- 统计热门类别排名
- 分析搜索词与类别的关联
- 识别跨类别销售机会

#### 3. 搜索词热度分析
- 计算搜索词平均排名和趋势
- 识别增长最快的搜索词
- 分析搜索词类型分布

#### 4. 搜索词词频统计 ⭐
- 拆解所有搜索词，统计单词出现频率
- 将高频词分类为：
  - **人群词**：women, men, kids, college, business
  - **场景词**：travel, work, school, gaming, outdoor
  - **属性词**：waterproof, leather, large, 17 inch, slim
  - **品牌词**：品牌名称
- 为每个高频词关联搜索排名最靠前的搜索词
- 输出词频统计表和词汇分类汇总

#### 5. 商品竞争力分析
- 识别出现频率最高的ASIN（明星产品）
- 计算商品的平均点击份额和转化份额
- 分析商品市场覆盖度（覆盖多少个搜索词）

#### 6. ASIN转化效率分析
- 计算每个商品的转化效率比
- 四象限分类：
  - **明星商品**：高点击 + 高转化
  - **潜力商品**：低点击 + 高转化
  - **流量陷阱**：高点击 + 低转化
  - **问题商品**：低点击 + 低转化

#### 7. 关键词转化效率分析 ⭐
- 计算每个搜索词的点击份额TOP3合计
- 计算转化份额TOP3合计
- 评估市场垄断程度：
  - **高垄断** (>40%): 头部商品占据绝对优势
  - **中等垄断** (20-40%): 有竞争空间
  - **低垄断** (<20%): 市场分散，新品机会大
- 计算转化效率比（转化份额合计 ÷ 点击份额合计）
- 四象限分类：
  - **黄金关键词**：低垄断 + 高转化（优先投放）
  - **红海关键词**：高垄断 + 高转化（谨慎投放）
  - **潜力关键词**：低垄断 + 低转化（优化后投放）
  - **避坑关键词**：高垄断 + 低转化（不建议投放）

#### 8. 时间序列分析
- 绘制月度趋势图
- 识别季节性特征
- 标注重要节点（促销季、节假日）

### 第4步：生成可视化图表
- 品牌竞争分布图
- 类别分布饼图
- 转化效率散点图
- 词频分布图
- 关键词四象限分布图
- 时间序列趋势图

### 第5步：输出分析报告
生成以下文件：

#### 📁 analysis_reports/ 目录
每个分析维度生成独立的CSV数据表和MD分析报告（共16个文件）：

1. **01_品牌竞争分析.csv + .md** - TOP品牌排名、市场集中度、竞争格局分析
2. **02_类别趋势分析.csv + .md** - 热门类别分布、跨类别机会识别
3. **03_搜索词热度分析.csv + .md** - 搜索词排名趋势、增长机会分析
4. **04_词频统计分析.csv + .md** - 高频词汇统计（人群词/场景词/属性词/品牌词）
5. **05_商品竞争力分析.csv + .md** - 明星ASIN识别、市场覆盖度评估
6. **06_ASIN转化效率分析.csv + .md** - 四象限分类（明星/潜力/流量陷阱/问题商品）
7. **07_关键词转化效率分析.csv + .md** - 垄断度评估、黄金关键词识别
8. **08_时间序列分析.csv + .md** - 月度趋势、季节性规律分析

#### 📊 每个MD报告包含
- **核心数据摘要**：关键指标和数据概览
- **详细数据表格**：完整的分析数据
- **💡 实操建议**：广告投放、Listing优化、选品决策等具体行动建议
- **可视化图表**：数据趋势和分布图（部分维度）

### 第6步：提供实操建议
根据分析结果，我会为你提供：

- **广告投放建议**：黄金关键词列表、出价策略、预算分配
- **Listing优化建议**：标题结构、高频词布局、五点描述优化
- **选品建议**：市场机会识别、竞争格局评估
- **竞品策略**：头部品牌和商品分析、差异化建议

## 报告文件格式要求

### 支持的文件格式
- CSV文件（UTF-8编码）
- 文件名包含"搜索词"或"Search Term"关键词
- 亚马逊官方导出的搜索词报告格式

### 必需的字段
报告必须包含以下字段（中文或英文）：
- 搜索频率排名 / Search Frequency Rank
- 搜索词 / Search Term
- 点击量最高的品牌 #1/#2/#3 / Top Clicked Brands
- 点击量最高的类别 #1/#2/#3 / Top Clicked Categories
- 点击量最高的商品 #1/#2/#3：ASIN / Top Clicked Products ASIN
- 点击量最高的商品 #1/#2/#3：点击份额 / Click Share
- 点击量最高的商品 #1/#2/#3：转化份额 / Conversion Share
- 报告日期 / Report Date

### 支持多月份数据
- 可以同时分析多个月份的报告
- 文件名建议包含日期（如：US_热门搜索词_2025_12_31.csv）
- 自动合并多月数据进行趋势分析
