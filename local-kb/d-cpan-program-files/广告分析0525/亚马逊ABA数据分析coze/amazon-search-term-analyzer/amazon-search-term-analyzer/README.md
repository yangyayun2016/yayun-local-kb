# 亚马逊搜索词报告分析器 Skill

## 📋 简介

这是一个专业的亚马逊搜索词报告分析工具，适用于**任何类目**的搜索词报告。通过8个维度的深度分析，帮助运营团队做出数据驱动的决策。

## 🎯 核心功能

1. **品牌竞争分析** - 识别市场主导品牌和竞争格局
2. **类别趋势分析** - 了解用户类别偏好和跨类别机会
3. **搜索词热度分析** - 追踪市场需求趋势和增长机会
4. **搜索词词频统计** ⭐ - 拆解搜索词，识别高频词汇（人群词/场景词/属性词/品牌词）
5. **商品竞争力分析** - 评估头部商品表现和市场覆盖度
6. **ASIN转化效率分析** - 四象限分类，识别明星商品和问题商品
7. **关键词转化效率分析** ⭐ - 评估关键词垄断度，识别黄金关键词和红海关键词
8. **时间序列分析** - 发现季节性规律和市场变化节点

## 🚀 使用方法

### 方式1：在Claude Code中调用

```bash
# 在报告目录下
cd /path/to/your/reports/
/amazon-search-term-analyzer

# 或指定路径
/amazon-search-term-analyzer /path/to/your/reports/
```

### 方式2：直接运行Python脚本

```bash
cd amazon-search-term-analyzer/scripts/
python3 analyze_search_terms.py /path/to/your/reports/
```

### 方式3：自然语言调用

在Claude Code中直接说：
```
帮我分析这个文件夹里的亚马逊搜索词报告
```

## 📊 输出文件

分析完成后，会在报告目录生成 **analysis_reports/** 文件夹，包含16个文件（8个CSV数据表 + 8个MD分析报告）：

### 数据表（CSV格式）
1. **01_品牌竞争分析.csv** - TOP品牌排名、出现频率、市场集中度
2. **02_类别趋势分析.csv** - 热门类别分布、搜索词关联度
3. **03_搜索词热度分析.csv** - 搜索词排名、趋势、增长率
4. **04_词频统计分析.csv** - 高频词汇统计（人群词/场景词/属性词/品牌词）
5. **05_商品竞争力分析.csv** - 明星ASIN、点击份额、转化份额、覆盖度
6. **06_ASIN转化效率分析.csv** - 四象限分类（明星/潜力/流量陷阱/问题商品）
7. **07_关键词转化效率分析.csv** - 垄断度评估、转化效率比、关键词分类
8. **08_时间序列分析.csv** - 月度数据趋势、季节性规律

### 分析报告（Markdown格式）
每个CSV对应一个MD报告，包含：
- 📊 核心数据摘要
- 📋 详细数据表格
- 💡 实操建议（广告投放/Listing优化/选品决策）
- 📈 可视化图表（部分维度）

## 📋 报告格式要求

### 支持的文件格式
- CSV文件（UTF-8编码）
- 文件名包含"搜索词"或"Search Term"关键词
- 亚马逊官方导出的搜索词报告格式

### 必需的字段
- 搜索频率排名
- 搜索词
- 点击量最高的品牌 #1/#2/#3
- 点击量最高的类别 #1/#2/#3
- 点击量最高的商品 #1/#2/#3：ASIN
- 点击量最高的商品 #1/#2/#3：点击份额
- 点击量最高的商品 #1/#2/#3：转化份额
- 报告日期

## 💡 实操应用场景

### 广告投放
- 使用"关键词转化效率表"识别黄金关键词
- 优先投放低垄断+高转化的关键词
- 根据垄断程度调整出价策略

### Listing优化
- 使用"词频统计表"优化标题和五点描述
- 将高频人群词、场景词、属性词融入文案
- 参考TOP商品的关键词布局

### 选品决策
- 分析品牌竞争格局，识别市场机会
- 查看类别分布，发现跨类别销售机会
- 评估市场垄断程度，判断进入难度
