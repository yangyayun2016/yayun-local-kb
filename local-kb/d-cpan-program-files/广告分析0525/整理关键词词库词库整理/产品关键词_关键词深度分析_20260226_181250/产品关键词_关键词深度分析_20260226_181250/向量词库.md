| 点击份额 | Top3 ASIN点击份额 | 转化份额、集中度 |

**🔧 操作SOP：**
```
Step 1: 在卖家精灵拉取小类目BSR 1-100名ASIN列表
Step 2: 批量输入ABA后台（最多100个ASIN）
Step 3: 导出所有流量词 → 提取关键词清单
Step 4: 统一维度整理：搜索量大小 + 份额占比
Step 5: 去重合并（多ASIN会有重叠词，按最高搜索量/份额保留）
```

**⚠️ 去重逻辑：**
```
多ASIN流量词重叠处理规则：
├── 同一关键词出现在多个ASIN → 保留该词
├── 统一指标维度：以「搜索词频率排名」为主排序
├── 辅助指标：点击份额、转化份额
└── 重叠次数本身也是信号 → 重叠越多=类目核心词概率越大
```

### 2.2.1 相关性分析 —— 占位率模型

```
┌───────────────────────────────────────────────────────────────┐
│                      占位率分析模型                              │
│                                                                 │
│  定义：某关键词搜索结果中，与你产品相同/相似的产品所占的比例           │
│                                                                 │
│  公式：占位率 = 搜索结果首页与你产品强相关的Listing数 / 首页总展示数  │
│                                                                 │
│  ┌─────────────────────────────────────────┐                   │

│  │                                           │                  │
│  │ 🟢 强相关产品: 40个  →  占位率 = 83%       │                  │
│  │ 🟡 中相关产品: 5个                         │                  │
│  │ 🔴 不相关产品: 3个                         │                  │
│  │                                           │                  │
│  │ 判断: 占位率>70% → 高相关词 → 值得主推     │                   │
│  └─────────────────────────────────────────┘                   │
│                                                                 │
│  占位率判断标准：                                                 │
│  ├── > 80%: 核心相关词，必须布局                                  │
│  ├── 60-80%: 高相关词，重点布局                                   │

└───────────────────────────────────────────────────────────────┘
```

### 2.2.2 占位率详细解释

```
什么是占位率？

占位率是衡量一个关键词与你产品相关程度的实战指标。

举例说明：
搜索 "phone case for iPhone 15"
→ 首页出现48个结果
→ 其中45个都是iPhone 15手机壳
→ 占位率 = 45/48 = 93.75%
→ 结论：这是一个高度精准的关键词

搜索 "phone accessories"
→ 首页出现48个结果
→ 其中只有8个是手机壳，其他是充电器、支架等
→ 占位率 = 8/48 = 16.7%
→ 结论：这个词太宽泛，占位率低，不建议主推

占位率的核心价值：
1. 衡量搜索意图匹配度 —— 买家搜这个词是不是真的想买你的产品？
2. 预判转化率 —— 占位率高 → 搜索意图精准 → 转化率更高
3. 指导广告投放 —— 占位率高的词优先投放，ACOS更低
4. 识别否词 —— 占位率极低的词应该进入否词库
```

> **一句话总结：** 在Rufus + COSMOS时代，关键词词库不再只是「搜索词的列表」，而是**产品完整语义图谱**——它告诉亚马逊算法：你的产品是什么、适合谁、在哪用、解决什么问题、为什么值得买。词库搭建的终极目标是让算法从各个维度**完整理解你的产品**，从而在所有相关的买家触达场景中展示你的产品。

### 1.2 A9 vs COSMO 对比

| 维度 | A9 算法（旧） | COSMO 算法（新） |
|------|-------------|-----------------|
| **核心逻辑** | 关键词匹配 + 销量 + 评价 | 用户意图理解 + 个性化推荐 |
| **匹配方式** | 关键词精确/模糊匹配 | 大数据 + AI语义理解 |
| **排名依据** | 单量 + 点击率 + 转化率 | 单量 + 点击率 + 转化率 **+ 人群精准度** |

| **流量分配** | 集中在头部卖家 | 更均匀分配，长尾卖家受益 |
| **产品理解** | 基于文本关键词 | 基于语义 + 常识推理 + 用户画像 |

## 一、什么是向量库？—— 从底层原理讲起

### 1.1 核心概念

### 1.2 向量是如何"理解"语义的？

```

│                                                                    │

│                                                                    │

│  "travel yoga mat"    → [0.88, 0.30, 0.20, 0.95, 0.60, 0.40]     │

│                                                                    │
```

### 4.2 Python 核心代码实现

```python
"""
亚马逊关键词向量库 - 核心实现
适用于中小卖家的轻量级方案
"""

import numpy as np
from openai import OpenAI
from sklearn.cluster import KMeans
from sklearn.metrics.pairwise import cosine_similarity
import json, csv

# =============================================
# 第一步: 向量化引擎
# =============================================
client = OpenAI(api_key="your-api-key")

def get_embedding(text, model="text-embedding-3-small"):
    """将文本转换为向量"""
    response = client.embeddings.create(input=text, model=model)
    return response.data[0].embedding

def batch_embed(keywords: list) -> dict:
    """批量向量化关键词"""
    embeddings = {}
    # OpenAI支持批量请求，每次最多2048个
    for i in range(0, len(keywords), 2000):
        batch = keywords[i:i+2000]
        response = client.embeddings.create(
            input=batch, model="text-embedding-3-small"
        )
        for j, item in enumerate(response.data):
            embeddings[batch[j]] = item.embedding
    return embeddings

# =============================================
# 第二步: 相关性计算
# =============================================
def calculate_relevance(product_desc: str, keywords: list) -> list:
    """
    计算每个关键词与产品描述的语义相关性
    返回: [(关键词, 相关性分数, 相关性级别), ...]
    """
    product_vec = np.array(get_embedding(product_desc)).reshape(1, -1)
    results = []
    
    keyword_embeddings = batch_embed(keywords)
    
    for kw, vec in keyword_embeddings.items():
        kw_vec = np.array(vec).reshape(1, -1)
        similarity = cosine_similarity(product_vec, kw_vec)[0][0]
        
        # 自动分级
        if similarity >= 0.80:
            level = "强相关★★★"
        elif similarity >= 0.60:
            level = "中相关★★☆"
        elif similarity >= 0.40:
            level = "弱相关★☆☆"
        else:
            level = "不相关☆☆☆→否词候选"
        
        results.append((kw, round(similarity, 4), level))
    
    # 按相关性降序排列
    results.sort(key=lambda x: x[1], reverse=True)
    return results

# =============================================
# 第三步: 关键词自动聚类
# =============================================
def cluster_keywords(keywords: list, n_clusters: int = 15) -> dict:
    """
    将关键词按语义自动聚类分组
    返回: {cluster_id: [关键词列表], ...}
    """
    embeddings = batch_embed(keywords)
    
    kw_list = list(embeddings.keys())
    vectors = np.array(list(embeddings.values()))
    
    # K-Means 聚类
    kmeans = KMeans(n_clusters=n_clusters, random_state=42, n_init=10)
    labels = kmeans.fit_predict(vectors)
    
    # 整理结果
    clusters = {}
    for kw, label in zip(kw_list, labels):
        cluster_id = int(label)
        if cluster_id not in clusters:
            clusters[cluster_id] = []
        clusters[cluster_id].append(kw)
    
    # 为每个簇生成标签（用簇中心最近的词代表）
    for cluster_id in clusters:
        cluster_indices = [i for i, l in enumerate(labels) if l == cluster_id]
        center = kmeans.cluster_centers_[cluster_id]
        cluster_vecs = vectors[cluster_indices]
        distances = cosine_similarity(center.reshape(1,-1), cluster_vecs)[0]
        representative_idx = cluster_indices[np.argmax(distances)]
        clusters[cluster_id] = {
            "representative": kw_list[representative_idx],
            "keywords": clusters[cluster_id],
            "size": len(clusters[cluster_id])
        }
    
    return clusters

# =============================================
# 第四步: 否词智能识别
# =============================================
def identify_negative_keywords(
    product_desc: str, 
    search_terms: list,
    auto_negate_threshold: float = 0.20,
    review_threshold: float = 0.45
) -> dict:
    """
    智能否词识别
    返回三级分类: 自动否定 / 人工审核 / 保留
    """
    product_vec = np.array(get_embedding(product_desc)).reshape(1, -1)
    term_embeddings = batch_embed(search_terms)
    
    result = {
        "auto_negate": [],      # 自动否定 (< 0.20)
        "review_needed": [],     # 需人工审核 (0.20-0.45)
        "keep": []              # 保留 (> 0.45)
    }
    
    for term, vec in term_embeddings.items():
        term_vec = np.array(vec).reshape(1, -1)
        sim = cosine_similarity(product_vec, term_vec)[0][0]
        
        if sim < auto_negate_threshold:
            result["auto_negate"].append((term, round(sim, 4)))
        elif sim < review_threshold:
            result["review_needed"].append((term, round(sim, 4)))
        else:
            result["keep"].append((term, round(sim, 4)))
    
    # 排序
    for key in result:
        result[key].sort(key=lambda x: x[1], reverse=True)
    
    return result

# =============================================
# 第五步: 新词发现（语义邻居探索）
# =============================================
def discover_new_keywords(
    core_keywords: list,
    candidate_pool: list,
    existing_keywords: set,
    min_similarity: float = 0.65,
    max_similarity: float = 0.95
) -> list:
    """
    发现语义相近但词库中尚未收录的潜力词
    candidate_pool: 来自行业大词库/竞品词库的候选词
    """
    core_embeddings = batch_embed(core_keywords)
    candidate_embeddings = batch_embed(candidate_pool)
    
    core_vecs = np.array(list(core_embeddings.values()))
    discoveries = []
    
    for candidate, vec in candidate_embeddings.items():
        if candidate in existing_keywords:
            continue  # 已在词库中，跳过
        
        cand_vec = np.array(vec).reshape(1, -1)
        similarities = cosine_similarity(cand_vec, core_vecs)[0]
        max_sim = float(np.max(similarities))
        nearest_core = core_keywords[int(np.argmax(similarities))]
        
        # 相似度在合理范围内的词（太高=重复，太低=不相关）
        if min_similarity <= max_sim <= max_similarity:
            discoveries.append({
                "keyword": candidate,
                "similarity": round(max_sim, 4),
                "nearest_core_keyword": nearest_core,
                "potential": "高" if max_sim > 0.80 else "中"
            })
    
    discoveries.sort(key=lambda x: x["similarity"], reverse=True)
    return discoveries

# =============================================
# 第六步: Listing语义匹配度审计
# =============================================
def audit_listing_coverage(
    listing_parts: dict,  # {"title": "...", "bullets": "...", "desc": "..."}
    target_keywords: list
) -> list:
    """
    审计Listing各部分对目标关键词的语义覆盖度
    """
    # 向量化listing各部分
    listing_vecs = {}
    for part_name, text in listing_parts.items():
        listing_vecs[part_name] = np.array(get_embedding(text)).reshape(1,-1)
    
    # 向量化关键词
    kw_embeddings = batch_embed(target_keywords)
    
    audit_results = []
    for kw, vec in kw_embeddings.items():
        kw_vec = np.array(vec).reshape(1, -1)
        scores = {}
        for part_name, part_vec in listing_vecs.items():
            scores[part_name] = round(
                float(cosine_similarity(kw_vec, part_vec)[0][0]), 4
            )
        
        overall = round(np.mean(list(scores.values())), 4)
        
        # 诊断
        if overall >= 0.75:
            diagnosis = "✅ 覆盖良好"
        elif overall >= 0.55:
            diagnosis = "⚠️ 需要加强"
            # 找出最弱的部分
            weakest = min(scores, key=scores.get)
            diagnosis += f" (重点优化: {weakest})"
        else:
            diagnosis = "❌ 严重不足，需要重写相关内容"
        
        audit_results.append({
            "keyword": kw,
            "scores": scores,
            "overall": overall,
            "diagnosis": diagnosis
        })
    
    audit_results.sort(key=lambda x: x["overall"])
    return audit_results

# =============================================
# 第七步: 覆盖盲区检测
# =============================================
def detect_coverage_gaps(
    my_keywords: list,
    competitor_keywords: dict  # {"competitor_A": [...], "competitor_B": [...]}
) -> list:
    """
    检测竞品覆盖但自己未覆盖的语义盲区
    """
    my_embeddings = batch_embed(my_keywords)
    my_vecs = np.array(list(my_embeddings.values()))
    
    gaps = []
    for comp_name, comp_kws in competitor_keywords.items():
        comp_embeddings = batch_embed(comp_kws)
        for kw, vec in comp_embeddings.items():
            if kw in set(my_keywords):
                continue
            
            kw_vec = np.array(vec).reshape(1, -1)
            max_sim_to_mine = float(
                np.max(cosine_similarity(kw_vec, my_vecs)[0])
            )
            
            # 如果这个词和我现有词库中任何词的相似度都低于0.75
            # → 说明这是我的覆盖盲区
            if max_sim_to_mine < 0.75:
                gaps.append({
                    "keyword": kw,
                    "from_competitor": comp_name,
                    "max_similarity_to_my_keywords": round(max_sim_to_mine, 4),
                    "gap_severity": "严重" if max_sim_to_mine < 0.5 else "中等"
                })
    
    gaps.sort(key=lambda x: x["max_similarity_to_my_keywords"])
    return gaps
```
