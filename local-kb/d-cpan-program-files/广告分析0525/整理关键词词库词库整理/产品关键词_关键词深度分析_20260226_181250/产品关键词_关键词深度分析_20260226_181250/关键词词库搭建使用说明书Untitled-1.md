## 一、为什么必须搭建关键词库？

## 二、关键词分类体系（四维分类法）

### 2.1 维度一：按流量大小分类

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ⚠️ 核心认知：不要仅靠"搜索量"判断流量大小！

  原因：
  ┌──────────────────────────────────────────────────────────┐
  │ 第三方工具的搜索量是估算值，不同工具数据差异很大              │
  │ 真实流量 ≠ 搜索量，还取决于：                               │
  │   • 点击率（搜索后有多少人真的点击了？）                      │
  │   • 竞品数量（搜索结果有多少产品在抢这个词？）                │
  │   • 广告占比（首页多少位置被广告占据？）                      │
  │                                                          │
  │ ★ 正确做法：用 ABA搜索频率排名 作为流量大小的核心判断依据      │
  │   ABA排名是亚马逊官方数据，是相对排名，更准确                 │
  └──────────────────────────────────────────────────────────┘

  流量分层标准（基于ABA搜索频率排名）：
  ┌──────────────┬─────────────────┬─────────────────────────┐
  │ 流量层级      │ ABA搜索频率排名  │ 说明                     │
  ├──────────────┼─────────────────┼─────────────────────────┤
  │ 超大流量词    │ Top 1-10,000    │ 行业通用大词，竞争极激烈   │
  │ 大流量词      │ 10,001-50,000   │ 品类核心词，必须布局       │
  │ 中等流量词    │ 50,001-200,000  │ 细分属性词，性价比高       │
  │ 小流量词      │ 200,001-500,000 │ 长尾精准词，转化率高       │
  │ 微流量词      │ 500,000+        │ 超长尾，单独看价值不大     │
  └──────────────┴─────────────────┴─────────────────────────┘

  ★ 不同阶段的产品应该重点攻打哪一层：
  ┌────────────────────────────────────────────────────────┐
  │  新品期(0-30天)  → 小流量词 + 中等流量词（先拿下能拿的）  │
  │  成长期(1-3个月) → 中等流量词 + 大流量词（逐步扩大）      │
  │  成熟期(3个月+)  → 大流量词 + 超大流量词（全面进攻）      │
  └────────────────────────────────────────────────────────┘

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### 2.2 维度二：按相关性强弱分类（★ 占位率判断法 — 核心方法）

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  占位率 = 一个关键词的自然搜索结果前X位中，
           属于你选定的目标竞品的产品数(Y) ÷ 总位数(X)

  ★ 占位率越高 → 相关性越强 → 这两者基本可以划等号

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  【占位率计算示例】

  假设你选择了50个目标竞品，检查某个关键词的搜索结果：

  ┌────────────────────────────────────────────────────────┐
  │                                                        │
  │  查看范围        竞品命中数    占位率      含义            │
  │  ──────────────  ──────────  ────────   ─────────       │
  │  前4个自然位     4/4 命中    = 100%     极强相关          │
  │  前8个自然位     7/8 命中    = 87.5%    非常强相关         │
  │  前16个自然位    12/16 命中  = 75%      强相关            │
  │  前32个自然位    20/32 命中  = 62.5%    中强相关           │
  │  前48个自然位    28/48 命中  = 58.3%    中等相关           │
  │                                                        │
  └────────────────────────────────────────────────────────┘

  【相关性分级标准】(可根据类目自定义调整)
  ┌────────────────────┬───────────────────────────────────┐
  │  占位率区间          │  相关性判定                        │
  ├────────────────────┼───────────────────────────────────┤
  │  50% - 100%        │  ★★★ 强相关 — 必须布局的核心词      │
  │  20% - 50%         │  ★★  中等相关 — 重点补充词           │
  │  1% - 20%          │  ★   弱相关 — 可选观察词             │
  │  0% - 1%           │  ✗   不相关 — 排除或否定              │
  └────────────────────┴───────────────────────────────────┘

  【看前几名自然位比较合适？】
  ┌────────────────────────────────────────────────────────┐
  │  推荐看前 8 位或前 16 位：                                │
  │                                                        │
  │  • 前4位太少，样本不够，容易受广告位干扰                    │
  │  • 前8位 = 搜索结果首屏，代表该词最核心的产品               │
  │  • 前16位 = 搜索结果前两行，覆盖度更好                     │
  │  • 前48位 = 约首页全部，数据更全但计算量大                  │
  │                                                        │
  │  ★ 建议：快速判断用前8位，精确判断用前16位                  │
  │  ★ 工具：SIF 支持8个站点的占位率查询，可批量操作            │
  └────────────────────────────────────────────────────────┘

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

```

  关键词 = 核心词根 + 修饰词

  修饰词类型决定了用户的搜索意图和产品匹配方向

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ┌─────────────┬──────────────────────┬──────────────────────┐
  │  修饰词类型  │  示例 (以apron为例)   │  用户意图              │
  ├─────────────┼──────────────────────┼──────────────────────┤
  │ 名称规格词   │ apron, kitchen apron │ 品类搜索，需求明确      │

  │             │ apron with pockets   │                      │
  ├─────────────┼──────────────────────┼──────────────────────┤
  │ 材质词      │ leather apron        │ 对材质有偏好            │
  │             │ cotton apron         │                      │
  ├─────────────┼──────────────────────┼──────────────────────┤
  │ 场景词      │ apron for cooking    │ 使用场景明确            │
  │             │ apron for grilling   │                      │
  │             │ apron for gardening  │                      │
  ├─────────────┼──────────────────────┼──────────────────────┤
  │ 人群词      │ apron for men        │ 目标人群明确            │
  │             │ apron for kids       │                      │
  │             │ apron for women      │                      │
  ├─────────────┼──────────────────────┼──────────────────────┤
  │ 颜色/外观词  │ black apron          │ 有外观偏好             │

  ★ 分类原则：
  ┌────────────────────────────────────────────────────────┐
  │  1. 不同品类的修饰词构成完全不同                           │

  │  3. 按修饰词共性进行分组归类                               │
  │  4. 同时可以按「相同词根」进行另一维度的分类                 │
```

### 2.4 维度四：按类目搜索转化率分类

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  数据来源：后台 → 增长 → 商机探测器 → 输入关键词 →
           买家需求和热门搜索词 → 搜索词

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  搜索转化率 = 该关键词搜索后最终产生购买的比例

  ┌────────────────────┬────────────────────────────────────┐
  │  转化率分层          │  含义与策略                         │
  ├────────────────────┼────────────────────────────────────┤
  │  高转化词            │ 用户搜索意图明确，购买意愿强           │
  │  (转化率 > 品类均值) │ → 优先投放，精准匹配，抢自然排名       │
  │                    │ → 通常是长尾精准词                    │
  ├────────────────────┼────────────────────────────────────┤
  │  中等转化词          │ 有一定购买意图，但还在比较             │
  │  (转化率≈品类均值)   │ → 正常投放，Listing优化提升转化       │
  │                    │ → 通常是品类中等词                    │
  ├────────────────────┼────────────────────────────────────┤
  │  低转化词            │ 搜索意图模糊，或竞争太激烈             │
  │  (转化率 < 品类均值) │ → 谨慎投放，控制花费                  │
  │                    │ → 通常是泛词/大词                     │
  └────────────────────┴────────────────────────────────────┘

  ★ 商机探测器独特价值：
  • 可以看到类目维度的搜索量、点击率、转化率
  • 可以发现「搜索增长率高 + 产品数少」的蓝海商机
  • 搜索转化率比搜索量更能反映一个词的质量
```

### 2.5 同类产品判断标准（选竞品前的关键步骤）

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  在选择竞品做反查之前，必须先判断「什么是你的同类产品」

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  【标品的同类判断】
  ┌────────────────────────────────────────────────────────┐
  │  判断维度：                                              │
  │  ① 品名功能 → 是否一致？                                 │
  │  ② 适用场景 → 是否一致？                                 │
  │  ③ 受众群体 → 是否一致？                                 │
  │                                                        │
  │  示例 — 书灯(Book Light)：                               │
  │                                                        │
  │  ┌──────────┬──────────┬──────────┐                     │
  │  │ 夹书式书灯│ 挂脖款书灯│ 长脖款书灯│  ← 都是书灯         │
  │  └──────────┴──────────┴──────────┘                     │
  │  品名功能：都是书灯 ✅                                    │
  │  适用场景：都是夜间阅读纸质书 ✅                            │
  │  受众群体：都是阅读爱好者 ✅                                │
  │                                                        │
  │  → 属于同类产品，不同款式                                  │
  │  → 选竞品时：优先选同款式，同款不足再补充其他款              │
  │                                                        │
  │  ★ 同赛道商品的标准：                                     │
  │    • 同类商品                                            │
  │    • 受众购买力相当                                       │
  │    • 受众喜好款式类似                                     │
  └────────────────────────────────────────────────────────┘

  【非标品的同类判断】
  ┌────────────────────────────────────────────────────────┐
  │  非标品（如服装）→ 看款式中最核心的3个属性                   │
  │                                                        │
  │  示例 — 连衣裙(Dress)：                                  │
  │                                                        │
  │  所有属性：无袖、有口袋、V领、中短款、纯色/花色、            │
  │           收腰、棉/聚酯纤维、L/M/S、女性、夏季             │
  │                                                        │
  │  最核心的3个属性：                                        │
  │  ┌─────────────────────────────────────┐               │
  │  │  ① 中短款（到膝盖）                   │               │
  │  │  ② 无袖                              │               │
  │  │  ③ V领                               │               │
  │  └─────────────────────────────────────┘               │
  │                                                        │
  │  → 选竞品时以这3个核心属性为筛选标准                       │
  │  → 核心属性一致的产品 = 同类竞品                           │
  │                                                        │
  │  ★ 如果外观完全不一样的品类：                               │
  │    根据「产品名称 + 功能属性 + 受众群体 + 适用场景」         │
  │    四要素一致性来判断是否同类                               │
  └────────────────────────────────────────────────────────┘
```

## 三、关键词查找方法 — 以竞品反查为核心

### 3.1 方法论核心：48+竞品ASIN反查法

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

            ★★★ 效率最高的找词方法 ★★★

        反查优秀竞品的流量词 → 构建自己的词库

  为什么是48+个ASIN？
  • 单个ASIN的流量词有限且有偏差
  • 48+个同类ASIN的流量词取并集，才能覆盖全量关键词
  • 数量越多越能发现"共性出单词"
  • 48+是经验值，类目大可以扩展到100-200个

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### 3.2 实操案例：花园软管(Garden Hose)

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  产品信息：                                                  │
│  ┌──────────────────────────────────────────────┐           │
│  │  产品名称：花园软管 (Garden Hose)               │           │
│  │  核心特点：                                    │           │
│  │    • 材质：纱线编织 (Yarn Woven)               │           │
│  │    • 功能：可伸缩 (Expandable)                 │           │
│  └──────────────────────────────────────────────┘           │
│                                                             │
│  第一步：确定核心词根                                         │
│  ──────────────────                                         │
│  • garden hose (品类核心词)                                   │
│  • expandable garden hose (功能+品类)                         │
│  • water hose (同义品类词)                                    │
│                                                             │
│  第二步：收集48+竞品ASIN                                      │
│  ──────────────────                                         │
│  来源1：核心关键词「garden hose」搜索结果前3页                  │
│         → 约 15-20个同类ASIN                                 │
│  来源2：BSR榜单中的同类产品                                    │
│         → 如果类目大，看前200-400名，边浏览边收集                │
│         → 约 20-30个同类ASIN                                 │
│  合计：48+个预选ASIN                                         │
│                                                             │
│  ★ 收集过程中的判断标准：                                      │
│    • 是否是同类产品？（品名/功能/场景/受众）                    │
```

## 九、完整流程总览（一页纸速查）

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

          亚马逊关键词库高效搭建 → 全链路闭环

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【Phase 1: 准备阶段】
 ① 确定产品核心词根（1-3个核心品类词）
 ② 判断同类产品标准（标品看品名/功能/场景/人群；非标品看3个核心属性）
 ③ 收集48+同类竞品ASIN（核心词前3页 + BSR榜单 + 关联推荐）
                    │
                    ▼
【Phase 2: 拓词阶段】
 ④ 多竞品反查为主（SIF/H10 批量反查48+ ASIN → 取流量词并集）
 ⑤ 词根拓展为辅（H10 Magnet / 搜索栏自动补全）
 ⑥ 类目拓词补充（商机探测器导出Niche搜索词）
 ⑦ ABA反查补充（品牌分析中ASIN反查）
 → 汇总去重 → 500-2000个初始词
                    │
                    ▼
【Phase 3: 分类打标阶段】
 ⑧ 占位率判相关性（强/中/弱/不相关 → 排除不相关词）
 ⑨ ABA排名判流量（超大/大/中/小/微流量）
 ⑩ 标注修饰词类型（品类/功能/材质/场景/人群/颜色...）
 ⑪ 商机探测器查转化率（高/中/低转化词）
 ⑫ 词频统计（在48+竞品中出现的频次）
 ⑬ 综合判定优先级（P0 / P1 / P2 / P3）
 → 形成完整的多维度词库
                    │
                    ▼
【Phase 4: 用词阶段】
 ⑭ Listing埋词（P0→标题 / P1→五点 / P2→ST / P3→描述）
 ⑮ 广告架构搭建（Auto探词 + P0精准 + P1词组 + P2广泛 + 防御 + ASIN定投）
                    │
                    ▼
【Phase 5: 分析优化阶段】
 ⑯ 每周下载广告搜索词报告
 ⑰ 四象限分析（高曝高转/高曝低转/低曝高转/低曝低转）
 ⑱ 效果数据回流词库（更新效果标签/生命周期/优先级）
 ⑲ 执行调整（调竞价/加词/否词/升级匹配/优化Listing）
                    │
                    ▼
【Phase 6: 动态维护（每月循环）】
 ⑳ 增量拓词（新竞品反查 + 新趋势词 + ABA更新）
 ㉑ 效果复盘（全量词效果重新评估）
 ㉒ 清理淘汰（僵尸词/衰退词清理）
 ㉓ 策略迭代（Listing调整 + 广告架构优化 + 季节布局）
     │
     └──→ 回到 Phase 5 循环 ♻️

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ★ 效率原则：自动化优先 → 批量化其次 → 手动操作最后
  ★ 维护周期：每月一次全面更新，每周一次效果回顾
  ★ 核心工具链：SIF(占位率+反查) + ABA(流量排名) + 
               商机探测器(类目词+转化率) + 广告报告(效果数据)
```

### 📌 来源1：ABA 品牌分析（Amazon Brand Analytics）

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  路径：卖家后台 → 品牌 → 品牌分析 → 搜索词分析
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

⬇ 导出方法：
  1. 选择时间范围（周/月/季度）
  2. 输入关键词 或 输入ASIN进行反查
  3. 点击右上角「下载」→ CSV文件

⬇ 导出字段说明：
  ┌────────────────────┬────────────────────────────────────┐
  │ 字段名称            │ 含义与用途                          │
  ├────────────────────┼────────────────────────────────────┤
  │ Search Term        │ 用户实际搜索的关键词                  │
  │ Search Frequency   │ 搜索频率排名(越小越热门)              │
  │   Rank             │ ★核心指标：判断词的热度                │
  │ #1 Clicked ASIN    │ 该词下点击最多的ASIN                  │
  │ #1 Click Share     │ 该ASIN的点击份额                     │
  │ #1 Conversion      │ 该ASIN的转化份额                     │
  │   Share            │ ★判断该词的垄断程度                   │
  │ (同理#2, #3)       │ Top3 ASIN的数据                     │
  └────────────────────┴────────────────────────────────────┘

⬇ 能做的分析维度：
  ✅ 竞品反查   → 输入竞品ASIN，看它吃了哪些词的流量
  ✅ 热词追踪   → 按搜索频率排名，找大词/飙升词
  ✅ 市场份额   → 看Top3 ASIN的点击&转化份额集中度
  ✅ 趋势分析   → 对比不同时段搜索频率排名变化
  ✅ 竞争格局   → 某个词是否被1-2个ASIN垄断

⬇ 使用技巧：
  • 用ASIN反查：输入自己ASIN和竞品ASIN对比流量词差异
  • 周数据更敏感，月数据更稳定，建议两者结合
  • 搜索频率排名 < 50,000 的词才有实际投放价值
  • 关注 #1 Click Share > 50% 的词 → 说明该词被某ASIN垄断
```

## 5.2 核心指标计算与判断标准

```
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  指标1：CTR（点击率）= 点击数 / 曝光数                         │
│  ────────────────────────────────────                        │
│  基准：0.3% - 0.5% (SP广告平均)                               │
│  > 0.5%  → 好 → 说明主图/标题/价格有吸引力                     │
│  < 0.2%  → 差 → 检查：相关性？主图？价格竞争力？                │
│                                                              │
│  指标2：CVR（转化率）= 订单数 / 点击数                         │
│  ────────────────────────────────────                        │
│  基准：10% - 15% (品类差异大)                                  │
│  > 15%   → 优秀 → 加大投入                                   │
│  < 5%    → 差 → 检查Listing/评价/价格                         │
│                                                              │
│  指标3：ACOS = 广告花费 / 广告销售额                           │
│  ────────────────────────────────────                        │
│  目标ACOS = 产品利润率（毛利率）                                │
│  ACOS < 毛利率 → 盈利                                        │
│  ACOS = 毛利率 → 盈亏平衡                                    │
│  ACOS > 毛利率 → 亏损（但可能为了推排名可接受）                  │
│                                                              │
│  指标4：TACOS = 广告花费 / 总销售额（含自然单）                  │
│  ────────────────────────────────────                        │
│  TACOS更能反映整体广告效率                                     │
│  TACOS下降 → 自然流量占比提升 → 健康趋势                       │
│                                                              │
│  指标5：CPC = 广告花费 / 点击数                                │
│  ────────────────────────────────────                        │
│  参考建议竞价，结合ACOS目标反推最高可承受CPC                     │
│  最高CPC = 客单价 × 转化率 × 目标ACOS                         │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 5.3 分析工作流（每周执行）

```
每周关键词分析 SOP：

Step 1  下载报告
        ├── 广告后台 → 搜索词报告（最近7天 + 最近30天）
        ├── 业务报告 → ASIN维度的流量和转化
        └── ABA → 核心词的搜索频率排名变化

Step 2  数据清洗
        ├── 去除曝光 < 100 的词（数据量不足，无统计意义）
        ├── 按 花费 降序排列 → 找到花钱最多的词
        └── 按 订单 降序排列 → 找到出单最多的词

Step 3  分类处理
        ├── 出单好 + ACOS低 → 标记为「明星词」→ 提竞价/提预算
        ├── 出单好 + ACOS高 → 标记为「优化词」→ 降竞价/查Listing
        ├── 花费高 + 0单    → 标记为「否定候选」→ 分析原因后否定
        ├── 新发现的好词    → 标记为「新机会」→ 加入手动精准
        └── 无曝光的投放词  → 标记为「僵尸词」→ 提竞价或删除

Step 4  执行调整
        ├── 调整竞价（每次不超过20%）
        ├── 添加否定词
        ├── 新词加入手动广告
        └── 更新词库状态标签

Step 5  记录归档
        ├── 更新词库的效果数据区
        ├── 记录本周操作日志
        └── 标记关键词生命周期变化
```
