# 📘 模块一：不同广告活动层级关注的不同指标

## 🔷 层级1：广告活动（Campaign）

### 可修改设置

| 设置项 | 操作要点 |
|-------|---------|
| **预算** | 根据广告活动效果（ACoS、CR）决定是否补充预算 |
| **竞价策略** | 动态竞价-仅降低 / 动态竞价-提高和降低 / 固定竞价 |
| **广告位溢价** | 针对三大广告位分别设置溢价百分比 |

### 关注指标

```
┌────────────────────────────────────────────────────────────┐
│                                                            │
│  📌 关注指标①：超预算时间                                     │
│  └→ 过早超预算 → 根据ACoS、CR决定是否补充预算                  │
│  └→ 判断逻辑：效果好(ACoS低/CR高) → 加预算                    │
│              效果差(ACoS高/CR低) → 不加，优化后再说             │
│                                                            │
│  📌 关注指标②：点击量                                        │
│  └→ 点击量高低与预算直接相关                                   │
│  └→ ⚠️ 建议：广告前期先保证足够点击量，设置充足预算               │
│  └→ 数据不够时不要急于优化，先跑量                              │
│                                                            │
└────────────────────────────────────────────────────────────┘
```

## 🔷 层级2：广告位（Placement）

### 三大广告位属性对比

| 广告位 | 曝光量 | 点击率 | 转化率 | ACoS |
|:-----:|:-----:|:-----:|:-----:|:----:|
| 🥇 **搜索结果顶部（首页）** | 低 | **高** | **高** | 低 |
| 🥈 **产品页面** | **大** | 较大 | 中等 | 中等 |
| 🥉 **搜索结果其余位置** | **大** | 较大 | 中等 | 中等 |

### 广告位优化决策树

```
📍 搜索结果顶部（首页）& 产品页面：

  点击量不高 + 转化率高 + ACoS稳低
      │
      ▼ ✅ 操作：提高广告位溢价 → 扩大该位置曝光和点击
      
  点击量高 + 转化率低 + ACoS偏高
      │
      ▼ ❌ 操作：降低广告位溢价 / 竞价策略改为"动态竞价-仅降低"


📍 搜索结果其余位置：

  点击量不高 + 转化率高 + ACoS稳低
      │
      ▼ ✅ 操作：提高投放竞价 / 匹配方式改为"扩大"
      │        （变相扩大该位置曝光和点击）
      
  点击量高 + 转化率低 + ACoS偏高
      │
      ▼ ❌ 操作：降低广告位溢价 / 竞价策略改为"动态竞价-仅降低"
```

### ⭐ 核心关注指标

> **点击量 & 转化率 & ACoS** — 三者联动判断广告位效果

  ┌──────────┬──────────┬──────────┬──────────┬──────────┐

### ⭐ 广告组分组原则（三大分组逻辑）

```
┌─────────────────────────────────────────────────────────┐
│                                                         │
│  分组原则①：不同变体分组投放                                │
│  └→ 颜色A一组 / 颜色B一组 / 尺寸C一组                     │
│  └→ 目的：区分不同变体的广告表现                            │
│                                                         │

│  └→ "wireless earbuds" 广泛匹配一组                      │

│  └→ 目的：对比匹配方式效果                                │
│                                                         │
│  分组原则③：不同词根下的投放词分组投放                        │
│  └→ 词根"earbuds"相关词一组                              │
│  └→ 词根"headphones"相关词一组                           │
│  └→ 目的：按词根分析流量质量                               │

## 🔷 层级4：投放（Targeting）

### 可修改设置

| 设置项 | 操作详情 |
|-------|---------|
| **投放竞价** | 调整单个关键词/ASIN的出价 |
| **匹配方式** | 广泛/词组/精确 切换 |
| **开启/暂停（换词）** | 暂停表现差的投放词，新增优质词 |

### 三大关注指标详解

```
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  📌 关注指标①：点击率                                          │
│  ┌──────────────────────────────────────────────────┐        │
│  │ 影响因素：与竞价直接相关                               │        │
│  │ • 竞价足够 → 广告位靠前 → 点击率高                     │        │
│  │ • 竞价不足 → 广告位靠后 → 点击率低                     │        │
│  └──────────────────────────────────────────────────┘        │
│                                                              │
│  📌 关注指标②：转化率                                          │
│  ┌──────────────────────────────────────────────────┐        │
│  │ 影响因素：与"投放词的选择"及"匹配方式"相关              │        │
│  │ • 投放词越精准 → 转化率越高                            │        │
│  │ • 广泛匹配 → 流量大但转化率偏低                        │        │
│  │ • 精确匹配 → 流量小但转化率偏高                        │        │
│  └──────────────────────────────────────────────────┘        │
│                                                              │
│  📌 关注指标③：ACoS                                           │
│  ┌──────────────────────────────────────────────────┐        │
│  │ 影响因素：与竞价 & 转化率 & 产品售价三者共同相关         │        │
│  │ • ACoS = 广告花费 ÷ 广告销售额                        │        │
│  │ • 竞价高 + 转化率低 + 售价低 → ACoS飙升               │        │
│  │ • 竞价合理 + 转化率高 + 售价高 → ACoS可控              │        │
│  └──────────────────────────────────────────────────┘        │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

│                                                                 │
│  情况①：点击量高 + 转化率高                                       │
│  └→ ✅ 匹配合理！保留该搜索词                                     │
│  └→ 💡 可考虑将其加入手动精确投放，给予更高竞价                      │
│                                                                 │
│  情况②：点击量高 + 转化率低                                       │

│                                                                 │

│  └→ 📈 潜力词！可加入手动投放提升曝光                               │
│                                                                 │
│  情况④：点击量低 + 转化率低                                       │

│                                                                 │

## 🔷 指标1：曝光量（Impressions）

### 影响曝光量的两大因素体系

```
                        曝光量
                     ┌────┴────┐
                广告因素         产品因素
              ┌───┴───┐           │
         ┌────┴────┐  │     LISTING中是否
         │         │  │     有埋此关键词
    广告竞价    其他因素│      (参考)
    ┌──┴──┐        │
 基本竞价  广告位竞价 │
    │              │
 竞价策略           │
                   │
         ┌─────────┼──────────┐
     关键词排名  关键词搜索量  自动广告是否
                            出现相关搜索词
                   │
              ┌────┼────┐
            预算   否词
```

### 广告因素详解

| 因素 | 具体内容 | 影响逻辑 |
|------|---------|---------|
| **广告竞价** | 基本竞价 + 广告位竞价 + 竞价策略 | 竞价越高 → 广告排名越靠前 → 曝光越多 |
| **关键词排名** | 关键词在广告搜索结果中的位置 | 排名越高 → 曝光越大 |
| **关键词搜索量** | 该关键词的市场搜索热度 | 搜索量越大 → 潜在曝光池越大 |
| **自动广告相关词** | 自动广告中是否出现相关搜索词 | 相关性越强 → 亚马逊分配的曝光越多 |
| **预算** | 每日/活动预算上限 | 预算耗尽 → 曝光立即停止 |
| **否词** | 否定关键词设置 | 否词过多 → 曝光减少（需谨慎） |

### 产品因素

| 因素 | 影响逻辑 |
|------|---------|
| **Listing中是否埋词** | Listing未包含目标关键词 → 亚马逊不会为该词分配广告曝光 |

> **💡 关键认知**：Listing是广告的基础。如果Listing中没有埋入关键词，即使出价再高，亚马逊也可能不给曝光。

## 🔷 指标2：点击率CTR（Click-Through Rate）

### CTR影响因素全景图

```
                              点击率 CTR
                ┌───────────────┼───────────────┐
           广告因素            产品因素         其他外部因素
         ┌───┴───┐        ┌───┴───┐            │
    ┌────┴──┐    │   ┌────┴──┐    │      ┌─────┴─────┐
  广告竞价  预算  否词 产品主图 视觉  产品配置  库存/购物车/
  /广告位        /匹配       /品牌        跟卖/时间段
```

### 一、广告因素对CTR的影响

| 广告因素 | 影响机制 | 优化方向 |
|---------|---------|---------|
| **广告竞价/广告位** | PPC出价低 → 广告位靠后 → 刷会变差 → 展示质量不好 → CTR低 | 适当提高竞价，争取优质广告位 |
| **广告预算** | 当CPC过高 + 预算超低 → 曝光效果越低 → CTR受影响 | 预算要匹配CPC水平 |
| **否词** | 否词太多 → 否掉了大流量词 → 曝光大幅减少 → CTR数据失真 | 否词要精准，不要过度否定 |
| **投放词选择** | 词的精准度直接影响CTR | 见下方详细分析 |

### 投放词选择与匹配方式详解

```
┌──────────────────────────────────────────────────────────────┐
│                     投放词选择策略                              │
│                                                              │
│  📌 大词策略                                                  │
│  └→ 一般用广泛匹配，低价去跑                                    │
│  └→ 目的：扩大流量入口，发现潜力词                               │
│                                                              │
│  📌 长尾词策略                                                │
│  └→ 跑出更多长尾词、转化更好的关键词再加价                        │
│  └→ 目的：精准获取高转化流量                                    │
│                                                              │
│  📌 匹配方式                                                  │
│  ┌────────────┬─────────────────────────────────┐            │
│  │ 广泛匹配    │ 流量大，精准度低 → CTR相对较低      │            │
│  │ 词组匹配    │ 流量中，精准度中 → CTR适中          │            │
│  │ 精确匹配    │ 流量小，精准度高 → CTR相对较高      │            │
│  └────────────┴─────────────────────────────────┘            │
│                                                              │
│  ⭐ 核心逻辑：流量精准性 ↑ → CTR ↑                             │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 🔷 指标3：ACoTs广告花费占比

### 核心公式

```
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  📌 ACoS = 广告花费 ÷ 广告销售额 × 100%                       │
│                                                              │
│  📌 ASoTs = 广告销售额 ÷ 总销售额 × 100%                      │
│      (广告销售占比)                                            │
│                                                              │
│  📌 ACoTs = ACoS × ASoTs                                     │
│      (广告花费占总销售额的比例)                                  │
│                                                              │
│  ──────────────────────────────────────────────              │
│                                                              │
│  💡 ACoTs = 广告花费 ÷ 总销售额 × 100%                        │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### ACoTs的核心判断逻辑

```
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  场景：ACoS很高，但是...                                       │
│                                                              │
│  ✅ 如果广告订单占比控制得非常好                                  │
│  └→ 广告费用占比（ACoTs）达到可以接受的范围                       │
│  └→ 那么即使ACoS高，整体也是健康的                              │
│                                                              │
│  ──────────────────────────────────────────────              │
│                                                              │
│  💡 核心认知：                                                │
│  ACoS高 ≠ 一定不好                                           │
│  要看ACoTs（广告花费占总销售额的比例）是否可接受                    │
│                                                              │
│  ──────────────────────────────────────────────              │
│                                                              │
│  📈 良性循环逻辑：                                             │
│                                                              │
│  通过广告提高关键词排名                                         │
│       ↓                                                      │
│  关键词转化率提升                                              │
│       ↓                                                      │
│  关键词的自然排名逐步提升                                       │
│       ↓                                                      │
│  自然订单占比增加                                              │
│       ↓                                                      │
│  ASoTs下降（广告销售占比降低）                                   │
│       ↓                                                      │
│  ACoTs自然下降 → 广告投入更健康                                 │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### ACoTs健康度判断参考

| ACoTs范围 | 健康状态 | 建议动作 |
|:---------:|:------:|---------|
| < 5%   | 🟢 非常健康 | 可适当扩大广告投入 |
| 5%-10% | 🟡 正常 | 保持现有策略，持续优化 |
| 10%-15% | 🟠 需关注 | 检查ACoS和ASoTs，针对性优化 |
| > 15%   | 🔴 警告 | 需立即优化或缩减广告预算 |

## 📘 Skill 1：广告单占比控制策略（按公司模式区分）

> **核心认知**：广告单占比的控制方式取决于公司运营模式

### 两大模式对比

```
┌──────────────────────────┬──────────────────────────────────┐
│                          │                                  │
│     📦 精铺模式            │      💎 精品模式                  │
│                          │                                  │
├──────────────────────────┼──────────────────────────────────┤
│                          │                                  │
│  ❌ 不做刻意控制           │  ✅ 需要按阶段节奏控制              │

│                          │                                  │
│  💡 核心原则：             │  💡 核心原则：                     │
│  用可控的竞价              │  按阶段逐步降低广告单占比           │
│  保证广告单不亏钱           │  稳步提升自然单占比                │
│                          │                                  │
│  📊 判断标准：             │  📊 判断标准：                     │

如何提升链接的自然订单的方法  总结：

自然订单占比的提升不是"玄学"，而是一套基于ECPM算法底层逻辑的科学推导：

理论层：ECPM公式告诉我们，CTR和CVR是决定排名的核心变量
数学层：期望和方差的概念告诉我们，产品力决定上限，点击积累降低波动

# 📘 Skill 3：ECPM自然排名底层算法（最核心理论）

## 3.1 ECPM公式详解

```
┌──────────────────────────────────────────────────────────────────┐
│                                                                  │
│  📐 ECPM（Effective Cost Per Mille）= 千次展现的预估收益            │
│                                                                  │
│  ┌────────────────────────────────────────────────────┐          │
│  │                                                    │          │
│  │  ECPM = 1000次展现 × CTR × CVR × 客单价 × 抽佣比例   │          │
│  │         + FBA费用                                   │          │
│  │                                                    │          │
│  └────────────────────────────────────────────────────┘          │
│                                                                  │
│  📊 变量分类：                                                    │
│                                                                  │
│  ┌────────────────────┬────────────────────────────────┐         │
│  │     常数（固定值）    │        随机变量（离散值）         │         │
│  ├────────────────────┼────────────────────────────────┤         │
│  │ • 1000次展现        │ • CTR（点击率）                  │         │
│  │ • 客单价            │ • CVR（转化率）                  │         │
│  │ • 抽佣比例          │                                │         │
│  │ • FBA费用           │ 在不同竞争环境、不同消费者决策下   │         │
│  │                    │ 存在随机性 → 称为随机变量          │         │
│  └────────────────────┴────────────────────────────────┘         │
│                                                                  │
│  💡 平台逻辑（利益即态度）：                                        │
│  把亚马逊当做老板 → 所有ASIN都是打工仔                              │
│  哪个ASIN给老板创造更多价值（ECPM更高）                              │
│  → 老板就给他更好的排名（自然位更靠前）                               │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘
```

## 3.2 期望与方差：对随机变量的定量评估

```
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  📐 如何对CTR/CVR这类随机变量进行定量计算？                      │
│  → 引入 期望（Expectation）和 方差（Variance）                  │
│                                                              │
│  ══════════════════════════════════════════════════           │
│                                                              │
│  📌 期望（E）= 这组离散数值的集中位置/平均水平                    │
│  ┌──────────────────────────────────────────────┐            │
│  │ 类比：一名学生10次考试的平均分                    │            │
│  │ → 代表他的真实水平                               │            │
│  │ → 期望值越高越好 ✅                              │            │
│  └──────────────────────────────────────────────┘            │
│                                                              │
│  📌 方差（σ²）= 离散数值的波动程度                               │
│  ┌──────────────────────────────────────────────┐            │
│  │ 类比：10次考试成绩的稳定程度                      │            │
│  │ → 方差大 = 发挥不稳定，时高时低                    │            │
│  │ → 方差小 = 每次成绩在小范围内波动                   │            │
│  │ → 方差越小越好 ✅                                │            │
│  └──────────────────────────────────────────────┘            │
│                                                              │
│  ══════════════════════════════════════════════════           │
│                                                              │
│  📐 排名评估公式（简化版）：                                     │
│                                                              │
│  ┌────────────────────────────────────────┐                  │
│  │                                        │                  │
│  │  max(期望, 方差) = 期望 - r × 方差       │                  │
│  │                                        │                  │
│  │  r > 0，代表偏好系数                     │                  │
│  │  r越大 → 越看重稳定性                    │                  │
│  │  平台算法调整 = 改变r值                   │                  │
│  │                                        │                  │
│  └────────────────────────────────────────┘                  │
│                                                              │
│  ⭐ 要提升排名：                                               │
│  → 提高期望（提升CTR/CVR的平均水平）                             │
│  → 降低方差（让CTR/CVR更加稳定）                                │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 3.3 期望与方差的影响因素

```
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  📐 期望的定义：                                               │
│                                                              │
│  期望 = f(P, Q)                                              │
│                                                              │
│  P = Product（产品）                  Q = Query（搜索词）       │
│  ┌──────────────────────┐          ┌──────────────────┐      │

│  │ • 文案精准度           │          │   相关性          │      │
│  │ • 评价星级和数量        │          │ • 关键词匹配精准度 │      │
│  │ • 价格合理性           │          │                  │      │
│  │                      │          │                  │      │
│  │ → 决定CTR/CVR的高低    │          │ → 决定CTR/CVR    │      │
│  └──────────────────────┘          └──────────────────┘      │
│                                                              │
│  💡 指导意义：                                                │
│  产品素质天然决定CTR/CVR的高低                                  │
│  → 从数学底层证明了"7分选品3分运营"的正确性                      │
│  → 主图/文案/评价/价格的构建能力至关重要                         │
│                                                              │
│  ══════════════════════════════════════════════════           │
│                                                              │
│  📐 方差的定义：                                               │
│                                                              │
│  方差 = f(点击数)                                             │
│                                                              │
│  ┌──────────────────────────────────────────────┐            │
│  │ • 点击次数太少 → 时高时低 → 方差大               │            │
│  │ • 点击次数不断增加 → 方差不断收敛变小             │            │
│  │                                              │            │
│  │ 类比：10次考试成绩不稳定                        │            │
│  │ → 考20次、50次、200次...                       │            │
│  │ → 次数越多，波动越小，越接近真实水平             │            │
│  └──────────────────────────────────────────────┘            │
│                                                              │
│  💡 指导意义：                                                │
│  通过快速增加点击次数 → 降低方差                                │
│  → 使"期望 - r×方差"的数值更大                                 │
│  → 间接提升排名                                              │
│                                                              │
│  ⭐ 这就从数学层面解释了：                                      │
│  "关键词上首页"策略有效的原因                                   │
│  → 通过大量点击 → 短期内降低方差                                │
│                                                              │
│  ⚠️ 但注意：                                                 │
│  期望才是决定因素，方差只是次要因素                               │
│  点击次数增加只是帮助算法更快了解真实CTR                          │
│  真实CTR/CVR还是由产品硬实力决定                                │
│                                                              │
└──────────────────────────────────────────────────────────────┘

## 3.4 ECPM排名完整推导

```
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  📐 完整排名推导流程                                           │
│                                                              │
│  Step 1: 假设所有SKU放在相同排名位置                            │
│       │                                                      │
│       ▼                                                      │
│  Step 2: 对每个SKU的CTR/CVR进行定量评估                         │
│       │  （计算期望和方差）                                     │
│       ▼                                                      │
│  Step 3: 代入公式 max = 期望 - r × 方差                        │
│       │  （得到每个SKU的综合评分）                               │
