## 三、Skill 1：市场嗅觉 — 品类评论扫描

### 🎯 目标
> 从目标品类的**海量评论**中快速感知市场温度，识别值得进入的细分赛道。

### 执行流程

```
Step 1 ─ 品类圈定
  │  确定目标品类 → 锁定 Top 50-100 竞品ASIN/链接
  │
Step 2 ─ 数据采集
  │  ┌───────────────────────────────────────┐
  │  │ • Scrapy + Selenium 抓取评论           │
  │  │ • 多渠道：Amazon / 1688 / 速卖通 / Shopee │
  │  │ • 字段：评论文本 / 星级 / 日期 / 变体 / VP标记 │
  │  │ • 增量更新：基于时间戳去重              │
  │  └───────────────────────────────────────┘
  │
Step 3 ─ 评论概貌分析
  │  • 总评论量 & 增长趋势 → 判断市场热度
  │  • 星级分布（1-5星占比）→ 判断品类满意度天花板
  │  • 评论语言分布 → 判断区域市场潜力
  │
Step 4 ─ 输出：品类热度雷达图
```

### 关键指标

| 指标 | 计算方式 | 选品信号 |
|------|---------|---------|
| **评论增速** | 近30天新增评论 / 上月新增评论 | >1.2 = 上升赛道 🟢 |
| **差评率** | (1-2星评论数) / 总评论数 | >25% = 存在改进空间 🟡 |
| **品类满意度缺口** | 行业平均评分 vs 用户期望评分 | 差值>0.8 = 选品机会 🔴 |
| **评论深度比** | 长评论(>50字)占比 | >30% = 用户高度关注品类 |

### 三维验证评分卡

| 验证维度 | 权重 | 评分标准 | 得分范围 |
|----------|------|---------|---------|
| **频次密度** | 40% | 每千条评论中提及次数：>50次=满分 | 0-100 |
| **情感烈度** | 35% | BERT情感极性得分均值（绝对值） | 0-100 |
| **趋势斜率** | 25% | 近6个月提及率线性回归斜率 | 0-100 |

### 伪需求过滤规则

```python
# 伪需求识别逻辑
def is_false_demand(keyword_data):
    filters = {
        "水军检测": keyword_data.vp_ratio < 0.5,        # VP评论占比过低
        "情感矛盾": keyword_data.sentiment_std > 0.8,    # 情感极度分散
        "昙花一现": keyword_data.trend_slope < -0.3,     # 提及率持续下降
        "孤岛需求": keyword_data.co_occurrence < 3,      # 缺乏关联词共现
    }
    return sum(filters.values()) >= 2  # 触发2条以上 → 判定为伪需求
```

本选品Skills体系将VOC评论分析系统的**五层技术能力**（采集→清洗→分析→建模→可视化）转化为**五个可执行的选品技能模块**：

|-------|-------------------|-------------|
