> **核心作用**：基于用户历史搜索行为动态调整排名，平衡短期热度与长期稳定性

│  │                                                  │        │

│  │  │ • 长期稳定的搜索词排名                 │        │        │

│  │  │ • 短期波动可能影响排名                  │        │        │
│  │  │   但长期积累的数据权重更高               │        │        │

# 📘 Skill 7：常见索引失败原因与解决方案

| 失败原因 | 表现症状 | 解决方案 |
|---------|---------|---------|
| **关键词堆砌** | 部分关键词被系统忽略 | 精简关键词，每个位置放置不重复的词 |
| **类目选择错误** | 搜索不到产品 | 重新选择最细分的正确类目 |
| **特殊符号/停用词** | 索引效率降低 | 删除 #、%、! 以及 and/the/for |
| **前后台关键词重复** | 浪费索引空间 | 标题已含的词后台ST不重复 |
| **Listing长期未更新** | 被降权，索引优先级降低 | 每月优化一次关键词 |
| **属性字段未填写** | 筛选结果中不出现 | 完整填写颜色/尺寸/材质等 |
| **违规操作** | Listing被屏蔽 | 避免黑帽操作（虚假属性等） |
| **产品属性与类目不匹配** | 曝光偏差 | 核实BTG要求，确保属性一致 |
