# Browser Automation Skill

## 用途

执行浏览器自动化操作，模拟人工在浏览器中的行为。

## 支持的操作

### 页面导航
- 打开指定URL
- 点击浏览器前进/后退
- 刷新页面
- 新开标签页

### 元素交互
- 点击按钮、链接
- 输入文本
- 下拉选择
- 复选框勾选
- 文件上传

### 内容提取
- 获取页面文本
- 提取表格数据
- 获取元素属性
- 导出页面为PDF/HTML

### 等待与验证
- 等待元素出现
- 等待页面加载
- 验证元素存在
- 等待特定文本

## 亚马逊运营常用场景

### 场景1：登录卖家后台
```
1. 打开亚马逊卖家中心URL
2. 输入账号密码
3. 点击登录
4. 验证登录成功
```

### 场景2：下载库存报告
```
1. 导航到库存页面
2. 点击【库存报告】
3. 选择报告类型
4. 点击下载
5. 保存到本地
```

### 场景3：查看广告数据
```
1. 进入广告页面
2. 选择时间范围
3. 截图保存
4. 导出数据表格
```

## 使用示例

### 示例1：登录亚马逊
```
用户：帮我登录亚马逊卖家后台
助手：使用browser-automation技能：
1. 打开 https://sellercentral.amazon.com
2. 输入邮箱和密码
3. 点击登录按钮
4. 验证页面标题包含"Dashboard"
```

### 示例2：下载库存报告
```
用户：下载今天的库存报告
助手：
1. 导航到库存 > 库存报告
2. 选择报告类型为"库存一览"
3. 设置日期为今天
4. 点击生成报告
5. 等待报告完成
6. 点击下载按钮
7. 保存到 ~/Downloads/inventory_report.csv
```

## MCP工具使用

推荐使用以下MCP服务：
- `@modelcontextprotocol/server-puppeteer` - 基础浏览器操作
- `@modelcontextprotocol/server-playwright` - Playwright浏览器控制

## 最佳实践

1. **操作前截图** - 记录操作前状态
2. **操作后验证** - 确认操作成功
3. **设置超时** - 避免无限等待
4. **错误重试** - 失败后自动重试
5. **日志记录** - 记录每个操作步骤
6. **敏感信息** - 使用环境变量存储密码
