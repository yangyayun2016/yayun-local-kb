# Report Generator Skill

## 用途

自动生成各类运营报表，支持多种格式导出和定时生成。

## 报表类型

### 1. 销售报表
| 报表名称 | 频率 | 内容 |
|---------|------|------|
| 销售日报 | 每天 | 当日销售额、订单量、转化率 |
| 销售周报 | 每周 | 周销量趋势、品类对比 |
| 销售月报 | 每月 | 月度总览、同比环比 |

### 2. 广告报表
| 报表名称 | 频率 | 内容 |
|---------|------|------|
| 广告日报 | 每天 | 曝光、点击、花费、ACOS |
| 关键词报告 | 每周 | 关键词排名、转化率 |
| 广告周报 | 每周 | 广告效果分析、优化建议 |

### 3. 库存报表
| 报表名称 | 频率 | 内容 |
|---------|------|------|
| 库存日报 | 每天 | 当前库存、预计售罄日期 |
| 补货建议 | 每周 | 补货数量、补货时间 |
| 滞销品报告 | 每周 | 库龄分析、促销建议 |

### 4. 利润报表
| 报表名称 | 频率 | 内容 |
|---------|------|------|
| 利润日报 | 每天 | 销售额、利润、利润率 |
| 成本分析 | 每周 | 各项成本占比、优化空间 |
| 利润月报 | 每月 | 月度利润汇总、趋势分析 |

## 使用示例

### 示例1：生成销售日报
```
用户：生成昨天的销售日报
助手：
1. 读取昨天销售数据（从CSV/API）
2. 计算关键指标：
   - 销售额
   - 订单数
   - 平均客单价
   - 转化率
3. 生成图表：
   - 24小时销量趋势图
   - 品类销量占比饼图
4. 导出Excel，包含：
   - 数据汇总表
   - 明细数据
   - 趋势图表
5. 保存到 ~/Reports/销售日报_20240114.xlsx
```

### 示例2：生成广告周报
```
用户：生成上周广告效果周报
助手：
1. 采集上周广告数据（7天）
2. 计算关键指标：
   - 总曝光量
   - 总点击数
   - 总花费
   - 平均ACOS
   - 平均ROAS
3. 按广告组分析：
   - 表现最好的广告组
   - 需要优化的广告组
4. 生成图表：
   - ACOS趋势图
   - 广告花费占比
5. 导出PDF报告
```

### 示例3：库存预警报告
```
用户：检查库存并生成预警报告
助手：
1. 获取当前库存数据
2. 计算售罄日期：
   - 售罄天数 = 库存 / 日均销量
3. 生成预警：
   - 红色预警：<3天
   - 黄色预警：3-7天
   - 绿色正常：>7天
4. 生成补货建议：
   - 建议补货数量
   - 建议补货时间
5. 导出Excel报告
```

## 图表配置

### 折线图（趋势）
```python
图表类型: line
用途: 展示时间趋势
适用: 销售额趋势、流量趋势
```

### 柱状图（对比）
```python
图表类型: bar
用途: 对比不同类别
适用: 品类销量对比、广告组效果对比
```

### 饼图（占比）
```python
图表类型: pie
用途: 展示占比分布
适用: 销售额占比、花费占比
```

### 热力图（密度）
```python
图表类型: heatmap
用途: 展示密度分布
适用: 24小时销量分布、关键词排名热图
```
