## listing-generator (Listing生成)

### 完整Listing优化指南

#### 1. 标题优化

**标题撰写公式：**
```
品牌名 + 核心品类词 + 核心卖点 + 材质/颜色 + 尺寸 + 数量/单位
```

**示例：**
```
ANJAYLIE Waterproof Phone Pouch for Beach, Swimming -
Transparent Touch Screen Friendly IPX8 Water Resistant Dry Bag
with Adjustable Neck Strap (2 Pack, Blue)
```

**标题黄金法则：**
| 字符位置 | 内容 | 重要性 |
|---------|------|--------|
| 0-80字符 | 核心关键词 | ⭐⭐⭐⭐⭐ |
| 80-120字符 | 次要关键词 | ⭐⭐⭐⭐ |
| 120-200字符 | 补充信息 | ⭐⭐⭐ |

**标题优化要点：**
- 使用数字而非文字（2代替two）
- 避免使用特殊字符（!、*、$等）
- 不使用他人商标词
- 首字母大写（标准格式）
- 控制在150-200字符

#### 2. 图片优化

**主图标准：**
| 要求 | 规格 |
|------|------|
| 背景 | 纯白(RGB 255,255,255) |
| 尺寸 | 至少1000x1000像素 |
| 格式 | JPEG、PNG、GIF |
| 产品占比 | ≥85%画面 |
| 禁止 | 水印、logo、文字、配件 |

**副图组合建议：**
| 序号 | 类型 | 内容 |
|------|------|------|
| 1 | 正面图 | 产品正面展示 |
| 2 | 使用场景 | 实际使用场景 |
| 3 | 尺寸对比 | 与常见物品对比 |
| 4 | 细节特写 | 关键功能/特点 |
| 5 | 包装内容 | 包装/配件展示 |
| 6 | 说明图 | 使用说明/注意事项 |

#### 3. 五点描述优化

**五点撰写框架：**
```
Bullet 1：核心卖点 + 痛点解决
Bullet 2：材质/工艺优势
Bullet 3：使用场景
Bullet 4：功能特性
Bullet 5：品牌/售后承诺
```

**五点优化策略：**
- 每条不超过500字符
- 每条2-3个核心卖点
- 包含1-2个相关关键词
- 使用简洁有力的句子
- 避免冗长描述

#### 4. 产品描述/A+页面

**产品描述要点：**
- <2000字符
- 使用HTML格式（换行、加粗）
- 包含核心关键词
- 突出卖点和差异化

**A+页面设计原则：**
1. 品牌故事模块建立信任
2. 痛点对比模块突出优势
3. 功能特性模块传递信息
4. 使用场景模块场景代入

#### 5. 变体设置

**常见变体类型：**
| 类型 | 示例 |
|------|------|
| 颜色变体 | Red, Blue, Black |
| 尺寸变体 | S, M, L, XL |
| 数量变体 | 1 pack, 2 pack |
| 材质变体 | Plastic, Metal |

**变体注意事项：**
- 父子变体关系清晰
- 变体主题选择准确
- 各子ASIN信息完整

#### 6. 违禁词清单

**绝对禁止使用：**
| 类别 | 词汇 |
|------|------|
| 最高级 | Best, #1, Number 1, Top 1 |
| 承诺/保证 | Guarantee, Promise, Warranty |
| 免费 | Free, Complimentary |
| 绝对词 | Absolutely, Completely, Totally |
| 价格词 | Cheap, Inexpensive, Lowest price |
| 刺激购买 | Buy now, Order now, Don't miss |
| 医疗宣称 | Cure, Treat, Prevent |

## advertising-optimizer (广告优化)

### 广告类型详解

| 类型 | 全称 | 展示位置 | 适用场景 |
|------|------|---------|---------|
| SP | Sponsored Products | 搜索结果/商品页 | 核心推广 |
| SB | Sponsored Brands | 搜索结果顶部 | 品牌曝光 |
| SD | Sponsored Display | 站内/站外展示 | 再营销 |
| SPV | Sponsored Videos | 搜索结果/商品页 | 视频推广 |

### 新品广告策略

**新品期（0-2周）：**
| 策略 | 内容 |
|------|------|
| 目标 | 收集数据、测试listing |
| 广告类型 | 自动广告 |
| 竞价策略 | 较低竞价（建议$0.5-1） |
| 匹配方式 | 紧密匹配+宽泛匹配 |
| 预算 | $20-50/天 |

**成长期（2-8周）：**
| 策略 | 内容 |
|------|------|
| 目标 | 提升转化、积累review |
| 广告类型 | 自动+手动（词组/精准） |
| 竞价策略 | 动态竞价（提升和降低） |
| 预算 | $50-100/天 |
| 动作 | 将高效词转手动 |

**成熟期（8周+）：**
| 策略 | 内容 |
|------|------|
| 目标 | 扩大规模、稳定ROAS |
| 广告类型 | SP+SB+SD组合 |
| 竞价策略 | 基于位置竞价 |
| 预算 | $100-300/天 |
| 动作 | 多变体投放、品牌投放 |

### 否定关键词策略

**需要否定的类型：**
| 类型 | 特征 | 否定方式 |
|------|------|---------|
| 不相关词 | A产品词搜到B产品 | 精确否定 |
| 高点击低转化 | 多次点击无订单 | 精确否定 |
| 亏损严重词 | ACOS>60%持续 | 短语否定 |
| 品牌词误投 | 竞品品牌词 | 精确否定 |

**否定时机：**
- 展现>1000、点击>50、转化=0 → 考虑否定
- 连续3-7天表现差 → 执行否定

### ACOS优化方法

| 问题 | 分析 | 解决方案 |
|------|------|---------|
| 高展示低点击 | 主图/价格/排名 | 优化主图/检查价格 |
| 高点击低转化 | Listing质量问题 | 优化五点/描述 |
| 高ACOS | 竞价过高/词不准 | 降低竞价/否定词 |
| 低ROAS | 投入产出比低 | 重构广告结构 |

## keyword-tracker (关键词追踪)

### 关键词分类

| 类型 | 特征 | 策略 |
|------|------|------|
| 信息类 | How、What、Guide | 内容营销 |
| 导航类 | Brand、Model | 品牌词 |
| 交易类 | Buy、Best、For | 高转化词 |
| 竞争类 | 竞品词 | 对标竞品 |

### 关键词挖掘方法

**1. 亚马逊搜索框**
- 输入核心词
- 查看自动补全建议
- 记录相关词

**2. 竞品Listing分析**
- 提取标题关键词
- 分析五点关键词
- 查看QA高频词

**3. 第三方工具**
- Helium 10 Cerebro/Magic Keyword
- Jungle Scout
- Merchant Words

### 关键词排名提升策略

| 方法 | 效果 | 难度 |
|------|------|------|
| 提高销量 | ⭐⭐⭐⭐⭐ | 中 |
| 优化Listing | ⭐⭐⭐⭐ | 低 |
| 增加Reviews | ⭐⭐⭐⭐ | 中 |
| 广告推广 | ⭐⭐⭐⭐ | 中 |
| 站外引流 | ⭐⭐⭐ | 高 |

## 常见问题

Q: 如何自动化日常运营？
A: 使用`task-scheduler` + `browser-automation`组合，设置定时任务自动执行。

Q: 报表多久生成一次？
A: 根据需求：日报、每周、每月，建议至少每周一次。

Q: 广告优化多久见效？
A: 一般3-5天数据稳定，7天可看到明显效果。

Q: 新品什么时候开始打广告？
A: Listing优化完成后立即开始，建议上架当天。

Q: 关键词排名掉了怎么办？
A: 1.检查是否断货 2.分析竞品动态 3.加大广告投入 4.优化Listing

## task-scheduler (任务调度)

### 使用场景
- 定时下载报表
- 定时发送报告
- 定时检查库存
- 周期执行任务

### Cron表达式
```
# 格式
┌───────────── 秒 (0-59)
│ ┌───────────── 分钟 (0-59)
│ │ ┌───────────── 小时 (0-23)
│ │ │ ┌───────────── 日 (1-31)
│ │ │ │ ┌───────────── 月 (1-12)
│ │ │ │ │ ┌───────────── 星期 (0-6)
│ │ │ │ │ │
* * * * * *

# 示例
0 9 * * *          # 每天上午9点
0 9 * * 1          # 每周一上午9点
0 0 1 * *          # 每月1号午夜
*/30 * * * *       # 每30分钟
```

### 使用示例
```
用户：设置每天早上9点下载广告报告

助手会：
1. 创建定时任务
2. 配置执行时间和频率
3. 设置任务内容（调用browser-automation）
4. 配置完成通知
5. 记录任务日志
```

## inventory-monitor (库存监控)

### 使用场景
- 库存实时监控
- 售罄日期预测
- 补货建议
- 滞销品识别

### 预警级别
| 级别 | 售罄天数 | 行动 |
|------|---------|------|
| 🔴 紧急 | <3天 | 立即补货（空运） |
| 🟡 警告 | 3-7天 | 加快补货（快船） |
| 🟢 正常 | 7-14天 | 按计划补货 |
| ⚪ 充足 | >14天 | 暂无需补货 |

### 使用示例
```
用户：检查今天库存状况

助手会：
1. 查询所有SKU库存
2. 计算售罄天数
3. 生成预警清单
4. 计算建议补货量
5. 输出补货计划表
```

## advertising-optimizer (广告优化)

### 使用场景
- 广告策略制定
- 竞价调整
- ACOS优化
- ROAS提升
- 关键词优化

### 核心指标
| 指标 | 公式 | 健康标准 |
|------|------|---------|
| ACOS | 广告花费/广告销售额 | <30% |
| ROAS | 广告销售额/广告花费 | >3.3 |
| CTR | 点击次数/展示次数 | >0.6% |
| CVR | 订单数/点击次数 | >10% |

### 广告策略阶段
| 阶段 | 目标 | 策略 |
|------|------|------|
| 新品期 | 跑数据 | 自动广告为主，广泛匹配 |
| 成长期 | 优化ACOS | 手动广告+自动广告 |
| 成熟期 | 扩大规模 | 精细化运营，多广告类型 |

### 使用示例
```
用户：ACOS太高了，帮我优化

助手会：
1. 分析当前广告数据
2. 识别高效/低效关键词
3. 调整竞价策略
4. 优化否定词
5. 预期效果评估
```
