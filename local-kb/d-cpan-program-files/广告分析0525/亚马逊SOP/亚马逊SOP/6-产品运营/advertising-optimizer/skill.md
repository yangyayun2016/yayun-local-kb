# Advertising Optimizer Skill（Xflow OS SOP版）

## 用途

生成广告运营的**完整Solution Kit**，包含T+1爆发期的推广里程碑、方法论指导、资源工具包。

> **Xflow OS 理念**: 不是"教你怎么投广告"，而是"一套能自动运转的推广工作台"

## Solution Kit 输出结构

### X Flow（流程）— T+1爆发期推广里程碑

```
阶段T+1: 爆发期（推广中）
├── 推广前期准备
│   ├── 关键词上首页计划         [负责人: 运营]  [T+1 ~ T+7]
│   ├── 五星评论布局             [负责人: 客服]  [T+5 ~ T+14]
│   └── Vine计划                [负责人: 运营]  [T+0即启动]
│
├── 推广中配合
│   ├── 站外辅助引流             [负责人: 推广]  [T+3 ~ T+14]
│   ├── 新品推广计划广告         [负责人: 运营]  [T+0即启动]
│   └── 透明计划布局             [负责人: 运营]  [T+1 ~ T+30]
│
└── 持续优化
    ├── 关键词排名监控           [负责人: 运营]  [每日]
    └── 广告数据复盘             [负责人: 运营]  [每周]
```

### Y Method（方法论）

**透明计划布局方法论**：
```
1. 启动时间：上架前1周发透明计划（若有）
2. 竞价策略：动态竞价-提高和降低
3. 预算分配：首周预算 = 预期日销 × $0.5
4. 优化节奏：每3天调整一次竞价
```

### Z Resource（资源/工具）

- 模板：广告结构规划表
- 工具：ACOS自动计算器
- 工具：竞价优化建议引擎
- 清单：否定关键词清单模板

| 类型 | 展示位置 | 适用场景 |

## 核心指标

### 基础指标
| 指标 | 公式 | 含义 |
|------|------|------|
| CTR | 点击次数 / 展示次数 | 吸引力 |
| CVR | 订单数 / 点击次数 | 转化力 |
| ACOS | 广告花费 / 广告销售额 | 盈利能力 |

### 进阶级指标
| 指标 | 公式 | 含义 |
|------|------|------|
| ROAS | 广告销售额 / 广告花费 | 投入产出比 |
| TACoS | 广告花费 / 总销售额 | 对整体销售的影响 |
| 归因销售额 | 归因于广告的订单销售额 | 广告真实贡献 |

### 健康标准（参考）
| 指标 | 新品期 | 成长期 | 成熟期 |
|------|-------|-------|-------|
| ACOS | 50-80% | 30-50% | <30% |
| ROAS | 1.2-2 | 2-3.3 | >3.3 |
| CTR | >0.4% | >0.5% | >0.6% |
| CVR | >5% | >8% | >10% |

## 广告策略阶段

### 1. 新品期（1-4周）
**目标：** 跑数据、积累评论
```
策略：
- 自动广告为主
- 广泛匹配收集关键词
- 竞价：建议竞价的80-100%
- 预算：充足，保证24小时运行
- 不急于否定，快速学习
```

### 2. 成长期（5-12周）
**目标：** 优化ACOS、提升排名
```
策略：
- 手动广告+自动广告
- 精准/短语匹配投放核心词
- 竞价：动态调整
- 开始否定无效词
- 优化Listing配合
```

### 3. 成熟期（12周+）
**目标：** 稳定ROAS、扩大规模
```
策略：
- 精细化运营
- 广告位优化（顶部加价）
- 拓展长尾词
- 多广告类型配合
- ACoS持续优化

## 竞价策略

### 竞价类型
| 类型 | 说明 | 适用 |
|------|------|------|
| 动态竞价-仅降低 | 亚马逊可降低竞价 | 成熟期、利润敏感 |
| 动态竞价-提高和降低 | 亚马逊可调整竞价 | 成长期、流量敏感 |
| 固定竞价 | 固定出价 | 新品期、稳定期 |

### 竞价调整规则
```
高转化词：竞价 +10-20%
低ACOS词：竞价 +10%
高展示低点击：竞价 -10%
连续0转化：暂停或降价
```

## 关键词优化

### 否定关键词
| 类型 | 示例 | 处理 |
|------|------|------|
| 不相关 | 搜索"手机"买"手机壳" | 否定精确 |
| 低转化 | 长期高展示0点击 | 否定精确 |
| 亏损词 | ACOS>利润率 | 否定短语 |

### 关键词匹配类型
| 类型 | 流量 | 精准度 | 建议竞价 |
|------|------|-------|---------|
| 广泛 | 高 | 低 | 较低 |
| 短语 | 中 | 中 | 中等 |
| 精确 | 低 | 高 | 较高 |

## 广告位优化

### 搜索结果顶部
- 曝光高、点击高
- 建议竞价 +50-100%
- 适合高转化ASIN

### 商品页面
- 曝光大、转化低
- 竞价适中
- 适合低价引流

### 其余位置
- 流量较小
- 竞价较低
- 补充流量

## 自动化规则

### 常用规则
| 规则 | 条件 | 动作 |
|------|------|------|
| 高效词提价 | ROAS>3 持续3天 | 竞价+10% |
| 低效词降价 | ACOS>50% 持续7天 | 竞价-15% |
| 无效词否定 | 展示>1000 点击0 | 否定精确 |
| 亏损广告组暂停 | ACOS>80% | 暂停并通知 |

### 示例规则配置
```
规则名称：高效词自动加价
触发条件：
  - ROAS > 3
  - 持续天数 = 3
执行动作：
  - 竞价提高 10%
  - 发送Slack通知
```

## 最佳实践

1. **数据驱动** - 所有决策基于数据分析
2. **持续优化** - 广告需要长期维护
3. **配合Listing** - 广告引流转化的基础是Listing
4. **否定管理** - 定期清理无效词
5. **竞品分析** - 监控竞品广告动态
6. **测试心态** - 小预算测试新词/新品
7. **阶段目标** - 不同阶段不同策略
8. **归因分析** - 理解广告的真实贡献
