# Inventory Monitor Skill（Xflow OS SOP版）

## 用途

生成库存管理的**完整Solution Kit**，包含T-0/T+1阶段的库存里程碑、倒推式备货计算、滞销处理方法论。

> **Xflow OS 理念**: 不是"监控库存"，而是"一套能自动预警并指导行动的库存工作台"

## Solution Kit 输出结构

### X Flow（流程）— T-0激活期 + T+1爆发期里程碑

```
阶段T-0: 激活期（上架后）
├── 环节3.1: 检查asin收录、节点、类目   [负责人: 运营]
├── 环节3.2: 检查产品属性填写完成度     [负责人: 运营]
└── 环节3.3: 划线价激活listing         [负责人: 财务]

阶段T+1: 爆发期（推广中）
├── 环节3.4: 关键词上首页（推广前期）   [负责人: 运营]
├── 环节3.5: 五星评论布局               [负责人: 客服]
└── 环节3.6: 站外辅助（推广中配合）     [负责人: 推广]
```

### Y Method（方法论）

**倒推式备货法**：
```
开售日期 → 倒推各环节截止时间
         → 计算安全库存 = 峰值日均 × (物流天数 + 14天)
         → 生成补货建议表
```

### Z Resource（资源/工具）

- 模板：VC选品利润测算表
- 工具：售罄预警自动计算器
- 工具：补货方式推荐引擎
- 清单：滞销品促销策略清单

## 核心功能

### 1. 库存状态查询
| 状态 | 说明 |
|------|------|
| Available | 可售库存 |
| Inbound | 在途库存 |
| Reserved | 预留库存 |
| Unfulfillable | 不可售（损坏等） |

### 2. 关键指标计算
```
日均销量 = 近7天销量 / 7
售罄天数 = 可售库存 / 日均销量
库存周转率 = 销售额 / 平均库存
```

### 3. 预警级别
| 级别 | 售罄天数 | 颜色 | 行动 |
|------|---------|------|------|
| 紧急 | <3天 | 🔴 红色 | 立即补货，优先发快递 |
| 警告 | 3-7天 | 🟡 黄色 | 加快补货，选择快船 |
| 正常 | 7-14天 | 🟢 绿色 | 按计划补货 |
| 充足 | >14天 | ⚪ 灰色 | 暂无需补货 |

## 补货计算

### 公式
```
预计销量 = 日均销量 × (头程天数 + 入库天数 + 安全天数)
建议补货 = 预计销量 - 当前库存 - 在途库存
```

### 示例
```
当前库存：100件
日均销量：20件
在途库存：200件
头程天数：15天
入库天数：3天
安全天数：7天

预计销量 = 20 × (15 + 3 + 7) = 500件
建议补货 = 500 - 100 - 200 = 200件
```

### 补货方式选择
| 库存状态 | 建议方式 |
|---------|---------|
| <3天售罄 | 空运/快递 |
| 3-7天售罄 | 快船 |
| 7-14天售罄 | 普通船运 |
| >14天售罄 | 可等待 |

## 滞销品处理

### 识别标准
- 库龄 > 90天
- 日均销量 < 1
- 库存周转 < 1

### 处理策略
| 库龄 | 策略 |
|------|------|
| 90-180天 | 降价促销、站内促销 |
| 180-270天 | 站外促销、清仓 |
| >270天 | 销毁或移仓 |

## 最佳实践

1. **每日巡检** - 养成每日检查习惯
2. **提前规划** - 物流周期+安全天数
3. **关注IPI** - 避免仓储限制
4. **区分产品** - 新品/老品不同策略
5. **成本控制** - 平衡仓储费与滞销费
6. **促销配合** - 滞销品及时清理
