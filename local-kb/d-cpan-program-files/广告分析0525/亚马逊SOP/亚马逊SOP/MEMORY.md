## 核心方法论速查

### 1. 爆款文案4步法（关健明）

```
写文案 ≈ 追女生

【1.勾注意力】→ "嘿，看这边！" → 7个开头模板
【2.挑欲望】→ "我很有趣哦~" → 4个激发技巧
【3.建信任】→ "我很靠谱~" → 3个信任方法
【4.促行动】→ "周末吃饭？" → 10个促单技巧
```

**高转化关键词**: 你、免费、数字、秘密、好奇、紧迫、对比

### 2. 标题公式

```
品牌 + 核心品类词 + 【勾注意力】+【欲望+量化】+【信任】+规格
```

### 3. 五点描述4步法

```
【勾注意力】你+痛点 → 痛点唤醒
【挑欲望】场景+量化 → 心动
【建信任】事实+证言 → 安全感
【促行动】锚点+CTA → 下单
```

### 4. 关键词金字塔

```
                    [品牌词]
                       │
              ┌────────┴────────┐
         [核心关键词]      [二级关键词]
              │
     ┌────────┴────────┐
[长尾关键词]    [场景关键词]  [属性关键词]
```

### 5. 关键词5种挖掘方法

| 方法 | 操作 | 输出 |
|------|------|------|
| 亚马逊搜索框 | 下拉/相关搜索 | 高相关长尾词 |
| 竞品Listing | 提取Top10标题 | 核心词库 |
| 竞品Review | 好评/差评高频词 | 痛点/卖点 |
| 第三方工具 | 西柚/Sorftime反查 | 搜索量/PPC |
| Google工具 | Trends/Planner | 趋势/相关词 |

### 6. 竞品推广复盘框架

```
1. 推广节奏 - 上架→广告→促销→review
2. 广告策略 - 类型/竞价/覆盖/ACOS
3. 价格策略 - 定价/折扣/Coupon
4. 排名变化 - 自然/BSR/类目
5. 流量来源 - 自然/广告/关联/站外
```
