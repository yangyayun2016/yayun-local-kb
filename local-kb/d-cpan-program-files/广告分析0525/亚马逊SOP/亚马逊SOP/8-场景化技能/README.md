## 核心技能详解

### content-writer-pro 爆款文案写作专家

**核心特色**：关健明4步法框架

```
写文案 ≈ 追女生

1. 【勾注意力】→ "嘿，看这边！" → 7个爆款开头模板
2. 【挑欲望】→ "我很有趣哦~" → 4个激发欲望技巧
3. 【建信任】→ "我很靠谱~" → 3个建立信任方法
4. 【促行动】→ "周末吃饭？" → 10个促单技巧
```

**适用场景**：
- 写高转化标题
- 写高转化五点描述
- 写A+内容
- 写广告文案
- 写促销文案

**高转化关键词**：
| 关键词 | 作用 | 应用位置 |
|--------|------|---------|
| 你 | 直面读者 | 标题/五点开头 |
| 免费 | 吸引力 | 促销文案 |
| 数字 | 具体化 | 教程/功能 |
| 秘密 | 好奇心 | 差异化卖点 |
| 省钱 | 利益点 | 促单 |

### keyword-research-pro 关键词研究专家

**核心特色**：5种挖掘方法 + 金字塔模型 + 竞品复盘

**关键词层级金字塔**：
```
                    [品牌词]
                       │
              ┌────────┴────────┐
              │                 │
         [核心关键词]      [二级关键词]
              │                 │
     ┌────────┴────────┐       │
     │                 │       │
[长尾关键词]    [场景关键词]  [属性关键词]
```

**5种关键词挖掘方法**：
| 方法 | 操作 | 输出 |
|------|------|------|
| 亚马逊搜索框 | 记录下拉/相关搜索 | 高相关长尾词 |
| 竞品Listing分析 | 提取Top10标题关键词 | 核心词库 |
| 竞品Review分析 | 提取好评/差评高频词 | 痛点/卖点词 |

| Google工具 | Trends/Keyword Planner | 趋势/相关词 |

**竞品推广复盘框架**：
```
1. 推广节奏分析 - 上架→广告→促销→review
2. 广告策略分析 - 类型/竞价/覆盖/ACOS
3. 价格策略分析 - 定价/折扣/Coupon
4. 排名变化分析 - 自然排名/BSR/类目
```

## 核心公式/模板库

### 标题公式
```
品牌名 + 核心品类词 + 【勾注意力】 + 【欲望+量化】 + 【信任背书】 + 规格
```

### 五点描述4步法
```
【勾注意力】你+痛点 → 痛点唤醒
【挑欲望】场景描绘+好处量化 → 心动
【建信任】事实证明+客户证言 → 安全感
【促行动】价格锚点+CTA → 下单
```

### 关键词分配
| 位置 | 分配 | 关键词类型 |
|------|------|-----------|
| 标题前80字符 | 2-3个A级词 | 核心品类词 |
| 五点每点 | 1-2个相关词 | 场景/痛点词 |
| 后台Search Terms | 所有剩余词 | 长尾/变体 |

### 爆款文案检查清单
```
[ ] 标题够吸引吗？（钩子是否有力）
[ ] 好处说清楚了吗？（用户能得到什么）
[ ] 有信任背书吗？（数据/证书/评价）
[ ] 下单门槛低吗？（价格/保障/便捷）
[ ] 读起来顺畅吗？（逻辑通顺）
```
