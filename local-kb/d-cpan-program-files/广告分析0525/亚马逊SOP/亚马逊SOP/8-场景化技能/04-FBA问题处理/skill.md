# FBA问题处理技能使用指南

## 触发场景

当用户描述以下问题时自动触发：
- "货被拒收了"
- "货到哪里了"
- "IPI分数太低了"
- "库存断货了"
- "仓储费太贵了"

## 示例对话

```
用户：发了一批货，亚马逊说标签不对被拒收了

助手（使用本技能）：
【FBA问题诊断报告】

问题类型：入库异常-标签问题
详细描述：发货后被亚马逊拒收，原因是标签问题

诊断分析：
1. 标签问题通常原因：
   - FNSKU标签缺失
   - 标签打印不清晰
   - 标签贴错位置
   - 与亚马逊系统不匹配

解决方案：

步骤1：确认具体原因
- 查看亚马逊通知邮件
- 联系货代了解拒收详情
- 核对实际标签状态

步骤2：根据原因处理
- 缺失/不清晰：重新打印清晰标签
- 贴错位置：按要求重新贴标
- 系统不匹配：核对SKU匹配度

步骤3：重新发货
- 联系货代取件或补发
- 重新打印标签
- 确保贴标正确
- 再次发货

预防措施：
1. 发货前检查标签清晰度
2. 核对FNSKU与SKU对应关系
3. 按亚马逊要求贴标（箱唛+产品标）
4. 拍照留存
```
