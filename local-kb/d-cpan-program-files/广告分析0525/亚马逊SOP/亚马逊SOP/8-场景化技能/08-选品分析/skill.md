# 选品分析技能使用指南

## 触发场景

当用户描述以下问题时自动触发：
- "帮我分析[品类]市场"
- "这个产品能做吗"
- "帮我看看[竞品]的数据"
- "选品分析报告"
- "市场调研"

## 使用方法

提供以下信息，技能自动生成分析报告：

**推荐提供**：
- 品类关键词
- 目标站点（美国站/欧洲站/日本站）
- 目标价格区间（可选）
- 特殊要求（可选）

## 示例对话

```
用户：帮我分析 bike fender（自行车挡泥板）在亚马逊美国站的市场

助手（使用本技能）：
【选品分析报告】

品类：bike fender（自行车挡泥板）
站点：美国站
分析日期：2026-02-30

一、市场规模
- Top 10 月均总销量：约15,000单
- 平均月销量（Top 10）：约1,500单
- 市场容量评估：中

二、竞争度分析
- 头部垄断度：42%（较健康）
- 新品存活率：18%（新品有机会）
- 平均星级：4.3星
- 竞争程度：中等

三、利润测算（以$25售价为例）
- 产品成本：$8
- 头程运费：$2
- FBA费用：$5
- 平台佣金（15%）：$3.75
- 推广费用（15%）：$3.75
- 总成本：$22.5
- 净利润：$2.5
- 毛利率：10%

四、风险评估
- 侵权风险：低
- 认证要求：无
- 季节性：弱（全年销售）
- 同质化：中

五、选品建议
综合评估：谨慎推荐

主要理由：
- 利润空间较小（毛利率10%偏低）
- 市场竞争中等
- 无明显季节性

改进方向：
- 差异化设计（如外观、可折叠）
- 增加配件组合销售
- 优化包装降低成本

供应商建议：
- 寻找有研发能力的工厂
- 谈判降低单价（目标$6）
- 确认产品质量稳定性
```
