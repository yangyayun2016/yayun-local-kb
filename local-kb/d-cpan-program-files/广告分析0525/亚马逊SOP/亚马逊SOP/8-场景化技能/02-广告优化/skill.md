# 广告优化技能使用指南

## 触发场景

当用户描述以下问题时自动触发：
- "ACOS太高了，亏钱"
- "广告没有曝光"
- "广告有点展比低"
- "广告不出单"
- "帮我优化广告"

## 使用方法

直接描述问题，技能会自动：
1. 识别问题类型
2. 提供数据分析
3. 给出优化方案
4. 输出执行步骤

## 示例对话

```
用户：我的广告ACOS到50%了，每单还亏钱，怎么办

助手（使用本技能）：
【广告问题诊断报告】

问题类型：高ACOS/亏损
当前数据：
- ACOS: 50%
- ROAS: 2.0
- CTR: 0.5%
- CVR: 8%

诊断分析：
1. ACOS 50% > 目标ACOS 30%，确实亏损
2. CTR 0.5% 略低于标准(0.6%)，主图需优化
3. CVR 8% 还可以，Listing转化正常

优化方案：

步骤1：降低竞价
- 自动广告：$0.8 → $0.5
- 手动广告：$1.0 → $0.6
- 观察3天数据

步骤2：否定低效词
- 进入广告报告
- 找出7天无转化的词
- 添加精确否定

步骤3：优化主图
- 增加差异化元素
- 突出核心卖点
- 场景化展示

预期效果：
- 竞价降低30%后，ACOS预计降至35-40%
- 结合否定词，ACOS可降至30%左右

监测周期：7天
```

## 问题类型速查

| 问题 | 核心指标 | 优先动作 |
|------|---------|---------|
| ACOS高 | ACOS > 目标 | 降价/否定/优化 |
| 无曝光 | 展示=0/低 | 检查状态/提竞价 |
| 无点击 | CTR < 0.3% | 优化主图/价格 |
| 无转化 | CVR < 3% | 检查词/优化Listing |
| 亏损 | ROAS < 2 | 综合优化 |
