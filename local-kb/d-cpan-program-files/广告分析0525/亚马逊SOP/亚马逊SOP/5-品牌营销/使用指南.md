## brand-manager (品牌管理)

### 使用场景
- 品牌备案
- A+页面设计
- 品牌旗舰店
- 侵权监控
- 赶跟卖

### 品牌备案流程（详细）

```
步骤1：商标注册
   - 选择商标类型（标准字体/设计）
   - 选择类目（与销售类目匹配）
   - 提交申请（R标或TM标）
   - 等待审核（1-3个月）

步骤2：准备备案资料
   - 商标注册证书
   - 产品图片（显示品牌Logo）
   - 包装图片（显示品牌Logo）
   - 品牌官网或社交媒体页面

步骤3：开始品牌备案
   - 亚马逊品牌注册网站
   - 创建品牌账户
   - 填写品牌信息
   - 上传资料

步骤4：完成备案验证
   - 接收验证码（发送到品牌官网邮箱）
   - 输入验证码完成验证

步骤5：解锁品牌功能
   - A+页面
   - 品牌旗舰店
   - 品牌保护
   等等
```

### 品牌备案所需资料

| 资料 | 要求 |
|------|------|
| 商标证书 | R标（已注册）或TM标（申请中） |
| 产品图片 | JPG/PNG，清晰显示品牌Logo |
| 包装图片 | 显示品牌Logo和UPC/EAN |
| 品牌网站 | 展示品牌和产品（可选） |
| 社交媒体 | 品牌账号（可选） |

### A+页面设计

#### A+模块类型
| 模块名称 | 用途 | 推荐指数 |
|---------|------|---------|
| 标准对比表 | 旧款vs新款/竞品对比 | ⭐⭐⭐⭐⭐ |
| 品牌故事 | 品牌理念和历史 | ⭐⭐⭐⭐ |
| 生活方式图 | 产品使用场景 | ⭐⭐⭐⭐ |
| 规格详情图 | 产品参数说明 | ⭐⭐⭐ |
| 十字轮播 | 多产品展示 | ⭐⭐⭐ |
| -banner图 | 品牌/促销展示 | ⭐⭐⭐ |

#### A+页面最佳实践
1. 突出核心卖点
2. 使用高质量图片
3. 包含品牌故事
4. 清晰的CTA引导
5. 避免过多文字
6. 移动端友好

### 防跟卖策略

#### 主动防护
1. **品牌备案**（基础）
2. **透明计划**
   - 每件产品贴透明计划码
   - 防止假冒产品跟卖
3. **独家计划（Exclusives）**
   - 仅在亚马逊销售
   - 获得专属标识
4. **产品差异化**
   - 独特包装
   - 定制配件
   - 组合销售

#### 透明计划优势
- 一物一码，防假冒
- 消费者可扫码验证真伪
- 防止其他卖家跟卖

### 赶跟卖操作流程

**方法1：品牌投诉**
```
路径：亚马逊品牌注册 → 违规举报
类型：商标侵权
提供：品牌授权书、ASIN截图
```

**方法2：测试购买（Test Buy）**
```
步骤：
1. 用小号购买跟卖产品
2. 收到货后拍照/录像
3. 对比与自己产品的差异
4. 如果不符，投诉假冒商品
```

**方法3：发送警告信**
```
Subject: Cease and Desist - [Brand] Trademark Infringement

Dear [Seller],

We are the authorized brand owner of [Brand Name].

Your listing for ASIN [ASIN] is using our trademark
without authorization. This is trademark infringement.

Please remove your listing within 24 hours.
Otherwise, we will take further legal action.

Best regards,
[Brand Owner]
```

**方法4：联系亚马逊**
```
通过Seller Performance Team
或
通过Report a Violation页面
```

### 侵权监控

**监控方式：**
1. 定期搜索品牌词
2. 设置Google Alerts
3. 使用专业监控工具
4. 查看品牌注册后台

**侵权类型：**
| 类型 | 描述 | 处理方式 |
|------|------|---------|
| 商标侵权 | 未经授权使用品牌名/Logo | 品牌投诉 |
| 专利侵权 | 外观/实用专利侵权 | 专业评估后处理 |
| 版权侵权 | 图片/文案抄袭 | DMCA反通知 |
| 假冒产品 | 销售假货 | 测试购买+投诉 |

## review-generator (评价管理)

### 使用场景
- 获取更多评价
- 处理差评
- 管理Vine计划
- 使用Request a Review
- 评价数据分析

### 评价获取方法

#### 方法1: Request a Review
```
功能位置：卖家后台 > 订单 > 请求评论
发送时间：收到货后4-30天
效果：提升评价率30-50%
频率：每订单只能发送1次
最佳时间：工作日（美国时间上午）
```

#### 方法2: 产品插页（合规要求）
```
设计要点：
1. 简洁美观
2. 真诚请求留评
3. 提供帮助渠道
4. 避免"留评返现"
5. 可提供小礼品引导

禁止内容：
- 诱导性语言（如"好评返现"）
- 威胁性语言
- 与亚马逊政策冲突的承诺
```

#### 方法3: Vine计划
```
适用条件：
- 完成品牌备案
- 新品（90天内上架）
- FBA库存充足

费用档位：
- $75（2个Vine Voice）
- $200（10个Vine Voice）
- $375（40个Vine Voice）

注意：
- 需有足够库存
- 评价不可控（可能差评）
- 建议新品先测试小批量
```

### 站外引流ROI评估

**核心指标：**
| 指标 | 计算方式 | 目标值 |
|------|---------|-------|
| 转化率 | 订单数÷点击数 | >3% |
| ROAS | 销售额÷广告花费 | >150% |
| TACoS | 广告花费÷总销售额 | <15% |

**评估流程：**
```
1. 使用带参链接（UTM参数）
2. 跟踪流量来源
3. 对比站内数据
4. 计算真实ROI
5. 优化投放策略
```

## 常见问题

Q: 品牌备案需要什么资料？
A: 商标注册证书、产品图片（带Logo）、包装图片（带Logo）、品牌官网。

Q: 如何提高评价获取率？
A: 优化产品质量、提供优质服务、使用Request a Review、Vine计划。

Q: 站外引流多久能看到效果？
A: 一般需要2-4周测试优化，稳定后ROI可达150%+。

Q: 透明计划和独家计划哪个好？
A: 透明计划适合防跟卖，独家计划适合品牌保护，根据需求选择。

Q: A+页面能提升多少转化？
A: 一般提升3-10%转化率，配合品牌故事效果更佳。
