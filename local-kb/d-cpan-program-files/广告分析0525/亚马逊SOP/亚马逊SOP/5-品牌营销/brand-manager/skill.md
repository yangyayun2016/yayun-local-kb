# Brand Manager Skill

## 用途

品牌全生命周期管理，从备案到保护。

## 品牌备案流程

```
商标注册 → 品牌备案 → 解锁品牌功能 → 品牌旗舰店 → 品牌保护
```

### 商标注册要求
| 站点 | 商标要求 | 注册时长 |
|------|---------|---------|
| 美国站 | 美国商标 USPTO | 8-12个月 |
| 欧洲站 | 欧盟商标 EUIPO | 4-6个月 |
| 日本站 | 日本商标JPO | 6-10个月 |

### 品牌备案所需资料
```
1. 商标注册证书
2. 产品图片（带品牌Logo）
3. 包装图片（带品牌Logo）
4. 品牌官网（如有）
5. 品牌社交媒体（如有）
```

### 品牌功能解锁
| 功能 | 作用 |
|------|------|
| A+页面 | 增强品牌展示，提升转化 |
| 品牌旗舰店 | 专属品牌页面 |
| 视频上传 | 品牌视频功能 |
| Parent-Child变体 | 品牌专属变体管理 |
| 品牌分析 | 消费者洞察数据 |
| 侵权举报 | 品牌保护工具 |

## A+页面设计

### 模块类型
| 模块 | 适用 | 效果 |
|------|------|------|
| 标准对比 | 品牌旧款vs新款 | 高 |
| 生活方式 | 场景展示 | 高 |
| 故事品牌 | 品牌故事 | 中 |
| 十字轮播 | 多角度展示 | 中 |
| 标准 banner | 信息展示 | 中 |

### A+页面结构
```
1. 品牌故事模块（顶部）
2. 产品核心卖点（3-4个）
3. 产品细节展示
4. 场景使用展示
5. 品牌承诺/服务
```

### 制作流程
```
1. 内容策划（卖点提炼）
2. 图片素材收集
3. 模块选择
4. 页面制作（卖家后台）
5. 预览确认
6. 提交审核
7. 上线发布
```

### 审核常见问题
| 问题 | 解决方法 |
|------|---------|
| 图片模糊 | 使用高清原图 |
| 文案违规 | 删除主观词（Best、#1） |
| 联系方式 | 删除联系方式 |
| 竞品对比 | 避免点名竞品 |

### 页面管理

## 品牌保护

### 侵权监控
```
监控内容：
- 跟卖监控
- 假货监控
- 商标侵权
- 图片盗用

监控频率：每日
```

### 举报类型
| 类型 | 举报入口 | 处理时效 |
|------|---------|---------|
| 商标侵权 | 品牌备案 | 12-24小时 |
| 版权侵权 | Amazon CVP | 24-48小时 |
| 假冒产品 | Amazon ACC | 48-72小时 |

### 赶跟卖策略
```
1. Test Buy（测试购买）
2. 收集证据（订单、收货照片）
3. 提交举报
4. 跟进处理进度
5. 品牌备案投诉（更有效）
```

### 品牌保护工具
```
Amazon Brand Registry：
- 搜索备案
- 图片侵权检测
- 自动化保护
- 透明度计划（品牌贴标）
```

## 品牌分析

### 关键指标
| 指标 | 说明 | 目标 |
|------|------|------|
| 品牌搜索量 | 品牌词搜索次数 | 增长 |
| 搜索词报告 | 品牌相关搜索词 | 拓展关键词 |
| 商品转化率 | 品牌流量转化 | >平台平均 |
| 客户画像 | 年龄、性别、兴趣 | 精准营销 |

### 竞品对比
| 对比维度 | 本品牌 | 竞品A | 竞品B |
|---------|-------|-------|-------|
| 搜索词份额 | 35% | 25% | 20% |
| 平均评分 | 4.6 | 4.4 | 4.3 |
| 转化率 | 12% | 9% | 8% |

## 使用示例

### 示例1：创建A+页面
```
用户：帮我做一个厨房用品的A+页面
助手：
1. 确定卖点：
   - 食品级不锈钢
   - 易于清洁
   - 送礼首选
   - 品牌保障

2. 选择模块：
   - 品牌故事模块
   - 4个对比模块
   - 1个生活方式模块
   - 品牌承诺模块

3. 图片素材：
   - 产品主图（白底）
   - 场景图（厨房使用）
   - 细节图（材质特写）
   - 对比图（旧款vs新款）

4. 提交审核并上线
```

### 示例2：处理跟卖
```
用户：发现有跟卖，价格低很多
助手：
1. 确认跟卖：
   - 记录跟卖ASIN
   - 截图价格对比

2. Test Buy：
   - 用买家账号下单
   - 收货时拍照/录像
   - 保留完整证据

3. 提交举报：
   - 品牌备案页面举报
   - 上传证据（订单、照片）
   - 选择投诉类型（假货/仿冒）

4. 跟进结果：
   - 监控跟卖是否下架
   - 如未处理，继续投诉
```

## 最佳实践

1. **尽早备案** - 产品上架前完成品牌备案
2. **A+必做** - 转化提升15-20%
3. **旗舰店建设** - 提升品牌形象
4. **持续监控** - 每日侵权监控
5. **及时举报** - 发现侵权立即处理
6. **品牌内容** - 保持风格统一
7. **数据驱动** - 定期分析品牌数据
