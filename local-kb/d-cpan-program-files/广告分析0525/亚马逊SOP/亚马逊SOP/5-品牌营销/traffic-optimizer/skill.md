## 红人合作

### 红人筛选标准
| 维度 | 要求 |
|------|------|
| 粉丝数量 | 1万-100万（中腰部为主） |
| 受众匹配 | 与目标客户匹配 |
| 内容质量 | 制作精良、互动真实 |
| 历史合作 | 有类似产品合作经验 |
| 互动率 | >2% |

### 合作形式
| 形式 | 成本 | 效果 | 适用 |
|------|------|------|------|
| 产品置换 | 0 | 中 | 新品牌起步 |
| 付费推广 | $$ | 高 | 有预算 |
| 佣金分成 | $ | 中 | 长期合作 |
| 品牌大使 | $$$ | 高 | 核心红人 |

### 合作流程
```
1. 红人筛选 → 2. 初次联系 → 3. 合作洽谈
4. 发送样品 → 5. 内容审核 → 6. 发布追踪
7. 效果复盘 → 8. 长期合作
```

### 合作话术
```
初次联系邮件：

Hi [红人名字],

content about [相关主题].

audience would benefit from our [产品名称].

We'd love to send you a free sample for an honest review.

Best,
[你的名字]
```

## Google Ads

### 广告类型
| 类型 | 适用 | 特点 |
|------|------|------|
| 搜索广告 | 关键词流量 | 主动搜索用户 |
| 展示广告 | 品牌曝光 | 兴趣定向 |
| 购物广告 | 产品推广 | 直接展示产品 |
| 视频广告 | 品牌故事 | YouTube |

### 关键词策略
```
关键词类型：
1. 品牌词 - 低成本、高转化
2. 品类词 - 中成本、需求明确
3. 长尾词 - 低成本、高意向
4. 竞品词 - 高成本、精准打击
```

### ROI计算
```
ROI = (收入 - 成本) / 成本 × 100%

案例：
广告花费：$1000
带来订单：50单
平均客单价：$30
收入：$1500
利润（30%）：$450
ROI：45%

要求ROI>0，至少保本
```

### 渠道优化
```
测试阶段：
- 每个渠道小预算测试
- 收集7天数据
- 评估转化成本

放大阶段：
- 预算向高效渠道倾斜
- 优化高效渠道的内容
- 持续测试新渠道

淘汰阶段：
- ROI<0的渠道停止
- 低效渠道优化后复测
```

## 使用示例

### 示例1：找红人合作
```
用户：帮我找厨房用品类的YouTube红人
助手：
1. 搜索关键词："kitchen product review YouTube"
2. 筛选红人：
   - 粉丝：10万-50万
   - 内容：厨房用品评测
   - 互动：>3%
   - 更新频率：每周

3. 候选红人：
   - ChefReview（25万粉丝，互动4%）
   - KitchenHacks（15万粉丝，互动3.5%）
   - HomeCooking（50万粉丝，互动2%）

4. 建议：首选ChefReview，中腰部红人性价比高
```

### 示例2：评估Deal效果
```
用户：昨天发了一个Deal，帮忙分析效果
助手：
1. 数据汇总：
   - 折扣：30% off
   - 价格：$20.99 → $14.69
   - 帖子点击：2500次
   - 订单：180单
   - 销售额：$2,644
   - BSR排名：#150 → #35

2. 效果评估：
   - 转化率：7.2%（优秀）
   - 单均毛利：$5（30%）
   - 毛利：$900
   - Deal费用：免费

3. 建议：
   - 效果很好，可定期发布
   - 观察Listing排名变化
   - 考虑其他Deal网站复制
```

### 示例3：站外引流ROI
```
用户：Facebook广告花了$500，效果怎么样
助手：
1. 数据追踪：
   - 点击：1250次
   - 订单：35单
   - 销售额：$1,050
   - 平均客单价：$30

2. 转化分析：
   - CTR：1.25%
   - 转化率：2.8%
   - CPA：$14.29

3. ROI计算：
   - 销售额：$1,050
   - 产品成本（30%）：$315
   - 物流成本（10%）：$105
   - 广告成本：$500
   - 净利润：$130
   - ROI：26%

4. 建议：
   - ROI偏低，建议优化广告素材
   - 或降低竞价，测试低预算
   - 持续优化至ROI>50%
```

## 最佳实践

1. **站内优先** - 先优化站内转化，再做站外引流
2. **精准投放** - 选择与产品匹配的人群
3. **持续测试** - 小预算测试多个渠道
4. **数据追踪** - 每个渠道带UTM追踪
5. **内容为王** - 高质量内容带来高转化
6. **红人背书** - 真实评测比广告更可信
7. **Deal配合** - 配合活动期效果更好
