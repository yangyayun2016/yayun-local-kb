# Fulfillment Manager Skill

## 用途

FBA发货和海外仓管理全流程。

## FBA入库流程

```
创建 shipment → 打印标签 → 装箱发货 → 物流跟踪 → 仓库接收 → 上架销售
```

## 创建FBA Shipment

### 步骤
```
1. 登录亚马逊卖家后台
2. 进入【库存】→【发送库存至亚马逊】
3. 创建新 shipment
4. 选择目的地仓库
5. 添加SKU和数量
6. 设置箱规
7. 打印标签
8. 确认发货
```

### 箱规要求
| 项目 | 要求 |
|------|------|
| 纸箱尺寸 | 最大63.5cm（任意边） |
| 单箱重量 | 最大22.5kg（欧洲15kg） |
| 承重 | 需有足够强度 |
| 标签 | 每箱需贴FBA箱标 |

### 发货标签
```
每箱需包含：
1. FBA箱标（亚马逊提供）
2. 运输标签（物流公司）
3. 易碎标识（如需要）
4. 向上标识
```

## 发货方式

| 方式 | 时效 | 成本 | 适用场景 |
|------|------|------|---------|
| 快递 | 3-5天 | 高 | 急补货、小批量 |
| 空运 | 7-10天 | 中高 | 常规补货 |
| 快船 | 15-20天 | 中 | 大批量备货 |
| 海运 | 25-40天 | 低 | 新品首发、大批量 |

## 海外仓管理

### 库存监控表
| SKU | 在途 | 可售 | 预留 | 不可售 | 日均销量 | 售罄天数 |
|-----|------|------|------|--------|---------|---------|
| A001 | 200 | 500 | 50 | 10 | 30 | 17 |
| A002 | 0 | 100 | 0 | 5 | 20 | 5 |

### 库存周转
```
周转率 = 销售成本 / 平均库存
目标：周转率 > 6（每月）

周转天数 = 365 / 周转率
理想周转天数：30-60天
```

### IPI提升策略
| 策略 | 效果 | 实施难度 |
|------|------|---------|
| 滞销品促销 | 高 | 低 |
| 降低补货频率 | 中 | 低 |
| 优化选品 | 高 | 高 |
| 增量销售 | 中 | 中 |

## 盘点管理

### 盘点流程
```
制定计划 → 执行盘点 → 差异核对 → 账实调整 → 分析改进
```

### 盘点类型
| 类型 | 频率 | 范围 | 方式 |
|------|------|------|------|
| 全盘 | 每季度 | 所有SKU | 逐一清点 |
| 抽盘 | 每月 | 部分SKU | 随机抽查 |
| 循环盘 | 每周 | 滚动盘点 | 每日部分 |
| 盘点 | 每日 | 新入库 | 入库盘点 |

### 差异处理
| 差异类型 | 可能原因 | 处理方式 |
|---------|---------|---------|
| 盘盈 | 漏记入库 | 调整入库记录 |
| 盘亏 | 丢失、损坏 | 申请索赔 |
| 账实不符 | 系统错误 | 核查系统数据 |

## 仓储费用优化

### 亚马逊仓储费
| 费用类型 | 收费时段 | 标准费率 |
|---------|---------|---------|
| 月度仓储费 | 1-9月 | $0.75/立方英尺 |
| 月度仓储费 | 10-12月 | $2.40/立方英尺 |
| 长期仓储费 | 存放6-12月 | $1.50/立方英尺 |
| 长期仓储费 | 存放>12月 | $6.90/立方英尺 |

### 费用优化策略
```
1. 定期清理滞销库存
2. 避免季节性积压
3. 合理备货（2-3个月销量）
4. 促销清理冗余库存
5. 使用亚马逊清货计划
```

## 使用示例

### 示例1：创建FBA发货计划
```
用户：帮我创建一批FBA发货
助手：
1. 选择SKU和数量：
   - SKU001：200个
   - SKU002：150个

2. 计算箱规：
   - SKU001：20x15x10cm，0.5kg
   - 每箱装20个，箱重10kg

3. 选择仓库：IND2（中西部）

4. 计算物流成本：
   - 空运：$2/kg x 200kg = $400
   - 快船：$0.8/kg x 200kg = $160

5. 选择快船（省$240）

6. 生成发货计划文档
```

### 示例2：库存盘点
```
用户：这个月要做库存盘点
助手：
1. 制定盘点计划：
   - 盘点日期：1月20日
   - 盘点范围：全部SKU
   - 参与人员：张三、李四

2. 执行盘点：
   - 导出库存数据
   - 实地清点
   - 记录差异

3. 盘点报告：
   - 总SKU数：50
   - 盘点完成：50
   - 差异SKU：2
   - 差异率：4%
```

## 最佳实践

1. **标签准确** - FBA标签清晰粘贴
2. **箱规合规** - 避免额外费用
3. **及时跟踪** - 发货后持续跟踪
4. **定期盘点** - 每月抽盘、每季全盘
5. **费用监控** - 关注IPI和仓储费
6. **滞销处理** - 及时清理冗余库存
