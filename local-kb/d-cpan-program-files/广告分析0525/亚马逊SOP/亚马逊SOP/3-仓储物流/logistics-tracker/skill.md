# Logistics Tracker Skill

## 用途

头程物流和最后一公里全程追踪管理。

## 物流方式对比

| 方式 | 时效 | 成本/kg | 优点 | 缺点 |
|------|------|--------|------|------|
| 快递DHL/UPS | 3-5天 | $5-7 | 时效快 | 成本高 |
| 空运 | 7-12天 | $3-5 | 时效较快 | 旺季舱位紧张 |
| 快船 | 15-20天 | $0.8-1.2 | 性价比高 | 周期长 |
| 海运 | 25-40天 | $0.3-0.5 | 成本最低 | 时效慢 |

## 发货流程

```
备货 → 报关 → 运输 → 清关 → 派送 → 入库
```

## 物流跟踪节点

### 关键节点
```
1. 发货揽收
2. 出口报关
3. 航班/船期
4. 目的港清关
5. 亚马逊仓库接收
6. 上架
```

| 报关 | Day1 | Day1-2 | Day2-3 | Day3-5 |

## 海关清关

### 报关资料
```
1. 商业发票（Invoice）
2. 装箱单（Packing List）
3. 提单（Bill of Lading）
4. 产品申报价值
5. HS编码
6. 产品描述
```

### 关税计算
```
关税 = 申报价值 × 税率
美国关税 = 产品价值 × 税率（一般3-10%）
欧洲 VAT = 产品价值 × 20%（部分20-27%）
```

### 清关异常处理
| 问题 | 原因 | 处理方式 |
|------|------|---------|
| 查验 | 随机/申报异常 | 配合查验/补充资料 |
| 扣货 | 侵权/违禁 | 提供授权/放弃货物 |
| 关税争议 | 申报价值争议 | 申诉/补缴 |

## 物流异常处理

### 延误处理
| 延误原因 | 处理方式 |
|---------|---------|
| 旺季拥堵 | 提前发货/选快速渠道 |
| 海关查验 | 配合提供资料 |
| 天气原因 | 等待/改派 |
| 物流商延误 | 索赔/更换物流商 |

### 丢失/破损索赔
```
索赔流程：
1. 发现异常立即反馈物流商
2. 保留货物和外包装照片
3. 提交索赔申请
4. 跟进处理进度
5. 收到赔偿

索赔时限：到货后30天内
```

## 物流成本分析

### 成本构成
```
单位成本 = (产品成本 + 物流成本 + 关税) / 数量

物流成本占比 = 物流成本 / 销售额
行业标准：<15%
```

### 成本优化策略
```
1. 整柜出货（降低单件成本）
2. 轻重搭配（抛货+重货）
3. 淡季备货（运费低15-30%）
4. 多家比价
5. 长期合作折扣
```

## 使用示例

### 示例1：监控物流状态
```
用户：这批货到哪里了
助手：
1. 查询物流单号
2. 更新轨迹信息：
   - 1月10日：深圳揽收
   - 1月12日：出口报关
   - 1月15日：到达洛杉矶港
   - 1月18日：清关完成
   - 预计1月20日到达仓库
```

### 示例2：物流成本分析
```
用户：帮我分析这几个月的物流成本
助手：
1. 整理物流数据：
   - 1月：$5,000，时效8天
   - 2月：$6,200，时效10天
   - 3月：$4,800，时效9天

2. 成本分析：
   - 总物流成本：$16,000
   - 平均单价：$4.2/kg
   - 平均时效：9天

3. 优化建议：
   - 2月成本高（春节后涨价）
   - 3月恢复低价
   - 建议提前备货避开旺季
```

## 最佳实践

1. **提前预报** - 提前2-3天预报货物信息
2. **资料完整** - 报关资料准确完整
3. **轨迹跟踪** - 每日更新物流状态
4. **异常及时处理** - 24小时内响应异常
5. **保留凭证** - 所有运单和交接单保留
6. **定期评估** - 每月物流商评估
