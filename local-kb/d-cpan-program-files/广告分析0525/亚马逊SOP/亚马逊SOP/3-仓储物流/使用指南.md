## fulfillment-manager (FBA发货管理)

### 使用场景
- 创建FBA shipment
- 设置箱规和标签
- 选择目的仓库
- 库存盘点
- IPI优化

### 使用示例
```
用户：帮我创建FBA发货计划

助手会：
1. 选择SKU和数量
2. 计算箱规
3. 选择最优仓库
4. 生成箱贴和外箱标签
5. 计算物流成本
6. 跟踪入库状态
```

### FBA发货操作流程（详细）

```
步骤1：设置商品尺寸
   卖家后台 → 库存 → 管理FBA库存
   → 编辑 → 填写尺寸信息

步骤2：创建 shipment
   发送库存至亚马逊 → 创建新发货计划
   → 选择商品和数量

步骤3：设置包装
   选择包装类型：
   - 单件商品
   - 原厂包装（Prefilled）
   - 混合处理（不推荐）

步骤4：填写发货地址
   发货仓库/货代仓库地址
   → 亚马逊揽收或自配送

步骤5：分配仓库
   亚马逊自动分配
   或 手动选择

步骤6：打印标签
   产品标签（FNSKU）
   外箱标签（Shipment ID）

步骤7：发货
   联系货代
   提供物流单号
   确认签收
```

### FBA费用计算

**费用构成：**
```
总费用 = 配送费 + 仓储费 + 其他费用

配送费 = 按尺寸分段 + 按重量计算
仓储费 = 立方英尺 × 月费率
其他费用 = 移除费/退货处理费等
```

**美国站FBA费用参考：**

| 尺寸段 | 配送费 | 1-9月仓储 | 10-12月仓储 |
|--------|--------|----------|-------------|
| 小号标准 | $2.45 | $0.75/立方英尺 | $2.25/立方英尺 |
| 大号标准 | $3.19-5.19 | 同上 | 同上 |
| 小号大件 | $9.79+ | 同上 | 同上 |

### IPI分数优化

**提升方法：**
1. 清理滞销库存
2. 提高售出率
3. 减少冗余库存
4. 及时补货（避免断货）

**IPI目标：**
- 维持400分以上
- 避免仓储限制

## logistics-tracker (物流追踪)

### 使用场景
- 头程物流跟踪
- 海关清关进度
- 最后一公里
- 异常处理
- 成本分析

### 使用示例
```
用户：这批货到哪里了

助手会：
1. 查询物流单号
2. 更新轨迹信息
3. 分析时效是否正常
4. 预警潜在延误
5. 计算剩余时间
```

### 物流方式对比（详细）
| 方式 | 时效 | 成本/kg | 优点 | 缺点 | 适用场景 |
|------|------|---------|------|------|---------|
| 快递DHL/UPS | 3-5天 | $5-7 | 快、门到门 | 成本高 | 急补货、小批量 |
| 空运 | 7-12天 | $3-5 | 较快 | 成本较高 | 常规补货 |
| 快船（南航EMC） | 15-20天 | $0.8-1.2 | 性价比高 | 略慢 | 大批量备货 |
| 海运 | 25-40天 | $0.3-0.5 | 成本最低 | 周期长 | 新品首发、大批量 |

### 头程物流选择策略

**根据紧急程度：**
- 断货急救：快递 > 空运 > 快船
- 常规备货：快船 > 海运
- 新品首发：海运（大）+ 快递（小）

**根据产品特性：**
- 高价值产品：快递/空运
- 低价值产品：快船/海运
- 大件产品：海运为主
- 季节性产品：空运/快递

### 清关异常处理

| 问题 | 原因 | 症状 | 处理方式 |
|------|------|------|---------|
| 查验 | 随机/申报异常 | 清关延迟 | 配合查验/补充资料 |
| 扣货 | 侵权/违禁 | 货物扣留 | 提供授权/放弃货物 |
| 关税争议 | 申报价值争议 | 账单争议 | 申诉/补缴 |
| 标签不符 | FBA标签问题 | 拒收 | 重贴标签 |
| 箱规超标 | 超重/超大 | 拒收 | 重新打包 |

### 物流成本计算

```
单位成本 = 物流总价 / 产品数量

头程成本 = 物流费 / 产品数量 + 单件分摊包装费

总物流成本 = 头程成本 + FBA配送费 + 仓储费月均
```

## FBA常见问题

Q: 如何选择物流方式？
A: 根据紧急程度和预算选择：
- 急用→快递
- 常规→空运/快船
- 大批量→海运

Q: 入库被拒怎么办？
A: 检查：
1. 标签是否正确/清晰
2. 箱规是否合规
3. 数量是否准确
4. 包装是否完好

Q: 物流延误如何处理？
A:
1. 联系货代催问进度
2. 评估对销售的影响
3. 考虑更换物流方式
4. 调整销售计划（预售/限购）

Q: 如何降低FBA成本？
A:
1. 优化包装（减少体积）
2. 合理分仓（降低头程）
3. 备货周期优化（减少仓储）
4. 选用合适物流方式

Q: IPI分数低怎么办？
A:
1. 创建移除订单清理滞销
2. 参加促销活动提高售出
3. 降低备货量
4. 避免过度备货
