# Complaint Handler Skill

## 用途

复杂投诉处理和危机公关管理。

## 投诉分级

| 级别 | 类型 | 处理时效 | 升级对象 |
|------|------|---------|---------|
| P0紧急 | 人身安全、法律诉讼、媒体曝光 | 1小时 | 公司高管、法务 |
| P1高 | 重大财产损失、批量问题、媒体关注 | 4小时 | 部门经理 |
| P2中 | 重复投诉、VIP客户、批量相似问题 | 24小时 | 高级客服 |
| P3低 | 普通投诉升级 | 48小时 | 资深客服 |

## 处理流程

```
接收 → 评估 → 调查 → 方案 → 执行 → 跟进 → 闭环 → 改进
```

## 投诉处理策略

### 情绪安抚
```
1. 真诚道歉
2. 表示理解
3. 承诺解决
4. 给出时间预期
```

### 问题调查
```
收集信息：
- 订单记录
- 物流轨迹
- 产品批次
- 客户历史

调查重点：
- 是否我方责任
- 问题严重程度
- 客户真实诉求
```

### 解决方案
| 问题类型 | 建议方案 |
|---------|---------|
| 质量问题 | 全额退款+补发+优惠券 |
| 物流损坏 | 补发+赔偿运费 |
| 描述不符 | 退货+退款+改进Listing |
| 态度问题 | 道歉+更换对接人 |

## 赔偿决策

### 赔偿标准
| 损失程度 | 赔偿方式 | 审批权限 |
|---------|---------|---------|
| 小额损失(<$50) | 全额退款/补发 | 客服 |
| 中额损失($50-200) | 退款+补偿券 | 客服主管 |
| 大额损失($200-500) | 退款+补偿+升级服务 | 部门经理 |
| 重大损失(>$500) | 专项方案 | 高管审批 |

### 赔偿话术
```
After reviewing your case, we would like to offer:

- Full refund of $[金额]
- [补偿方式，如：$XX coupon for your next purchase]
- [额外服务，如：free expedited shipping]

We truly value your business and hope this resolves the issue.
```

## 危机公关

### 社交媒体监控
```
监控渠道：
- Twitter/推特
- Facebook
- Instagram
- Reddit
- 差评网站（ReviewSite等）

关键词：
- 品牌名
- 产品名
- 负面关键词组合
```

### 危机应对策略
| 危机类型 | 应对策略 |
|---------|---------|
| 单次负面帖 | 主动联系解决，礼貌回复 |
| 批量差评 | 内部调查，产品改进 |
| 媒体关注 | 统一口径，谨慎回复 |
| KOL差评 | 私下沟通，争取和解 |

### 应对模板
```
公开回复模板：

Thank you for bringing this to our attention. We take customer feedback
very seriously and are investigating this matter immediately.

We have reached out to [客户/博主] directly to resolve this issue.
[简要说明解决方向]

We are committed to providing quality products and service.
Please contact us at [邮箱] for any concerns.
```

## 法务相关

### 常见法务问题
| 问题类型 | 处理方式 |
|---------|---------|
| 商标侵权投诉 | 核实情况，准备证据 |
| 专利侵权 | 下架产品，法务介入 |
| 合同纠纷 | 法务审核，协商解决 |
| 虚假宣传指控 | 准备证据，修改Listing |

### 侵权申诉流程
```
1. 收到通知立即下架
2. 核实是否真的侵权
3. 如未侵权，准备申诉材料
   - 采购发票
   - 授权文件
   - 不侵权声明
4. 提交申诉
```

## 升级机制

### 升级触发条件
```
必须升级：
- 客户要求与经理沟通
- 涉及法律诉讼
- 涉及媒体曝光
- 涉及人身安全
- 损失>$500

建议升级：
- 重复投诉3次以上
- VIP客户投诉
- 涉及竞品对比
```

### 升级沟通
```
升级前准备：
- 问题摘要
- 已尝试的解决方案
- 客户诉求
- 建议方案

升级沟通：
- 清晰描述问题
- 客户情绪状态
- 建议的处理方向
```

## 问题闭环与改进

### 问题记录
| 日期 | 客户 | 问题 | 处理 | 结果 | 改进 |
|------|------|------|------|------|------|
| 01-15 | 张三 | 产品破损 | 补发+退款 | 满意 | 改进包装 |

```
问题类型统计：
- 产品质量：40%
- 物流损坏：30%
- 描述不符：20%
- 服务问题：10%

改进措施：
1. 加强供应商质检
2. 改进包装方案
3. 更新产品描述
```

## 使用示例

### 示例1：处理高额索赔
```
用户：客户说收到5个产品全部损坏，要求赔偿$500
助手：
1. 评估：P1级，金额大，可能涉及批量问题
2. 升级：上报部门经理
3. 调查：
   - 检查发货记录
   - 查看物流包装
   - 联系客户要照片
4. 发现：运输中挤压损坏
5. 解决：
   - 全额退款$150
   - 补发新品
   - 改进包装方案
6. 跟进：确认客户收到补发产品
```

### 示例2：处理社交媒体差评
```
用户：有博主在Twitter发差评帖，有200转发
助手：
1. 监控：发现帖文，评估影响
2. 评估：P1级，有传播风险
3. 行动：
   - 立即私信博主
   - 了解具体问题
   - 提出解决方案
   - 准备公开回复
4. 跟进：
   - 解决客户问题
   - 引导博主修改评价
   - 监控传播情况
```

## 最佳实践

1. **快速响应** - 投诉处理宜快不宜慢
2. **同理心** - 站在客户角度思考
3. **证据留存** - 所有沟通和处理留档
4. **合理赔偿** - 平衡客户满意度和成本
5. **及时升级** - 超出权限立即上报
6. **根因改进** - 问题闭环后分析改进
7. **定期复盘** - 每月投诉分析
