# Supplier Manager Skill

## 用途

供应商全生命周期管理，从开发、比价到绩效考核。

## 供应商开发流程

```
需求定义 → 市场搜索 → 初步筛选 → 资质审核 → 样品测试 → 建立合作
```

## 供应商评估标准

### 评估维度
| 维度 | 权重 | 评分标准 |
|------|------|---------|
| 产品质量 | 30% | 质检合格率>98%得满分 |
| 价格竞争力 | 25% | 对比市场平均价格 |
| 交期准时率 | 20% | 按时交付比例 |
| 配合度 | 15% | 响应速度、灵活性 |
| 工厂规模 | 10% | 产能是否匹配 |

### 供应商分级
| 等级 | 评分 | 策略 |
|------|------|------|
| A级 | 90-100 | 核心供应商，优先合作 |
| B级 | 70-89 | 常规供应商 |
| C级 | 50-69 | 备选供应商 |
| D级 | <50 | 淘汰或改进 |

| 工厂A | $8.5 | 15天 | 500 | 无 | 85 |

| 贸易商C | $9.0 | 10天 | 100 | 无 | 72 |

### 谈判策略
```
1. 大单诱惑（量换价）
2. 长期合作承诺
3. 账期谈判（30-60天）
4. 阶梯降价（1000件→$8.5, 5000件→$8.0）
5. 捆绑采购（多产品打包）
```

## 样品确认流程

### 阶段
```
1. 索取样品（付费或免费）
2. 外观检查
3. 尺寸测量
4. 功能测试
5. 包装检查
6. 耐磨/耐久测试（如需要）
7. 确认样品（签发确认函）
```

### 样品评估表
| 检查项 | 标准 | 结果 | 备注 |
|-------|------|------|------|
| 外观 | 无划痕、污点 | ✓ | 通过 |
| 尺寸 | ±2mm公差 | ✓ | 通过 |
| 功能 | 正常运作 | ✓ | 通过 |
| 包装 | 完好无损 | ✗ | 需改进 |

## 质量管控

### 来料检验（IQC）
- 抽检比例（一般5-10%）
- 检验项目清单
- 不合格品处理

### 常见问题
| 问题类型 | 比例 | 处理方式 |
|---------|------|---------|
| 外观缺陷 | 35% | 挑选或退货 |
| 尺寸不符 | 25% | 返工 |
| 功能异常 | 20% | 退货 |
| 包装问题 | 15% | 换包装 |
| 其他 | 5% | 协商 |

## 绩效考核

### 月度考核表
| 供应商 | 交期率 | 合格率 | 响应速度 | 价格竞争力 | 综合 |
|-------|-------|-------|---------|-----------|------|
| 工厂A | 95% | 98% | 4h | 90% | 92 |
| 工厂B | 85% | 96% | 6h | 85% | 86 |

### 考核指标
- 交期准时率 = 准时到货数 / 总订单数
- 合格率 = 合格品数 / 总到货数
- 问题响应时间 = 收到问题到回复的平均时间

## 使用示例

### 示例1：新供应商开发
```
用户：帮我找3家以上的厨房用品供应商
助手：
1. 在1688搜索"厨房用品制造商"
2. 筛选条件：诚信通>3年、工厂、回头率>20%
3. 获取10家供应商信息
4. 初步筛选3-5家
5. 发送询价函
6. 对比报价和交期
7. 建议实地考察（如近）
```

### 示例2：供应商比价
```
用户：帮我比较这5家供应商的报价
助手：
1. 整理报价对比表
2. 分析价格差异原因
   - 工厂A：$8.5（工厂直销，质量稳定）
   - 工厂B：$8.2（新工厂，账期30天）
   - 贸易商C：$9.0（价格高但服务好）
3. 建议：
   - 首选工厂A（性价比高）
   - 备选工厂B（成本更低）
   - 放弃贸易商C
```

## 最佳实践

1. **供应商多元化** - 每个品类至少2家供应商
2. **小单测试** - 新供应商首批不超过1000件
3. **账期谈判** - 争取30天以上账期
4. **定期评估** - 每月/季度绩效考核
5. **及时付款** - 建立良好信用
6. **保留记录** - 所有沟通留档
