## account-health-monitor (账号健康)

### 使用场景
- 绩效监控
- 违规预警
- 申诉处理
- 账号安全

### 绩效指标目标
| 指标 | 全称 | 目标 | 超标后果 |
|------|------|------|---------|
| ODR | Order Defect Rate | <1% | 账号冻结 |
| CR | Cancellation Rate | <2.5% | 警告 |
| LSR | Late Shipment Rate | <4% | 警告 |
| VTR | Valid Tracking Rate | >95% | 影响流量 |

### ODR组成
```
ODR = (差评数 + A-Z claim数 + 信用卡拒付数) / 总订单数
```

### 违规类型
| 违规类型 | 严重程度 | 后果 |
|---------|---------|------|
| 操纵评论 | 严重 | 永久封号 |
| 销售假货 | 严重 | 永久封号 |
| 商标侵权 | 中 | Listing下架 |
| 专利侵权 | 严重 | 永久封号 |
| 操纵排名 | 中 | 降权/封号 |

## compliance-checker (合规检查)

### 使用场景
- Listing合规检查
- 产品合规检查
- 广告合规检查
- 税务合规
- 政策更新监控

### Listing合规检查
| 检查项 | 标准 |
|-------|------|
| 标题长度 | <200字符 |
| 主图 | 纯白背景，正方形 |
| 主图无文字/水印 | 不含文字、水印 |
| 五点描述 | 5条，<500字符/条 |
| 产品描述 | <2000字符 |

### 违禁词检测
```
禁止使用：
1. 最高级词汇：Best, #1, Number 1
2. 承诺/保证：Guarantee, Promise
3. 免费相关：Free
4. 刺激购买：Buy now
5. 绝对词汇：Absolutely
6. 价格相关：Cheap
```

### 产品认证要求
| 产品类型 | 认证 | 站点 |
|---------|------|------|
| 电子产品 | FCC | 美国 |
| 电子产品 | CE | 欧洲 |
| 儿童产品 | CPC | 美国 |
| 儿童产品 | EN71 | 欧洲 |
| 食品 | FDA | 美国 |
| 化妆品 | FDA | 美国 |

### 税务合规
| 站点 | 要求 | 税率范围 |
|------|------|---------|
| 美国站 | 各州销售税注册 | 4-10% |
| 欧洲站 | VAT税号 | 17-27% |

## 常见问题

Q: ODR突然升高怎么办？
A: 分析原因（差评/A-Z/拒付），联系客户解决问题，改善产品/服务。

Q: 收到侵权通知如何处理？
A: 确认是否真的侵权，如未侵权准备证据申诉；如确实侵权立即下架。

Q: 如何预防账号风险？
A: 每日检查绩效指标，及时处理违规预警，保留所有运营记录。
