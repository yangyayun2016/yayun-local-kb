# Compliance Checker Skill

## 用途

全面合规检查，确保运营符合亚马逊政策。

## 合规检查清单

### Listing合规
| 检查项 | 标准 | 检查方法 |
|-------|------|---------|
| 标题长度 | <200字符 | 手动检查 |
| 主图 | 纯白背景，正方形 | 视觉检查 |
| 主图无文字/水印 | 不含文字、水印 | 视觉检查 |
| 五点描述 | 5条，<500字符/条 | 手动检查 |
| 产品描述 | <2000字符 | 手动检查 |
| 无违禁词 | 禁用词汇表 | 违禁词检测 |

### 违禁词检测
```
禁止使用：
1. 最高级词汇
   - Best, #1, Number 1
   - Top 1, Leading

2. 承诺/保证
   - Guarantee, Promise
   - Risk-free, Money-back

3. 免费相关
   - Free, For free

4. 刺激购买
   - Buy now, Click to buy

5. 绝对词汇
   - Absolutely, Definitely

6. 价格相关
   - Cheap, Inexpensive

处罚：Listing被删除或账号警告
```

## 产品合规

### 认证要求
| 产品类型 | 认证 | 站点 | 说明 |
|---------|------|------|------|
| 电子产品 | FCC | 美国 | 无线电频率产品 |
| 电子产品 | CE | 欧洲 | 欧盟安全认证 |
| 儿童产品 | CPC | 美国 | 儿童产品安全 |
| 儿童产品 | EN71 | 欧洲 | 玩具安全 |
| 食品 | FDA | 美国 | 食品接触材料 |
| 化妆品 | FDA | 美国 | 成分安全 |
| 户外用品 | REACH | 欧洲 | 化学物质限制 |

### 禁止销售产品
```
绝对禁止：
- 假冒产品
- 侵权产品
- 违禁品（武器、毒品等）
- 二手翻新当新品
- 与描述严重不符的产品

限制销售：
- 成人用品（需分类批准）
- 珠宝（需额外资质）
- 健康/个人护理（有限制）
```

## 广告合规

### 广告政策
```
禁止内容：
- 虚假陈述
- 误导性图片
- 不当比较（竞品）
- 攻击性内容
- 敏感内容

违规处罚：
- 广告被拒
- 广告账号受限
- 严重者账号封禁
```

### 关键词政策
```
允许：
- 产品相关关键词
- 通用属性词
- 用途描述词

不允许：
- 竞争对手品牌词
- 误导性关键词
- 色情暴力词汇
- 侵权商标词
```

## 税务合规

### 美国站税务
| 州 | 注册要求 | 税率范围 |
|---|---------|---------|
| 无销售税州 | 无需注册 | 0% |
| 经济关联州 | 有库存或销售额超阈值 | 4-10% |

### 欧洲站VAT
```
要求：
- 注册VAT税号
- 按时申报
- 代收VAT

税率：
- 英国：20%
- 德国：19%
- 法国：20%
- 意大利：22%
```

### 发票要求
```
所有卖家必须：
- 提供发票（或收据）
- 发票信息准确
- 24小时内响应发票请求

违规后果：
- 账号绩效影响
- 销售权限受限
```

## 合规审核流程

### 定期审核
```
频率：每月
审核范围：
- 所有Active Listing
- 广告活动
- 账号绩效

审核清单：
1. Listing信息完整
2. 违禁词检查
3. 图片合规
4. 产品认证有效期
5. 绩效指标正常
```

### 问题整改
| 问题类型 | 严重程度 | 整改时限 |
|---------|---------|---------|
| 违禁词 | 高 | 立即 |
| 侵权 | 高 | 24小时 |
| 图片违规 | 中 | 48小时 |
| 信息不完整 | 低 | 1周 |

## 使用示例

### 示例1：新品上架前检查
```
用户：新品马上上架，帮我做合规检查
助手：
1. Listing检查：
   - 标题：检查长度和违禁词 ✓
   - 主图：纯白背景，无文字 ✓
   - 五点：5条完整 ✓
   - 产品描述：<2000字符 ✓

2. 产品合规：
   - 认证：需要FCC ✓
   - 包装：无侵权Logo ✓

3. 广告合规：
   - 无竞品关键词 ✓
   - 无违禁描述 ✓

4. 结论：全部合规，可以上架
```

### 示例2：政策变化应对
```
用户：听说亚马逊更新了主图要求
助手：
1. 确认政策变化：
   - 主图必须纯白背景
   - 产品占画面85%以上
   - 不允许显示多个颜色变体

2. 评估影响：
   - 当前主图需要更新
   - 涉及30个ASIN

3. 制定计划：
   - 本周重新拍摄主图
   - 更新所有Listing
   - 预计工作量：2天

4. 执行并确认合规
```

4. **文件归档** - 保留所有合规证明
5. **问题快速响应** - 发现问题立即处理
6. **员工培训** - 确保团队了解政策
