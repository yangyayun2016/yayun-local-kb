## purchase-automation (采购自动化)

### 使用场景
- 根据库存自动生成采购单
- 供应商比价
- 下采购订单
- 跟踪订单进度
- 管理付款

### 使用示例
```
用户：库存不足，帮我生成采购单

助手会：
1. 分析当前库存数据
2. 计算售罄天数
3. 根据交期计算建议采购量
4. 生成采购单
5. 发送询价给供应商
```

### 采购单模板
```
采购单号：PO-20240129-001
日期：2024-01-29
供应商：XXX工厂
交货日期：2024-02-15
付款方式：30天账期

| SKU | 品名 | 数量 | 单价 | 金额 |
|-----|------|------|------|------|
| SKU001 | 产品A | 1000 | $8.50 | $8,500 |
| SKU002 | 产品B | 500 | $12.00 | $6,000 |

合计：$14,500
```

## quality-control (质量管理)

### 使用场景
- 来料检验(IQC)
- 生产过程质检(PQC)
- 成品检验(FQC)
- 质量问题分析
- 供应商质量评估

### 使用示例
```
用户：到了500个产品，帮我安排检验

助手会：
1. 确定抽检标准（500件抽20件）
2. 生成检验清单
3. 执行检验
4. 记录结果
5. 生成检验报告
6. 处理不合格品
```

### 检验项目清单
| 检验类型 | 检验项目 | 判定标准 |
|---------|---------|---------|
| 外观 | 颜色一致性 | 无明显色差 |
| 外观 | 表面缺陷 | 无划痕、污点 |
| 尺寸 | 产品尺寸 | ±2mm公差 |
| 功能 | 功能测试 | 正常工作 |
| 包装 | 包装完好 | 无破损 |

### 常见问题处理
| 问题类型 | 处理方式 |
|---------|---------|
| 外观缺陷 | 挑选或退货 |
| 尺寸不符 | 返工 |
| 功能异常 | 退货 |
| 包装问题 | 换包装 |

---

## 常见问题

Q: 采购单生成后如何下单？
A: 助手会生成完整的采购单文档，包含供应商联系方式和下单模板。

Q: 质量问题如何索赔？
A: 助手会根据检验报告计算索赔金额，生成索赔函模板。
