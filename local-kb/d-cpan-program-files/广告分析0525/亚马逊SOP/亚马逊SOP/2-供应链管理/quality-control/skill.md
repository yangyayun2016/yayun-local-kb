# Quality Control Skill

## 用途

全流程质量管理，从原料到成品的质量把控。

## 质量检验流程

```
IQC（来料）→ PQC（过程）→ FQC（成品）→ OQC（出货）
```

## 来料检验（IQC）

### 抽检标准
| 批次数量 | 抽检数量 | 抽检比例 |
|---------|---------|---------|
| 1-100 | 5 | 5-10% |
| 101-500 | 20 | 4% |
| 501-2000 | 50 | 2.5% |
| 2000+ | 80 | 0.4% |

### 检验项目清单
| 检验类型 | 检验项目 | 判定标准 |
|---------|---------|---------|
| 外观 | 颜色一致性 | 无明显色差 |
| 外观 | 表面缺陷 | 无划痕、污点 |
| 尺寸 | 产品尺寸 | ±2mm公差 |
| 功能 | 功能测试 | 正常工作 |
| 包装 | 包装完好 | 无破损 |

### 来料检验报告
```
检验单号：IQC-20240115-001
供应商：XXX工厂
到货日期：2024-01-15
到货数量：1000件
抽检数量：50件

检验结果：
- 合格：47件
- 不合格：3件（6%）
  ├─ 外观缺陷：2件
  └─ 尺寸超差：1件

判定：合格接收
检验员：张三
```

## 过程检验（PQC）

### 生产巡检要点
```
检查频率：每2小时一次
检查内容：
1. 设备运行状态
2. 工艺参数
3. 半成品质量
4. 操作规范
```

### 常见问题记录
| 时间 | 生产线 | 问题描述 | 处理措施 |
|------|-------|---------|---------|
| 10:00 | Line1 | 温度偏高 | 调整参数 |
| 14:00 | Line2 | 原料受潮 | 更换原料 |

## 成品检验（FQC）

### 检验项目
| 项目 | 方法 | 标准 |
|------|------|------|
| 外观 | 目视检查 | 无明显缺陷 |
| 功能 | 功能测试 | 100%通过 |
| 尺寸 | 抽样测量 | 符合规格 |
| 包装 | 目视检查 | 完好规范 |
| 标签 | 检查贴标 | 正确清晰 |

### 检验报告
```
检验单号：FQC-20240115-001
产品：产品A
批次：Batch001
数量：1000件
抽检：80件

检验结果：
- 外观合格：78件
- 功能合格：80件
- 包装合格：79件
- 综合合格：77件（96.25%）

判定：合格
```

## 问题处理

### 不合格品处理流程
```
1. 不合格品标识和隔离
2. 不合格品记录
3. 评审（判定处置方式）
4. 处置（退货/返工/降级/报废）
5. 验证处置效果
6. 原因分析和改进
```

### 质量问题分类
| 问题类型 | 占比 | 责任部门 | 处理方式 |
|---------|------|---------|---------|
| 原料问题 | 40% | 供应商 | 索赔/退货 |
| 工艺问题 | 35% | 生产 | 调整参数 |
| 设备问题 | 15% | 设备 | 维修保养 |
| 其他 | 10% | - | 分析处理 |

### 供应商质量索赔
```
索赔金额 = 不合格品数量 × 单价 × 系数

系数说明：
- 一般问题：0.5-0.8
- 严重问题：1.0-1.5
- 重复问题：加罚20%
```

## 使用示例

### 示例1：新批次来料检验
```
用户：到了500个产品，帮我安排检验
助手：
1. 确定抽检标准：500件抽20件
2. 生成检验清单
3. 执行检验：
   - 外观检查
   - 尺寸测量
   - 功能测试
4. 记录结果：
   - 合格：18件
   - 不合格：2件
5. 判定：合格接收
6. 生成检验报告
7. 不合格品处理建议
```

### 示例2：质量问题分析
```
用户：这个月质量投诉多了，怎么分析
助手：
1. 收集投诉数据
2. 问题分类统计
3. 帕累托分析：
   - 外观问题：45%（主要问题）
   - 尺寸问题：25%
   - 功能问题：15%
4. 原因分析：
   - 外观问题：包装运输导致
5. 改进建议：
   - 加强包装保护
   - 与物流沟通轻放
   - 工厂加外箱保护
```

## 最佳实践

1. **标准明确** - 检验标准可量化
2. **记录完整** - 所有检验有记录
3. **及时反馈** - 问题24小时内反馈
4. **持续改进** - 月度质量分析
5. **供应商管理** - 质量问题纳入考核
6. **培训到位**   - 检验员培训上岗
