# Purchase Automation Skill

## 用途

自动化采购管理，从需求确认到付款结算全流程。

## 采购流程

```
需求 → 询价 → 比价 → 下单 → 跟踪 → 验收 → 付款
```

## 采购需求来源

| 来源 | 触发条件 | 优先级 |
|------|---------|-------|
| 库存预警 | 库存<安全线 | 高 |
| 销售预测 | 预计销量>库存 | 高 |
| 促销备货 | 活动前备货 | 中 |
| 新品首批 | 新品上架 | 高 |

## 使用示例

### 示例1：根据库存自动生成采购单
```
用户：库存不足，帮我生成采购单
助手：
1. 分析库存数据：
   SKU001：当前50件，日均20件，售罄2.5天
   SKU002：当前30件，日均15件，售罄2天
   SKU003：当前200件，日均10件，安全

2. 计算采购量：
   采购量 = (交期+安全天数) × 日均销量 - 当前库存 - 在途

   SKU001：15+7=22天 × 20 = 440 - 50 = 390件
   SKU002：15+7=22天 × 15 = 330 - 30 = 300件

3. 生成采购单
4. 发送供应商询价
5. 根据回复确认订单
```

### 示例2：供应商付款提醒
```
用户：这个月要付哪些供应商
助手：
1. 筛选即将到期的应付账款
2. 生成付款计划表
3. 提醒财务安排付款
```
