## 用途

追踪亚马逊关键词排名、分析搜索趋势、挖掘优质关键词、监控竞品策略。

## 核心功能

### 1. 关键词排名追踪
| 指标 | 说明 |
|------|------|
| 自然排名 | 搜索结果的自然位置 |
| 广告排名 | SP广告展示位置 |
| 排名变化 | 与上次对比的变化 |
| 首页最低销量 | 首页商品最低销量 |

### 2. 搜索量分析
| 指标 | 说明 |
|------|------|
| 月搜索量 | 每月搜索次数 |
| 日均搜索量 | 估算的每日搜索 |
| 趋势变化 | 按周/月变化趋势 |
| 相关关键词 | 下游相关搜索词 |

### 3. 竞争度评估
| 指标 | 说明 |
|------|------|
| 竞品数量 | 首页商品数量 |
| 广告竞价 | 建议竞价范围 |
| 首页门槛 | 首页最低销量要求 |
| 相关性评分 | 与产品的相关程度 |

## 关键词分类

### 按搜索意图
| 类型 | 特征 | 策略 |
|------|------|------|
| 信息类 | How、What、Guide | 适合内容营销 |
| 导航类 | Brand、Model | 品牌词 |
| 交易类 | Buy、Best、For | 高转化词 |
| 竞争类 | 竞品词 | 对标竞品 |

### 按热度
| 类型 | 月搜索量 | 竞争度 |
|------|---------|-------|
| 热词 | >100,000 | 高 |
| 中等词 | 10,000-100,000 | 中 |
| 长尾词 | <10,000 | 低 |

## 使用示例

### 示例1：追踪核心关键词排名
```
用户：追踪关键词 "stainless steel water bottle" 的排名
助手：
1. 查询当前排名：
   - 自然排名：第5位
   - 广告排名：第3位

2. 搜索量分析：
   - 月搜索量：85,000
   - 趋势：上升 ↑15%

3. 竞争度分析：
   - 首页最低销量：150单/天
   - 平均竞价：$1.2-$2.5

4. 建议：
   - 排名中等，继续优化
   - 加大广告投入提升曝光
```

### 示例2：挖掘长尾关键词
```
用户：帮我找一些长尾关键词
助手：
1. 种子词：yoga mat
2. 挖掘结果：
   - yoga mat extra long (月搜索12,000)
   - yoga mat non slip (月搜索8,500)
   - yoga mat for hardwood floors (月搜索5,200)
   - thick yoga mat cushion (月搜索3,800)

3. 筛选建议：
   - non slip：竞争适中，优先投放
   - extra long：高搜索，难度大
   - for hardwood：蓝海机会
```

### 示例3：竞品关键词分析
```
用户：分析竞品ASIN B09ABC123的关键词
助手：
1. 抓取竞品Listing关键词：
   - 标题关键词：15个
   - 五点关键词：12个
   - 搜索关键词：8个

2. 排名对比：
   | 关键词        | 本品排名 | 竞品排名 |
   |--------------|---------|---------|
   | yoga mat     | 5       | 3       |
   | non slip     | 12      | 7       |

3. 关键词Gap：
   - 缺少：yoga mat for men
   - 落后：large yoga mat
```

### 示例4：趋势分析
```
用户："gift for men"的趋势如何
助手：
1. 年度趋势：
   - 1-2月：低谷（节后）
   - 5-6月：上升（父亲节前）
   - 9-11月：高峰（节日季）

2. 建议：
   - 提前1个月准备库存
   - 11月是黄金投放期
   - 12月竞争最激烈
```

## 最佳实践

1. **聚焦核心词** - 5-10个核心关键词重点追踪
2. **定期更新** - 每周至少追踪一次
3. **关注变化** - 排名波动及时分析原因
4. **长尾补充** - 核心词+长尾词组合
5. **竞品监控** - 每周分析一次竞品排名
6. **广告配合** - 广告数据验证关键词效果
7. **季节调整** - 根据季节调整关键词策略
