## 三、两套算法的底层逻辑拆解

### 3.1 西柚 — 自然位滚动率

```
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│  西柚找词: ASIN 自然位滚动率                                     │
│                                                                 │
│  输入变量:                                                       │
│  ┌─────────────────────────────────────────────┐                │
│  │ • 关键词下自然位数量 (共多少个自然坑位)        │                │
│  │ • 自然位ASIN数量    (有多少ASIN轮换出现)      │                │
│  │ • 等其他数据                                  │                │
│  └─────────────────────────────────────────────┘                │
│                                                                 │
│  计算逻辑:                                                       │
│                                                                 │
│            自然位出现的ASIN总数                                   │
│  滚动率 ≈ ─────────────────────── (× 修正系数)                   │
│            自然位坑位数量                                         │
│                                                                 │
│  举例:                                                           │
│  ┌──────────────────────────────────────────────┐               │
│  │ 关键词 "wireless earbuds"                     │               │
│  │ 自然位坑位: 20个 (第1页)                       │               │
│  │ 24小时内出现过的ASIN: 60个                     │               │
│  │                                               │               │
│  │ 滚动率 ≈ 60/20 = 3.0                          │               │
│  │ → 每个坑位平均有3个ASIN在轮换                  │               │
│  │ → 滚动率越高 = 竞争越激烈 = 位置越不稳定       │               │
│  └──────────────────────────────────────────────┘               │
│                                                                 │
│  ⚠️ 不涉及:                                                     │
│     ❌ 不关心搜索量大小                                           │
│     ❌ 不关心曝光时长                                             │
│     ❌ 不关心流量分配                                             │
│     只关心 → "坑位的竞争激烈程度"                                 │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 3.2 SIF — 自然流量份额 / 自然位赢得率

```
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│  SIF: 自然流量份额 & 自然位赢得率                                │
│                                                                 │
│  输入变量:                                                       │
│  ┌─────────────────────────────────────────────┐                │
│  │ • 关键词搜索量     (这个词有多少人搜)         │                │
│  │ • 自然位位置       (你排第几)                 │                │
│  │ • 曝光时长         (你在这个位置待了多久)      │                │
│  └─────────────────────────────────────────────┘                │
│                                                                 │
│  ✅ 使用三因子加权:                                              │
│                                                                 │
│  ┌─────────────────────────────────────────────────────┐        │
│  │                                                     │        │
│  │  流量得分 = 搜索量 × 0.4                             │        │
│  │           + 位置得分 × 0.1                           │        │
│  │           + 曝光时长 × 0.5                           │        │
│  │                                                     │        │
│  │  自然位赢得率 = 我的流量得分 / 该词所有ASIN得分之和   │        │
│  │  自然流量份额 = 我所有词的得分 / 品类所有得分之和     │        │
│  │                                                     │        │
│  └─────────────────────────────────────────────────────┘        │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## 五、关键差异用一张图说清楚

```
西柚 自然位滚动率:
─────────────────

  问的是: 坑位层面 → "位置稳不稳？"

  时间线 →  0h    6h    12h    18h    24h
  坑位#1:  [A]   [A]   [B]    [C]    [A]     ← 3个ASIN轮换
  坑位#2:  [D]   [D]   [D]    [D]    [D]     ← 1个ASIN稳定
  坑位#3:  [E]   [F]   [G]    [H]    [I]     ← 5个ASIN轮换

  滚动率 = (3+1+5) / 3坑位 = 3.0
  
  → 只看"有多少ASIN进进出出"
  → 不管每个ASIN分到了多少流量



SIF 自然流量份额:
─────────────────

  问的是: 流量层面 → "谁拿了多少流量？"

  同样的坑位:
  坑位#1:  [A] 出现18h(75%), 位置#1       ← 搜索量×0.4 + 位置×0.1 + 时长×0.5
           [B] 出现3h(12.5%), 位置#1      ← 搜索量×0.4 + 位置×0.1 + 时长×0.5  
           [C] 出现3h(12.5%), 位置#1      ← 搜索量×0.4 + 位置×0.1 + 时长×0.5

  → ASIN-A 虽然和B、C共享坑位
  → 但因为曝光时长75% >> 12.5%
  → SIF会给A分配远更多的流量份额

  ⭐ 西柚看到: 滚动率3.0, 三个ASIN"平等"竞争
  ⭐ SIF看到:  A拿75%流量, B和C各拿12.5%
```

## 六、两个指标的盲区 — 各自缺了什么

```
┌───────────────────────────────────────────────────────────────────────┐
│                                                                       │
│   西柚滚动率的盲区:                                                    │
│   ═══════════════                                                     │
│                                                                       │
│   场景: 两个关键词滚动率都是 2.0                                       │
│                                                                       │
│   关键词A: "wireless earbuds"  搜索量 500,000/月   滚动率 2.0         │
│   关键词B: "blue earbuds xyz"  搜索量     500/月   滚动率 2.0         │
│                                                                       │
│   西柚结论: 两个词竞争强度一样 (滚动率相同)                             │
│   实际情况: 关键词A的自然流量价值 >>>>>> 关键词B                        │
│                                                                       │
│   ❌ 因为不考虑搜索量 → 无法判断流量价值                                │
│   ❌ 因为不考虑曝光时长 → 无法判断谁真正拿到了流量                      │
│                                                                       │
├───────────────────────────────────────────────────────────────────────┤
│                                                                       │
│   SIF加权的盲区:                                                       │
│   ═════════════                                                       │
│                                                                       │
│   场景: 你的赢得率是 5%                                                │
│                                                                       │
│   情况A: 只有2个ASIN在竞争 (你5%, 对手95%)                             │
│   情况B: 有200个ASIN在竞争 (你5%, 分散在199个对手)                     │
│                                                                       │
│   SIF结论: 你都是5% (看起来一样)                                       │
│   实际情况: 情况A → 几乎不可能提升 (对手太强)                           │
│            情况B → 有很大提升空间 (对手分散)                            │
│                                                                       │
│   ❌ 因为不考虑竞争ASIN数量 → 无法判断提升难度                          │
│   ❌ 因为不考虑坑位轮换频率 → 无法判断排名稳定性                        │
│                                                                       │
└───────────────────────────────────────────────────────────────────────┘
```

## 八、实操建议：两者如何配合使用

```
决策流程:

                     ┌─────────────────┐
                     │ 发现一个关键词    │
                     └────────┬────────┘
                              │
                              ▼
                ┌─────────────────────────┐
                │ 第1步: 看 SIF 赢得率     │
                │ "这个词能给我多少流量?"   │
                └────────────┬────────────┘
                             │
                    ┌────────┴────────┐
                    │                 │
                ≥ 3%流量             < 1%流量
              有价值,值得打          流量太少
                    │                 │
                    ▼                 ▼
        ┌───────────────────┐    考虑放弃
        │ 第2步: 看西柚滚动率 │    或低优先级
        │ "这个词能不能打赢?" │
        └─────────┬─────────┘
                  │
         ┌────────┴────────┐
         │                 │
     滚动率 < 2.0      滚动率 > 4.0
     坑位稳定,易守住     坑位混乱,难守住
         │                 │
         ▼                 ▼
    ┌──────────┐     ┌──────────────┐
    │ 优先投入  │     │ 谨慎投入      │
    │ 自然+广告 │     │ 先用广告试水   │
    │ 性价比高  │     │ 确认转化再加码 │
    └──────────┘     └──────────────┘

    ⭐ SIF回答: 值不值得打 (流量价值)
    ⭐ 西柚回答: 打不打得赢 (竞争难度)
    ⭐ 两者结合: 既值得打，又打得赢 → 最优关键词
```
