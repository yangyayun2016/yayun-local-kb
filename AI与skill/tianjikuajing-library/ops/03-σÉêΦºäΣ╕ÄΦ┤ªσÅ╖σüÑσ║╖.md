# 03 合规与账号健康

## 要解决什么问题

让账号能长期稳定地卖货：产品合规、税务合规、账号绩效三条线都不出事。

> 本章是学习提纲，**不构成法律或税务意见**。具体要求请向官方渠道或持牌专业人士确认。

## 准备什么

- 每个 SKU 的合规档案（认证、测试报告、说明书、标签）
- 公司主体与税务登记信息
- 账号健康页面与绩效通知的查看权限

## 一步步怎么做

### Step 1：建 SKU 合规档案

| 项目 | 说明 |
|---|---|
| 产品安全 | 欧盟 GPSR 于 2024-12-13 起适用：欧盟境内责任人、产品标识与可追溯信息、安全信息 |
| 合格标志 | CE（欧盟）、UKCA（英国）等，依品类而定 |
| EPR | 包装、电子电气（WEEE）、电池等的注册与申报，例如德国的包装注册 |
| 品牌与商标 | 商标注册与品牌备案 |
| 税务 | 增值税登记与申报、一站式申报（OSS）等 |

### Step 2：盯账号健康指标

不同站点指标略有差异，一般包括订单缺陷率、迟发率、有效追踪率、政策合规与知识产权投诉。设定预警线，在指标接近阈值前就处理。

### Step 3：申诉写法（POA）

结构：**根本原因 → 已采取的纠正措施 → 预防措施**。语言要具体、可验证，附相关凭证；不要情绪化，不要重复空话。

### Step 4：红线

- 不操纵评论、不刷单、不以奖励换评价
- 不使用未经授权的品牌或图片
- 一个主体下的多账号需要有正当业务理由，并遵守亚马逊政策
- 自动化工具优先使用官方 API，遵守亚马逊的开发者与可接受使用政策

### Step 5：合规日历

把年度申报、证书到期、注册续期、政策更新检查排入日历，每月至少看一次官方政策更新。

## 常见坑

- 以为「别人都在卖」就等于合规。
- 认证证书过期没人提醒。
- 申诉时只道歉，不讲根因和预防措施。

## 完成检查清单

- [ ] 每个 SKU 有合规档案
- [ ] 欧盟责任人与标签已核对
- [ ] 税务与 EPR 登记状态已确认
- [ ] 账号健康预警线已设置
- [ ] 合规日历已建立
