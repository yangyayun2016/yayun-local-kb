# 04 日常巡检 SOP

## 要解决什么问题

把运营动作固定成清单，避免遗漏，也方便交接和 AI 辅助。

## 准备什么

- 数据来源：Seller Central、Vendor Central（如有）、广告后台、第三方工具
- 一张巡检表（电子表格即可）

## 一步步怎么做

### 每日（约 20–30 分钟）

- [ ] 订单与销量是否异常（对比前 7 日）
- [ ] Buy Box 占有率与价格是否被抢
- [ ] 库存是否低于补货点、有无不可售库存
- [ ] 新差评与低星评论，有无需处理的投诉
- [ ] 广告花费是否异常、预算是否提前耗尽
- [ ] 账号健康与政策通知

### 每周

- [ ] 广告周报：搜索词、否词、扩词、调价
- [ ] 核心词排名与自然单占比
- [ ] 库存周数与补货计划
- [ ] Listing 实验结果（主图、标题、价格）
- [ ] 竞品动态：价格、促销、新品

### 每月

- [ ] 利润复盘（含退货、仓储、广告）
- [ ] 类目趋势与季节性
- [ ] 合规日历检查
- [ ] KPI 复盘与下月目标

### KPI 一览

| 指标 | 用途 |
|---|---|
| 销量与销售额 | 规模 |
| ACOS / TACOS | 广告效率 |
| 自然单占比 | 对广告的依赖度 |
| 转化率 / 点击率 | Listing 质量 |
| 退货率 | 产品质量 |
| 库存周数 | 备货健康 |
| 现金周转天数 | 资金效率 |

## 常见坑

- 只在出问题时才看数据。
- 巡检结果没有记录，无法对比。
- 巡检项过多，最终没人做。

## 完成检查清单

- [ ] 日 / 周 / 月清单已落地
- [ ] 有固定负责人和时间点
- [ ] 异常处理有记录
