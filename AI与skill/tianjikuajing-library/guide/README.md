# 学习路径：从选品到 VC，亚马逊跨境实战主线

这是整个学习库的「总目录」。按下面的顺序读，每一篇都有**完成标准**，达标再进下一篇。

每个章节的结构统一：**要解决什么问题 → 准备什么 → 一步步怎么做 → 常见坑 → 完成检查清单 → 延伸阅读**。

> 约定：凡是「非亚马逊官方给出的数值」（如点击阈值、权重、调价幅度），一律标注 `【工程假设】`，使用前请按自己的类目和站点校准。

## 读的时候记住三件事

1. **先算账，再动手。** 利润、广告、现金流三张表没算清楚之前，不要下采购单。
2. **一次只改一个变量。** 广告和 Listing 都一样，否则你永远不知道是什么起了作用。
3. **平台规则会变。** 费用、合规、配送项目的规则经常调整，动手前以亚马逊官方最新页面为准。
