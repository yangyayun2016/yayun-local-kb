# 术语表

| 缩写 | 全称 / 中文 | 一句话 |
|---|---|---|
| SC / VC | Seller Central / Vendor Central | 3P 卖家后台 / 1P 供应商后台 |
| 3P / 1P | Third-party / First-party | 自己卖 / 卖给亚马逊 |
| FBA / FBM | Fulfillment by Amazon / by Merchant | 亚马逊履约 / 自发货 |
| ASIN | Amazon Standard Identification Number | 商品唯一编号 |
| BSR | Best Sellers Rank | 类目销量排名 |
| ABA | Amazon Brand Analytics | 品牌分析，含搜索词报告等，需品牌备案 |
| CVR | Conversion Rate | 转化率（订单 ÷ 点击或访问） |
| CTR | Click-Through Rate | 点击率（点击 ÷ 曝光） |
| CPC | Cost Per Click | 单次点击成本 |
| CPA | Cost Per Acquisition | 单笔订单广告成本 = CPC ÷ CVR |
| ACOS | Advertising Cost of Sales | 广告花费 ÷ 广告销售额 |
| TACOS | Total ACOS | 广告花费 ÷ 总销售额 |
| ROAS | Return on Ad Spend | 广告销售额 ÷ 广告花费，等于 1/ACOS |
| SP / SB / SBV / SD | Sponsored Products / Brands / Brands Video / Display | 四类站内广告 |
| PO | Purchase Order | 亚马逊发给供应商的采购订单（VC） |
| ASN | Advance Shipment Notice | 发货预报（VC） |
| DF / WHS | Direct Fulfillment / Warehouse | VC 的直发模式 / 备货到仓模式 |
| EFN | European Fulfilment Network | 欧洲履约网络，一国库存配送他国订单 |
| GPSR | General Product Safety Regulation | 欧盟通用产品安全法规，2024-12-13 起适用 |
| EPR | Extended Producer Responsibility | 生产者责任延伸（包装、电子电气、电池等） |
| WEEE | Waste Electrical and Electronic Equipment | 废弃电子电气设备指令 |
| CE / UKCA | 欧盟 / 英国合格标志 | 产品上市合规标识 |
| VAT / OSS | 增值税 / 一站式申报 | 欧洲销售税务相关 |
| POA | Plan of Action | 账号申诉的整改计划 |
| TRACE | Trigger / Required data / Assumption / Calculate / Explain | 本库 Skill 编写规范，见 [AI 篇](../ai/03-Skill编写规范TRACE.md) |
