# 你的第一个 30 天

把七篇压成按周的行动清单。每周末对照检查清单复盘一次。

## 第 1 周：打地基（选品篇）

- [ ] 读完[先想清楚](00-先想清楚.md)与[术语表](术语表.md)
- [ ] 写好边界清单与「不碰清单」
- [ ] 建候选池 ≥ 20 个，并开始记录淘汰理由
- [ ] 接入至少一个数据工具

## 第 2 周：筛与算（选品篇 + 广告篇）

- [ ] 完成五关漏斗，留下 3–5 个候选品
- [ ] 每个候选品做利润表与风险表
- [ ] 用[广告经济模型](../ads/02-广告经济模型.md)算出 CPC 上限与日预算
- [ ] 确定小批量验证的止损线

## 第 3 周：搭与跑（运营篇）

- [ ] 做 Listing 草稿与本地化审校
- [ ] 建 SKU 合规档案与合规日历
- [ ] 建日 / 周 / 月巡检表
- [ ] 规划补货点与头程

## 第 4 周：复盘与沉淀（VC 篇 + AI 篇 + 案例）

- [ ] 判断主要 ASIN 走 1P、3P 还是混合
- [ ] 选一个重复任务，写成第一个 TRACE Skill
- [ ] 登记一条资源对接
- [ ] 用[案例模板](../cases/_模板.md)写第一篇复盘

## 复盘三问

1. 这个月哪个数字最让我意外？
2. 哪个假设被推翻了？
3. 下个月只做一件事，是什么？
