# 资源对接

这里分两部分：**① 公开资源导航**（官方入口、数据工具、合规与知识产权）；**② 供需对接**（你能提供什么、需要什么）。

> 说明：下列条目只收录官方入口和知名工具，**未做付费服务商背书**。价格、功能、规则会变，使用前请自行核对；涉及法律、税务、认证的事项，请咨询持牌专业人士。

## ② 供需对接

### 对接规则

1. **先说边界。** 你能提供什么、需要什么、不做什么，写清楚。
2. **不公开个人隐私。** 不要在 Issue 或文件里留手机号、微信号、邮箱等，使用平台私信或 GitHub 主页联系方式。
3. **披露利益关系。** 推荐付费服务或有返佣时必须声明。
4. **不做背书。** 本库不对任何服务商的质量或结果作保证。
5. **验证再合作。** 先小额试单、先看样品和资质，再扩大合作。

### 如何登记

在仓库提交 Issue，选择「资源对接」模板；或按 [对接登记模板](对接登记模板.md) 填写后提交 PR。

### 对接分类

| 分类 | 例子 |
|---|---|
| 供应链 | 工厂、贸易商、验厂、质检 |
| 物流 | 头程货代、仓储、清关 |
| 合规与税务 | 认证、欧盟责任人、VAT、EPR |
| 内容与设计 | 摄影、A+ 设计、视频、本地化审校 |
| 工具与技术 | 数据工具、自动化、接口开发 |
| 学习与社群 | 线下交流、行业会议 |
