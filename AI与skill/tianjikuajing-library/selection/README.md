# 选品篇

选品的目标不是「找到爆款」，而是**用最小成本淘汰掉不该做的品**。本篇用「五关漏斗」把这件事流程化。

| 章节 | 你会知道 |
|---|---|
| [01 选品逻辑与漏斗](01-选品逻辑与漏斗.md) | 怎样划边界、建候选池、逐关淘汰、小批量验证 |
| [02 需求与竞争评估](02-需求与竞争评估.md) | 需求真假、竞争强度、新品窗口怎么量化 |
| [03 利润测算与风险排查](03-利润测算与风险排查.md) | 单品利润表、现金流、知识产权与合规一票否决项 |

## 选品一页纸（打分卡）

| 关卡 | 问题 | 通过标准（`【工程假设】` 请自行校准） |
|---|---|---|
| ① 需求 | 有稳定、可验证的搜索需求吗 | 至少两个数据源交叉验证，且非单季脉冲 |
| ② 竞争 | 新品有切入窗口吗 | 近 12 个月新上架且动销达标的链接占有一定比例 |
| ③ 利润 | 广告前毛利率够不够养广告 | 广告前毛利率明显高于目标 TACOS |
| ④ 合规 | 有一票否决项吗 | 认证、专利、商标、类目审核全部清晰 |
| ⑤ 差异化 | 你能做出买家看得见的不同吗 | 至少一个可写进主图或五点的改进 |

**完成标准：** 手里有 3–5 个通过五关的候选品，每个都附一张[利润测算表](03-利润测算与风险排查.md)和一份淘汰记录。
