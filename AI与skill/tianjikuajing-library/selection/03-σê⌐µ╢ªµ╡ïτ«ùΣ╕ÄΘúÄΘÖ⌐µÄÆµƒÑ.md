# 03 利润测算与风险排查

## 要解决什么问题

在下采购单之前，用一张表回答：每卖一件到底赚多少、钱要压多久、有没有一票否决项。

## 准备什么

- 报价：采购价、起订量、交期
- 头程报价与预计到仓时间
- 目标站点的官方费用页面（佣金、FBA 配送费、仓储费）
- 增值税率与你的税务处理方式

> 费用与规则会调整，下面的数字仅为演示，**请以官方最新费率为准**。

## 一步步怎么做

### Step 1：做单品利润表

演示案例（德国站，含税售价 €29.99，增值税 19%）：

| 项目 | 金额 | 说明 |
|---|---|---|
| 含税售价 | €29.99 | 消费者支付价 |
| 不含税销售额 | €25.20 | 29.99 ÷ 1.19 |
| 平台佣金 | €4.50 | 按 15% 计；欧洲站点佣金口径请以官方说明为准 |
| 采购成本 | €4.50 | 演示数字 |
| 头程 | €1.20 | 演示数字 |
| FBA 配送费 | €5.50 | 演示数字 |
| **广告前毛利** | **€9.50** | 25.20 − 4.50 − 4.50 − 1.20 − 5.50 |
| 广告前毛利率（占含税售价） | 约 31.7% | 9.50 ÷ 29.99 |

**平本 ACOS = 广告前毛利率**（广告花光毛利即平本），上例约为 31.7%。广告销售额是否含税，要与财务口径保持一致，否则 ACOS 和毛利率无法对比。再把退货损耗、仓储费、促销折扣放进去，才是真实利润。

### Step 2：算现金流

现金占用 ≈ 采购款 + 头程 + 税费 + 广告预付，占用时间 ≈ 生产交期 + 头程 + 上架时间 + 销售周期。亚马逊 3P 通常按周期结算回款，具体以账户设置为准。**压货周期越长，对利润率的要求越高。**

### Step 3：风险排查（一票否决清单）

| 风险 | 怎么查 | 一票否决吗 |
|---|---|---|
| 专利 / 外观设计 | 在目标市场的专利库检索（如 USPTO、EUIPO、DPMA、UKIPO） | 是，除非有明确规避方案 |
| 商标 | 品牌名、卖点词、包装文字都查 | 是 |
| 产品认证 | CE、UKCA、电气/玩具/化妆品等专项要求 | 是，未取得不要发货 |
| GPSR（欧盟） | 欧盟境内责任人、标签与安全信息、可追溯信息 | 是 |
| EPR | 包装、电子电气（WEEE）、电池等注册与申报，例如德国包装注册 | 是 |
| 类目审核 / 品牌闸门 | 卖家后台类目申请页 | 视情况 |
| 危险品 | 电池、液体、压力容器等的亚马逊审核 | 视情况 |
| 供应链 | 单一供应商、交期波动、质检 | 否，但要有备选 |

### Step 4：汇总成「候选品档案」

每个候选品一页：数据结论、利润表、风险表、差异化想法、止损线。进入采购前，由你本人签字确认（自己对自己负责）。

## 常见坑

- 用含税价当收入，高估利润。
- 漏掉退货、仓储、长期仓储费和促销折扣。
- 认证和 EPR 留到上架后才处理。
- 只算单件利润，不算占用资金的时间成本。

## 完成检查清单

- [ ] 利润表中增值税、佣金、FBA、头程、采购都已计入
- [ ] 平本 ACOS 已算出，且口径与财务一致
- [ ] 现金占用金额与时间已估算
- [ ] 风险表每一行都有结论
- [ ] 候选品档案已归档
