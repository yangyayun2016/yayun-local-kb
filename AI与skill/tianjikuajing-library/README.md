## 核心方法论

- **先算账，再动手。** 利润、广告、现金流三张表没算清，不下采购单。
- **一次只改一个变量。** 否则无法归因。
- **假设要显式。** 所有非官方数值标注 `【工程假设】`，按自己的类目和站点校准。
- **AI 做计算与整理，人做决策。** 缺数据就列缺口，不编造；写操作由人确认。

## 说在前面

- **这里没有任何收益承诺。** 文中数字均为演示，不代表真实或预期结果。
- **规则会变。** 费用、合规、配送项目、VC 条款经常调整，动手前以亚马逊及各主管机构的官方最新说明为准。
