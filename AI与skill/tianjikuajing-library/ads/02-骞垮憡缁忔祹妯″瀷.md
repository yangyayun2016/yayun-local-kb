# 02 广告经济模型

## 要解决什么问题

回答三个问题：这个客单价和目标 ACOS 下 CPC 最多出多少？现在是盈利、平本还是亏损？每天广告预算给多少？

## 准备什么

| 数据 | 来源 | 用途 |
|---|---|---|
| 搜索词报告 | 广告后台报告 | 实际 CPC、点击、广告订单 |
| 总订单与广告订单 | 业务报告 | 拆出自然订单占比 |
| 类目平均转化率 | 第三方工具、品牌分析 | 转化率基准 |
| 广告前毛利率 | 财务口径：（售价 − 成本 − 头程 − FBA − 佣金）÷ 售价 | 平本 ACOS |
| 目标转化率与目标 ACOS | 运营目标 | 反推 CPC 上限 |

**缺哪项就先补哪项，不编造转化率或毛利率。**

## 一步步怎么做

### Step 1：核心公式

```
ACOS        = 广告花费 / 广告销售额 = CPC / (CVR × 客单价)
CPC上限     = 目标ACOS × 客单价 × CVR
CPA         = CPC / CVR
日广告预算  = 预计日单量 × CPA
平本ACOS    = 广告前毛利率
TACOS       = 广告花费 / 总销售额 = ACOS × 广告销售占比（同客单价前提下）
整体转化率  = (广告订单 + 自然订单) / 总点击量
```

### Step 2：代入演示数字

沿用[选品篇 03](../selection/03-利润测算与风险排查.md)的案例：含税售价 €29.99，平本 ACOS 约 31.7%。

| 转化率 CVR | CPC 上限（目标 ACOS 30%） |
|---|---|
| 5% | €0.45 |
| 8% | €0.72 |
| 10% | €0.90 |
| 12% | €1.08 |

- 转化率 10% 时，CPC 上限 = 0.30 × 29.99 × 0.10 ≈ **€0.90**
- 若实际 CPC 为 €0.90，则 CPA = 0.90 ÷ 0.10 = **€9.00**
- 若日目标 10 单，日预算 ≈ 10 × €9.00 = **€90**
- 平本 CPC ≈ 0.317 × 29.99 × 0.10 ≈ **€0.95**，超过就是亏损
- 若 ACOS 为 30%、广告销售占总销售 50%，则 TACOS ≈ 15%

### Step 2：盈亏三态

- **盈利**：广告花费 < 广告预算空间 + 毛利
- **平本**：广告花费 = 广告预算空间 + 毛利，此时 ACOS = 平本 ACOS
- **亏损**：广告花费 > 广告预算空间 + 毛利

### Step 3：红黄绿判断 `【工程假设】`

- 🔴 实际 CPC > CPC 上限 × 1.3，且转化率低于类目均值：结构性问题，先修 Listing 与价格，不要先调竞价
- 🟡 实际 CPC 在 CPC 上限的 1.0–1.3 倍：收词、分时段、降广泛，观察两周
- 🟢 实际 CPC ≤ CPC 上限，且出单所需点击数不超过阈值：可以加预算放量
- 词级阈值：默认「15 个点击出一单」（隐含转化率约 6.67%），属于 `【工程假设】`，应按类目转化率校准：临界点击数 ≈ 1 ÷ 类目转化率 × 安全系数（1.0–1.5）

### Step 4：回答三个经营问题

1. 这个客单价 + 目标 ACOS 下，转化率要做到多少才成立？
2. 当前实际 CPC 与转化率处于哪个区间，距离平本差多少？
3. 自然单占比要提到多少，TACOS 才进入健康区？

## 常见坑

- 用含税售价和不含税成本混着算。
- 把「类目平均转化率」直接当成自己的转化率。
- 只看 ACOS 不看 TACOS，忽略广告对自然单的拉动。
- 以为 ACOS 低就一定好：放量不足，利润总额反而更小。
