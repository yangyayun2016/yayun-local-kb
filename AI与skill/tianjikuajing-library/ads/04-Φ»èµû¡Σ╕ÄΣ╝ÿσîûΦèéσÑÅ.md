# 04 诊断与优化节奏

## 要解决什么问题

ACOS 突然变高、花费不出、订单下滑时，能按固定顺序排查，而不是凭感觉调竞价。

## 准备什么

- 近 14–28 天的广告报告与业务报告
- 同期的价格、库存、Buy Box、评分变化记录
- 改动日志

## 一步步怎么做

### Step 1：按诊断树定位

| 症状 | 优先怀疑 | 检查 | 动作 |
|---|---|---|---|
| 曝光低 | 出价太低、预算耗尽、预售/库存问题、类目词不相关 | 预算耗尽时间、竞价建议、库存状态 | 提预算或价、修库存 |
| 曝光高点击低 | 主图、价格、评分、标题前段缺乏吸引力 | 对比首页竞品 | 优化主图和标题 |
| 点击高转化低 | Listing、评论、价格、变体、Buy Box | 评论近期差评主题、价格与竞品比 | 修 Listing，必要时调价 |
| ACOS 高 | CPC 偏高、转化率低、词不精准 | 搜索词报告 | 收词、否词、降价 |
| 花费不出 | 竞价过低、词太窄、被抑制 | 广告状态、相关性 | 提价、扩词、检查合规状态 |
| 订单掉但广告没变 | 自然流量下滑、竞品动作、库存、价格 | 自然排名、Buy Box 占有率 | 先查非广告因素 |

**铁律：先查非广告因素（价格、库存、Buy Box、评论），再动广告。**

### Step 2：定节奏

| 频率 | 动作 |
|---|---|
| 每日 | 看花费是否异常、预算是否提前耗尽、库存是否支撑 |
| 每周 | 看搜索词报告：否词、扩词、迁移、调价；更新词表 |
| 每月 | 复盘 ACOS / TACOS / 自然单占比 / 排名；调整阶段与预算 |

### Step 3：改动纪律 `【工程假设】`

- 一次只改一个变量
- 单次调价幅度控制在较小范围，例如 ±10%–20%
- 改动后至少观察 3–7 天再评估，因为广告归因存在窗口
- 每次改动写入日志：时间、对象、改动、预期、结果

### Step 4：观察「广告 → 自然」的传导

看广告投入上升后，核心词的自然排名与自然单占比是否同步提升。若广告一直在花钱，自然订单却没有跟上，要回头检查转化率和 Listing 质量，而不是继续加预算。

## 常见坑

- 一周内频繁改价，数据无法归因。
- 只盯 ACOS，没看订单总量和利润总额。
- 忽略库存和价格变化对广告表现的影响。

## 完成检查清单

- [ ] 诊断树已贴在手边
- [ ] 日 / 周 / 月节奏已排入日历
- [ ] 改动日志已建立
- [ ] 每次异常都先查了非广告因素
