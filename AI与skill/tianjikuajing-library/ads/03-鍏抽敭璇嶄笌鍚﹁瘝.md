# 03 关键词与否词

## 要解决什么问题

建立一个会生长的关键词库：能说清每个词为什么投、投在哪、什么时候该停。

## 准备什么

- 搜索词报告（自动广告和手动广告的都要）
- 竞品反查关键词（第三方工具）
- ABA 搜索词（已品牌备案时）

## 一步步怎么做

### Step 1：收集词

来源：自动广告搜索词报告、竞品反查、ABA、评论与问答里买家的真实用语、站内搜索联想词。

### Step 2：给词打标签

| 标签 | 含义 | 典型投放方式 |
|---|---|---|
| 核心词 | 高相关、高需求 | 精准 + 词组，重点预算 |
| 长尾词 | 具体需求、竞争小 | 词组或精准，低价 |
| 竞品词 | 竞品品牌或型号 | 谨慎测试，注意商标与政策 |
| 品牌词 | 自己品牌 | 防守，成本低 |
| 排除词 | 不相关 | 否定 |

### Step 3：词迁移流程

**自动 → 手动词组 → 手动精准。** 在自动广告里跑出订单的搜索词，迁移到手动广告并做精准投放，同时在自动广告和上层匹配中否定，避免重复竞价。

### Step 4：否词规则 `【工程假设】`

- 点击数超过阈值（见[广告篇 02](02-广告经济模型.md)）仍无订单：否词或降价
- 明显不相关：直接精准否定
- 相关但贵：先降价，不要立刻否定
- 否定匹配方式：不确定变体时用词组否定；确定不要的完整词用精准否定

### Step 5：词表模板

```
keyword,tag,match_type,campaign,bid,clicks,orders,cvr,acos,status,note
```

每周更新一次，保留变更历史。

## 常见坑

- 只否词不扩词，流量越来越窄。
- 竞品词不看商标风险。
- 没有词表，所有判断凭记忆。

## 完成检查清单

- [ ] 词表有标签、匹配方式、归属活动
- [ ] 自动广告的出单词已迁移
- [ ] 否词规则写进了 SOP
- [ ] 竞品词已做商标检查
