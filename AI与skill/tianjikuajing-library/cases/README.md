# 案例

案例是学习库里最值钱的部分：**真实数据 + 完整过程 + 诚实复盘**。成功和失败都要写。

## 怎么写

1. 复制 [案例模板](_模板.md)，命名为 `编号-简短标题.md`
2. 所有数字取自后台或财务数据，注明口径（含税或不含税、统计周期）
3. 必须脱敏：不写供应商名称、成本明细、账号信息、未公开的合同条款
4. 失败案例同样重要：写清楚当时的判断依据与事后发现的偏差

## 写作要求

- 区分**事实**（后台数据）与**判断**（你的推断）
- 非官方数值标注 `【工程假设】`
- 附上「可复用 SOP」，让别人看完能照着做
