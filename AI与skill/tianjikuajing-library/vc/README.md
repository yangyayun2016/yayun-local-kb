# VC 篇（Vendor Central · 1P）

VC 是把货**卖给亚马逊**的模式。它与 SC（3P）在定价权、库存、回款、费用结构上都不同。本篇帮你判断一个 ASIN 该走哪条路，并读懂 PO、账期和扣款项。

| 章节 | 你会知道 |
|---|---|
| [01 VC 基础与 1P/3P 选择](01-VC基础与1P3P选择.md) | 两种模式的区别、适用条件、入驻方式 |
| [02 PO、履约与回款](02-PO履约与回款.md) | 采购订单流程、直发与备货模式、账期与扣款项 |
| [03 VC 内容、广告与数据](03-VC内容广告与数据.md) | A+、广告、零售分析、促销工具 |
| [04 VC 与 SC 混合策略](04-VC与SC混合策略.md) | 按 ASIN 分层、避免 Buy Box 内耗、统一报表口径 |

**完成标准：** 对手里每个 ASIN 都能给出「走 1P / 3P / 混合」的理由，并能读懂一张 PO 和一份付款对账。

> 说明：VC 的合作条款（成本价、津贴、账期等）主要由与亚马逊采购经理（Vendor Manager）的谈判和合同决定，各站点、各类目差异很大。本篇讲的是通用框架，具体以你的合同和官方说明为准。
