# 01 VC 基础与 1P/3P 选择

## 要解决什么问题

分清 1P 与 3P 的本质区别，判断你的品牌和产品更适合哪一种，或者两种并行。

## 准备什么

- 品牌与产品线清单、年销售规模、毛利率结构
- 对「控价」「回款」「库存风险」的偏好
- 现有 SC 的运营数据（如有）

## 一步步怎么做

### Step 1：看清区别

| 维度 | 3P（SC） | 1P（VC） |
|---|---|---|
| 谁是零售商 | 你 | 亚马逊 |
| 谁定零售价 | 你 | 亚马逊（你定供货成本价） |
| 谁持有库存 | 你（或在 FBA 仓里仍是你的） | 亚马逊采购后持有 |
| 谁履约 | 你 / FBA | 亚马逊 |
| 回款 | 按结算周期回款 | 按发票与合同账期付款 |
| 费用结构 | 佣金 + FBA + 广告等 | 供货折扣、津贴、合作费用等 |
| 控制力 | 价格、Listing、促销自主 | 价格与促销由亚马逊主导，你通过成本价、促销协议和内容影响 |
| 入驻方式 | 注册即可（需资质审核） | 通常由亚马逊采购经理邀请，依站点而定 |

### Step 2：用决策表判断

| 条件 | 倾向 |
|---|---|
| 品牌认知强、标品、规模大、希望降低运营复杂度 | 1P |
| 新品、长尾、需要自主控价和快速迭代 | 3P |
| 同一品牌下 SKU 差异大 | 混合（按 ASIN 分层） |
| 现金流紧张、无法承受长账期 | 3P 更灵活 |
| 无法承受价格被动调整 | 3P |

### Step 3：估算两条路的利润

把 1P 的供货折扣、津贴、物流承担，与 3P 的佣金、FBA、广告、退货损耗放到同一张表里，按相同口径比较。不要只比较「毛利率」，要比较**净利润额和资金占用**。

### Step 4：确认入驻路径

联系你所在类目的采购经理，或通过官方渠道了解邀请条件；了解你能否保留 SC 账号并行。

## 常见坑

- 只看「亚马逊帮我卖」的省心，忽略价格被动调整的风险。
- 没算清楚账期对现金流的影响。
- 把 1P 与 3P 混在同一 ASIN 上，没有明确规则。

## 完成检查清单

- [ ] 我能说出 1P 与 3P 在价格、库存、回款上的区别
- [ ] 每个 ASIN 有倾向结论与理由
- [ ] 两条路的净利润和资金占用已对比
- [ ] 入驻路径已确认
