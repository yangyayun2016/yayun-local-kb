# 04 VC 与 SC 混合策略

## 要解决什么问题

同一个品牌同时有 VC 与 SC 时，避免内耗：价格打架、Buy Box 争夺、库存错配、报表混乱。

## 准备什么

- 全部 ASIN 的清单与当前归属（VC / SC / 双边）
- 价格、库存、利润、增长阶段数据
- 与采购经理沟通的边界与协议

## 一步步怎么做

### Step 1：按 ASIN 分层

| 层级 | 特征 | 倾向 |
|---|---|---|
| 新品 / 测试品 | 需要快速迭代、自主定价 | SC |
| 稳定走量 / 标品 | 需要稳定曝光与履约体验 | VC |
| 长尾 / 低频 | 库存风险不适合让亚马逊承担 | SC |
| 需要强控价的品 | 品牌价格体系敏感 | SC，或与采购经理约定价格策略 |

### Step 2：避免同一 ASIN 双边竞争

同一个 ASIN 上，亚马逊零售与第三方卖家会争夺 Buy Box。常见做法是**按 ASIN 明确归属**，并为例外情况（如 VC 缺货时是否由 SC 补位）写清规则。

### Step 3：同步价格与库存

建立价格看板：同一商品在不同渠道的价格差。库存按渠道隔离核算，防止 VC 备货与 SC 备货互相占用。

### Step 4：统一报表口径

写一页《口径说明》：销售额含税与否、订单时间点（下单 / 发货）、退货与津贴如何处理。月度汇总时按同一口径对齐。

### Step 5：迁移检查清单

某 ASIN 从 SC 迁到 VC（或反向）前，检查：价格与库存清零或转移计划、评论与排名是否受影响、广告结构调整、对账切换时间点。

## 常见坑

- 价格体系没有统一，出现渠道间价差并被买家看到。
- 迁移时没有提前清库存，出现重复备货。
- 报表口径不一致，导致老板和运营对不上数字。

## 完成检查清单

- [ ] 每个 ASIN 有归属与理由
- [ ] 例外规则已书面化
- [ ] 价格与库存看板已建立
- [ ] 口径说明文档已发布
