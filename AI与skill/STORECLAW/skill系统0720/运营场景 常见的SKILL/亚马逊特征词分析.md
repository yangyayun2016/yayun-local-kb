已理解：你要做的是**亚马逊广告搜索词 → 特征词/词根分析**，把搜索词拆成单词和两个词组合，再汇总广告表现，用来判断哪些词根值得加预算、精准投放、降价或否词。

上传的说明里，数据来源是亚马逊广告后台近 7 / 30 / 90 天搜索词数据，核心保留字段包括：`Customer Search Terms`、`Impressions`、`Clicks`、`Spend`、`7 Day Total Sales`、`7 Day Total Orders`；输出分为**单个词 Result**和**两个词组合 Result**两张结果表。

核心计算口径建议如下：

| 指标    | 公式                  | 含义         |
| ------ | -------------------- | ---------- |
| CPC    | Spend / Clicks       | 平均点击成本     |
| CTR    | Clicks / Impressions | 点击率        |
| CVR    | Orders / Clicks      | 转化率        |
| ACOS   | Spend / Sales        | 广告花费销售比    |
| CPA    | Spend / Orders       | 单笔订单广告成本   |
| 目标 CPC | 目标 ACOS × 售价 × CVR   | 用于反推合理竞价   |
| 目标 CPA | 目标 ACOS × 售价         | 用于控制广告单笔获客成本 |

分析逻辑可以这样落地：

1. **清洗搜索词数据**
   去掉空值、统一大小写、去标点，把每个 `Customer Search Term` 拆成单个词。

2. **单词维度汇总**
   例如搜索词 `stainless steel cat water fountain` 会拆出 `stainless`、`steel`、`cat`、`water`、`fountain`，然后分别汇总曝光、点击、花费、销售额、订单数，并计算 CPC / CTR / CVR / ACOS / CPA。

3. **两个词组合维度汇总**
   例如 `cat water fountain` 可以生成 `cat water`、`water fountain`，也可以按任意两词组合生成 `cat fountain`。建议默认使用**相邻双词**，更接近真实词组含义。

4. **判断词根价值**
   高 CVR、低 ACOS、低 CPA 的词：适合加预算、单独建精准广告。
   高点击、高花费、低订单的词：适合降竞价、优化 Listing 或否词。
   高曝光、低 CTR 的词：说明展现有量但吸引力弱，优先检查主图、价格、标题相关性。
   低曝光、高 CVR 的词：适合拓展长尾词、提高竞价获取更多流量。

Excel 模板里已经有 `Data`、`Result`、`两个词Result` 三个工作表；下一步只需要把你的亚马逊广告搜索词报表数据放进 `Data` 表，就可以按这个结构输出特征词分析结果。
