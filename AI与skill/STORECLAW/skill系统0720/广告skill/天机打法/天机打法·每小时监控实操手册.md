## 一、天机打法总体逻辑

### 1.1 核心思想

> **天机打法的本质：** 不是广撒网，而是找到5~6个占品类流量70%~80%的核心词，集中全部资源精准占位，用营销力（广告）拉动自然力（排名），最终实现"广告减投、自然放量"的飞轮。

```
选定5~6核心词
      ↓
集中广告资源抢占这5~6个词的首页首位
      ↓
每小时监控4个坑位（SP首位/SP常规/SB/自然位）
      ↓
根据eCPM拟合实时调整竞价
      ↓
营销力拉升自然排名
      ↓
自然流量放大 → 广告依赖度降低 → TACOS下降 → 利润提升
```

### 1.2 天机打法三阶段目标

| 阶段 | 时间 | 目标 | 核心动作 |
|------|------|------|----------|
| **占位期** | D1~D14 | 5~6核心词稳定进首页 | 高竞价抢位，每小时监控 |
| **巩固期** | D15~D45 | 广告排名稳定 → 自然排名提升 | 精细化调竞价，监控自然位变化 |
| **收割期** | D45+ | 自然排名稳定，广告降本 | 降广告竞价，提升利润 |

### 1.3 四大坑位定义

| 坑位 | 名称 | 位置描述 | 流量特点 |
|------|------|----------|----------|
| **坑位①** | SP-推荐位（首页顶部） | 搜索结果首页第1~2个广告位 | CTR最高，CVR最高，CPC最贵 |
| **坑位②** | SP-常规位（其余位置） | 首页第3个以后 + 第2页 | CTR中等，CVR中等，CPC居中 |
| **坑位③** | SB/SBV位 | 搜索结果页顶部Banner + 视频广告位 | 曝光大，品牌感知强 |
| **坑位④** | 自然位 | 非广告的自然排名位置 | 零成本流量，算法综合评分决定 |

## 二、Phase 0：上线前准备工作

### 2.1 Listing 质检清单（必须全部达标）

在开始天机打法之前，Listing必须通过以下质检，否则砸再多广告也无法维持排名。

**基础资格层（不达标禁止开广告）：**

| 检查项 | 标准 | 检查方法 |
|--------|------|----------|
| 有货率 | 库存充足，至少支撑30天 | Seller Central库存页面 |
| Featured Offer（购物车） | 赢得率≥90% | Business Reports查看 |
| Prime标志 | 必须有FBA或SFP | 前台查看 |
| ASIN状态 | 无suppressed/抑制 | Manage Inventory检查 |
| 价格竞争力 | 到手价在竞品中位以下 | 前台搜索对比 |

**内容质量层（越高eCPM越强）：**

| 检查项 | 标准 | 分值参考 |
|--------|------|----------|
| 主图 | 白底，主体占比≥85%，长边≥1500px | 必须 |
| 图片数量 | ≥6张（含1个视频更佳） | 高分项 |
| 标题 | 结构完整，核心词前置，≤200字符 | 必须 |
| 五点 | 5条全部填写，覆盖功能/场景/规格/兼容/保障 | 必须 |
| A+内容 | 已上线（Basic A+起步） | 高分项 |
| 评分/评价 | ≥3.8星，≥10条评价 | 必须 |
| 后台属性 | 尺寸/材质/兼容型号等全部填满 | 必须 |

**CDQ / PQS 快速自评：**
```
CDQ评估：用卖家精灵"Listing评分"功能，目标分 ≥ 竞品均值
PQS优先修复顺序：Listing(45%) → 品牌资产(35%) → 价格促销(20%)
```

### 2.2 监控工具准备

| 工具 | 用途 | 必选/可选 |
|------|------|---------|
| **卖家精灵 / SIF** | 关键词流量分析，竞品反查 | 必选 |
| **亚马逊后台 Ads Console** | 广告数据实时查看 | 必选 |
| **自建Excel/Google Sheet** | 每小时排名记录表 | 必选 |
| **亚马逊前台（无痕浏览器）** | 手动验证广告位排名 | 必选 |
| **品牌分析（Brand Analytics）** | SQP数据验证词的真实份额 | 强烈推荐 |
| **Helium10 / Jungle Scout** | 关键词排名追踪（可选辅助） | 可选 |

## 三、Phase 1：核心词选定 SOP

### Step 1：竞品流量对比分析

**目标：** 找到品类中流量最集中的5~6个核心词。

**操作步骤：**

```
① 找到品类中销量最好的5~10个竞品ASIN
   → 参考：BSR榜单 TOP10 / 搜索结果首页前6个自然位

② 在 SIF（或卖家精灵）中做"多产品流量对比"
   → 输入5~10个竞品ASIN
   → 下载流量对比数据

③ 关注核心指标：
   - 每个关键词的：周搜索量 / 流量占比 / 点击份额 / 转化份额
   - 重点找：多个竞品ASIN共同依赖的词（高重叠词 = 品类核心词）
```

**筛选标准（同时满足以下4条）：**

| 标准 | 说明 |
|------|------|
| ✅ 流量占比高 | 单词流量占品类总流量 ≥5%；5~6个词合计占比 70%~80% |
| ✅ 多竞品共有 | ≥3个头部竞品ASIN都在这个词上有流量 |
| ✅ 强相关 | 词义与你的产品高度相关，不偏移 |
| ✅ 有转化可能 | 该词在竞品上有购买转化数据（SQP/BA可查） |

### Step 2：用 Brand Analytics 验证

```
后台路径：Seller Central → Brand Analytics → Search Query Performance
→ 选择目标关键词
→ 查看：
  - 该词的搜索量级别（Tier）
  - 前3个ASIN的点击份额（Click Share）
  - 前3个ASIN的购买份额（Purchase Share）
```

**判断依据：**
- 如果前3 ASIN 的 Purchase Share 合计 < 70% → 这个词还有机会进入
- 如果前3 ASIN 的 Purchase Share 合计 > 85% → 这个词极难突破，考虑换词

### Step 3：最终确定5~6个核心词

**核心词档案（每个词填写）：**

| 字段 | 说明 |
|------|------|
| 关键词 | 词本身 |
| 周搜索量 | 最新数据 |
| 流量占比 | 占品类总流量% |
| 当前我的自然排名 | 目前第几位 |
| 目标自然排名 | 天机打法结束后目标 |
| 主要竞品（该词上） | 主要争夺对象 |
| 当前建议竞价 | Ads Console显示 |
| 首页顶部预计CPC | 建议竞价×1.2~1.5 |

## 四、Phase 2：广告结构搭建

### 4.1 天机打法广告活动架构

```
【核心词层】天机-精准-核心词
  广告活动：天机_SP_精准_[词组名]_[日期]
  广告组1：[核心词1]_精准
  广告组2：[核心词2]_精准
  ...
  广告组N：[核心词N]_精准
  → 每个核心词独立一个广告组（1v1结构）
  → 竞价策略：动态竞价-提高和降低
  → 首页顶部溢价：80%~100%

【辅助扩展层】天机-自动-探索
  广告活动：天机_SP_Auto_[日期]
  → 竞价策略：动态竞价-仅降低
  → 否定词：已确定的5~6个核心词（防止与精准层竞争）
  → 目的：发现新词，低成本补充

【品牌防守层】天机-SB-品牌词
  广告活动：天机_SB_品牌词_[日期]
  → 投放：品牌词+核心词，SB格式
  → 目的：在5~6核心词搜索页顶部占据Banner位（霸屏）

【竞品进攻层】天机-SP-ASIN定向
  广告活动：天机_SP_ASIN定向_[日期]
  → 定向：主要竞品ASIN列表
  → 目的：补充关联流量
```

### 4.2 核心词广告组竞价设置

| 核心词等级 | 竞价设置逻辑 |
|------------|-------------|
| 流量Top1词 | 建议竞价 × 1.5，搏首位 |
| 流量Top2~3词 | 建议竞价 × 1.3，争前3位 |
| 流量Top4~6词 | 建议竞价 × 1.1~1.2，稳首页 |

**首页顶部溢价设置：**
```
广告活动设置 → 竞价 → 按广告位调整竞价
→ 搜索结果首页顶部：设置 80%（保守）或 100%（激进）
→ 商品页面：设置 0%~20%（天机打法不主打商品页）
→ 其余搜索位置：设置 30%~50%
```

### 4.3 预算设置原则

```
天机打法日预算 = 目标CPC × 目标日点击量 × 1.3（余量系数）

示例：
目标CPC = $1.2（核心词平均）
目标日点击量 = 50次
日预算 = $1.2 × 50 × 1.3 = $78

→ 分配：核心精准层70% + 自动探索层15% + SB品牌层10% + ASIN定向层5%
```

**关键原则：** 宁可预算充足浪费一点，也不能让广告因预算耗尽而在关键时段停投。

## 五、Phase 3：每小时坑位监控实操

> 这是天机打法的核心差异点。普通广告7天看一次数据，天机打法每小时看。

### 5.1 监控时间安排

**建议监控时间段（以美国东部时间为参考，北京时间+13小时）：**

| 时间段（北京时间） | 对应美东时间 | 流量特点 | 监控优先级 |
|-------------------|-------------|----------|-----------|
| 09:00~10:00 | 20:00~21:00（前日） | 晚间购物高峰后段 | ⭐⭐⭐ |
| 13:00~14:00 | 00:00~01:00 | 深夜低谷期 | ⭐⭐ |
| 17:00~18:00 | 04:00~05:00 | 凌晨低竞争 | ⭐⭐ |
| 21:00~22:00 | 08:00~09:00 | 早间流量上升 | ⭐⭐⭐ |
| 23:00~24:00 | 10:00~11:00 | 午前购物高峰 | ⭐⭐⭐⭐ |
| 次日01:00~02:00 | 12:00~13:00 | 午间高峰 | ⭐⭐⭐⭐ |
| 次日03:00~04:00 | 14:00~15:00 | 下午高峰起始 | ⭐⭐⭐ |
| 次日06:00~07:00 | 17:00~18:00 | 下班购物潮 | ⭐⭐⭐⭐⭐ |
| 次日09:00~10:00 | 20:00~21:00 | **黄金晚间高峰** | ⭐⭐⭐⭐⭐ |

**实操建议：** 不需要真的每小时都手动查，以下三种方式结合：
1. **黄金时段**（北京时间 21:00~次日02:00）：每小时手动查一次
2. **非高峰时段**：每2~3小时查一次
3. **工具辅助**：开启Helium10 / 卖家精灵关键词排名追踪，自动记录排名变化

### 5.2 每次监控的标准操作流程（约15分钟/次）

**第一步：打开无痕浏览器（必须，否则会受Cookie影响）**

```
Chrome → 新建无痕窗口（Ctrl+Shift+N）
→ 打开 www.amazon.com（或对应站点）
→ 确认地址栏无登录状态
→ 地址栏输入目标站点，切换到目标地区（如美东、西部IP）
```

**注意：** 亚马逊前台会根据地理位置显示不同结果，建议用VPN切换到目标市场IP，确保看到的是真实用户视角。

**第二步：搜索核心词，记录每个坑位排名**

对5~6个核心词，逐一搜索，按以下顺序记录：

```
搜索词：[核心词1]
→ 记录以下内容：

坑位① SP推荐位（首页顶部）
  - 第几位出现我的产品？（如：第1位 / 第2位 / 未出现）
  - 我旁边/前后的竞品是谁？（记录ASIN或品牌名）
  - 这个位置竞品的价格/评分/促销状态

坑位② SP常规位（首页其余+往后翻）
  - 首页中第几位出现？（除顶部广告外的其他SP广告）
  - 翻到第2页是否还有我的广告？

坑位③ SB/SBV位（顶部Banner）
  - Banner位置是否是我的品牌？
  - 如果不是，是哪个竞品占了？
  - 视频广告位（搜索结果中间）有没有我的SBV？

坑位④ 自然位（非广告标志的排名）
  - 我的ASIN在自然搜索结果中排第几？
  - 前10个自然位中，有几个是竞品？
  - 自然位旁边有没有竞品广告覆盖？
```

**第三步：拍截图或直接记录到监控表**

每次监控完成后，将数据填入监控记录表（见第六章模板）。

**第四步：快速判断是否需要立即调价**

```
判断逻辑（见下表），如需调价 → 直接进Ads Console操作 → 记录调价时间和幅度
```

### 5.3 坑位判断与即时决策规则

**坑位①（SP首页顶部）判断规则：**

| 情况 | 判断 | 操作 |
|------|------|------|
| 稳定占据第1~2位 | 理想状态 ✅ | 维持竞价不动 |
| 排在第3~4位 | 竞价不足 ⚠️ | 本词竞价 +10%~15% |
| 首页顶部没有出现 | 竞价明显不足 🔴 | 本词竞价 +20%~30% |
| 频繁第1位但ACOS>150% | 竞价过高 ⚠️ | 竞价 -10%，观察是否仍在首位 |
| 新竞品突然挤进来 | 竞争加剧 ⚠️ | 先查对方竞价水平，决定是否跟涨 |

**坑位④（自然位）判断规则：**

| 自然排名 | 判断 | 操作方向 |
|----------|------|----------|
| 自然位进入前10 | 营销力开始见效 ✅ | 可小幅降低广告竞价5%，测试是否稳住 |
| 自然位进入前5 | 营销力强劲 ✅✅ | 可将广告竞价降低10%~15%，提升利润 |
| 自然位排名下滑 | 需分析原因 ⚠️ | 检查：评价/价格/库存是否异常；广告是否断投 |
| 自然位排名长期未动（>7天） | 广告转化未有效积累 🔴 | 检查转化率；是否流量不够；考虑配合促销拉转化 |

### 5.4 竞品情况监控：记录什么

每次监控时，同时记录核心词首页上**每个坑位周围竞品**的情况：

| 记录项 | 说明 | 为什么重要 |
|--------|------|-----------|
| 竞品ASIN/品牌 | 谁在占据你的竞争位置 | 识别主要威胁对手 |
| 竞品当前价格 | 是否在打价格战 | 决定是否要跟价或调促销 |
| 竞品评分 | 对比自身优劣势 | 判断截流成功率 |
| 竞品是否有Coupon/Deal标志 | 是否在做促销 | 促销期竞品流量会变大，需相应加竞价 |
| 竞品广告类型 | SP/SB/SBV/SD | 判断对方广告策略 |
| 竞品新进还是常驻 | 是否突然出现 | 新进竞品可能刚开始打该词 |

### 6.3 流量得分记录

**流量得分 = 该词为我带来的综合流量价值：**

```
流量得分（参考）= 排名权重分 × 流量乘数

排名权重分：
  自然位第1位 = 100分
  自然位第2位 = 75分
  自然位第3位 = 55分
  自然位第4~7位 = 35分
  自然位第8~15位 = 15分
  自然位第16~25位 = 5分
  广告位首页 = +30分加成（有广告辅助）
  广告位首位 = +50分加成

流量乘数 = 该词周搜索量 / 品类最高词搜索量
```

**每日记录各核心词流量得分变化，观察趋势：**
- 连续3天上升 → 营销力见效，维持策略
- 连续3天不变 → 检查：竞价是否足够/CVR是否拖后腿
- 单日大幅下降 → 立即检查竞品动作/自己的广告状态

## 七、Phase 5：eCPM 拟合与调竞价决策

### 7.1 eCPM 公式理解

```
eCPM = CTR × CVR × 售价 × 平台常量

亚马逊将此公式用于决定：同样的竞价，谁的广告优先展示？
→ eCPM越高的ASIN，在同等竞价下越容易拿到首位
→ 反过来：eCPM高 → 可以用更低竞价拿到同样位置
```

**各变量对eCPM的影响：**

| 变量 | 如何提升 | 提升eCPM幅度 |
|------|----------|-------------|
| CTR（点击率） | 优化主图/标题/价格/促销标签 | 高（主图改好CTR可翻倍） |
| CVR（转化率） | 优化评价/A+/价格/库存/Listing | 高 |
| 售价 | 不能单独为提升eCPM而提价（CVR会掉） | 中，需平衡 |
| 广告竞价 | 竞价是独立变量，影响广告位但不影响eCPM计算 | — |

**eCPM拟合操作：**

```
每隔3~7天，计算你的eCPM估算值：
eCPM估算 = 实际CTR × 实际CVR × 售价

例：
CTR = 0.4%（0.004）
CVR = 15%（0.15）
售价 = $32

eCPM估算 = 0.004 × 0.15 × 32 = 0.0192

对比上周：
  如果eCPM↑ → 说明CTR或CVR在提升，可以小幅降竞价，维持同样排名
  如果eCPM↓ → 说明CTR或CVR在下降，需要找原因修复（不能靠提竞价掩盖）
```

### 7.2 竞价动态调整决策矩阵

**每次监控后，基于坑位排名+eCPM趋势做出竞价决策：**

| 坑位①排名 | eCPM趋势 | CVR水平 | 竞价操作 | 幅度 |
|-----------|----------|---------|----------|------|
| 第1位稳定 | 上升 | 正常 | 小幅降价 | -5%~10% |
| 第1位稳定 | 下降 | 正常 | 维持竞价，查CTR/CVR原因 | 0% |
| 第2~3位 | 上升 | 正常 | 小幅提价争首位 | +10% |
| 第2~3位 | 下降 | 低 | 先修CVR，再考虑提价 | 0% |
| 未在首页 | 任意 | 任意 | 提价 | +20%~30% |
| 首位但ACOS>目标×1.5 | 下降 | 低 | 降价，找CVR根因 | -10%~20% |

**调价频率限制：** 同一广告组同一天最多调价2次，等系统学习稳定后再调。每次调整后至少等48小时再评估效果。

## 八、Phase 6：营销力 vs 自然力评估

### 8.1 两种力量的关系

```
营销力（广告力）：用花钱的方式强行占位，短期有效，停广告即失效
自然力（算法力）：算法综合评分决定的自然排名，持久有效，停广告不掉

天机打法的终极目标：用营销力积累足够的销量、转化、评价数据，
让算法认定你是该词下的"优质相关产品"，
从而将自然力提升到不依赖广告也能稳居前10的水平。
```

### 8.2 营销力→自然力转化的评估指标

每周评估以下转化率：

| 指标 | 计算方式 | 健康标准 | 说明 |
|------|----------|----------|------|
| **自然排名周变化** | 本周自然位 - 上周自然位 | 每周上升1~3位 | 营销力正在转化为自然力 |
| **广告/自然流量比值** | 广告Sessions / 自然Sessions | 初期>3:1；成熟期目标<1:1 | 比值下降说明自然力增强 |
| **TACOS趋势** | 广告花费 / 总销售额 | 每月下降1~2% | TACOS下降说明自然出单增加 |
| **关键词自然收录数** | 在卖家精灵查询自然收录词数量 | 持续增长 | 相关词收录越多，自然流量越稳 |

### 8.3 榜单得分（SCS）辅助营销力

**进入以下榜单 = 算法额外扶持（权重约10%）：**

```
如何配合天机打法进入榜单：

① New Release榜（新品起量能力）：
   → 上线第1~4周集中广告放量，快速积累销量
   → 冲进细分类目 New Release Top100

② Best Seller榜（稳定销量能力）：
   → 天机打法巩固期（D15~D45）维持稳定日销量
   → 锁定细分类目 BSR Top100

③ Movers & Shakers（增长榜）：
   → 在短期内（1周）快速拉升销量
   → 配合BD/LD/Coupon拉单

进入任一榜单后：
  → 打开前台该榜单页面
  → 截图记录自己的排名
  → 监控是否有竞品在此榜单也在争夺
  → 榜单位置本身也是流量入口，可在广告中定向榜单类目
```

## 九、异常情况处理 SOP

### 9.1 排名突然掉位处理流程

```
发现：核心词SP首位突然从第1位掉到第4位或首页消失

Step 1：检查广告活动状态（2分钟）
  → 进入Ads Console → 确认该活动/广告组 "已启用"
  → 确认预算没有提前耗尽（今天剩余预算>0）
  → 确认竞价没有被意外修改

Step 2：检查竞品是否突然加价（5分钟）
  → 无痕浏览器搜索该词
  → 查看新进入首位的竞品：是否是新面孔？价格/评价是否有变化？
  → 如果竞品明显加价或上新活动 → 我方适度跟涨竞价+10%~20%

Step 3：检查Listing状态（5分钟）
  → 前台检查ASIN是否仍然可以正常购买
  → 检查是否有新的差评拉低了评分
  → 检查库存是否充足（Featured Offer是否丢失）

Step 4：执行操作，记录到监控表
  → 记录掉位时间、原因判断、执行操作、调整竞价幅度
```

### 9.2 ACOS突然飙升处理流程

```
发现：某核心词的ACOS从35%飙升到80%+

Step 1：查CVR（转化率）
  → 是否从上周的15% 降到了 5%？
  → CVR下降原因：差评爆发/价格被竞品打低/Listing被改/库存不足/季节变化

Step 2：查点击质量（CTR与搜索词）
  → 下载搜索词报告
  → 是否有大量宽泛匹配词带来不精准点击？
  → 是否该词被宽泛匹配到不相关搜索？
  → 立即添加否定词

Step 3：查竞价是否过高
  → 是否刚刚提过价，CPC上涨但CVR没跟上？
  → 如果是 → 将竞价降回前一版本，等待CVR恢复

Step 4：判断是否暂时降低该词预算
  → 短期ACOS飙升（<3天）：先查原因，不轻易减预算
  → 持续ACOS飙升（>7天）：在修复CVR前，该词竞价降20%保护利润
```

### 9.3 竞品在我产品页铺广告处理流程

```
发现：我的ASIN详情页被大量竞品SD广告覆盖

Step 1：开启防守层广告
  → 在SD广告中，定向我自身的ASIN
  → 竞价：比竞品稍高（通常$0.5~$1.0），将自己的广告推回页面

Step 2：在SP广告中加入自身ASIN
  → SP商品定向 → 定向自身ASIN
  → 竞价：中等即可

Step 3：监控防守效果
  → 无痕浏览器查看自身详情页
  → 确认自身广告已出现在页面中，竞品广告减少
```

### 9.4 核心词突然断流处理流程

```
发现：某核心词曝光量骤降（<昨日50%）

可能原因及对应操作：

原因A：广告预算白天耗尽
  → 检查：广告活动今日已花费 vs 日预算
  → 操作：将日预算提高20%~50%

原因B：该词竞价不足以进入展示
  → 检查：建议竞价是否最近上涨
  → 操作：将竞价提高至新建议竞价×1.2

原因C：Listing被抑制（Suppressed）
  → 检查：Manage Inventory查看ASIN状态
  → 操作：修复抑制原因（通常是图片/价格/属性问题）

原因D：关键词匹配被系统限制
  → 检查：Brand Analytics该词搜索量是否本周骤降
  → 操作：检查是否季节性原因，考虑补充其他词

原因E：账号健康问题
  → 检查：Account Health页面
  → 操作：立即处理违规项，恢复账号评分
```

### 10.2 D8~D14：占位期第二周

**目标：** 5~6个词中，至少3个词的SP首位占比达到 70%+。

| 关键动作 | 操作细节 |
|----------|----------|
| 强化首位竞价 | 对首位占比<70%的词，再次提价+10%~20% |
| 添加否定词 | 处理第一周发现的无效搜索词 |
| 验证STR效果 | 高转化搜索词是否可以升级为手动精准 |
| 监控自然排名 | 核心词自然位是否开始从50位以外移动 |
| 促销配合 | 考虑上Coupon（5%~10%）配合转化率提升 |

### 10.3 D15~D45：巩固期

**目标：** 广告排名稳定 → 自然排名开始进入前30 → 部分词进入前10。

| 周 | 关键指标目标 | 竞价策略 |
|----|------------|----------|
| 第3周 | 自然位进入前25，ACOS<目标×1.2 | 稳竞价，精细否词 |
| 第4周 | 自然位进入前20，ACOS达标 | 部分词可微降竞价5% |
| 第5~6周 | 自然位进入前10（核心词1~2个） | 该词广告竞价降10%~15% |

### 10.4 D45+：收割期

**目标：** TACOS持续下降，自然订单占比超过50%。

```
进入收割期的信号：
  ✅ 2个以上核心词自然位进入前5
  ✅ 自然Sessions超过广告Sessions
  ✅ TACOS低于12%

收割期操作：
  → 核心词广告竞价每2周降10%，直到找到"不影响排名的最低竞价"
  → 维持SB品牌广告（品牌防守低成本）
  → 减少自动广告预算
  → 新增精力投向第二阶段：击穿关联流量 / 海量词收录
```
