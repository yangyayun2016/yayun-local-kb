后续资料如何加入

可由资料维护者继续补充本次大会的手册、宣传册、PDF、照片或个人回忆。资料统一并入这个会议专题，不另建一份互不关联的会议记录。

  1. 原件保存在本目录 后续补充资料目录，保留原始文件名；重名时增加批次前缀，避免覆盖。
  2. 为新资料登记文件名、接收日期、资料日期／版本、相关议题与证据位置。
  3. 优先补充已有章节；遇到不同版本或矛盾表述，保留两边来源并标注变化，不悄悄替换历史现场口径。
  4. 新发现回填下方待核实事项；明确区分“照片转录”“手册说明”“官方在线核验”“个人回忆”。
  5. 更新会议记录的版本和更新日志；图片继续使用库内附件链接，避免依赖 原始收集目录。
