## 这次整理做了什么

原分享包把内容按"会议记录／合并资料／技术附件"分成 9 份文件，同一个话题（财务七项接口、四类分析报表、身份权限辨别、余额层级、自然销量口径等）在 2–3 处重复出现。本次按**业务主题**重组为一份主文档：

- **0–2 章** 使用说明、会议速览、更新总览
- **3 章** 业务接口分主题：订单 / 商品 / 促销 / 定价 / FBM / MCF / 企业购 / 财务 / 报表 / 数据分析
- **4–5 章** AI·MCP·工作流、接入与授权
- **6–7 章** 安全合规、实测证据与结论边界
- **8–9 章** 运营落地（场景、学习卡、提示词）、术语表
- **10–12 章** 待核实清单、资料链接目录（50 条）、附录（57 类接口快照、41 张照片索引）

每条内容都标了证据等级：现场照片、官方文档、本地实测、整理者解读、待核实。**合并过程中没有删掉任何限定语**，"读取可用不等于写入可用""单次跑通不等于生产验收"这类边界全部保留。
