# 亚马逊特征词分析方法论

> 来源：天机跨境 · 亚马逊官方教程系列 关键词之特征词分析工具——广告词根及属性数据分析

## 1. 数据来源

亚马逊广告后台搜索词报告（Search Term Report），时间段任选：
- 最近 7 天 / 30 天 / 90 天
- 获取方式：后台手动下载，或通过 Amazon Ads API 调用

## 2. 数据清洗

需要保留的字段（其余列丢弃）：

| 字段 | 含义 |
|---|---|
| Customer Search Terms | 消费者搜索词 |
| Impressions | 曝光量 |
| Clicks | 点击量 |
| Spend | 广告花费 |
| 7 Day Total Sales | 7 天总销售额 |
| 7 Day Total Orders (#) | 7 天总订单量 |

清洗规则：
- 搜索词统一小写、去首尾空格、多空格合一
- 数值列去币种符号与千分位，转 float
- 剔除搜索词为空的行；ASIN 定向行（b0 开头 10 位）单独归类，不参与词根拆解
- 同一搜索词多行（不同广告活动）先按搜索词聚合再拆词

## 3. n-gram 拆词逻辑

- **单词结果（1-gram）**：搜索词按空格切分，每个词根继承该搜索词的全部指标；跨搜索词按词根求和（Impressions / Clicks / Spend / Sales / Orders），再统一派生 CPC / CTR / CVR / ACOS / CPA。
- **双词结果（2-gram）**：相邻两词组合（如 "wireless charger fast" → "wireless charger"、"charger fast"），同口径聚合；结果中并列展示组合内两个单词各自的 CVR / ACOS / CPA，用于判断组合效果是由哪个词驱动。

注意：词根指标是"包含该词根的所有搜索词"的加总，同一次点击会被计入多个词根，因此词根 Spend 之和 > 总 Spend，属正常现象，用于横向比较而非财务对账。

## 4. 核心公式（共识口径）

```
CPC  = Spend / Clicks                点击成本
CTR  = Clicks / Impressions          点击率
CVR  = Orders / Clicks               转化率
ACOS = Spend / Sales                 广告成本占销售额比例
CPA  = Spend / Orders                单笔订单广告成本

广告销售额 = 点击量 × CVR × 客单价
广告花费   = 点击量 × CPC
ACOS       = CPC / (CVR × 客单价)

CPC上限（目标BID） = 目标ACOS × 客单价 × CVR
可承受CPC          = CVR × 单笔订单可承受的广告成本 = CVR × CPA
CPA                = CPC / CVR
ACOS               = CPA / 客单价   （售价固定时 ACOS 与 CPA 成正比）
日广告预算         = 预计日单量 × CPA
```

### 示例

客单价 30 美金，CVR = 10%，目标 ACOS = 30%：
- 可承受 CPC = 30 × 10% × 30% = **0.90 美金**
- CPA = 0.90 / 10% = **9 美金**（单笔订单可承受广告成本）
- 预计日 10 单 → 日广告预算 = **90 美金**

推论：客单价固定后，CVR 做不到 10%，长期就很难达成 30% ACOS，CPC 也会超 0.9 美金。**CVR 不达标是结构性问题，优先改 Listing / 价格 / 评论，而不是只调出价。**

### 低毛利示例

产品利润只有 6 美金，CVR = 8%（前期不考虑自然订单）：
- 12.5 个点击出 1 单
- 平本 CPC = 6 / 12.5 = **0.48 美金**（CPC 只能做到 0.48 刚好平本）

## 5. 广告策略与毛利关系

- **新品前期**：可用全部毛利做广告，即 **ACOS = 毛利率**（平本打法）。部分类目激进打法广告预算超过毛利（亏损烧市场），需明确标注为激进策略。
- **稳定期**：CVR 起来后控 ACOS、压 CPC，把利润拉上来。
- 根据广告策略、公司模式、类目，设定毛利率与 ACOS 的差额，打法分：**保守 / 正常 / 激进**。

盈亏三态（转交 amazon-ppc-economics 深算）：
- 平本：广告花费 = 预期广告预算 + 毛利
- 亏损：广告花费 > 预期广告预算 + 毛利
- 盈利：广告花费 < 预期广告预算 + 毛利

## 6. 前提准备清单

1. 广告后台搜索词报告数据
2. 订单数据
3. 类目平均转化率
4. 预计广告出单临界值：**15 个点击出一单**（隐含 CVR ≈ 6.67%）`engineering_assumption`
5. 自己的目标转化率
6. 竞品转化率
7. 广告的转化率（区别于整体转化率）

## 7. 整体转化率拆分

```
整体转化率 = (广告订单 + 自然订单) / 总点击量
```

细分为：广告转化率 + 自然转化率。需分别测算以下场景对 ACOS/TACOS 的影响：
- 全部订单都是广告单（自然单 0%）
- 自然单占 40% / 50% / 70%

自然单占比越高，同样广告花费下 TACOS 越低，广告可承受空间越大。

## 8. 预估量方法（经验，`engineering_assumption`）

平均 CPC 与转化率的预估：
1. 市场调研得到同行平均 CPC 后**适当上调 50–60% 空间**
2. 在售同品类商品的历史 CPC 基础上适当上调

新品期波动大，采用**梯度预估**：

| 场景 | CPC | CVR | 完成日销目标广告费 |
|---|---|---|---|
| 悲观 | $2.5 | 5% | $105/天 |
| 乐观 | $2.3 | 7% | $69/天 |

按梯度给区间而非单点数字，向老板/团队汇报时呈现敏感性。
