# Gbrian Brain

这是一个本地 Markdown 知识库，配合 GBrain 使用。GBrain 负责导入、检索和图谱化；本目录负责保存人类和 agent 都能直接阅读、维护、版本管理的知识文件。

## 入口

- `RESOLVER.md`：新增知识时先读，决定内容应该放到哪个目录。
- `schema.md`：页面结构、引用、时间线和维护规则。
- `index.md`：知识库目录和当前状态。
- `log.md`：所有重要导入和维护动作的时间线。
- `AGENTS.md`：给 AI agent 的操作规则。

- GBrain 数据库目录：`E:\gbrian-home`
- Markdown 知识库目录：`E:\gbrian-brain`

## 使用方式

1. 保存新资料前，先读 `RESOLVER.md`。
2. 不确定放哪的内容先放 `inbox/`。
3. 稳定知识进入对应分类目录。
4. 原始资料和来源摘要放 `sources/`。
5. 重要页面用 `schema.md` 的“Compiled Truth + Timeline”结构。
6. 不保存密码、API key、token、私钥或高敏感个人信息。
