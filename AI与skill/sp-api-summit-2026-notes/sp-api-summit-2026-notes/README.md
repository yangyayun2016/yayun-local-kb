## 证据分级

每段内容都带标记，先看标记再看结论：

| 标记 | 含义 |
|---|---|
| 现场 | 会议投影片／演示屏幕照片可见的内容 |
| 官方 | 官方文档、发布日志、仓库等公开资料 |
| 实测 | 本地测试记录中已跑通的链路 |
| 解读 | 整理者的业务解释与实践建议 |
| 待核实 | 证据不足，不下结论（见第 10 章） |

## 最需要记住的四条

1. **读取能力与写入能力分开看。** 促销读取已发布，不等于创建更新也已开放（现场口径：私测 2026 年底、正式 2027 年初）。
2. **AI 输出要回到版本与测试。** MCF 迁移演示用的是 pre-release schema，与正式演讲页版本不同，不能直接照用。
3. **数据连接要先统一口径。** `orders7d` 是订单数不是件数，`sales7d` 是广告归因销售额；"总销量减广告销量"未对齐前只能算待验证差额。
4. **API 接入包含持续维护。** 同步、分页、错误处理、权限、删除与测试都是可用性的一部分。
