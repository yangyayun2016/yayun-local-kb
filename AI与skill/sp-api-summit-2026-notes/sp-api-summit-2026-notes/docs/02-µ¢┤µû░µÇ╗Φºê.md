# 2 更新总览

## 2.1 先分清四种状态

"大会提到""官方发布""某个授权可用""已通过生产验证"不是同一件事。本汇编的实测来自不同对话形成的操作记录，合并时分别标注范围，没有把不同测试视为同一次执行。本次整理未重新连接店铺执行业务测试。

**名称辨析：** SP-API 是 Selling Partner API（销售伙伴业务接口），连接订单、库存、商品、财务；广告投放中的 SP 是 Sponsored Products，含义不同。广告活动及效果数据主要通过 Amazon Ads API 获取。

## 2.2 近期发布时间线【官方】

下表是相关更新摘选，不是全部更新，也不表示均在大会当天首次发布。版本名称中的日期与正式发布日期要分开理解。

| 发布日期 | 变化 | 可以解决的问题 |
|---|---|---|
| 2026-01-28 | Orders v2026-01-01 以 getOrder、searchOrders 整合查询 | 少拼接订单数据，按需获取获授权的信息 |
| 2026-05-28 | 官方仓库发布 Local MCP 公告 | 给 AI 提供文档、接口与工作流工具入口 |
| 2026-07-29 | Finances 新增 listBalances、listSummary；Transfers 增加付款查询 | 核对余额、收支汇总、付款与预计付款 |
| 2026-07-29 | Listings 支持同一区域多个站点读取 | 减少逐站点重复请求 |
| 2026-07-29 | 发布 Fulfillment Outbound v2026-07-04 | 改善多渠道配送集成、沙盒和异步处理 |
| 2026-08-05 | Tracking API 与货件里程碑通知 | 获取物流状态；该次查询发布标明美国站 |
| 2026-08-18 | 官方 MCP 工具包 v1.0.5 发布 | 本批安装与工作流资料采用的工具版本 |
| 2026-08-26 | Promotions API 发布；效果报表增加 promotionsApiMappingId | 关联活动信息与效果报表 |

依据：[官方发布日志](https://developer-docs.amazon/sp-api/docs/sp-api-release-notes)、[Local MCP 公告](https://github.com/amzn/selling-partner-api-samples/discussions/382)、[v1.0.5 发布记录](https://github.com/amzn/selling-partner-api-samples/releases/tag/mcp-server-v1.0.5)。适用站点、角色及开放范围需查对应操作。

## 2.3 发布路线图（现场口径，IMG_2375）【现场】

| 能力 | 现场披露状态／计划 |
|---|---|
| 促销管理 API 读取操作 | 2026 年 9 月初已正式推出 |
| 促销管理 API 创建和更新 | 私有测试版：2026 年底；正式推出：2027 年初 |
| getCompetitiveSummary 相似商品 | 自 2026 年 5 月起正式推出 |
| getCompetitiveSummary 促销 | 私有测试版已开启；正式推出计划：2026 年第三季度 |

> **口径差异已记录：** 促销读取现场称 9 月初推出，官方发布日志列于 8 月 26 日。两种口径并存保留，以正式采用版本的官方定义为准。
