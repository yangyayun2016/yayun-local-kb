## 10.3 后续资料如何加入

1. 原件保存在 `archive/`，保留原始文件名；重名时增加批次前缀，避免覆盖。
2. 为新资料登记文件名、接收日期、资料日期／版本、相关议题与证据位置。
3. 优先补充已有章节；遇到不同版本或矛盾表述，**保留两边来源并标注变化，不悄悄替换历史现场口径**。
4. 新发现回填 10.1 待核实事项；明确区分"照片转录""手册说明""官方在线核验""个人回忆"。
5. 更新版本与更新日志；图片继续使用库内相对链接。
