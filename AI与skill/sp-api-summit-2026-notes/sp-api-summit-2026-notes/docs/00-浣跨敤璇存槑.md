# 0 使用说明

## 0.1 这次整理做了什么

| 动作 | 说明 |
|---|---|
| 主题重组 | 原来按"会议记录／合并资料／技术附件"分文件，现改为按业务主题（订单、促销、财务、安全……）组织 |
| 合并去重 | 财务七项清单、四类分析报表、身份权限辨别、余额层级、自然销量公式等在原包中出现 2–3 次，现各归一处 |
| 保留边界 | 所有"现场口径 / 待核实 / 不能推导"的限定语一字不减，不因为合并而变成确定结论 |
| 保留原件 | 原 9 份 Markdown、HTML、DOCX 与 41 张照片全部保留，未覆盖、未压缩 |

## 0.2 证据分级（阅读时先看这一列）

| 标记 | 含义 | 可以用来做什么 |
|---|---|---|
| 【现场】 | 会议投影片／演示屏幕照片可见的内容 | 了解官方对外表述，需再核对正式文档 |
| 【官方】 | 官方文档、发布日志、仓库等公开资料 | 可作为接入依据，仍需核对版本与站点 |
| 【实测】 | 本地测试记录中已跑通的链路 | 证明"这条路走得通"，不等于生产验收 |
| 【解读】 | 整理者的业务解释与实践建议 | 用于培训和需求沟通，不是官方承诺 |
| 【待核实】 | 证据不足，不下结论 | 见第 10 章清单，收到资料后回填 |

## 0.4 记录范围与安全边界

会议记录依据 **44 个来源照片文件，按 SHA-256 去掉 3 个完全相同副本后为 41 张**，不是录音逐字稿；讲师姓名、口头讲解、问答答案、酒店名称均未确认。

本汇编不含真实账号、密钥、原始业务响应、后台截图、运行标识或真实工作流输入。照片属于会场材料，保留现场观众与演示画面，转发请整包发送并完整解压，不要单独移动网页而遗漏照片目录。
