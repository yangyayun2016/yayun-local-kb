# 流量、关键词、广告位与竞品诊断

当用户要求关键词治理、广告位下钻、预算打满、竞品对标、ABA/SIF 机会、排名下滑根因时使用本参考。

## 关键词动作分类

`立即停投/否定`

- 花费高、订单为 0 或购买份额为 0。
- ACOS 明显高于盈亏平衡 ACOS。
- SIF 显示时机错误，或产品与词不匹配。
- 与 ASIN 关系弱，带来无效点击。

`降 bid/限流`

- 有订单但 ACOS 高于盈亏线。
- CVR 下降且 CPC 上涨。
- 需要保留少量曝光，但不能继续放量。

`保留/微增`

- ACOS 低于盈亏线，订单稳定。
- ABA 有购买份额，广告也能转化。
- 预算未明显浪费。

`转 Exact/加预算`

- 搜索词有订单且 ACOS 健康。
- ABA 购买份额高，但广告花费很少。
- 自然排名已有基础，广告可强化排名。

`中期布局`

- SIF 显示旺季上升或峰值临近。
- 大词当前转化不稳，但自然流量已有出单，需要低价养排名。
- 长尾词搜索量小但购买份额高。

## 三维交叉验证

优先用三类证据同时判断关键词：

1. 广告数据：花费、点击、订单、销售额、ACOS、CVR。
2. ABA：点击占比、购买占比、购买次数、自然排名。
3. SIF/卖家精灵：搜索量、季节时机、竞品强度、需求趋势。

示例判断：

- 花费最高但 ABA 购买为 0：不是单纯 bid 问题，可能词不适配，优先停投或否定。
- ABA 购买占比高但广告几乎没覆盖：优先加入 Exact 或提高预算。
- SIF 显示旺季还未到，大词当前无转化：低价观察，不重仓。

## Campaign 结构判断

检查：

- SP/SB/SD 是否单一。
- 手动精准词是否过度集中。
- 是否缺少商品定向和详情页承接。
- 是否 Auto/Broad 探索层浪费、Exact 收割层不足。
- Campaign 命名是否能看出层级和目标。

输出不要只说“广告结构不稳定”，要指出缺哪一层、哪一层浪费、预算应该怎么转。

## 广告位下钻

广告位必须按 Campaign 分析：

```text
Campaign | 广告位 | 花费 | 订单 | ACOS | 判断 | 动作
```

判断方式：

- 同一广告位在不同 Campaign 下表现可能相反。
- 搜索首位亏损只在某 Campaign 出现时，调整该 Campaign 的搜索首位倍增。
- 详情页或其他搜索位高效时，不要因为整体 ACOS 高而误停。

## 预算打满与断流

重点识别：

- 日预算过低导致上午 6-9 点打满，下午无广告。
- 旺季 CPC 上涨但预算/出价未跟上。
- 高效 Campaign 预算打满导致销量和自然排名被限制。
- 低效 Campaign 预算打满导致亏损扩大。

因果链模板：

```text
旺季到来或竞品加大投放
-> CPC 上涨
-> 低日预算 Campaign 提前打满
-> 下午广告断流
-> 广告流量断崖
-> 销量不足
-> 自然排名/BSR 恶化
```

## 竞品对标

销量或排名下滑时，第一步看竞品是否同步下滑：

- 竞品同步下滑：市场整体原因。
- 只有我们下滑：内部广告、价格、库存、Listing 或评价问题。
- 我们下滑幅度更大：市场原因 + 内部投放问题混合。

输出要写清：

- 竞品对比时间段。
- 我们与竞品的变化幅度。
- 判断是市场、内部还是混合原因。

## 动作优先级

今日止损：

- 停投或否定高花费 0 购买词。
- 降低高 ACOS 活动预算。
- 暂停三个广告位全面亏损的 Campaign。

本周修结构：

- 高效 Campaign 加预算。
- 亏损搜索首位降低倍增。
- 高效搜索词转 Exact。
- 无转化小词暂停或低价观察。

中期布局：

- 旺季大词低价养排名。
- ABA 高购买长尾词新建精准。
- 评论积累和 Listing 转化修复。
