# ACOS 与利润止损规则

当出现 ACOS 提升、广告亏损、CVR 下滑、负毛利、盈亏平衡 ACOS、目标毛利率或自然流量掩盖广告亏损时使用本参考。

## 盈亏判断

广告是否亏损，优先比较：

```text
当前 ACOS vs 盈亏平衡 ACOS
```

- ACOS < 盈亏平衡 ACOS：广告本身大概率盈利。
- ACOS 接近盈亏平衡 ACOS：广告边际安全，需要控制扩量。
- ACOS > 盈亏平衡 ACOS：广告亏损，需要定位浪费。
- 广告后毛利率为负：广告和产品经济性同时触发红线，先止损。

不要只看 TACOS。自然流量订单多时，TACOS 可能好看，但广告本身仍然亏损。

## 严重度分级

优先使用用户给出的平台标签，如“ACOS提升（极高）”。没有标签时按以下启发判断：

`极高`

- 当前 ACOS 明显高于盈亏平衡 ACOS，且广告后毛利为负或产品毛利率为负。
- ACOS 近 7 天仍然高位，且 CVR 下滑超过 40%。
- 广告花费未随转化下降同步收紧，造成烧钱速度失控。
- 缺搜索词或 Campaign 明细，无法定位高花费低转化对象。

`高`

- ACOS 高于盈亏平衡 ACOS，广告亏损金额明确。
- TACOS 或总利润被自然流量掩盖，但广告加权 ACOS 明显亏损。
- 高花费活动或关键词疑似无效，但仍需报表确认。

`中`

- ACOS 高于目标但接近盈亏平衡，或样本不足。
- CVR、CPC、CTR 中有单项异常，但亏损金额不大。

`低`

- 轻微偏离目标，适合观察或小幅调 bid。

## 极高 ACOS 默认止损动作

当同时满足“ACOS 远高于盈亏平衡”和“利润/毛利为负或亏损严重”时，先输出止损建议，再要求补数。

可用话术：

```text
复核前，建议先将该 ASIN 相关广告活动日预算总额降低约 50%，或暂停高 ACOS 活动，以控制烧钱速度；待补齐搜索词报告和 Campaign 明细后，再精准降 bid 或否定低效词。
```

如果只有店铺维度数据：

```text
建议先按 ASIN/SKU 维度拆出 ACOS 超盈亏线且广告后毛利为负的对象，对这些对象进行预算止损；不要对全店高效 ASIN 一刀切。
```

## 自然流量掩盖广告亏损

识别信号：

- 广告加权 ACOS 高于盈亏平衡 ACOS。
- 广告亏损金额明确。
- 整体销量或 TACOS 看起来尚可，但广告订单质量差。
- 自然流量订单较多，掩盖了广告端亏损。

输出重点：

- 明确说“整体表现不能证明广告盈利”。
- 分开广告利润和自然流量表现。
- 要求补充搜索词报告和活动层级数据，定位亏损词与亏损活动。

## CVR 下滑导致 ACOS 飙升

因果链模板：

```text
CVR 从 A% 降至 B%
-> 同等点击带来的订单减少
-> 广告花费未同步收紧
-> ACOS 从 X% 上升至 Y%
-> 超过盈亏平衡 ACOS Z%
-> 广告加剧亏损
```

可能原因只能在有证据时写：

- 搜索词流量质量下降。
- Campaign 混入泛词或竞品词。
- 搜索首位倍增在错误 Campaign 上烧钱。
- CPC 上涨但预算未调整。
- Listing、价格、库存、评分影响转化。

## 高影响动作边界

- 预算降低、暂停活动、否定词、关闭广告位倍增都要标注“建议人工确认”。
- 不能在缺少活动或搜索词报告时声称已定位具体亏损词。
- 不能用目标毛利率替代实际盈亏平衡 ACOS，除非用户明确指定这是当前诊断阈值。
