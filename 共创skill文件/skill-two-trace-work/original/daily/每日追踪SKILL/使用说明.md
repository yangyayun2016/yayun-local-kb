# ASIN 每日竞争追踪 · 使用说明（v1.1）

这是一个帮你每天追踪自有产品和竞品关键指标（BSR、评分、评分数、价格、Buy Box）的工具。它每天把数据拉下来、跟昨天比，只告诉你**值得管的变化**，十秒看完，省掉每天手动搜词翻链接的功夫。

v1.1 在原来基础上多了三件事：**自动标记产品动作并在 7 天内提醒**、**结合动作给一段 AI 分析**、**报告固定带一行竞品深挖入口**。下面会讲到。

---

## 一、先搞清楚：这工具能做什么、不能做什么

- 它是**半自动**的：不是无人值守的定时任务，需要你每天来说一句"跑今天的追踪"触发。想定时，自己设个手机提醒即可。
- 它的价值在**判断逻辑**（什么变化值得报、谁和谁是竞品、怎么管住数据额度），不在取数本身。
- 取数有两种方式：连**卖家精灵 MCP**自动拉，或者**手动把数据喂给它**。没有卖家精灵也能用，只是要自己贴数据。

---

## 二、数据从哪来：两种模式

**模式 A · 卖家精灵 MCP（推荐，自动）**
你已连接卖家精灵 MCP 的话，它直接调接口拉数据，你什么都不用贴。
> 注意额度：卖家精灵每调用一次接口消耗一次次数。常见套餐 1000 次/月。一次追踪消耗 = 你追踪的 ASIN 总数（自有+竞品）。建议每天追踪 5 个 ASIN 以内，给选品调研留余量。工具会帮你本地记账、接近上限时提醒。
> 关于"剩余次数"：卖家精灵的 MCP **没有**提供查后台真实剩余次数的工具（官方 REST API 有个查余额接口，但没被包进 MCP）。所以工具记的是**本地估算**，跟后台真实余额会有偏差（你在别处的调用算不进来）。建议月初去卖家精灵后台看一眼真实剩余，手动校准一下记账文件。

**模式 B · 手动喂数（没有卖家精灵时）**
每天自己从任意工具（卖家精灵网页端、Helium10、亚马逊前台等）复制各 ASIN 的 BSR、评分、评分数、价格、Buy Box 卖家，贴给它。判断和报告逻辑完全一样，效果取决于你喂的数据。

---

## 三、数据会不会丢？换聊天框 / 换设备怎么办

这是最多人困惑的点，先讲清楚。追踪数据存在**文件**里（历史记录、配置、动作记录、配额）。数据在不在，取决于这些文件在不在，跟用哪个聊天框无关。按你用的工具分两条路：

**路径一：聊天类 App（Claude 桌面版 / 网页版、CherryStudio 等）**

这类工具的文件存在临时环境里，**不跨聊天框保留，长时间不动也可能被回收**。所以：
- 尽量**在同一个聊天框**里完成日常追踪。
- **每次追踪后，把更新过的 history.csv、actions_log.json（和配额文件）下载保存到本地**——这是关键习惯。即使聊天框换了或环境清空，你手上始终有最新文件。
- 要**换聊天框 / 换设备**时：在新框里先把保存的这些文件上传进去，再让它接着追踪。数据就续上了。
- 一句话：**文件随身带，聊天框可以换。**

**路径二：Claude Code 本地方式（推荐长期使用）**

这类方式直接读写**你电脑硬盘上的文件**，数据落在你电脑的工作目录里，不依附于任何会话。所以：
- 每天**开全新会话**都行，它重新读电脑里的文件，数据还在，直接接着追。
- 换会话、关软件、第二天再开都不影响，只要文件还在原目录。
- 不用每次手动下载上传，省心。**长期每天追踪建议用这种。**

**最省事的上手方式（不用装任何东西）：** 如果你用的是 Claude 桌面软件，它已经**内置了 Claude Code**，无需另外去终端安装。做两步即可：
1. 在软件里**切换到 Code 工作区**；
2. **新建一个文件夹**（比如叫 `asin-tracker`）作为工作目录，把这个 skill 放进去。

之后每天在这个工作区里说"跑今天的追踪"，数据就读写在这个文件夹的文件里，换会话照样接着用。这是对大多数人最简单的本地方式——既有本地文件持久化的好处，又省掉了单独安装命令行工具的麻烦。

（如果你不用 Claude 桌面软件，也可以单独安装 Claude Code 命令行版，或用 Cursor 等工具，原理一样，只是安装多几步。）

**简单选：** 偶尔用、图方便 → 路径一（记得每次存文件）；长期每天追、不想倒腾文件 → 路径二，且优先用 Claude 桌面软件内置的 Code 工作区。

## 四、第一次怎么配置

第一次使用时，把这个 skill 装好后，直接对它说"我要开始配置追踪"，它会让你填：

```
1. 数据模式：A 卖家精灵 MCP（自动） / B 手动喂数
2. 自己的 ASIN（可多个）：
3. 竞品 ASIN（可多个）：
4. 哪个竞品对应你哪个产品？（可选；不填它会按类目+产品名自动配对再请你确认）
5. （模式 A）卖家精灵套餐月额度（默认 1000 次）：
6. （可选）追踪 Amazon's Choice 标变化？（默认不追）：
7. （可选）每个 ASIN 的代号 / 后台 SKU（方便你认，ASIN 多时很有用）：
8. （可选）动作记录窗口天数（默认 7 天）：
```

填完它会帮你生成配置文件，并按你的 ASIN 数量算一笔额度账，提醒你追踪的数量安不安全。

## 五、每天怎么用

配好之后，每天来一句：

> 跑今天的追踪

它就会：拉数据 → 跟上次比 → 给你一份当天异动报告 → 把今天数据存进历史。报告里包含下面第六节讲的几块内容。

**用路径一（聊天 App）的，记得追踪完把更新的文件存下来。**

## 六、v1.1 新增：动作标记、AI 分析、竞品深挖入口

**1. 自动标记产品动作，7 天内提醒**
排名、转化的变化常常是几天前某个动作（调价、上 coupon、加变体等）的滞后结果。隔两天再看报告，很容易忘了"这产品最近排名往上走，前几天它是不是降过价"。

所以每天比对时，工具会**从数据里自动认出"动作型"变化**并记一条带日期的标记，往后 **7 天内**挂在对应产品行下面提醒你。能认出来的动作：调价、coupon 上/撤、变体增减、Buy Box 易主、AC/BS 标得失、评论数异常增减。**自有和竞品都会标。**

要说清楚两点：
- 这是**从数据里认**，不是你手动登记，也不是你后台操作的记录。所以只能认出"数据看得到的动作"——开广告、站外引流、改主图内容这些数据里看不到的，它认不出来，不会假装知道。
- 评论数异常（比如单日暴增）只会提醒你"关注是不是买评/站外"，**不会替你下"它在刷单"的结论**——看到的只是数字反常，成因有多种，判断留给你。

**2. 结合动作的 AI 分析**
每个竞争组的表格下面，会多一小段分析，把"这周数值怎么变"和"7 天内标记到的动作"放一起读，比如"自有 A 的 BSR 这两天回升，时间上和 3 天前那次降价对得上"。
注意它的措辞是"时间上对得上 / 可能相关"，**不会写成"因为降价所以排名升"**——它只看到先后顺序，看不到因果，不会硬给你下因果结论。

**3. 报告固定带一行竞品深挖入口**
报告末尾**固定**有一行通往"竞品监控"（competitor-monitor skill）的入口：
- 有竞品异动较大时，它会点名建议你深挖，你回一句"深挖 X"就转过去看那个竞品具体改了什么。
- 没有竞品达到阈值时，也会留一行中性提示，告诉你想主动查就回"深挖 X"或"监控竞品变动"。

这一步是**建议 + 你确认**，不会自动花额度——深挖要多调一次接口，要不要花由你决定。（竞品监控是配套的另一个 skill，想用就一并装上。）

## 八、一点说明

- 工具里的异动阈值（BSR 变化多少算"值得报"、动作侦测的幅度等）是通用默认值。用一段时间后，按你自己类目的日常波动校准——有些类目排名天然每天大幅跳，默认阈值可能太敏感。它怎么帮你也取决于你怎么调它。
- 模式 A 第一次正式跑时，让它顺带核对一下卖家精灵返回的字段名（coupon、变体、标识这些）跟工具里写的对不对得上，对不上提醒它改一下——不同账号/版本偶尔有差异，免得某类动作静默漏标。
