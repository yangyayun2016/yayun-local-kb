# 天哥复刻 · 安装与 API 配置指南（从零到能出片）

这份是给**第一次用**的人看的全流程。照着一步步做，不用懂代码。
工具的作用：扔一条爆款短视频 → 自动复刻成「骨架神似、画面全新」的新片 + 上下屏对比片。

> 配合阅读：`新手必读-大白话.md`（怎么用）、`SKILL.md`/`AGENTS.md`（给 Codex 看的引擎说明）。

---

## 一、先装好运行环境（只做一次）

1. **Codex（桌面端）**：本工具是 Codex 技能。把整个 `天哥复刻` 文件夹放进 Codex 能访问的目录即可。
   - 想用斜杠命令：把 `tiange_fuke.md` 复制到 `~/.codex/prompts/tiange_fuke.md`，以后在 Codex 里敲 `/tiange_fuke`。
2. **ffmpeg**（拆视频/拼视频必须，免费）：
   - Windows：PowerShell 里 `winget install Gyan.FFmpeg`，**装完重开终端**。
   - Mac：`brew install ffmpeg`；Linux：`sudo apt install ffmpeg`。
   - 验证：敲 `ffmpeg -version` 能出一堆字就行。
3. **Python 依赖**：在本文件夹敲 `pip install -r requirements.txt`（只有一个包）。

---

## 二、两个 API 是干嘛的（先搞清楚）

本工具按「这一镜有没有人脸」自动分流到两条后端，**两家都要有 key**：

| 镜头类型 | 走哪家 | 为什么 |
|---|---|---|
| **有人脸**（人物、换装真人） | **APIMart** | 人脸更稳 |
| **没人脸**（产品、场景、清单、空镜） | **火山方舟（Seedance Mini）** | 最便宜 |

> 只填一家也能跑，但只能做对应那类镜头（缺哪条工具会提示）。
> 想全部走火山（火山一个 key 也能调 Fast 跑人脸）：在 `_work/.secret.env` 加一行 `FK_FACE_ROUTE=ark`。

---

## 三、APIMart 注册 + 拿 key（简单，5 分钟）

1. 打开官网 **https://apimart.ai/** ，注册账号（邮箱即可，免费注册）。
2. 登录后进控制台 **Dashboard**，找到 **API Keys**，点 **Create / 创建**，复制出来的 key（形如 `sk-...`）。
3. **充值**：在控制台的「充值 / Billing」里充一点（支持的支付方式以官网为准）。按量计费，先充几十块够测很多条。
4. 文档备查：**https://docs.apimart.ai/** ；接口地址是 `https://api.apimart.ai/v1`（工具里已配好，你不用管）。

> 这个 key 等下要填到 `_work/.secret.env` 的 `APIMART_TOKEN=` 后面。

---

## 四、火山方舟（Seedance）注册 + 开通 + 拿 key（稍复杂，按步来）

火山的流程比较绕，关键是「**先开通模型**，再**建 API Key**，再**充钱/买资源包**」，三步缺一不可。

### 第 1 步：注册 + 实名认证
- 打开 **https://www.volcengine.com/** ，注册火山引擎账号。
- 完成**实名认证**（个人或企业都行）。**没实名认证，后面模型用不了。**

### 第 2 步：进方舟控制台，开通视频生成模型
- 进入方舟控制台：**https://console.volcengine.com/ark**
- 左侧找到「**开通管理**」（开通服务）→ 找到「**视频生成 / 视觉大模型**」里的 **Doubao-Seedance（即梦/豆包 视频生成）系列**，点**开通**。
  - 要用便宜的 **Mini**，就把 **Doubao-Seedance-2.0-mini** 开通；要跑人脸也想用火山，就把 **Fast** 也开通。
- 快速入门官方文档：**https://www.volcengine.com/docs/82379/1399008**

### 第 3 步：创建 API Key
- 方舟控制台左侧「**API Key 管理**」→ **创建 API Key** → 复制保存（形如一串字符）。
- 官方说明：**https://www.volcengine.com/docs/82379/1361424**
- 说明：本工具直接用「模型 ID」调用（不需要你额外建「在线推理接入点 Endpoint」）。如果你的账号必须用接入点，去「在线推理 → 推理接入点」建一个即可，但通常用模型 ID 就行。

### 第 4 步：充钱 / 买资源包（二选一）
- **按量付费**：账户里有余额即可（费用中心充值）。
- **买资源包更便宜**：费用中心 →「**资源管理 / 资源包**」→ 购买 **Doubao-Seedance-2.0-mini 在线推理资源包**（按 token 计费的包）。无人脸镜会自动用 Mini，最省。
- ⚠ **账户欠费/没余额会直接报错**（HTTP 403 AccountOverdue），所以先确保有余额或买了包。

### 第 5 步：确认模型 ID（重要）
- 本工具默认 Mini 的模型 ID 是 `doubao-seedance-2-0-mini-260128`（按命名规律填的）。
- Seedance 2.0 API 文档：**https://www.volcengine.com/docs/82379/1520757**
- **第一次用先验一下**（见第六节）：如果模型 ID 跟你账号的不一致，照下面办法改，不用动代码。

> 火山方舟的 key 等下填到 `_work/.secret.env` 的 `ARK_API_KEY=` 后面。

---

## 五、把两个 key 填进去（一个文件搞定）

1. 把 `_work/.secret.env.example` **复制一份**，改名成 `_work/.secret.env`。
2. 用记事本/VSCode 打开 `_work/.secret.env`，填上两行：
   ```
   APIMART_TOKEN=[已移除]
   ARK_API_KEY=[已移除]
   ```
3. 保存。🔒 这个文件只在你电脑里，不上传、不进代码（已自动忽略）。
- 如果火山 Mini 的模型 ID 跟默认不符，在同一个文件里再加一行覆盖：
  `FK_MODEL_MINI=你账号里正确的mini模型id`

---

## 六、先验证一下能不能跑（只花几毛钱）

让 Codex（或你自己在本文件夹）跑：
```
python -m pipeline.verify_mini
```
- 出现 **✅ Mini 可用** → 配好了，可以正式用了。
- 出现 **❌** → 按提示改（多半是 key 没填对、没余额、或模型 ID 要改 `FK_MODEL_MINI`）。

---

## 七、怎么用（出片）

把要复刻的视频放进来，对 Codex 说：
> **「按 AGENTS.md 复刻这个视频：`<视频文件名>`，跑完给我上下屏对比片。」**

它会自动：拆骨架 → 想清「这视频为什么火」→ 重写每镜 → 生成 → 拼接 → 出上下屏对比片。
成片在 `_work/final/`。（细节见 `新手必读-大白话.md` 和 `AGENTS.md`。）

---

## 八、花多少钱

- 按用量（token）计费，**不是按条**。一条 13 秒竖屏片通常**几块到十几块**。
- 省钱已内置：没人脸的镜头走火山 Mini（最便宜），默认 480p 草稿档。
- 想更省：`_work/.secret.env` 写 `FK_RESOLUTION=480p`（整片都 480p）。

---

## 九、常见问题

- **报错「没找到 ffmpeg」**：没装/装了没重开终端 → 回第一节装好重开。
- **报错「没读到 key / 缺 key」**：`_work/.secret.env` 没建或没填对 → 回第五节。
- **火山报 403 / 欠费**：账户没余额或没买包 → 回第四节充值/买包。
- **报错「爆款点没填完 / 每镜都是静态」**：正常，是在逼你先想清「为什么火」，让 Codex 把换装/转身等动作写进去再跑。
- **某个镜头崩了（脸歪/多手指）**：让它只重跑那一个，不用整条重来。
