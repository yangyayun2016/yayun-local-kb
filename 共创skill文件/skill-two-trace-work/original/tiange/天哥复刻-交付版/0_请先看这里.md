# 天哥复刻 · 请先看这里

爆款短视频复刻引擎：扔一条爆款视频 → 自动复刻成「骨架神似、画面全新」的新片 + 上下屏对比片。
在 **Codex** 里用，对它说人话即可。

## 该看哪个文件
1. **完全不懂技术** → 先看 **`新手必读-大白话.md`**（三句话上手）。
2. **配两个 API（注册/充值/拿 key/填 key）** → 看 **`安装与API配置指南.md`**（火山方舟稍复杂，照着一步步来）。
3. 想看效果 → **`样片演示/`** 文件夹里有成片样片 + 一段 Codex 操作速看（30秒）。
4. `SKILL.md` / `AGENTS.md` / `tiange_fuke.md` / `GOAL.md` 是给 Codex 读的引擎说明，你不用专门看。

## 最快路径（三步）
1. 装好 `ffmpeg` + `pip install -r requirements.txt`（见新手必读）。
2. 把 `_work/.secret.env.example` 复制成 `_work/.secret.env`，填上两个 API key（见 API 指南）。
3. 在 Codex 里把本文件夹丢进去，说：「按 AGENTS.md 复刻这个视频：<视频文件名>，跑完给我上下屏对比片。」

## 样片说明（`样片演示/`）
- `样片1-产品类-原片vs复刻-并排.mp4`：产品展示型复刻（左原片 / 右复刻）。
- `样片2-人物穿搭-上下屏对比.mp4`：人物穿搭型复刻（上复刻 / 下原片）。
- `样片3-换装-原片vs复刻-并排.mp4`：换装型复刻（并排对比）。
- `演示-Codex操作速看版-30s.mp4`：在 Codex 里一句话复刻的全过程速看。
