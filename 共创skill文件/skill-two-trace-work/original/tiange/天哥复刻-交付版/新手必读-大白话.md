# 爆款复刻 · 新手必读（大白话版）

你不用懂代码。你只要会三件事：**扔视频 → 说一句话 → 等出片**。下面照着做就行。

---

## 这玩意儿是干嘛的？

你看到一条爆款短视频，想做一条"长得很像、但东西全换成你自己的"。
这个工具就帮你：把原片**拆开看懂它为什么火** → **照着骨架重做一条新的** → 还给你一条
**上下对比片**（上面是你的新片，下面是原片），一眼看出像不像。

> 它不是把原片"抄一遍"，是**照着套路重拍一条**。东西、人、颜色都是新的，节奏和爆点跟原片一样。

---

## 你要准备的（只做一次）

**1. 装 ffmpeg（拆视频/拼视频必须，免费）**
没装的话，第一步就会报一句英文 `FileNotFoundError`。装法：
- Windows：打开 PowerShell，敲 `winget install Gyan.FFmpeg`，**装完把终端关了重开**。
- Mac：`brew install ffmpeg`　Linux：`sudo apt install ffmpeg`
- 装没装好，敲 `ffmpeg -version` 能出一堆字就是好了。（工具跑之前也会自动帮你检查、缺了会提示。）

**2. 装一个 Python 小依赖**：在本文件夹敲 `pip install -r requirements.txt`（就一个包，几秒）。

**3. 申请并填两个 API key（充值后才能生成视频）**。本工具用两条后端：
- **APIMart**：跑「有人脸」的镜头（脸更稳）。
- **火山方舟**：跑「没人脸」的镜头（产品/场景），用便宜的 Mini。
两家怎么注册、怎么充值、怎么拿 key、怎么填——**完整图文流程见 `安装与API配置指南.md`**（火山注册稍复杂，照着一步步来）。
拿到 key 后：把 `_work/.secret.env.example` 复制成 `_work/.secret.env`，填上：
```
APIMART_TOKEN=[已移除]
ARK_API_KEY=[已移除]
```
- 🔒 这个文件只在你电脑里，不上传、不进代码。
- 只填一条也能跑，但只能做对应那类镜（缺哪条，工具会提示你去填）。

**4. 填完先验一下火山 Mini 能不能用**（只花几毛钱）：让 agent 跑 `python -m pipeline.verify_mini`。
出现 ✅ 就说明配好了；出现 ❌ 会告诉你怎么改。

**没充值也能先打磨**：不生成视频，前面"拆解、看帧、写分镜"都不花钱，可以先把流程跑顺。

---

## 怎么用（就一句话）

把整个 `爆款复刻` 文件夹丢进 Codex / Claude，然后对它说：

> **"按 AGENTS.md 复刻这个视频：`<把视频文件名贴这里>`，跑完给我上下屏对比片。"**

剩下的它自己干。它会：
1. 拆开原片，**先想清楚"这视频为什么火"**（比如：换装 + 转身 + 人跟着衣服一起转）。
2. 把每个镜头重新设计成你的新内容。
3. 生成画面、拼成片、自动做好上下对比片。

成片在 `_work/final/` 文件夹里。

---

## 关于钱（花多少）

- 按用量（token）扣费，**不是按条**。一条 13 秒竖屏片，通常**几块到十几块钱**。
- 省钱已经替你做好了：
  - **没人脸的镜头**（产品、清单、空镜）自动用最便宜的 **Mini**。
  - **有人脸的镜头**用稳一点的 **Fast**。
  - 默认出 **480p**（够发，便宜又快）。想要高清再说。
- Mini 很便宜（大概"1 亿 token ≈ 1400 元"这个量级），但**它对人脸不行**（脸容易崩/被过滤）。
  所以有人出镜的片子，人脸那几镜会自动走 Fast。

## 最容易踩的坑（一句话记住）

**换装、转身、人跟着衣服转——这些"动作"才是爆点，不能做成"站着不动展示一遍"。**

工具已经帮你盯着这条了：如果它发现原片爆点是"换装/转身"，但分镜写成了静态展示，
**会直接报错拦下来**，逼着把"转身换装"的动作写进去再生成。所以你不用怕它偷懒做成静态清单。

---

## 哪些视频现在能复刻、哪些先别（很重要，别白烧钱）

**现在做得好的**（画面驱动、单主体）：换装/转场、产品多角度展示、前后反差、宠物萌、慢节奏 Vlog 片段。
**现在做不好、先别扔进去**：
- **口播/讲解**（爆点在"说的话"上）——会做成对不上嘴的画面。
- **卡点踩拍/高密度快剪**（爆点在踩节奏）——节奏很难 1:1。
- **3 人以上互动 / 复杂剧情**——多个人物跨镜容易乱、对不上。
若你的片属于"先别"这几类，要么换一条画面型爆款，要么做好"只能像个七八分"的预期。

## 出问题了怎么办

- **报错"没读到 API key"**：`_work/.secret.env` 没建或 key 没填对。按上面"准备第3步"检查。
- **报错"没找到 ffmpeg"**：没装/装了没重开终端。按"准备第1步"装，然后**重开终端**再跑。
- **报错"爆款点没填完 / 每镜都是静态丢了爆点"**：正常，这是在逼你先想清"为什么火"。让 agent 看完原片，把爆点和转身/换装动作写进去再跑。（真就是静态片，让 agent 在 storyboard 顶部加一行 `"confirm_static": true` 放行。）
- **报错"storyboard.json 格式坏了"**：八成是手改时少了逗号/引号。让 agent 帮你修一下。
- **生成很慢 / 一直在重试**：排队是常态，它会自动等、自动重试。可以**让 agent 先只跑第一个镜头**确认没问题，再让它跑全部——你只管对 agent 说人话，不用自己敲命令。
- **某个镜头崩了**（脸歪、多手指）：让 agent 只重跑那一个，不用整条重来。

## 🚨 发之前必看的 3 条红线（保命用）

1. **真人样貌/换脸的片，发国内平台要打"AI 生成"标识**。让 agent 把 `_work/storyboard.json` 顶部 `ai_label` 设成 `true`，出片会自动叠上"AI生成"角标。
2. **换脸只能用你自己的脸、或拿到书面授权的脸**。别拿明星/网红/陌生人的脸——肖像权 + 封号风险。本工具默认生成的是"虚构人物"，是安全的。
3. **别原样保留原片的人脸、商标、字幕、背景音乐**。复刻是"照着套路重拍"，不是搬运；东西要换成你自己的。
