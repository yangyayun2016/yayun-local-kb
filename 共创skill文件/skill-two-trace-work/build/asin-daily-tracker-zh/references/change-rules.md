# 异动规则、动作标记与深挖入口

## 日常异动阈值

只报告达到阈值的变化，其余写“其他指标无明显变化”。

- BSR：大类排名变化 >= 10%，或小类排名变化 >= 3 名。
- 价格：变化 >= 0.5 USD 或 >= 5%。
- 评分数：单日新增 >= 20，或出现下降。
- 评分：变化 >= 0.1。
- Buy Box：卖家变化，尤其自有 Buy Box 易主。
- Amazon's Choice / Best Seller：得到或失去，仅在用户开启或字段可用时报告。

BSR 数字越小越好。报告箭头按“名次升降”：

- BSR 数字变小 = 排名上升 = ↑。
- BSR 数字变大 = 排名下降 = ↓。

## 动作型变化

以下变化自动写入 `actions_log.json`：

- 调价：价格变化达到阈值。
- coupon 上/撤。
- 变体增减。
- Buy Box 易主。
- Amazon's Choice / Best Seller 标得失。
- 评论数异常：单日新增 >= 50 或出现下降。

不写入动作日志的连续波动：

- BSR 常规波动。
- 评分常规小幅波动。
- 评论数正常小幅增加。

动作记录只说明“数据上看到的动作”，不是后台操作记录。

## 7 天动作挂载

报告时读取 `actions_log.json` 中最近 `action_window_days` 天的动作，挂在对应产品行下。

格式：

```text
📌 A简称 · 近期动作：3 天前调价 $28.99→$26.99；昨天上 5% coupon。
```

没有动作的产品不写“无动作”，避免占空间。

## 组内 AI 分析

把数值变化和动作放在一起读，但不要硬下因果。

推荐措辞：

- “时间上吻合”
- “可能相关”
- “对得上”
- “信息不足，建议看一眼”

避免措辞：

- “一定是因为”
- “竞品刷单”
- “必然导致”

评论数异常要写成“关注是否买评/站外/促销”，不要直接定性。

## 竞品深挖升级

满足任一条件时，提示用户可转入 competitor-monitor 深挖：

- 竞品大类 BSR 单日变化 >= 25%。
- 竞品降价 >= 10%，或新上/撤 coupon。
- 竞品评分数单日新增 >= 50。
- 竞品 Buy Box 易主或跟卖风险明显。

报告末尾固定保留深挖入口，但不自动执行：

```text
🔗 下一步：今日无竞品达到深挖阈值。想主动查某个竞品 listing 改动，回复“深挖 [竞品简称]”。
```

如果有竞品达到阈值，最多点名 1-2 个最值得深挖的竞品。
