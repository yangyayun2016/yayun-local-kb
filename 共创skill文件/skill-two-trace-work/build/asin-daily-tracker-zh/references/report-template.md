# 报告模板

## 默认结构

```text
### 今日重点
1-3 条最重要变化。没有就写“今日无重大异动”。

### 竞争组：{group_name}
| 产品 | 角色 | BSR(大类) | 评分 | 评分数 | 价格 | Buy Box |
|---|---|---|---|---|---|---|
| A简称 | 自有 | 1,240 ↑8% 🟢 | 4.6 — | 312 (+5) | $26.99 — | 你 |
| B简称 | 竞品 | 980 ↓3% 🔴 | 4.5 — | 890 (+24) 🔴 | $24.79 ↓$1.20 🔴 | 第三方 |

📌 A简称 · 近期动作：3 天前调价 $28.99→$26.99。

组内 AI 分析：
...

### 待确认配对
...

### 配额提醒
...

### 下一步
🔗 ...
```

## 符号约定

- 🟢 = 对我有利。
- 🔴 = 对我不利或需警觉。
- `—` = 已检查，无明显变化，不是缺数据。

只在达到阈值的变化项上加符号，不要满屏箭头。

## 今日重点写法

好的写法：

```text
🔴 竞品B今日降价 $1.20，且 BSR 排名上升 31%，建议观察是否配合 coupon 抢量。
🟢 自有A排名上升 8%，时间上和 3 天前降价动作吻合，可继续观察 2 天。
```

差的写法：

```text
竞品很危险。
自有表现不错。
```

## 配额提醒

仅模式 A 且接近上限时出现。

```text
配额提醒：本月本地估算已用 860/1000 次。该数字不包含你在其他地方的卖家精灵调用，建议去后台核对真实余额。
```

## 深挖入口

有竞品达到升级阈值：

```text
🔗 下一步：竞品B本次异动较大（BSR 上升31% + 新上 coupon），建议深挖它改了什么。回复“深挖 竞品B”。
```

无竞品达到升级阈值：

```text
🔗 下一步：今日无竞品达到深挖阈值。想主动查某个竞品 listing 改动，回复“深挖 [竞品简称]”或“监控竞品变动”。
```

## 语气

冷静、短句、少渲染。数据不足时直接说不足，不猜。
