# 关键词分类与动作规则

## 分类定义

### 精准词

产品品类、材质、核心功能、人群高度匹配，买家意图清晰。

推荐动作：

- 标题埋词：只给最核心、最贴合产品定位的 1-3 个词。
- 精准广告：新品前 2 周优先测试。
- 五点埋词：用于补充核心卖点和场景。

### 高转化词

搜索量可能不大，但意图强、价格带/材质/人群匹配，Top3 垄断不严重，适合验证转化。

推荐动作：

- 五点埋词 + 精准广告。
- 预算优先级高于泛大词。
- 如果自然排名开始上升，进入稳定防守。

### 扩展词

与产品相关，但意图较宽，或者是场景词、人群词、长尾变体词。可作为补充，不做第一阶段主攻。

推荐动作：

- 小预算测试。
- 五点或后台搜索词补充。
- 不要占用核心预算；转化和自然位有信号后再加。

### 相斥词

结构、功能、材质、价格带、适用场景与产品不匹配，容易带来低 CTR/CVR 或错误人群。

推荐动作：

- 否词或排除。
- 不埋入标题和五点。
- 除非产品真实具备该属性，否则不测试。

### 暂不主攻词

相关但竞争太强、需求断续、历史数据不稳定、搜索量太小或沉淀效率低。不是永久否定，而是新品第一阶段不优先。

推荐动作：

- 暂缓广告、仅观察、小预算验证。
- 等精准词稳定后再打开。

## 判断维度

每个关键词至少从以下 4 个维度提炼判断依据：

1. 需求：搜索量、趋势、季节位置、需求是否增长或萎缩。
2. 竞争：Top3 点击/转化集中度、头部垄断、竞争可进入性。
3. 相关性：是否匹配品类、材质、功能、场景、人群、价格带。
4. 沉淀可能性：是否容易带来自然排名、自然流量或自然订单占比提升。

## SIF 工具建议

- `market_get_keyword_history`：看精确词搜索量、ABA 排名、Top3 点击/转化集中度。
- `market_get_keyword_demand`：判断需求生命周期、季节性和当前行动时机。
- `market_get_keyword_root_trend`：判断大词/词根是否应拆成长尾。
- `market_get_keyword_competition`：判断竞争结构、可进入性、沉淀可能性。
- `market_get_asin_keyword_signals`：有 ASIN 时看关键词贡献、自然排名稳定性和付费依赖。
- `ads_get_asin_ad_structure`、`ads_get_asin_ad_traffic_trend`：有 ASIN 且需要结合广告结构时使用。

## 排序规则

第一阶段排序不是按搜索量，而是按以下顺序：

1. 精准词：高度相关，能承接核心转化和自然排名。
2. 高转化词：量可能中小，但买家意图强，适合快速验证。
3. 扩展词：可测试但不占核心预算。
4. 暂不主攻词：相关但现在不适合硬冲。
5. 相斥词：排除或否词。

## 动作映射

| 信号组合 | 关键词类型 | 推荐动作 |
|---|---|---|
| 高相关 + 需求稳定/增长 + 竞争不垄断 + 沉淀可能强 | 精准词 | 标题埋词 + 精准广告 |
| 高相关 + 强购买意图 + 搜索量中等 + 可进入 | 高转化词 | 五点埋词 + 精准广告 |
| 相关但意图宽或需求分散 | 扩展词 | 五点埋词 + 小预算测试 |
| 搜索量大但泛、竞争强、相关性不够窄 | 暂不主攻词 | 暂缓广告或仅观察 |
| 功能/材质/结构/人群不匹配 | 相斥词 | 否词或排除 |
| 数据断续、样本太小、季节低谷 | 暂不主攻词 | 小预算验证或暂缓 |

## 反模式

- 不要把大词默认排第一。
- 不要因为搜索量高就建议大预算。
- 不要把不匹配词写进标题。
- 不要把竞品品牌词、弱相关泛词、功能不匹配词混进精准广告。
- 不要只输出“建议测试”，必须说明测试方式和优先级。
