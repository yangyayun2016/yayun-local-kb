# 新品作战表输出模板

最终报告使用中文 Markdown，按以下顺序输出。不要删除章节；无数据时写“暂无可确认信号”，并说明缺口。

## 开头判断

```markdown
基于 SIF 的最新周度/月度数据，我建议第一阶段按“相关性 + 能否沉淀自然排名”排序，不按搜索量排序。
```

如用户提供了产品信息，先用一行概括：

```markdown
产品口径：{品类}，定位 {定位}，价格带 {价格带}，核心卖点 {核心卖点}，第一阶段目标是验证高相关流量能否稳定转化并带动自然排名。
```

## 1. 新品前期识别重点

```markdown
### 新品前期真正要看的是：

- 广告有没有带来自然排名上升？
- 自然流量有没有增长？
- 自然订单占比有没有开始出现？

如果广告花费上去了，自然流量没有变化，那说明这批流量可能只是买来的；如果某些词广告订单不多，但自然排名持续上升，这些词反而要重点观察。

新品推广的效率，最后不是看广告调得多频繁，而是看能不能尽快识别：

| 要识别的流量 | 运营动作 |
|---|---|
| 值得继续买的流量 | 保持预算，观察自然位 |
| 只是在消耗预算的流量 | 降 BID、否词或者暂停 |
| 已经开始沉淀自然位的流量 | 继续放量或稳定防守 |
| 需要延后测试的流量 | 先不抢，等核心词稳定后再打开 |
```

## 2. 第一阶段关键词作战表

表格列固定为截图口径：

```markdown
### 第一阶段关键词作战表

| 关键词 | 关键词类型 | 推荐动作 | 判断依据：需求、竞争、相关性、沉淀可能性 | 前 2 周优先级 |
|---|---|---|---|---|
| {keyword} | {精准词/高转化词/扩展词/相斥词/暂不主攻词} | {标题埋词/五点埋词/精准广告/小预算测试/否词/暂缓广告/仅观察} | {需求信号；竞争信号；相关性判断；自然排名沉淀可能性} | {高/中/低/排除} |
```

写法要求：

- 关键词不要只按搜索量从高到低排列。
- 先排“精准词”和“高转化词”，再排可测试扩展词，最后排相斥词或暂不主攻词。
- 判断依据必须写成可执行理由，例如“周搜索量中等但长期平稳；Top3 点击集中度不高；材质和人群完全匹配；适合沉淀自然排名”。
- 如果是相斥词，推荐动作写“否词”或“排除”，并说明不匹配点。

## 3. 前 2 周执行顺序

```markdown
### 前 2 周执行顺序

前 2 周执行顺序：先打 {第一批精准词/高转化词}；再小预算测试 {第二批扩展词/场景词}；{暂不主攻词} 先观察或延后；{相斥词} 在产品没有对应功能/卖点时直接否掉。
```

如需要更细，继续给周计划：

```markdown
| 周期 | 动作 | 关键词/结构 | 验证指标 |
|---|---|---|---|
| 第 1 周 | 标题/五点埋词 + 精准广告 | {keywords} | 点击是否稳定、转化是否出现、自然排名是否进入可观察区间 |
| 第 2 周 | 保留正向词 + 小预算扩展 | {keywords} | 自然排名是否上升、自然流量是否增长、广告是否只买短期曝光 |
| 暂缓 | 否词/观察 | {keywords} | 避免预算被弱相关或不匹配流量消耗 |
```
